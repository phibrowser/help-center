# Gérer les onglets et les favoris

Phi vous permet de sélectionner plusieurs éléments et de les traiter comme un seul lot. Vous pouvez faire un clic droit sur la sélection pour des actions groupées, ou la faire glisser pour réorganiser onglets classiques, Split Views, favoris et dossiers de favoris sans déplacer chaque élément séparément.

## Sélectionner plusieurs éléments

Utilisez l'une ou l'autre touche de modification pour construire une sélection :

- **Commande + clic (⌘ + clic)** sur un onglet ou un favori ajoute cet élément à la sélection ou l'en retire. L'onglet actif est inclus automatiquement, donc Commande + clic sur un autre onglet sélectionne les deux.
- **Maj + clic** sur un autre élément sélectionne la plage continue entre celui-ci et votre point de départ.

Dans la barre latérale, une plage peut inclure les onglets visibles, les favoris, les dossiers de favoris et le contenu des groupes ou dossiers dépliés. Les éléments masqués dans un groupe ou un dossier replié ne sont pas inclus. Une Split View est traitée comme un seul élément visible, donc ses deux volets restent ensemble.

En disposition Confortable, les mêmes gestes Commande + clic et Maj + clic fonctionnent pour les onglets de la bande d'onglets horizontale. La multisélection de favoris est disponible depuis la barre latérale dans les dispositions Équilibré et Performance.

## Travailler avec la sélection

Faites un clic droit sur n'importe quel élément en surbrillance pour ouvrir le menu groupé. Phi adapte les actions disponibles à ce que vous avez sélectionné, donc certaines actions n'apparaissent que pour des onglets, des favoris ou un mélange compatible.

| Action                                             | Effet                                                                                           |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| **Dupliquer les onglets**                          | Ouvre des copies des pages sélectionnées dans l'Espace actuel.                                  |
| **Copier les liens**                               | Copie les URL des pages sélectionnées sous forme de liste.                                      |
| **Ouvrir en Split View**                           | Place exactement deux éléments sélectionnés compatibles côte à côte.                            |
| **Ajouter aux favoris / Ajouter à un dossier**     | Enregistre les onglets sélectionnés, ou range les favoris sélectionnés à l'emplacement choisi.  |
| **Ajouter les onglets à un nouveau groupe**        | Crée un Groupe d'onglets à partir des éléments sélectionnés compatibles.                        |
| **Déplacer les onglets vers un groupe**            | Déplace les éléments sélectionnés compatibles vers un Groupe d'onglets existant.                |
| **Déplacer vers un Espace**                        | Transfère la sélection vers un autre Espace et la retire de l'Espace actuel.                    |
| **Cloner vers un Espace**                          | Crée une copie dans un autre Espace en laissant la sélection d'origine là où elle est.          |
| **Fermer les onglets / Fermer les autres onglets** | Ferme les onglets classiques sélectionnés, ou tous les onglets classiques hors de la sélection. |
| **Supprimer les favoris/dossiers/éléments**        | Supprime définitivement les éléments enregistrés sélectionnés, après confirmation.              |

## Faire glisser plusieurs éléments pour les organiser

Après avoir fait une sélection, faites glisser n'importe quel élément en surbrillance pour déplacer toute la sélection. L'aperçu de glissement montre combien d'éléments visibles se déplacent. Si vous commencez à faire glisser un élément qui n'est pas sélectionné, Phi abandonne le lot et ne déplace que cet élément.

L'endroit où vous déposez la sélection détermine ce qui se passe :

- **Dans la liste des onglets :** réordonnez les onglets sélectionnés ensemble, ou déposez-les dans un Groupe d'onglets.
- **Dans la zone des favoris :** réordonnez les favoris et dossiers sélectionnés, ou déposez-les sur un dossier pour les y ranger.
- **Des onglets vers les favoris :** déposez les onglets sélectionnés dans la zone des favoris ou sur un dossier de favoris pour les y enregistrer.
- **Des favoris vers les onglets :** déposez les pages de favoris sélectionnées dans la liste des onglets ou un Groupe d'onglets pour les ouvrir et les organiser comme onglets.
- **Avec une sélection mixte :** onglets et favoris peuvent se déplacer ensemble quand la destination prend en charge chaque élément sélectionné.

Les Split Views restent entières pendant un glissement. Une sélection contenant un dossier de favoris reste dans la zone des favoris ; plutôt que de scinder la sélection, Phi refuse les destinations de la liste des onglets et des Groupes d'onglets qui ne peuvent pas préserver le dossier.

## Déplacer ou cloner des éléments vers un autre Espace

Utilisez **Déplacer vers un Espace** quand les éléments sélectionnés doivent quitter l'Espace actuel. Utilisez **Cloner vers un Espace** quand vous voulez les mêmes onglets ou favoris dans les deux Espaces.

Les deux actions acceptent un mélange compatible d'onglets classiques, de Split Views, de favoris et de dossiers de favoris. Phi garde les volets d'une Split View ensemble et préserve l'organisation des favoris lors du transfert de la sélection. Choisissez la destination dans le sous-menu de l'action.

L'Espace actuel et les Espaces de navigation privée ne sont pas proposés comme destinations. Les actions de transfert entre Espaces sont aussi indisponibles pendant que vous naviguez en navigation privée.

## Quitter la multisélection

Appuyez sur **Échap**, ou cliquez normalement sur un élément pour y passer et quitter la multisélection. Dans la barre latérale, cliquer sur une zone vide efface aussi la sélection. La plupart des actions groupées l'effacent automatiquement une fois terminées.

Pour en savoir plus sur l'endroit où vivent les éléments, voir [Espaces et Profils](/fr/spaces/). Pour comprendre comment les favoris s'ouvrent sur place et comment se comportent les onglets épinglés, voir [Favoris et onglets épinglés](/fr/bookmarks/).
