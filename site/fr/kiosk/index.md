# Kiosk

Un Kiosk est une fenêtre légère pour une seule page. Il vous permet d'ouvrir un lien à l'écart de vos onglets et de votre barre latérale, de le parcourir, puis de décider s'il a sa place dans l'un de vos Espaces.

Utilisez un Kiosk pour les liens qui peuvent être utiles mais n'ont pas encore mérité de place permanente. Un article venu de Mail, un document venu de Messages ou un lien à vérifier sans interrompre votre travail en cours peuvent tous rester dans leur propre fenêtre. Fermez le Kiosk quand vous avez terminé, ou déplacez la page dans un Espace si vous voulez la garder.

Un Kiosk est temporaire et ne revient pas quand Phi redémarre.

## Ouvrir une page dans Kiosk

Il existe trois façons courantes d'en ouvrir un :

| Où se trouve le lien                            | Que faire                                                                          |
| ----------------------------------------------- | ---------------------------------------------------------------------------------- |
| Sur une page dans Phi                           | Faites un clic droit sur le lien et choisissez **Ouvrir dans Kiosk**.              |
| Sur une page dans Phi, avec le raccourci activé | Maintenez Commande et Option, puis cliquez sur le lien.                            |
| Dans une autre app                              | Activez **Ouvrir les liens externes dans Kiosk** sous **Paramètres → Navigation**. |

Un Kiosk ouvert depuis une page dans Phi utilise le Profil de cette page. Un lien ouvert depuis une autre app utilise votre dernier Profil utilisé.

## Ouvrir les liens correspondants avec les Règles d'URL

Utilisez une Règle d'URL quand les liens vers un site doivent toujours s'ouvrir dans Kiosk.

1. Ouvrez **Paramètres → Navigation**.
2. Sous **Règles d'URL**, cliquez sur **Gérer les règles d'URL…**.
3. Ajoutez une règle pour le domaine ou l'URL à reconnaître.
4. Choisissez **Kiosk** comme destination.

Les liens qui correspondent à la règle s'ouvrent désormais dans une fenêtre Kiosk. Cela convient bien aux sites que vous voulez garder en dehors de vos Espaces, à moins de décider plus tard d'y déplacer la page.

## Changer de Profil

Le Profil actuel apparaît à gauche de la barre d'adresse.

1. Cliquez sur le nom du Profil.
2. Choisissez un autre Profil dans le menu.

Phi rouvre la page actuelle avec le Profil choisi. Le compte affiché sur le site peut changer, car chaque Profil a ses propres cookies et ses propres sessions connectées. Tout ce que vous n'avez pas encore envoyé sur la page, comme le texte d'un formulaire, peut être perdu au rechargement.

## Ouvrir la page dans un Espace

La commande **Ouvrir dans [Espace]** se trouve à droite de la barre d'outils du Kiosk.

- Cliquez sur la partie principale de la commande pour déplacer la page dans le dernier Espace utilisé dans une fenêtre Phi normale.
- Cliquez sur la flèche et choisissez un Espace pour déplacer la page ailleurs.
- Avec le raccourci par défaut, appuyez sur **⌘O** pour utiliser l'action principale et déplacer la page dans votre Espace actuel.

La page devient un onglet normal dans l'Espace sélectionné. La déplacer vers un autre Espace peut recharger la page ; envoyez ou enregistrez donc votre travail d'abord.

## Choisir quand Kiosk s'ouvre

Ouvrez **Paramètres → Navigation**, puis repérez **Kiosk**.

- **Ouvrir les liens externes dans Kiosk** envoie les liens d'apps comme Mail et Messages vers leur propre fenêtre Kiosk. Désactivez-le pour ouvrir ces liens dans une fenêtre Phi normale.
- **Ouvrir Kiosk en cliquant sur un lien avec ⌘⌥ enfoncées** vous laisse maintenir Commande et Option en cliquant sur un lien dans Phi. Désactivez-le si vous ne voulez pas que ce geste ouvre un Kiosk.

Ces réglages ne retirent pas l'élément **Ouvrir dans Kiosk** du menu contextuel d'un lien.
