# Blocage de contenu

Phi est basé sur Chromium, avec le moteur open source de filtrage de contenu de Brave. Vous pouvez bloquer séparément les publicités, les traqueurs et les bannières de cookies.

## Ce que Phi peut bloquer

| Réglage                              | Effet                                                                                                        |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| **Bloquer les publicités**           | Bloque les publicités et les requêtes publicitaires correspondantes.                                         |
| **Bloquer les traqueurs**            | Bloque les scripts de suivi, les balises et les requêtes d'analyse correspondants.                           |
| **Bloquer les bannières de cookies** | Masque les avis sur les cookies correspondants. Phi ne choisit pas une option de consentement à votre place. |

Les trois interrupteurs sont désactivés au départ. Ils sont propres à un [profil](/fr/spaces/), qui peut donc avoir ses propres réglages et listes de filtres.

Le blocage de contenu s'appuie sur des règles issues de listes de filtres. Une liste peut cibler les publicités ou les traqueurs courants, les avis sur les cookies, les sites d'une région ou vos règles personnalisées. Phi ne bloque pas toutes les publicités ni tous les traqueurs. Certaines règles peuvent aussi modifier le fonctionnement de certains sites.

## Activer le blocage de contenu

1. Ouvrez **Paramètres → Profils**.
2. Sélectionnez un profil et repérez **Blocage de contenu**.
3. Activez les catégories souhaitées.
4. Si Phi vous demande de choisir des listes de filtres, sélectionnez celles que vous voulez utiliser, puis cliquez sur **Terminé** pour télécharger les listes sélectionnées qui ne sont pas encore sur votre Mac.

Vous pouvez ouvrir le sélecteur de règles à côté d'une catégorie pour modifier ses listes. Un téléchargement commence uniquement après votre choix d'une action de téléchargement. **Mettre à jour les listes téléchargées** récupère la dernière version des listes déjà présentes sur votre Mac.

Dans le sélecteur, cliquez sur **Ajouter un filtre…** pour ajouter une liste par URL ou coller directement des règles. Une liste personnalisée s'applique aux trois catégories de ce profil.

Les listes de filtres téléchargées peuvent être partagées entre plusieurs profils. Chaque profil conserve ses sélections, ses listes personnalisées et ses exceptions de site.

## Autoriser le contenu sur un site

Ouvrez le menu de la barre d'adresse et choisissez **Blocage de contenu sur ce site** pour désactiver ou réactiver le blocage sur le site actuel dans le profil actif. Cela ne modifie que l'exception de ce profil pour le site. Les catégories restent actives sur les autres sites.

Cette option n'est pas disponible dans les fenêtres de navigation privée.

## Si un site ne fonctionne pas correctement

Certains sites ont besoin d'une ressource bloquée par une liste de filtres. Choisissez **Blocage de contenu sur ce site** dans le menu de la barre d'adresse pour créer une exception, puis rechargez la page. Vous pouvez aussi désactiver une catégorie ou modifier ses listes dans **Paramètres → Profils**.

Les listes de filtres ne repèrent pas toutes les publicités, tous les traqueurs ni tous les avis sur les cookies. Le blocage des bannières masque les éléments correspondants. Il n'accepte pas les cookies et ne ferme pas une demande de consentement à votre place.
