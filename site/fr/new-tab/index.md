# Nouvel onglet et widgets

Phi remplace le nouvel onglet standard par une page d'accueil personnalisée. Chaque nouvel onglet vous offre un message d'accueil, une zone unique pour rechercher ou poser une question, et une grille de widgets que vous organisez vous-même. Il suit automatiquement votre [thème et votre choix clair/sombre](/fr/themes/).

## Votre nouvel onglet

- **Un message d'accueil**, une bienvenue personnalisée qui évolue avec le temps, tirée de ce que Phi sait de vous. Vous pouvez le partager ou en discuter avec votre assistant.
- **Une zone pour rechercher ou demander** : tapez pour rechercher sur le web, poser une question à votre assistant ou aller droit à une URL, le tout au même endroit. Vous pouvez [joindre un onglet](/fr/ai/#chat-with-tabs) ou un fichier et amener des Skills dans la conversation.
- **Le menu ⋮** : en haut à droite, il ouvre **Widgets** et la bibliothèque de [Skills](/fr/skills/), et contient **Rétablir les rappels masqués**.

Parce que la zone de recherche est branchée sur votre assistant, le nouvel onglet est souvent l'endroit le plus rapide pour lancer quelque chose, recherche, question ou tâche, sans ouvrir d'abord une conversation à part. Voir [Découvrir votre assistant](/fr/ai/) pour ce qu'il sait faire.

## Les widgets

Les widgets sont de petites cartes que vous épinglez au nouvel onglet : une horloge, la météo, vos sites les plus visités, un minuteur de concentration, et plus encore. Vous choisissez lesquels apparaissent et où ils se placent.

### Ouvrir le panneau Widgets

Tout ce qui concerne les widgets se passe dans le panneau **Widgets**. Pour l'ouvrir, choisissez **Widgets** dans le menu ⋮ en haut à droite, ou faites défiler la page jusqu'en bas et cliquez sur **Personnalisé**.

La première fois que **Personnalisé** s'affiche à l'écran, un message le signale : **Créez vos propres widgets ici**. Dès que vous cliquez sur **Ignorer** ou que vous ouvrez le panneau, il ne réapparaît plus.

### Widgets suggérés

Phi ne propose pas de catalogue fixe à parcourir. Le panneau vous offre plutôt quelques suggestions choisies d'après ce que Phi se rappelle de vous, chacune avec un titre pensé pour vous. Elles sont tirées d'un ensemble de types de widgets intégrés, par exemple une horloge, la météo, un minuteur de concentration Pomodoro, un convertisseur de devises, vos sites les plus visités, les pages que vous avez lues dernièrement, un flux RSS, les étoiles et les forks d'un dépôt GitHub, et un rapport quotidien ou hebdomadaire de ce que vous avez fait.

Cliquez sur **Actualiser** sur une suggestion pour la remplacer par une autre.

### Ajouter et organiser les widgets

1. Cliquez sur **Installer** sur une suggestion. Elle rejoint aussitôt vos widgets dans le panneau.
2. Faites-la glisser sur la page pour l'épingler, ou choisissez **Ajouter à la page** dans son menu.

Tant que le panneau est ouvert, vous pouvez réorganiser la page : faites glisser un widget épinglé pour le déplacer, faites glisser son bord pour le redimensionner, ou faites-le glisser de nouveau sur le panneau pour le retirer de la page.

Le menu d'un widget épinglé propose :

- **Actualiser** : recharger ses données. Seuls les widgets qui chargent des données disposent de cette option.
- **Modifier** : décrire un changement pour que Phi réécrive le widget à votre place.
- **Supprimer** : retirer le widget de la page. Il reste dans le panneau, vous pouvez donc l'ajouter de nouveau plus tard.
- **TOUT supprimer** : retirer tous les widgets de la page, après confirmation.

Pour vous débarrasser définitivement d'un widget, choisissez **Supprimer** dans son menu à l'intérieur du panneau. Phi vous demande d'abord de confirmer.

Votre disposition est enregistrée dans ce navigateur, sur votre appareil : le nouvel onglet a la même allure à chaque ouverture. Elle n'est pas synchronisée avec vos autres appareils.

### Un widget suggéré sur un nouvel onglet vide

Si vous n'avez encore aucun widget à vous, Phi peut en épingler un pour vous, marqué **Suggéré**. Il s'appuie sur votre Mémoire, si bien qu'une installation toute récente peut ne pas en afficher avant un certain temps.

Un widget suggéré auquel vous ne touchez pas est remplacé le lendemain par un autre. Pour décider de son sort :

- **Conserver** : le widget devient le vôtre et la rotation quotidienne s'arrête. Le déplacer, le redimensionner ou le modifier revient aussi à le conserver.
- **✕** : retire ce widget. La carte affiche brièvement **Retrait en cours**, avec **Annuler** si vous changez d'avis. Une autre suggestion peut encore apparaître un jour suivant.
- **Ne plus suggérer** : proposé tant que la carte affiche **Retrait en cours**, désactive les widgets suggérés.

### Créer votre propre widget

Cliquez sur **+** (**Ajouter un widget**) dans le panneau et décrivez le widget que vous voulez. Phi le construit et vous montre le résultat avant que vous l'enregistriez. Si une version ne vous convient pas, générez-la de nouveau. Pour modifier un widget plus tard, choisissez **Modifier** dans son menu.

Les widgets sont générés par IA et peuvent parfois être inexacts.

### Des widgets qui vous connaissent

Les suggestions, ainsi que le contenu de certains widgets, sont personnalisés d'après ce que Phi se rappelle de vous, par exemple en faisant remonter les pages où vous revenez vraiment.

Tout cela repose sur la même mémoire « local d'abord » que le reste de Phi : ce dont les widgets se nourrissent reste sur votre appareil et sous votre contrôle. Quand un widget a besoin de l'IA, par exemple pour rédiger votre rapport quotidien ou hebdomadaire, créer l'image du jour, ou construire ou modifier un widget, le contenu nécessaire à cette étape est envoyé à un modèle, comme pour toute autre requête d'IA. Voir [Confidentialité et vos données](/fr/privacy/) pour savoir où il va et comment en garder davantage sur votre Mac.
