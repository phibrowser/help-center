# Consejos rápidos para Phi Browser

Esta página reúne gestos y atajos de Phi que no resultan tan evidentes desde la interfaz. Los atajos de teclado que se muestran aquí son los predeterminados. Puedes cambiarlos en **Configuración → Atajos**.

## Referencia de atajos

| Acción                                          | Atajo o gesto                                                                                  |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Crear una Vista dividida                        | Clic con Opción (⌥) en una pestaña, una pestaña fijada, un marcador o un enlace web compatible |
| Ver la vista previa de un enlace en un Peek     | Clic con Mayúsculas (⇧) en un enlace web                                                       |
| Cambiar entre las pestañas usadas recientemente | Control (⌃) + Tab                                                                              |
| Cambiar en orden inverso                        | Control (⌃) + Mayúsculas (⇧) + Tab                                                             |
| Copiar la URL de la página actual               | Comando (⌘) + Mayúsculas (⇧) + C                                                               |
| Buscar entre las pestañas abiertas              | Comando (⌘) + Mayúsculas (⇧) + A                                                               |
| Ir al Espacio anterior o siguiente              | Comando (⌘) + Opción (⌥) + ← o →                                                               |
| Abrir uno de los primeros nueve Espacios        | Control (⌃) + 1 a 9                                                                            |

## Crear una Vista dividida

- Mantén presionada la tecla Opción (⌥) y haz clic en otra pestaña, una pestaña dentro de un grupo, una pestaña fijada, un marcador o un enlace web compatible. Phi lo coloca junto a tu página actual.
- Arrastra una sola pestaña, una pestaña fijada o un marcador al lado izquierdo o derecho de la página actual. El lado que elijas decide dónde aparece.
- Suelta un elemento sobre un panel de una Vista dividida existente sin fijar para reemplazar ese panel.

## Volver a una URL guardada

Una pestaña fijada o un marcador puede alejarse de la URL que guardaste originalmente. Puedes volver sin perder la página que estás viendo.

- Haz doble clic en una pestaña fijada para devolverla a su URL guardada.
- Haz clic en el favicon de un marcador para devolverlo a su URL guardada.
- Mantén presionada la tecla Comando (⌘) con cualquiera de los dos gestos para conservar la página actual abierta como una pestaña aparte antes de restaurar la URL guardada.

## Usa la Vista general del grupo

Haz clic en el encabezado de un Grupo de pestañas para abrir la Vista general del grupo. Muestra una instantánea de cada página, y una Vista dividida aparece como una sola tarjeta combinada.

Desde la Vista general del grupo puedes cambiar a una página, cerrar una página, crear una pestaña nueva o cambiar el nombre y el color del grupo. Si usas la barra de direcciones mientras la Vista general del grupo está abierta, la pestaña nueva se une a ese grupo.

Arrastra un Grupo de pestañas completo al área de marcadores para convertirlo en una carpeta de marcadores. Phi conserva el orden de sus pestañas y disuelve el grupo, pero las pestañas abiertas siguen abiertas.

## Trabaja con varias pestañas y marcadores

- Haz clic con Comando (⌘) en pestañas normales y marcadores para seleccionarlos uno a uno.
- Haz clic con Mayúsculas (⇧) para seleccionar un rango.
- Las acciones disponibles pueden incluir crear un Grupo de pestañas, añadir elementos a una carpeta de marcadores, moverlos o clonarlos a otro Espacio, y cerrarlos.
- Arrastra cualquier elemento seleccionado para mover la selección completa. Los dos lados de una Vista dividida permanecen juntos.
- Presiona Esc para borrar la selección.

## Cambia, busca y copia

Control (⌃) + Tab sigue el orden de uso reciente, no el orden de las pestañas en la ventana.

- Presiónalo una vez para cambiar entre la pestaña actual y la anterior.
- Mantenlo presionado o presiónalo varias veces para mostrar hasta cinco pestañas usadas recientemente.
- Añade Mayúsculas (⇧) para recorrer la lista en orden inverso.
- Presiona Comando (⌘) + Mayúsculas (⇧) + A para buscar entre todas las pestañas abiertas.
- Presiona Comando (⌘) + Mayúsculas (⇧) + C para copiar la URL de la pestaña actual.

## Personaliza cada Espacio

Abre **Configuración → Espacios** y selecciona un Espacio.

- Elige un icono del conjunto integrado de Phi, o usa un emoji.
- Elige un color de tema y ajusta su saturación.

Cada Espacio conserva su propio icono y tema. Al cambiar de Espacio se aplica la apariencia que elegiste para ese Espacio sin cambiar la de los demás.

## Muévete entre Espacios

- Presiona Comando (⌘) + Opción (⌥) + ← o → para ir al Espacio anterior o siguiente.
- Presiona Control (⌃) + 1 a 9 para abrir directamente uno de los primeros nueve Espacios.

## Dirige los sitios con Reglas de URL

Abre **Espacios → Reglas de URL…** desde la barra de menús, o abre **Configuración → Navegación** y haz clic en **Administrar reglas de URL…**. Una regla puede coincidir por **Sufijo de dominio**, **Dominio**, **El dominio contiene** o **URL**.

Envía una coincidencia a un Espacio normal, a Incógnito o a Kiosk. Elige **Preguntar cada vez** si quieres que Phi pregunte antes de mover la página. Cuando varias reglas coinciden, gana la más específica.

::: tip Dirigir a un Espacio normal no aísla las cookies
Dirigir un sitio a un Espacio normal no aísla sus cookies ni su sesión iniciada. Asigna los Espacios de destino a Perfiles distintos cuando quieras esa separación.
:::

## Mantén el video a la vista con imagen en imagen

Phi puede sacar el video en reproducción a una ventana flotante cuando cambias de pestaña o de Espacio. Elige el comportamiento en **Configuración → General → Imagen en imagen automática**.

| Modo                   | Comportamiento                                                                                                  |
| ---------------------- | --------------------------------------------------------------------------------------------------------------- |
| **Desactivado**        | Nunca abre la imagen en imagen automáticamente. La imagen en imagen manual sigue funcionando.                   |
| **Normal**             | Saca el video en reproducción cuando cambias de pestaña o de Espacio.                                           |
| **Anclar en el borde** | Saca el video en reproducción y luego ancla la ventana en el borde de la pantalla hasta que hagas clic en ella. |

Mueve o redimensiona una ventana de imagen en imagen y Phi recordará su posición y tamaño la próxima vez que ese sitio abra la imagen en imagen. Esto se guarda por sitio en un Perfil normal. Los Espacios de incógnito no lo conservan. Si la pantalla guardada ya no está conectada, Phi usa la ubicación predeterminada.

Para anclar tú mismo una ventana de imagen en imagen abierta, mueve el puntero sobre ella y haz clic en la flecha hacia abajo, con la etiqueta **Anclar en el borde de la pantalla**. Phi arrima la ventana al borde más cercano de la pantalla y deja visible una lengüeta. Haz clic en la lengüeta para traer la ventana de vuelta. Este control funciona incluso cuando la imagen en imagen automática está en **Desactivado**.

## Pregunta al asistente sobre tu trabajo actual

- Selecciona un texto, haz clic derecho y elige **Preguntar a [tu asistente] sobre…** para llevar la selección a una conversación.
- Abrir el asistente adjunta la pestaña actual de forma predeterminada. Si esa pestaña está en un grupo, Phi puede adjuntar el grupo completo.
- Un Grupo de pestañas o una Vista dividida puede adjuntarse como una sola unidad.

Para iniciar conversaciones sin la pestaña actual adjunta, desactiva **Añadir automáticamente la pestaña actual como contexto en las conversaciones nuevas** en **Configuración → Phi AI → Barra lateral de IA**.

Cuando usas Phi Cloud, el contenido necesario para responder tu pregunta se envía a un proveedor de modelos externo para su procesamiento. Con la IA privada, se queda en tu Mac. Consulta [Privacidad y tus datos](/es/privacy/) para más detalles.
