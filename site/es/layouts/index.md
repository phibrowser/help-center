# Diseños y navegación

Phi organiza la navegación en torno a una barra lateral vertical y varios modos de diseño entre los que elegir. Si vienes de Chrome o Safari, este es el cambio más grande, y lo primero con lo que merece la pena familiarizarse.

## ¿Por qué una barra lateral vertical?

La mayoría de las pantallas modernas son anchas, no altas. El espacio horizontal suele sobrar, mientras que el vertical es el primero que se agota, sobre todo al leer, escribir, investigar o trabajar dentro de aplicaciones web. Una barra lateral vertical aprovecha mejor la forma de las pantallas actuales y deja más sitio para la página.

## Modos de diseño

Phi ofrece tres modos de diseño para que elijas cuánto espacio de pantalla va al contenido y cuánto a los controles del navegador. Eliges uno durante la configuración inicial y puedes cambiarlo cuando quieras.

- **Rendimiento**, da el máximo espacio a la página. Usa la barra lateral vertical para las pestañas y los marcadores y quita la barra de direcciones del área de contenido.
- **Equilibrado**, mantiene la barra lateral vertical pero añade la barra de direcciones encima del contenido. Es el punto medio entre aprovechar el espacio y lo familiar.
- **Cómodo**, es el que más se parece a un navegador tradicional: pestañas arriba, barra de direcciones visible y un diseño cercano a Chrome. Las pestañas pasan a la franja horizontal, así que la barra lateral cede el protagonismo en la navegación diaria.

### ¿Con cuál empiezo?

- Si vienes de Chrome o Safari: empieza con **Cómodo**.
- Si prefieres un navegador moderno de barra lateral: empieza con **Equilibrado**.
- Si quieres el máximo espacio para la página: usa **Rendimiento**.

Para consejos de migración más amplios, consulta [Cambiar a Phi](/es/switching-to-phi/).

## Pestañas, pestañas fijadas y marcadores

En Phi, las pestañas, las pestañas fijadas y los marcadores conviven en la barra lateral, porque en el fondo son extremos de lo mismo: las páginas que te importan. Las **pestañas** están abiertas ahora mismo, las **pestañas fijadas** se sitúan arriba para las páginas en las que vives, y los **marcadores** quedan debajo para las páginas que quieres conservar. Una forma sencilla de verlo: **las pestañas fijadas son páginas en las que vives; los marcadores, páginas que quieres conservar.**

Para saber cómo los marcadores se abren donde están como pestañas, y cómo fijar y organizar páginas, consulta [Marcadores y pestañas fijadas](/es/bookmarks/). Para las notas de migración desde Arc y Dia, consulta [Cambiar a Phi](/es/switching-to-phi/).

## Vista dividida

La Vista dividida coloca dos páginas una junto a otra en la misma ventana, útil para leer y escribir a la vez, comparar dos páginas o tener la documentación al lado de una aplicación web en lugar de saltar de una a otra.

Para crear una, haz clic con el botón derecho en una pestaña, un marcador o una pestaña fijada y elige **Abrir en vista dividida**, o arrastra una pestaña sobre la página actual. También puedes mantener pulsada la tecla **Opción (⌥)** y hacer clic en una pestaña fijada, un marcador o un enlace de una página web. Phi lo abre junto a la pestaña actual en Vista dividida.

## Grupos de pestañas

Los Grupos de pestañas reúnen pestañas relacionadas en un grupo con nombre, algo práctico cuando varias páginas pertenecen al mismo proyecto, viaje, tema de investigación o sesión de compras.

La Vista dividida y los Grupos de pestañas están pensados para funcionar juntos: puedes usar la Vista dividida dentro de un grupo y mover pestañas divididas dentro o fuera de un grupo, de modo que el trabajo relacionado se mantiene organizado en lugar de flotar como pestañas sueltas.

Un reparto sencillo de funciones: **la Vista dividida es para comparar y hacer varias cosas a la vez; los Grupos de pestañas, para organizar una tarea, un proyecto o un tema.**

## El asistente entiende tu diseño

Cuando chateas desde una Vista dividida, Phi puede usar contexto de ambas páginas. Cuando chateas desde un Grupo de pestañas, puede usar contexto de todo el grupo, así que puedes preguntar sobre varias páginas relacionadas sin explicar cómo lo tienes organizado. (Consejo: usa **ctrl+tab** para recorrer tus pestañas recientes y **ctrl+shift+tab** para volver atrás.)
