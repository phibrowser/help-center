# 開始使用

Phi Browser 可在 macOS 上執行（Apple Silicon，macOS 14 或以上版本）。用下列任一方式安裝，然後完成首次啟動流程。

## 安裝 Phi

### 從官方網站下載

前往 [Phi 下載頁面](https://phibrowser.com/download/)，下載 `.dmg` 檔案，打開它，然後把 Phi 拖曳到「應用程式」資料夾。

### 使用 Homebrew 安裝

如果你使用 [Homebrew](https://brew.sh/)，可以用以下指令安裝 Phi：

```sh
brew install --cask phibrowser/tap/phi
```

這會自動加入 `phibrowser/tap` 並安裝 Phi 的 cask。更新由 Phi 自行處理，所以你不需要透過 Homebrew 升級。

## 首次啟動

第一次開啟 Phi 時，新手引導會協助你完成設定：

- **選擇版面配置模式**：效能、平衡或舒適。之後隨時可以更改，所以挑一個聽起來最接近你目前瀏覽習慣的就好。各模式的說明請見[版面配置與導覽](/zh-Hant/layouts/)。
- **認識你的助理**：進入瀏覽器後，新分頁頂端的橫幅會邀請你認識你的助理：幫它取個名字，它會為自己產生相配的頭像，讓它擁有自己的身分，而不像一個千篇一律的聊天機器人。你也可以先略過，之後再回來設定。
- **登入，或不登入直接探索**：使用 Phi 帳號登入後，AI 功能與瀏覽器記憶就會開啟。你也可以選擇**不登入，直接探索 Phi**，之後再登入；請見[之後再登入](#signing-in-later)。
- **AI 預設為開啟**：登入後，Phi 的 AI 功能出廠即啟用。如果你偏好單純的瀏覽器，之後可以在**設定 → Phi AI** 中關閉。

## 之後再登入 {#signing-in-later}

如果你選擇了**不登入，直接探索 Phi**，仍然可以正常瀏覽，但 Phi 的 AI 功能與瀏覽器記憶會保持關閉，直到你登入為止。準備好了隨時可以登入，入口有以下幾個：

- **設定 → 訪客**：這裡會顯示你目前未登入即使用 Phi，並提供登入按鈕。
- **設定 → Phi AI**：這裡會顯示「登入即可使用 AI 功能」的提示。
- **任何 AI 功能本身**：開啟任一 AI 功能，Phi 會顯示「登入即可使用 Phi AI」，並附上開啟登入流程的按鈕。

登入後，你的釘選分頁和書籤都會一併帶入。

## 從其他瀏覽器改用 Phi？

如果你習慣 Chrome 或 Safari，先從**舒適模式**開始，轉換起來最輕鬆。想看為 Chrome、Safari、Arc 和 Dia 使用者準備的完整轉換指南，請見[改用 Phi](/zh-Hant/switching-to-phi/)。
