# 主題與外觀

Phi 讓你決定瀏覽器的樣貌：一個顏色 **主題**，加上 **淺色或深色** 的選擇，而且套用範圍是整個瀏覽器，不是單一畫面。挑好一種樣貌，視窗、側邊欄和你的新分頁都會跟著它。

這些控制項目位於 **設定 → 一般**。

## 選擇主題

在 **主題** 之下，**顏色** 列提供一組具名的預設配色，以色票顯示。每一種都是完整的配色方案，各自有淺色和深色版本，因此無論你使用哪種外觀，主題看起來都對。

顏色旁邊的 **不透明度** 滑桿，控制上色圖層透出視窗的程度。調高可以讓顏色更濃，調低則更接近素面。

## 淺色、深色或系統

**外觀** 與主題的顏色是分開的選擇。在 **顏色外觀** 之下你可以挑選：

- **系統**，跟隨你的 macOS 設定並隨之切換。
- **淺色**，一律淺色。
- **深色**，一律深色。

無論哪種模式，你選擇的主題都會保持自己的性格；這裡只決定你看到的是它的哪個版本。

## 主題會出現在哪裡

主題套用於整個瀏覽器，而不是單一介面：

- **視窗**，工具列、網址列和分頁會帶上主題顏色。**不透明度** 滑桿決定上色的濃淡。
- **側邊欄**，選取中和游標懸停的分頁會帶上主題。
- **新分頁**，你的 [新分頁](/zh-Hant/new-tab/) 會自動跟隨同一個主題，與瀏覽器其他部分一致；更換主題時，它會和其他一切一起換上新色。
- **網頁上選取的文字**，預設情況下，在頁面上選取文字時，選取範圍會染上你的主題顏色。如果你希望網頁保留自己原生的選取顏色，請在主題設定中關閉 **將主題套用到網頁上的文字選取範圍**。
