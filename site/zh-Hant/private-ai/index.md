# 私有 AI

Phi 的 AI 功能預設在 **Phi Cloud** 上執行。**私有 AI** 讓你逐項任務決定每一類 AI 工作交給誰處理：Phi Cloud、下載到這部 Mac 上的模型，或你自行連接的 AI 供應商，例如 Ollama、LM Studio、OpenAI 或 OpenRouter。

私有 AI 預設為關閉。如果你從未開啟它，所有 AI 功能都會照常運作，並使用 Phi Cloud。

## 助理、Phi Cloud 與 AI 供應商 {#assistant-phi-cloud-and-providers}

這三者很容易混淆，所以先把它們分清楚會有幫助：

- **助理**就是你取了名字的那一位。它是 Phi 的 AI 代理：它會判斷你在要求什麼，並決定要做什麼，無論是讀取頁面、執行瀏覽器 Skill、在瀏覽器中採取行動，還是建立任務。不論它使用哪個模型，都是同一位助理，你的對話、記憶和任務也不會隨模型改變。
- **模型**是助理借來思考的「大腦」。在每個步驟中，助理會把需要的內容送給模型，再由模型回答。
- **AI 來源**決定這個模型在哪裡執行。來源有三種：
  - **Phi Cloud**，Phi 內建的 AI 服務。它不是 AI 代理，也不是某個特定的模型，而是一組由 Phi 連接並替你管理的雲端模型。它使用你的 Phi 登入身分，不需要 API 金鑰，也不會要你挑選模型。
  - **本機模型**，下載到這部 Mac、並在這部 Mac 上執行的模型。
  - **你的供應商**，你自行連接的 AI 服務，使用你自己的位址、帳號或 API 金鑰。

所以 Phi Cloud 和 Ollama 或 OpenAI 處在同一個位置：它是「助理的模型在哪裡執行？」這個問題的其中一個答案。差別在於 Phi Cloud 是內建的，開箱即用，其他來源則要由你自己設定。

### 各來源比較 {#comparing-sources}

|                     | Phi Cloud                                                      | 本機模型                              | 你的本機供應商（Ollama、LM Studio）     | 你的雲端供應商（OpenAI、OpenRouter、Codex 等） |
| ------------------- | -------------------------------------------------------------- | ------------------------------------- | --------------------------------------- | ---------------------------------------------- |
| 你需要什麼          | 登入 Phi 即可，不需要其他東西                                  | 一個設定步驟，會把模型下載下來        | 已安裝並開啟 Ollama 或 LM Studio        | 該服務的帳號或 API 金鑰                        |
| 你的內容會送到哪裡  | 經過 Phi，送到 Phi 使用的模型供應商                            | 哪裡都不去。內容留在這部 Mac 上       | 你設定的位址，通常是這部 Mac 或你的網路 | 直接從你的 Mac 送到該服務                      |
| 以誰的帳號送達      | Phi 的帳號。模型供應商不會被告知你是誰                         | 不適用                                | 不適用                                  | 你的，透過你自己的帳號或金鑰                   |
| 費用                | 包含在 Phi 中，以你的[使用額度](/zh-Hant/ai/#usage-limits)為限 | 免費，使用這部 Mac 的記憶體和運算能力 | 免費，使用執行它的那部電腦              | 依該服務自己的定價                             |
| 是否計入 Phi 的額度 | 是                                                             | 否                                    | 否                                      | 否                                             |
| 離線可用            | 否                                                             | 是                                    | 是，在這部 Mac 上執行時                 | 否                                             |
| 品質                | 穩定，適合每一項任務                                           | 取決於模型大小，通常不如雲端模型      | 取決於你選擇的模型                      | 取決於你選擇的模型                             |

Phi Cloud 如何處理你的內容，請見[隱私權與你的資料](/zh-Hant/privacy/)。當你使用自己的雲端供應商時，適用的是該供應商的隱私權政策。

## Phi 何時會使用你的供應商 {#when-phi-uses-your-provider}

單單加入供應商，不會改變任何事。只有在以下兩個條件都成立時，Phi 才會使用它：

1. 你已在**私有 AI → AI 任務**中，選擇該供應商的某個模型作為某項任務的來源。
2. **私有 AI** 開關已開啟。

你沒有變更過的任務都會繼續使用 Phi Cloud。關閉私有 AI 會讓所有任務立即回到 Phi Cloud，但你的選擇會保留下來，所以再次開啟時，這些選擇就會恢復，不必重新設定。

## 為每項任務選擇來源 {#choosing-a-source-for-each-task}

私有 AI 不是全有或全無。你逐項任務設定它，頁面頂端會顯示有多少任務不在 Phi Cloud 上，例如 **4 項 AI 任務中有 2 項以私有方式執行**。

| AI 任務      | 涵蓋範圍                                     | 可選擇的來源                                |
| ------------ | -------------------------------------------- | ------------------------------------------- |
| **對話**     | 側邊欄和 Phi Chat 中的回覆                   | Phi Cloud、本機模型、你的供應商、Codex      |
| **記憶**     | 背景工作，例如根據瀏覽建立記憶，以及產生摘要 | Phi Cloud、本機模型、你的供應商、Codex      |
| **網頁任務** | 助理在瀏覽器中採取行動，以及自動化           | Phi Cloud、本機模型、你的供應商、Codex      |
| **資料搜尋** | 搜尋你連接的資料                             | 只能是 Phi Cloud，或 Phi 下載的本機搜尋模型 |

旁邊還有幾列：

- **視覺模型回退**。當你為某項任務選擇的模型無法讀取圖片時，圖片會改送到這裡設定的模型。它一開始是**未設定**。
- **AI 分頁整理**在 macOS 上由 Apple Intelligence 處理，無法變更。沒有 Apple Intelligence 的 Mac 上不會出現這一列。
- **圖片生成**一律使用 Phi Cloud。

當你把某項任務切換到不同的來源時，Phi 會先測試那個模型。如果測試失敗，任務會回到原本的來源，並告訴你原因。

一旦對話使用 Phi Cloud 以外的來源，對話中就會顯示**你正在使用私有 AI**，因為回答的品質可能和線上模型不同。

## 開啟私有 AI {#turning-on-private-ai}

有兩種方式可以進入私有 AI 設定：

- 在 [Phi Chat](/zh-Hant/phi-chat/) 中，按一下頂端列的設定（齒輪）按鈕，選擇**私有 AI**。
- 在瀏覽器中，前往**設定 → Phi 與 AI → Phi Sentinel → 私有 AI**，會在 Phi Chat 中開啟同一個頁面。

第一次開啟開關時，Phi 會檢查這部 Mac 能否執行本機模型：

- **如果可以**，設定視窗會列出下載大小、模型執行時大約使用多少記憶體，以及哪些任務會移到這部 Mac 上。按一下**開始設定**，Phi 就會安裝本機執行環境、下載模型、啟動並驗證它們。你可以按**縮到最小**，讓設定在背景繼續進行。在設定完成之前，所有 AI 功能都會繼續使用 Phi Cloud。
- **如果不行**，視窗會說明原因。你仍然可以按一下**使用自己的 AI 服務**，在沒有本機模型的情況下連接你自己的供應商。

### 系統需求 {#requirements}

| 項目         | 需求                                        |
| ------------ | ------------------------------------------- |
| 晶片         | Apple Silicon。Intel Mac 無法執行本機模型   |
| 記憶體       | 至少 16 GB                                  |
| 可用磁碟空間 | 至少 10 GB，而且比下載內容本身多出至少 2 GB |

如果你只連接自己的供應商，例如你網路中另一部電腦上的 Ollama，或 OpenAI，以上需求都不適用。

### 設定會安裝什麼 {#what-setup-installs}

設定目前會下載兩個模型，兩者執行時合計使用約 7 GB 記憶體：

- **Gemma 4 E4B (4-bit)**，用於**記憶**。
- **BGE-M3**，用於**資料搜尋**。

**對話**和**網頁任務**會留在 Phi Cloud。這兩項需要能穩定處理長上下文和工具呼叫的模型，只有在有 200 億個參數以上的本機模型可用時，Phi 才會自動把它們移到這部 Mac 上。設定下載的 Gemma 模型大約有 40 億個參數：適合背景工作，但不足以撐起一段對話。只要它通過測試，你仍然可以在 **AI 任務**中手動把對話切換給它。設定完成時，會明確告訴你哪些任務現在在這部 Mac 上執行。

設定完成後，記憶用來找出相關項目的索引仍然是在 Phi Cloud 上建立的。如果你希望這件事也在這部 Mac 上完成，請手動為**資料搜尋**選擇一次本機模型，兩者就會一起移到這部 Mac 上。

## 連接 Ollama 或 LM Studio {#connecting-ollama-or-lm-studio}

Ollama 和 LM Studio 是免費的 App，可以在你自己的電腦上執行開放模型。兩者都以供應商的形式內建在 Phi 中，預設位址分別是 Ollama 的 `http://127.0.0.1:11434`，以及 LM Studio 的 `http://127.0.0.1:1234/v1`。

1. 安裝並開啟 Ollama 或 LM Studio，然後下載一個模型（請見[推薦模型](#recommended-models)）。
   - Ollama：在終端機中執行 `ollama pull <model>`，例如 `ollama pull gpt-oss:20b`。
   - LM Studio：在 App 中搜尋模型並下載，然後在 **Developer** 頁面啟動本機伺服器。
2. 在 Phi Chat 中，開啟**設定 → AI 供應商**，選擇 **Ollama** 或 **LM Studio**。
3. 開啟**使用此供應商**。如果服務在你網路中的另一部電腦上執行，請把**基礎 URL** 改成那部電腦的位址。
4. 按一下**載入**取得它的模型。在**模型允許範圍**中，選擇**全部允許**，或選擇**僅允許所選**並勾選你要的模型。
5. 選擇一個模型，按一下**測試**，等它回報連線成功後，按一下**儲存修改**。
6. 回到**私有 AI**，在 **AI 任務**中，為你要移轉的任務選擇那個模型，例如**對話**。
7. 開啟**私有 AI** 開關。

如果是其他提供 OpenAI 相容 API 的服務，請使用**新增自訂供應商**，輸入名稱、基礎 URL，以及 API 金鑰（如果該服務需要的話）。

值得知道的事：

- 基礎 URL 可以是 `http` 或 `https`，API 金鑰則是選填，因為本機服務通常不需要金鑰。送往 `http` 位址的金鑰會以未加密的方式傳輸，所以凡是不在你自己的 Mac 或網路上的服務，請使用 `https`。
- Ollama 或 LM Studio 必須保持開啟。如果電腦進入睡眠或 App 結束，受影響的任務會依照你的[回退設定](#when-a-local-source-is-unavailable)處理。
- 網頁任務和長對話會帶著大量文字。如果回覆不完整，或助理無法完成某個動作，請把上下文長度調高，例如調到 32K：在 Ollama 的設定中調整 **Context length**，或在 LM Studio 載入模型時調整 **Context Length**。上下文越長，使用的記憶體越多。
- 若要讓你網路中的其他電腦連到 Ollama，那部電腦上的 Ollama 必須監聽它的網路位址（`OLLAMA_HOST=0.0.0.0`）。

## 推薦模型 {#recommended-models}

開放模型更新得很快，所以請把下面的名稱當作範例。同樣大小的較新模型效果一樣好。最重要的有兩件事：模型必須夠大，而且必須放得進記憶體。模型執行時使用的記憶體大約等於它的下載大小，再加上幾 GB，而且 macOS 和你的其他 App 也需要空間。

| 你的 Mac 記憶體 | 建議                                                                                                                        |
| --------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 16 GB           | 使用設定讓記憶和資料搜尋在這部 Mac 上執行，對話和網頁任務則留在 Phi Cloud。這樣的記憶體容量放不下適合對話的模型             |
| 32 GB           | 你可以為對話執行 200 億參數等級的模型，例如 **gpt-oss-20b**（Ollama：`gpt-oss:20b`）或 **Qwen3 30B**（Ollama：`qwen3:30b`） |
| 64 GB           | 你可以選擇更穩定的 300 億參數等級模型，例如 **Qwen3 32B**（Ollama：`qwen3:32b`），還有空間容納更長的上下文                  |
| 128 GB 以上     | 你可以執行 1,000 億參數等級的模型，例如 **gpt-oss-120b**（Ollama：`gpt-oss:120b`），表現更接近雲端模型                      |

依任務：

- **對話和網頁任務**：選擇 200 億個參數以上、支援工具呼叫（函式呼叫）的模型。網頁任務最依賴工具呼叫，小模型常常在這方面失敗。
- **視覺模型回退**：選擇能讀取圖片的模型，例如 Gemma 3 12B（Ollama：`gemma3:12b`）或 Qwen2.5-VL 7B（Ollama：`qwen2.5vl:7b`）。
- **記憶**：設定提供的 Gemma 模型就夠用，通常沒有理由更換。
- **資料搜尋**：只能使用 Phi 下載的本機搜尋模型，或 Phi Cloud。

不論多大，本機模型通常仍比不上 Phi Cloud 背後的前沿模型。如果比起讓內容留在 Mac 上，你更在意回答的品質，把對話和網頁任務留在 Phi Cloud 是合理的選擇。

## 本機來源無法使用時 {#when-a-local-source-is-unavailable}

當本機模型、Ollama 或 LM Studio 停止回應時，Phi 會依照**當本機或自行架設的來源無法使用時**這項設定處理：

- **自動改用 Phi Cloud（預設）**。受影響的任務會暫時使用 Phi Cloud，讓 AI 功能繼續運作。這也表示在這段期間，這些任務的內容會送到雲端。
- **暫停受影響的 AI 功能（絕不將資料傳送到雲端）**。受影響的功能會暫停，直到本機來源再次回應。

如果你開啟私有 AI 的原因是讓內容留在這部 Mac 上，請選擇第二個選項。

這項設定只涵蓋本機和自行架設的來源。當 OpenAI、OpenRouter 或 Codex 等雲端供應商發生故障時，Phi 不會切換到 Phi Cloud。

出問題時，私有 AI 頁面會顯示**需要處理**，並提供**重新啟動本機服務**按鈕。

## 使用 Codex {#using-codex}

如果你有 ChatGPT 訂閱，並且已在這部 Mac 上登入 Codex，就可以把這份訂閱當作 AI 供應商使用。前往**設定 → AI 供應商 → Codex**，按一下**連線**。Phi 會使用 Codex 已經保存的登入資訊，不會複製你的憑證。

- 請先安裝 Codex，並在終端機中執行 `codex login`。Phi 無法讀取存放在鑰匙圈中的 Codex 登入資訊。
- Codex 可以處理對話、記憶、網頁任務和視覺模型回退，但不能處理資料搜尋。
- Codex 所做的事會計入你 ChatGPT 訂閱的用量限制。如果用完了，或登入失效，Phi 不會切換到其他來源。

## 關閉與重設 {#turning-off-and-resetting}

- **關閉私有 AI**：使用它的開關。所有任務會立即回到 Phi Cloud，已下載的模型和你的選擇都會保留。
- **移除供應商**：在該供應商的頁面上使用**移除供應商**。原本使用它的任務會回到 Phi Cloud。
- **重設**：在**進階設定**中使用**重設 AI 設定**。這會把所有任務移回 Phi Cloud、清除你的供應商及其 API 金鑰，並刪除本機模型。
