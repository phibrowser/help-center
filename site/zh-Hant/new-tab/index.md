# 新分頁與小工具

Phi 以一個個人化的首頁取代標準新分頁。每個新分頁都會給你一則問候、一個可以搜尋或提問的輸入框，以及一組排成格狀、由你自行安排位置的小工具。它會自動跟隨你的[主題與淺色或深色選擇](/zh-Hant/themes/)。

## 你的新分頁

- **一則問候**，一段隨時間變化的個人化歡迎詞，取材自 Phi 對你的認識。你可以分享它，也可以和助理聊聊它。
- **一個搜尋與提問合一的輸入框**，輸入文字即可搜尋網路、向助理提問，或直接前往某個網址，全都在同一個地方完成。你可以[附加分頁](/zh-Hant/ai/#chat-with-tabs)或檔案，也可以把 Skill 帶進對話。
- **⋮ 選單**，位於右上角，可以開啟「**小工具**」和 [Skill](/zh-Hant/skills/) 庫，也提供「**還原隱藏的提示**」。

由於搜尋框直接連著你的助理，新分頁往往是啟動事情最快的地方：無論是一次搜尋、一個問題還是一項任務，都不必先另開一個對話。想知道助理能做什麼，請見[認識你的助理](/zh-Hant/ai/)。

## 小工具

小工具是你釘選在新分頁上的一張張小卡片：時鐘、天氣、你最常造訪的網站、專注計時器等等。要顯示哪些、放在哪裡，都由你決定。

### 開啟小工具面板

小工具的一切操作都在「**小工具**」面板中進行。你可以從右上角的 ⋮ 選單選擇「**小工具**」來開啟它，也可以捲動到頁面底部，按一下「**自訂**」。

「**自訂**」第一次出現在畫面上時，會有一則提示指向它：「**在這裡建立你自己的小工具**」。只要你按一下「**忽略**」或開啟過面板，這則提示就不會再出現。

### 建議的小工具

Phi 不會提供一份固定的目錄讓你瀏覽，而是在面板中根據 Phi 對你的記憶，挑出幾個建議，每個都有為你量身取的標題。這些建議取自一組內建的小工具類型，例如時鐘、天氣、番茄鐘專注計時器、匯率換算、常用網站、你最近讀過的頁面、RSS 饋給、GitHub 儲存庫的星數與 fork 數，以及彙整你最近動態的每日或每週報告。

在某個建議上按一下「**重新產生**」，就能把它換成另一個。

### 新增與排列小工具

1. 在某個建議上按一下「**安裝**」，它會立即加入面板中你的小工具。
2. 把它拖曳到頁面上即可釘選，或從它的選單選擇「**加到頁面**」。

面板開啟時，你可以重新安排頁面：拖曳已釘選的小工具來移動位置、拖曳它的邊緣來調整大小，或把它拖回面板，將它從頁面上移除。

已釘選小工具的選單包含：

- **重新整理**，重新取得它的資料。只有會載入資料的小工具才有這個選項。
- **編輯**，描述你想要的變更，Phi 會替你改寫這個小工具。
- **刪除**，把小工具從頁面上移除。它仍會留在面板中，之後可以再加回來。
- **全部刪除**，在你確認後，把頁面上所有小工具都移除。

如要永久移除某個小工具，請在面板中從它的選單選擇「**刪除**」。Phi 會先請你確認。

你的版面配置會儲存在這部裝置的這個瀏覽器中，所以每次開啟新分頁，看到的都是同一個樣子。它不會同步到你的其他裝置。

### 空白新分頁上的建議小工具

如果你還沒有任何自己的小工具，Phi 可能會替你釘選一個，並標示為「**推薦**」。它取材自你的「記憶」，所以剛安裝不久時，可能要過一陣子才會出現。

如果你不理會建議的小工具，隔天它就會換成另一個。要決定如何處理它：

- **保留**，讓它成為你的小工具，並停止每天更換。移動、調整大小或編輯它，也都算是保留。
- **✕**，移除這個小工具。卡片會短暫顯示「**移除中**」，如果你改變主意，可以按「**復原**」。之後的某一天仍可能出現其他建議。
- **停止推薦**，會在卡片顯示「**移除中**」時出現，可以關閉建議的小工具。

### 製作你自己的小工具

在面板中按一下「**+**」（「**新增小工具**」），描述你想要的小工具。Phi 會建立它，並在你儲存前先讓你看看結果。如果不滿意某個版本，可以重新產生。之後想修改小工具，請從它的選單選擇「**編輯**」。

小工具由 AI 產生，偶爾可能不準確。

### 懂你的小工具

建議的小工具，以及部分小工具的內容，會根據 Phi 對你的記憶個人化，例如優先呈現你真的會回訪的頁面。

這一切建立在與 Phi 其他部分相同的本機優先記憶上：小工具取用的資料留在你的裝置上，也由你掌控。當小工具需要用到 AI，例如撰寫你的每日或每週報告、製作每日圖片，或建立、編輯小工具時，該步驟所需的內容會傳送給模型，和其他 AI 要求一樣。這些內容會傳送到哪裡，以及如何讓更多資料留在你的 Mac 上，請見[隱私權與你的資料](/zh-Hant/privacy/)。
