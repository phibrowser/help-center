# 新分頁與小工具

Phi 以一個個人化的首頁取代標準新分頁。每個新分頁都會給你一則問候、一個可以搜尋或提問的輸入框，以及一組排成格狀、由你自行安排位置的小工具。它會自動跟隨你的[主題與淺色或深色選擇](/zh-Hant/themes/)。

## 你的新分頁

- **一則問候**，一段隨時間變化的個人化歡迎詞，取材自 Phi 對你的認識。你可以分享它，也可以和助理聊聊它。
- **一個搜尋與提問合一的輸入框**，輸入文字即可搜尋網路、向助理提問，或直接前往某個網址，全都在同一個地方完成。你可以[附加分頁](/zh-Hant/ai/#chat-with-tabs)或檔案，也可以把 Skill 帶進對話。
- **快速存取**，從右上角的選單開啟最近的對話、你的小工具，以及 [Skill](/zh-Hant/skills/) 庫。

由於搜尋框直接連著你的助理，新分頁往往是啟動事情最快的地方：無論是一次搜尋、一個問題還是一項任務，都不必先另開一個對話。想知道助理能做什麼，請見[認識你的助理](/zh-Hant/ai/)。

## 小工具

小工具是你釘選在新分頁上的一張張小卡片：時鐘、天氣、你最常造訪的網站、專注計時器等等。要顯示哪些、放在哪裡，都由你決定。

### 內建小工具

- **一目瞭然**，「時鐘」（任何時區的當地時間與日期）、「天氣」（指定地點的目前天氣狀況）、「每日金句」，以及「每日圖片」（取材自你近期記憶主題的氛圍圖片）。
- **工具**，「番茄鐘專注計時器」、「匯率換算」和「快速翻譯」。
- **捷徑**，「常用網站」（你最常造訪的網站）和「GitHub 星數」（儲存庫的星數趨勢）。
- **你的活動**，「最近閱讀」（你最近讀過的頁面）、「熱門貼文」（來自 Hacker News、Reddit 等來源的熱門項目），以及彙整你最近動態的「每日報告」與「每週報告」。

### 新增與排列小工具

從右上角的「**小工具**」選單開啟小工具庫，或使用捲動時出現的「**自訂**」按鈕。接著：

- **把小工具拖曳到頁面上**即可釘選。
- 透過已釘選小工具的選單，可以「**移動與調整大小**」、「**重新整理**」它的資料、「**編輯**」或「**刪除**」它。

你的版面配置會儲存在裝置上，所以每次開啟新分頁，看到的都是同一個樣子。

### 懂你的小工具

小工具庫會根據 Phi 對你的記憶，建議幾個入門的小工具；有些小工具也會用同樣的方式讓內容更貼近你，例如優先呈現你真的會回訪的頁面。你也可以直接在對話中請助理**建立自訂小工具**，或**調整**現有的某一個。

這一切建立在與 Phi 其他部分相同的本機優先記憶上：小工具取用的資料留在你的裝置上，也由你掌控。詳情請見[隱私權與你的資料](/zh-Hant/privacy/)。
