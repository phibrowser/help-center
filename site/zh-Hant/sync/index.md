# 同步

同步會讓 Phi 自己的資料，在每一部登入同一個 Phi 帳號的 Mac 上保持一致。在一部 Mac 上儲存書籤或重新命名空間，變更就會出現在其他 Mac 上。同步要在每一部 Mac 上設定後才會開啟，而且它的設計讓我們無法讀取它傳送的內容：所有資料在上傳前都會先在你的 Mac 上加密，使用的金鑰只有你的 Mac 持有。

本頁說明的所有功能都位於**設定 → 同步**。

## 會同步的內容

| 項目                       | 說明                                                                                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **空間**                   | 名稱、圖示、顏色、主題，以及每個空間屬於哪個設定檔。                                                                                             |
| **設定檔**                 | 設定檔名稱，以及每個設定檔底下有哪些空間。                                                                                                       |
| **書籤與資料夾**           | 每個空間的書籤，包括資料夾結構與排列順序。                                                                                                       |
| **釘選分頁**               | 釘選分頁，依照你在**設定 → 空間**中選擇的範圍。                                                                                                  |
| **網址規則**               | 把符合的網站導向某個空間、無痕模式或 Kiosk 的規則。                                                                                              |
| **支援的設定**             | 版面配置模式、外觀、主題與選取色調、書籤列和完整網址設定、新分頁快速鍵、無痕模式的關閉警告、自動子母畫面、釘選分頁範圍，以及哪個空間是預設空間。 |
| **瀏覽資料，依設定檔區分** | 瀏覽歷史記錄、瀏覽器本身的偏好設定（例如預設搜尋引擎），以及擴充功能和它們已同步的設定。                                                         |

::: warning 刪除也會同步
在一部 Mac 上刪除空間或設定檔，所有與它同步的 Mac 上也會一併刪除，書籤也包括在內。Phi 會在確認對話框中說明這一點，所以確認前請先讀過。
:::

有些內容刻意留在原處：

- **密碼、Cookie 和自動填入資料。** 它們永遠不會進入同步。Phi 沒有自己的密碼管理工具，而你透過 [AI 代理密碼管理員](/zh-Hant/agent-passwords/)連接的密碼庫屬於它的供應商，依照該供應商的條款同步。
- **開啟中的分頁。** 一般開啟中的分頁不會在另一部 Mac 上重新建立。釘選分頁則會。
- **Phi Chat 和記憶。** 你與助理的對話會留在進行對話的那部 Mac 上，[記憶](/zh-Hant/memory/)也一樣。
- **無痕空間**，以及 AI 代理工作時使用的空間。其中的任何內容都不會同步。把網站導向無痕模式的網址規則仍然是一條規則，所以會像其他規則一樣同步。
- **只屬於單一 Mac 的設定**，包括 AI 與 AI 代理的設定。

## 開始之前

- **一個 Phi 帳號，並在每一部 Mac 上登入。** 沒有帳號時，這個面板只會顯示**登入即可在裝置間同步**。如果你選擇了不登入直接探索，請見[之後再登入](/zh-Hant/get-started/#signing-in-later)。
- **官方版本的 Phi。** 同步透過 Phinomenon 的同步服務運作，你自行從開源程式碼建置的 Phi 無法使用它。

## 設定第一部 Mac

1. 開啟**設定 → 同步**，按一下**在此裝置上設定同步**。視窗會說明接下來會發生什麼事；按一下**繼續**。
2. **儲存你的復原代碼。** Phi 會建立一組復原代碼，而且只顯示一次：共 27 個字元，每五個一組。按一下**複製**，把它存放在安全的地方，例如密碼管理工具，然後按一下**我已儲存**。
3. **確認你的復原代碼。** Phi 會請你輸入剛才儲存的代碼。連字號、空格和大小寫都不影響。代碼核對成功之前，同步會保持關閉，所以你不會在日後才發現它根本沒存下來。如果你在這一步關閉視窗，下次開啟設定流程或重新啟動時，Phi 會再問一次。
4. **配對你的設定檔和空間。** 在第一部 Mac 上，帳號裡還沒有可以配對的內容，所以這一步主要是確認要加入哪些項目：為每個設定檔選擇**註冊為新設定檔**，空間則選擇**全部加入為新空間**。帳號裡已有資料時，這兩個步驟會做什麼，請見[加入另一部 Mac](#add-another-mac)。
5. 按一下**完成**。這部 Mac 上傳資料期間，面板會顯示**初次同步進行中**，完成後顯示**已是最新狀態**。

::: warning 復原代碼只會顯示一次
復原代碼在你的 Mac 上產生，永遠不會傳送給我們，所以我們無法再次顯示它、寄送替代代碼，或將它重設。要加入另一部 Mac，你需要這組代碼，或一部已經設定好的 Mac。兩者都遺失的話，沒有人能解鎖你帳號中的加密副本，我們也不例外。
:::

## 加入另一部 Mac {#add-another-mac}

1. 登入同一個 Phi 帳號，開啟**設定 → 同步**，按一下**在此裝置上設定同步**，然後按**繼續**。
2. 在**將此裝置加入你的帳號**畫面中，選擇這部 Mac 加入的方式：
   - **向另一部裝置請求核准。** Phi 會顯示一組短代碼並開始等待。在一部已經設定好的 Mac 上開啟**設定 → 同步**：請求會出現在**裝置**底下，附上同一組代碼和請求的到期時間。確認兩組代碼相符後按一下**核准**；如果這不是你預期的請求，就按**拒絕**。這組代碼用來辨識新的 Mac，並不是機密，所以透過電話唸給對方聽也沒問題。請求被拒絕或過期時，會提供**試試其他方式**。
   - **輸入復原代碼。** 輸入你在第一部 Mac 上儲存的代碼。
3. **配對你的設定檔。** Phi 會把這部 Mac 上的設定檔與你帳號中的設定檔配對，並詢問無法自動配對的那些。為這部 Mac 上的每個設定檔選擇**指派給**某個帳號設定檔，或選擇**註冊為新設定檔**。帳號中在這部 Mac 上沒有對應的設定檔，會列在**尚未配對的帳號設定檔**底下，按**在這部 Mac 上建立**即可加入。
4. **配對你的空間。** 為這部 Mac 上的每個空間挑選它對應的帳號空間，或選擇**加入為新空間**。**全部加入為新空間**會一次處理所有尚未決定的空間，名稱完全相同的空間則會自動幫你挑好。帳號中有、但這部 Mac 上沒有的空間，會出現在**將從你的帳號加入的空間**底下，並在你完成時建立。這部 Mac 上的任何內容都不會被刪除。按一下**完成**。
5. **檢視變更內容**，只有在這部 Mac 上有內容會被覆寫時才會出現。如果你把這部 Mac 上的某個空間配對到帳號中的空間，帳號裡的名稱、圖示、顏色和主題會取代這部 Mac 上的設定，而且該空間可能會移到它在帳號中所屬的設定檔。這部 Mac 上的分頁、書籤、釘選分頁和網址規則不受影響。如果想保留這部 Mac 上的設定，請按**上一頁**，改把該空間加入為新空間。按一下**套用**即可開始同步。如果沒有任何內容會被覆寫，按下**完成**後同步就會立即開始。

載入帳號時，Phi 需要清點你的空間，可能要花上兩分鐘，而且必須連上網路：沒有可以退而使用的快取副本。同步開始後，兩部 Mac 上的書籤、釘選分頁和網址規則都會保留，所以任何一邊的內容都不會遺失。

### 稍後完成

配對頁面上會出現**稍後完成**。選擇它或關閉視窗後，這部 Mac 會繼續在本機瀏覽：不會同步任何內容，面板顯示**尚未配對**，Phi 也不會自行重新開啟設定流程。準備好時，回到**設定 → 同步**並按一下**繼續設定**。Phi 會在那時重新載入你的帳號，所以先前未完成的選擇不會保留。

## 查看同步狀態

同步面板頂端會顯示目前的狀態：

- **已是最新狀態**、**正在同步…**，或在第一次同步進行期間顯示**初次同步進行中**。
- **離線**，並附註變更會在連線後同步。Phi 會繼續使用本機資料運作，等 Mac 恢復連線後再傳送你的變更。
- **同步已暫停。** 這部 Mac 上有個設定檔尚未設定同步，通常是你在完成設定後才建立的設定檔。Phi 會自行註冊它並持續重試；下方那一行會說明它在等待什麼，按**重試**則會立即再試一次。
- **需要注意。** 有地方出錯了，**上次的問題**會指出是什麼。**登入已過期**表示你需要重新登入。**沒有網路連線**和**伺服器錯誤**會在下一次同步成功時自行消失。**同步需要重新設定**請見[重新設定同步](#set-up-sync-again)。

**詳細資訊**會為每一類 Phi 資料（空間、書籤、釘選分頁、網址規則、設定）各列出一行，顯示這部 Mac 最近收到、送出和仍在等待送出的內容，另外每個設定檔的瀏覽資料也各有一行。**立即同步**會要求這部 Mac 馬上同步所有內容。你很少需要用到它：另一部 Mac 有所變更時，Phi 會收到通知，它也會自行檢查，而且兩次同步之間至少會相隔一分鐘。

## 裝置

**裝置**區段會列出你帳號中每一部已設定的 Mac，並標示**這部 Mac**；正在等待加入的 Mac 也會列在這裡，附上它的代碼、**核准**、**拒絕**，以及請求的到期時間。要核准請求，這部 Mac 必須已經登入，而且自己的設定已經完成。

每部 Mac 只能從自己的同步面板移除自己。目前還沒有辦法移除你已經不再擁有的 Mac：遺失的 Mac 會留在帳號中，只要它仍處於登入狀態，就會繼續收到變更。如果你還能取得那部 Mac，將它登出就能停止這種情況。

## 從同步中移除 Mac {#remove-a-mac-from-sync}

在**設定 → 同步**的**復原與移除**底下，按一下**從同步中移除此裝置…**，然後按**移除此裝置**確認。

- 這部 Mac 會停止同步，同步服務會撤銷它的授權，它的同步設定、金鑰，以及設定檔和空間的配對資訊，都會從這部 Mac 上清除。
- 你瀏覽的一切都會保留：空間、書籤、歷史記錄和釘選分頁完整保留，你也會繼續登入你的帳號。
- 你的其他 Mac 不受影響，會繼續彼此同步。
- 要讓這部 Mac 重新加入，請再次開始設定流程，並透過核准或復原代碼加入。

你無法移除帳號中的最後一部 Mac。請先在另一部 Mac 上設定同步。

::: warning 移除 Mac 不會更換帳號的金鑰
移除 Mac 會讓它不再收到任何新內容，但不會變更你帳號的加密金鑰，也無法收回那部 Mac 先前已經同步的內容。原本在它上面的資料會繼續留在它上面。
:::

## 重新設定同步 {#set-up-sync-again}

如果面板顯示**帳號的同步資料已變更。Phi 資料的同步已暫停。**，表示你帳號中的同步資料已被重設，這部 Mac 的設定與它不再相符。在你採取行動之前，Phi 的資料會停止同步；重試或重新啟動都無法解除這個狀態。按一下**重新設定同步**並確認。Phi 會清除這部 Mac 的同步設定和配對資訊，保留你的本機瀏覽資料和帳號中的內容，並帶你重新走一次設定流程，包括透過核准或復原代碼加入。

## 登出

登出你的 Phi 帳號後，那部 Mac 上的同步就會停止，在你重新登入之前，其他 Mac 的內容都不會傳過來。重新登入同一個帳號後，同步會從中斷的地方繼續，並補上錯過的內容；如果還有需要完成的步驟，同步面板會告訴你。切換到另一個帳號時，兩個帳號的資料永遠不會混在一起：每個帳號都有自己的同步資料和自己的配對資訊。

## 你的資料如何受到保護

- **離開你的 Mac 之前就已加密。** 金鑰由你的 Mac 建立，上傳的只有加密後的副本。同步服務會儲存它並轉交給你的其他 Mac，但無法將它解密。
- **光是登入還不足以讀取它。** 新的 Mac 只能透過已持有金鑰的 Mac 核准，或透過你的復原代碼取得金鑰。這也是為什麼任何地方都沒有「忘記復原代碼」的連結。
- **它仍然是我們替你保管的資料。** 加密副本存放在 Phinomenon 的同步服務上，所以同步也是 Phi 會傳送出去的內容之一。其他內容列在[隱私權與你的資料](/zh-Hant/privacy/)中，而[隱私權政策](https://phibrowser.com/privacy/)和[服務條款](https://phibrowser.com/terms/)是這一切的權威說明。

## 同步還是匯出

同步適合你會同時持續使用的多部 Mac。如果只是一次性搬到新的 Mac，或想自己保留一份副本，**說明**選單中的<strong>管理使用者資料 → 匯出使用者資料…</strong>是更合適的工具；請見[匯入與匯出](/zh-Hant/import-export/)。
