# 同步

同步會讓 Phi 自己的資料，在每一部登入同一個 Phi 帳號的 Mac 上保持一致。在一部 Mac 上儲存書籤或重新命名空間，變更就會出現在其他 Mac 上。同步要在每一部 Mac 上設定後才會開啟，而且它的設計讓我們無法讀取它傳送的內容：所有資料在上傳前都會先在你的 Mac 上加密，使用的金鑰只有你的 Mac 持有。

本頁說明的所有功能都位於**設定 → 同步**。

## 會同步的內容 {#what-syncs}

| 項目                       | 說明                                                                                                                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **空間**                   | 名稱、圖示、顏色、主題，以及每個空間屬於哪個設定檔。                                                                                                                     |
| **設定檔**                 | 設定檔名稱，以及每個設定檔底下有哪些空間。                                                                                                                               |
| **書籤與資料夾**           | 每個空間的書籤，包括資料夾結構與排列順序。                                                                                                                               |
| **釘選分頁**               | 釘選分頁，依照你在**設定 → 空間**中選擇的範圍。                                                                                                                          |
| **網址規則**               | 把符合的網站導向某個空間、無痕模式或 Kiosk 的規則。                                                                                                                      |
| **支援的設定**             | 版面配置模式、外觀、主題與選取色調、書籤列和完整網址設定、**新分頁行為**（按 ⌘T 時開啟的內容）、無痕模式的關閉警告、自動子母畫面、釘選分頁範圍，以及哪個空間是預設空間。 |
| **瀏覽資料，依設定檔區分** | 瀏覽歷史記錄、瀏覽器本身的偏好設定（例如預設搜尋引擎），以及擴充功能和它們已同步的設定。                                                                                 |

::: warning 刪除也會同步
在一部 Mac 上刪除空間或設定檔，所有與它同步的 Mac 上也會一併刪除，書籤也包括在內。Phi 會在確認對話框中說明這一點，所以確認前請先讀過。
:::

有些內容刻意留在原處：

- **密碼、Cookie 和自動填入資料。** 它們永遠不會進入同步。Phi 沒有自己的密碼管理工具，而你透過 [AI 代理密碼管理員](/zh-Hant/agent-passwords/)連接的密碼庫屬於它的供應商，依照該供應商的條款同步。
- **開啟中的分頁。** 一般開啟中的分頁不會在另一部 Mac 上重新建立。釘選分頁則會。
- **Phi Chat 和記憶。** 你與助理的對話會留在進行對話的那部 Mac 上，[記憶](/zh-Hant/memory/)也一樣。
- **無痕空間**，以及 AI 代理工作時使用的空間。其中的任何內容都不會同步。把網站導向無痕模式的網址規則仍然是一條規則，所以會像其他規則一樣同步。
- **鍵盤快速鍵。** 你在**設定 → 快速鍵**中設定的內容，會留在你設定它的那部 Mac 上。
- **只屬於單一 Mac 的設定**，包括 AI 與 AI 代理的設定。

## 開始之前

- **一個 Phi 帳號，並在每一部 Mac 上登入。** 沒有帳號時，這個面板只會顯示**登入即可在裝置間同步**。如果你選擇了不登入直接探索，請見[之後再登入](/zh-Hant/get-started/#signing-in-later)。
- **官方版本的 Phi。** 同步透過 Phinomenon 的同步服務運作，你自行從開源程式碼建置的 Phi 無法使用它。

## 設定第一部 Mac {#set-up-your-first-mac}

1. 開啟**設定 → 同步**，按一下**在此裝置上設定同步**。視窗會說明接下來會發生什麼事；按一下**繼續**。
2. **儲存你的復原代碼。** Phi 會建立一組復原代碼，而且只顯示一次：共 27 個字元，每五個一組。按一下**複製**，把它存放在安全的地方，例如密碼管理工具，然後按一下**我已儲存**。
3. **確認你的復原代碼。** Phi 會請你輸入剛才儲存的代碼。連字號、空格和大小寫都不影響。如果你沒有儲存，請按一下**上一頁**：Phi 會再次顯示同一組代碼，讓你現在就儲存。代碼核對成功之前，同步會保持關閉，所以你不會在日後才發現它根本沒存下來。如果你在這一步關閉視窗，下次開啟設定流程或重新啟動時，Phi 會再問一次，但那時已經沒有**上一頁**按鈕，因為視窗關閉後就不會保留這組代碼。
4. **Phi 會自行設定同步。** 在第一部 Mac 上，帳號裡還沒有可以配對的內容，所以沒有需要填寫的配對頁面。Phi 會把這部 Mac 的設定檔和空間加入帳號，並在進行期間顯示**正在設定同步…**。如果 Phi 無法讀取帳號中的所有內容，則會改為顯示[加入另一部 Mac](#add-another-mac) 中的配對頁面。
5. 設定完成後，這部 Mac 上傳資料期間，面板會顯示**初次同步進行中**，完成後顯示**已是最新狀態**。

::: warning 復原代碼只會顯示一次
復原代碼在你的 Mac 上產生，永遠不會傳送給我們，所以我們無法再次顯示它、寄送替代代碼，或將它重設。要加入另一部 Mac，你需要這組代碼，或一部已經設定好的 Mac。兩者都遺失的話，沒有人能解鎖你帳號中的加密副本，我們也不例外。如果代碼已經遺失，請見[忘記復原代碼？](#forgot-your-recovery-code)
:::

## 加入另一部 Mac {#add-another-mac}

1. 登入同一個 Phi 帳號，開啟**設定 → 同步**，按一下**在此裝置上設定同步**，然後按**繼續**。
2. 在**將此裝置加入你的帳號**畫面中，選擇這部 Mac 加入的方式：
   - **向另一部裝置請求核准。** Phi 會顯示一組短代碼並開始等待。在一部已經設定好的 Mac 上開啟**設定 → 同步**：請求會出現在**裝置**底下，附上同一組代碼和請求的到期時間。確認兩組代碼相符後按一下**核准**；如果這不是你預期的請求，就按**拒絕**。這組代碼用來辨識新的 Mac，並不是機密，所以透過電話唸給對方聽也沒問題。請求被拒絕或過期時，會提供**試試其他方式**。
   - **輸入復原代碼。** 輸入你在第一部 Mac 上儲存的代碼。
3. **選擇這部 Mac 的同步方式。** 當你的帳號已有資料，而這部 Mac 也有自己的資料時，Phi 會詢問<strong>這部 Mac 要如何同步？</strong>並顯示雙方各有哪些內容：
   - **將這部 Mac 與你的帳號合併**，標示為**建議**。你會在接下來的步驟中逐一配對設定檔和空間，雙方的書籤、釘選分頁和網址規則都會保留。
   - **使用你帳號的資料**。這部 Mac 的空間、書籤、釘選分頁、網址規則和已同步的設定，會被你帳號的資料取代，你帳號中沒有的設定檔也會從這部 Mac 上刪除。只有這部 Mac 會變更，而且無法復原。選擇之前，請先閱讀[使用你帳號的資料](#use-your-accounts-data)。

   如果這部 Mac 上除了預設設定檔和預設空間之外沒有其他內容，也沒有書籤、釘選分頁或網址規則，就不會看到這個步驟。沒有任何選項能用這部 Mac 的資料覆蓋你的帳號。

4. **配對你的設定檔。** Phi 會把這部 Mac 上的設定檔與你帳號中的設定檔配對，並詢問無法自動配對的那些。這部 Mac 的預設設定檔一律會與你帳號的預設設定檔配對：它那一列會直接顯示該帳號設定檔，沒有可供挑選的選單。為這部 Mac 上的其他每個設定檔選擇**指派給**某個帳號設定檔，或選擇**註冊為新設定檔**。帳號中在這部 Mac 上沒有對應的設定檔，會列在**尚未配對的帳號設定檔**底下，按**在這部 Mac 上建立**即可加入。如果某個選擇會違反預設設定檔的規則，Phi 會顯示**這部 Mac 的預設設定檔只能與帳號的預設設定檔配對。請檢視配對內容後再試一次。**
5. **配對你的空間。** 為這部 Mac 上的每個空間挑選它對應的帳號空間，或選擇**加入為新空間**。**全部加入為新空間**會一次處理所有尚未決定的空間，名稱完全相同的空間則會自動幫你挑好。帳號中有、但這部 Mac 上沒有的空間，會出現在**將從你的帳號加入的空間**底下，並在你完成時建立。這部 Mac 上的任何內容都不會被刪除。按一下**完成**。
6. **檢視變更內容**，只有在這部 Mac 上有內容會被覆寫時才會出現。如果你把這部 Mac 上的某個空間配對到帳號中的空間，帳號裡的名稱、圖示、顏色和主題會取代這部 Mac 上的設定，而且該空間可能會移到它在帳號中所屬的設定檔。這部 Mac 上的分頁、書籤、釘選分頁和網址規則不受影響。如果想保留這部 Mac 上的設定，請按**上一頁**，改把該空間加入為新空間。按一下**套用**即可開始同步。如果沒有任何內容會被覆寫，按下**完成**後同步就會立即開始。

Phi 只會顯示有事情需要詢問你的頁面。沒有需要詢問的事項時，例如在一部只有預設資料的 Mac 上，它會自行完成並顯示**正在設定同步…**，你帳號的設定檔和空間就會出現在這部 Mac 上。

載入帳號時，Phi 需要清點你的空間，可能要花上兩分鐘，而且必須連上網路：沒有可以退而使用的快取副本。選擇**將這部 Mac 與你的帳號合併**時，同步開始後，兩部 Mac 上的書籤、釘選分頁和網址規則都會保留，所以任何一邊的內容都不會遺失。

### 使用你帳號的資料 {#use-your-accounts-data}

如果你不想保留 Phi 在這部 Mac 上的內容，例如一部只用來測試的 Mac，就選擇這個方式。Phi 會先刪除這部 Mac 上的 Phi 資料，再下載你帳號的資料。

- **從這部 Mac 移除**：預設空間以外的空間，它們開啟中的分頁也會關閉；書籤、釘選分頁、網址規則和已同步的設定；以及你帳號中沒有的每個設定檔，連同它的歷史記錄、擴充功能和網站資料。
- **保留**：這部 Mac 的預設設定檔，以及名稱與你帳號中某個設定檔相同的設定檔，都會保留它們的歷史記錄、擴充功能和網站資料。你的帳號和你的其他 Mac 不受影響。

按一下**繼續**後，Phi 會詢問<strong>要取代這部 Mac 上的資料嗎？</strong>並列出會移除和會下載的內容。按一下**取代這部 Mac 的資料**即可進行。Phi 會顯示**正在取代這部 Mac 的資料…**，視窗會保持開啟直到完成。接著你帳號的資料會隨第一次同步傳來，面板會顯示**初次同步進行中**；帳號很大時，這可能需要幾分鐘。如果取代因錯誤而中止，請見[無法完成取代這部 Mac 的資料](#replace-did-not-finish)。

::: warning 取代後無法復原
Phi 不會保留它所刪除內容的副本。如果你想要一份副本，請先選擇**稍後完成**，用<strong>說明 → 管理使用者資料 → 匯出使用者資料…</strong>匯出（請見[匯入與匯出](/zh-Hant/import-export/)和[同步還是匯出](#sync-or-export)），再回到設定流程。若要保留本機的設定檔，請改為選擇**將這部 Mac 與你的帳號合併**。
:::

### 設定流程無法載入你的帳號時 {#setup-cannot-load-account}

設定流程會先讀取你的帳號，才顯示任何選項。讀取失敗時，視窗會說明原因並提供**重試**：

- **未能及時載入你帳號的空間。** 帳號很大，或網路連線很慢。請檢查網路連線後再試一次。
- **同步目前無法使用，因此無法載入你帳號的空間。** Phi 目前無法連上同步服務。請確認你已連上網路且仍處於登入狀態，然後再試一次。
- <strong>無法載入你帳號的設定檔。</strong>或**無法載入你帳號的空間。** 請檢查網路連線後再試一次。
- 標示為**目前無法讀取**的帳號設定檔：Phi 會在背景持續重試，設定流程的其他部分仍然可以使用。
- **目前無法在這部 Mac 上讀取你帳號的預設設定檔，因此現在無法取代這部 Mac 的資料。** 在可以讀取之前，**使用你帳號的資料**無法執行。請選擇**將這部 Mac 與你的帳號合併**，或選擇**稍後完成**後再試一次。

### 稍後完成 {#finish-later}

同步方式步驟和配對頁面上會出現**稍後完成**。選擇它或關閉視窗後，這部 Mac 會繼續在本機瀏覽：不會同步任何內容，面板顯示**尚未配對**，Phi 也不會自行重新開啟設定流程。準備好時，回到**設定 → 同步**並按一下**繼續設定**。Phi 會在那時重新載入你的帳號，所以先前未完成的選擇不會保留，包括同步方式：下一次設定時，會預先選取**將這部 Mac 與你的帳號合併**。

已經開始的取代是例外。Phi 一旦開始取代這部 Mac 的資料，離開並不會取消它。如果取代中途停止，例如發生錯誤或 Phi 結束，而你也關閉了視窗，下次開啟設定流程時會直接進入**要取代這部 Mac 上的資料嗎？**，沒有**上一頁**，而**取代這部 Mac 的資料**會從中斷的地方繼續。那裡仍然提供**從同步中移除此裝置…**；選擇它會讓這部 Mac 退出同步，取代尚未移除的內容則會留在這部 Mac 上。

## 忘記復原代碼？ {#forgot-your-recovery-code}

沒有人能再次顯示你的復原代碼，或為同一份同步資料產生新的代碼，我們也不例外。你還能做什麼，取決於你的情況。**輸入你的復原代碼**頁面上的<strong>忘記復原代碼？</strong>連結會開啟這一節。

### 你仍在設定第一部 Mac

如果你正在**確認你的復原代碼**頁面，而且還沒有關閉設定視窗，請按一下**上一頁**。Phi 會再次顯示同一組代碼。把它儲存下來，按一下**我已儲存**，再輸入代碼確認。

Phi 2.14 及更早的版本沒有**上一頁**按鈕。如果你已經關閉視窗或重新啟動 Phi，代碼也已經消失了：Phi 會一直要求你輸入，卻無法顯示它。不論是哪一種情況，請視需要更新 Phi，然後依照下方的說明，使用[重設同步](#reset-sync)重新開始。

### 還有另一部 Mac 已設定同步

你不需要復原代碼。在新的 Mac 上選擇**向另一部裝置請求核准**，然後在已設定好的那部 Mac 上核准請求；請見[加入另一部 Mac](#add-another-mac)。同步會在你現有的 Mac 上繼續運作。

代碼仍然無法再次顯示或替換。請至少讓一部 Mac 保持已設定同步的狀態：只要還有一部，你就能在沒有代碼的情況下加入 Mac。

### 這是你唯一的 Mac，或你想重新開始

在那部 Mac 上使用[重設同步](#reset-sync)。它會將這部 Mac 從同步中移除，並刪除為你的帳號儲存的所有同步資料。你的本機瀏覽資料會留在這部 Mac 上，而任何仍為此帳號設定同步的其他 Mac，之後都會顯示[重新設定同步](#set-up-sync-again)。接著依照[設定第一部 Mac](#set-up-your-first-mac)，在這部 Mac 上從頭設定同步。Phi 會建立一組新的復原代碼；請先儲存它，再按一下**我已儲存**。

**重設同步**只會出現在帳號中最後一部已設定同步的 Mac 上。如果你想在其他 Mac 仍設定著同步時重新開始，請先將其他每一部 Mac 從同步中移除。

### 你手邊沒有任何一部已設定同步的 Mac

如果代碼已經遺失，而你手邊沒有任何一部已設定同步的 Mac，你帳號中的加密副本就無法解鎖，你和我們都辦不到。尚未設定同步的 Mac 也無法重設帳號的同步，所以無法從它重新開始。這也包括在已設定同步時遺失或被清除的 Mac：它仍算是已設定同步，而且無法從另一部 Mac 將它移除。

## 查看同步狀態 {#check-sync-status}

同步面板頂端會顯示目前的狀態：

- **已是最新狀態**、**正在同步…**，或在第一次同步進行期間顯示**初次同步進行中**。
- **離線**，並附註變更會在連線後同步。Phi 會繼續使用本機資料運作，等 Mac 恢復連線後再傳送你的變更。
- **同步已暫停。** 這部 Mac 上有個設定檔尚未設定同步，通常是你在完成設定後才建立的設定檔。面板會列出它正在等待的設定檔以及原因。Phi 會自行註冊它們並持續重試，按**重試**則會立即再試一次。請見[同步已暫停](#sync-paused)。
- **需要注意。** 有地方出錯了。下方會出現<strong>部分內容需要注意。請查看詳細資訊並檢查網路連線。</strong>這一行，**上次的問題**會指出最近一次的問題以及發生的時間。請見[每個問題代表什麼](#needs-attention)。

在狀態下方，**這部 Mac 上次成功同步的時間**會顯示這部 Mac 最近一次完成同步的時間。**正在等待載入設定檔**表示 Phi 還沒有讀取到這部 Mac 的設定檔清單。它會自行持續嘗試，五分鐘後狀態會變成**需要注意**。

如果你變更了釘選分頁範圍，不論是在這部 Mac 還是另一部 Mac 上，可能會出現一行**釘選分頁範圍的變更尚未套用**，附上嘗試次數和原因：**正在從其他瀏覽器移轉**、**無法使用本機瀏覽器資料**或**無法在這部 Mac 上儲存釘選分頁**。這表示這部 Mac 還沒有把釘選分頁移到新的範圍。Phi 會自行持續重試，同步的其他部分也會照常進行。如果這一行一直沒有消失，請重新啟動 Phi；如果仍然沒有消失，請使用視窗右上角選單中的**意見回饋**傳送意見回饋。

### 每個問題代表什麼 {#needs-attention}

**上次的問題**會顯示下列其中一項。它會一直保留，直到下一次完整完成的同步將它清除。

| 上次的問題                        | 代表的意思                                                               | 你該怎麼做                                                                           |
| --------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| **登入已過期**                    | 同步服務不再接受這部 Mac 的登入。                                        | 重新登入你的 Phi 帳號。                                                              |
| **沒有網路連線**                  | 這部 Mac 無法連上同步服務。                                              | 不需要做任何事。連上網路後，它會在下一次同步成功時消失。                             |
| **伺服器錯誤**                    | 同步服務傳回錯誤。                                                       | 不需要做任何事。它會在下一次同步成功時消失。                                         |
| **伺服器拒絕了變更**              | 同步服務拒絕了這部 Mac 的部分變更，例如在與另一部 Mac 反覆發生衝突之後。 | 按一下**立即同步**。如果問題再次出現，請重新啟動 Phi；若仍持續發生，請傳送意見回饋。 |
| **無法讀取這部 Mac 上的資料**     | Phi 無法讀取它自己在這部 Mac 上的部分資料。                              | 按一下**立即同步**。如果問題再次出現，請重新啟動 Phi；若仍持續發生，請傳送意見回饋。 |
| **無法在這部 Mac 上儲存同步狀態** | Phi 無法儲存它記錄哪些內容已同步的資料。                                 | 按一下**立即同步**。如果問題再次出現，請重新啟動 Phi；若仍持續發生，請傳送意見回饋。 |
| **部分同步資料無法讀取**          | 你帳號中的某些內容無法在這部 Mac 上讀取。                                | 按一下**立即同步**。如果問題再次出現，請重新啟動 Phi；若仍持續發生，請傳送意見回饋。 |
| **正在等待設定檔配對**            | 有些已同步的項目要等到這部 Mac 上的某個設定檔與你的帳號配對後才能處理。  | 等待 Phi 設定好該設定檔，或在面板顯示**同步已暫停**時按一下**重試**。                |
| **同步需要重新設定**              | 你帳號中的同步資料已被重設，這部 Mac 的設定與它不再相符。                | 按一下**重新設定同步**。請見[重新設定同步](#set-up-sync-again)。                     |

已保留的項目（說明見[詳細資訊](#sync-details)）也可能讓狀態停留在**需要注意**，而不顯示問題名稱。請見[釘選分頁遭到保留](#held-pinned-tabs)。

### 詳細資訊 {#sync-details}

**詳細資訊**會列出你的設定檔，每個設定檔附上其瀏覽資料的狀態，接著每一類 Phi 資料各有一列：**設定**、**空間**、**書籤**、**釘選分頁**和**網址規則**。每一類的那一列會說明它最近一次有變更的同步，以及那是多久以前：

| 計數         | 計算的內容                                                                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **已接收**   | 這部 Mac 從你的帳號收到的變更。                                                                                                                                    |
| **已傳送**   | 這部 Mac 上傳的變更。                                                                                                                                              |
| **等待傳送** | 這部 Mac 上尚未上傳的變更。之後的同步會把它們送出。                                                                                                                |
| **保留**     | 這部 Mac 已收到但還無法套用的項目。Phi 會保留它們直到可以套用為止，例如所屬設定檔或空間尚未在這部 Mac 上配對的釘選分頁。屬於其他釘選分頁範圍的釘選分頁不計算在內。 |

**等待傳送**和**保留**只有在不為零時才會出現。最近沒有變更的類別會顯示**最近沒有變更**。

### 立即同步 {#sync-now}

**立即同步**會要求這部 Mac 馬上同步所有內容。你很少需要用到它：另一部 Mac 有所變更時，Phi 會收到通知，它也會自行檢查，最多每分鐘一次。**立即同步**會略過這段等待。同步在等待或進行中時，按鈕會顯示進度，它的工具提示會說明正在等待什麼，例如**正在等待所有設定檔就緒**。

當你啟動的同步沒有完成時，狀態下方會出現一行說明，直到你再次按下按鈕為止：

- 如果那次同步期間有記錄到問題，會顯示上表中該問題的名稱。
- **同步未完成**，表示同步在沒有特定問題的情況下停止。請稍後再試。如果某一部 Mac 一直發生這種情況，請見[釘選分頁遭到保留](#held-pinned-tabs)。
- **無法開始同步。請稍後再試。**，表示這部 Mac 完全無法開始同步。

同步完成時不會新增任何一行，**這部 Mac 上次成功同步的時間**會更新為新的時間。

## 裝置

**裝置**區段會列出你帳號中每一部已設定的 Mac，並標示**這部 Mac**；正在等待加入的 Mac 也會列在這裡，附上它的代碼、**核准**、**拒絕**，以及請求的到期時間。要核准請求，這部 Mac 必須已經登入，而且自己的設定已經完成。

每部 Mac 只能從自己的同步面板移除自己。目前還沒有辦法移除你已經不再擁有的 Mac：遺失的 Mac 會留在帳號中，只要它仍處於登入狀態，就會繼續收到變更。如果你還能取得那部 Mac，將它登出就能停止這種情況。

## 從同步中移除 Mac {#remove-a-mac-from-sync}

在**設定 → 同步**的**移除**底下，按一下**將這部 Mac 從同步中移除**那一列的<strong>移除…</strong>，然後按**移除此裝置**確認。如果這部 Mac 尚未完成設定，設定視窗底部則會改為提供<strong>從同步中移除此裝置…</strong>。

- 這部 Mac 會停止同步，同步服務會撤銷它的授權，它的同步設定、金鑰，以及設定檔和空間的配對資訊，都會從這部 Mac 上清除。
- 你瀏覽的一切都會保留：空間、書籤、歷史記錄和釘選分頁完整保留，你也會繼續登入你的帳號。
- 你的其他 Mac 不受影響，會繼續彼此同步。
- 要讓這部 Mac 重新加入，請再次開始設定流程，並透過核准或復原代碼加入。

當這部 Mac 是帳號中唯一一部已設定同步的 Mac 時，該列會改為**重設同步**，因為移除最後一部 Mac 也會刪除帳號的同步資料。請見[重設同步](#reset-sync)。

::: warning 移除 Mac 不會更換帳號的金鑰
移除 Mac 會讓它不再收到任何新內容，但不會變更你帳號的加密金鑰，也無法收回那部 Mac 先前已經同步的內容。原本在它上面的資料會繼續留在它上面。
:::

### 重設同步 {#reset-sync}

當這部 Mac 是你帳號中唯一一部已設定同步的 Mac 時，**移除**區段會顯示**重設同步**，並附上<strong>重設…</strong>按鈕。重設會將這部 Mac 從同步中移除，並刪除為此帳號儲存的所有同步資料，讓你可以重新開始，例如在遺失復原代碼之後。

1. 在**設定 → 同步**的**移除**底下，按一下<strong>重設…</strong>。
2. Phi 會詢問<strong>要刪除此帳號的所有同步資料嗎？</strong>按一下**刪除所有同步資料**確認。此動作無法復原。

- 所有裝置都會從同步中移除，同步伺服器上為此帳號儲存的所有內容都會刪除。
- 你的本機瀏覽資料會留在這部 Mac 上：空間、書籤、歷史記錄和釘選分頁都會保留，你也會繼續登入你的帳號。
- 任何仍為此帳號設定同步的其他 Mac，都會顯示[重新設定同步](#set-up-sync-again)。
- 若要再次使用同步，請從頭設定。Phi 會建立一組新的復原代碼。

如果你從設定視窗移除這部 Mac，而它正好是最後一部，Phi 會告訴你：<strong>這是最後一部設定了同步的裝置。你可以移除它並刪除為此帳號儲存的所有同步資料，或先在另一部裝置上設定同步。</strong>接著它會提供<strong>移除此裝置並刪除所有同步資料…</strong>，並要求同樣的確認。

如果在此期間有另一部 Mac 加入了帳號，就不會刪除任何內容。Phi 會顯示<strong>在此期間已有另一部裝置加入此帳號，因此沒有刪除任何資料。你可以改為將這部 Mac 從同步中移除。</strong>同時該列會變回**將這部 Mac 從同步中移除**。

## 重新設定同步 {#set-up-sync-again}

如果面板顯示**帳號的同步資料已變更。Phi 資料的同步已暫停。**，表示你帳號中的同步資料已被重設，這部 Mac 的設定與它不再相符。在你採取行動之前，Phi 的資料會停止同步；重試或重新啟動都無法解除這個狀態。按一下**重新設定同步**並確認。Phi 會清除這部 Mac 的同步設定和配對資訊，保留你的本機瀏覽資料和帳號中的內容，並帶你重新走一次設定流程，包括透過核准或復原代碼加入。

在帳號的最後一部 Mac 上使用過**重設同步**之後，你也會在其他 Mac 上看到這個狀態，因為這些 Mac 當初設定時所用的同步資料已被刪除。

## 疑難排解 {#troubleshooting}

### 第二部 Mac 沒有收到我的鍵盤快速鍵或開啟中的分頁 {#missing-shortcuts-and-open-tabs}

這是預期中的行為。**設定 → 快速鍵**中的鍵盤快速鍵永遠不會同步，一般開啟中的分頁也不會：只有釘選分頁會同步。AI 與 AI 代理的設定也會留在各自的 Mac 上。請在每一部你想使用它們的 Mac 上分別設定。請見[會同步的內容](#what-syncs)。

### 某部 Mac 顯示同步未完成，並保留了釘選分頁 {#held-pinned-tabs}

其中一部 Mac 顯示**同步未完成**，而且它在**詳細資訊**中的**釘選分頁**那一列顯示**保留**和一個數字，另一部 Mac 則顯示**已是最新狀態**。**保留**表示這部 Mac 收到了無法放置的釘選分頁，因為它們所屬的設定檔或空間沒有在這裡配對。

常見的原因是兩部 Mac 的預設設定檔在設定時沒有彼此配對。在 Phi 2.12 上配對的 Mac 可能會發生這種情況。從 Phi 2.13 開始，設定流程一律會把預設設定檔與你帳號的預設設定檔配對。

目前的修正方式是：在保留釘選分頁的那部 Mac 上，[將這部 Mac 從同步中移除](#remove-a-mac-from-sync)，然後依照[加入另一部 Mac](#add-another-mac) 重新設定。如果 Phi 詢問這部 Mac 要如何同步，請選擇**將這部 Mac 與你的帳號合併**。在這個過程中，書籤、歷史記錄和其他所有內容都會留在這部 Mac 上，而它的預設設定檔會與你帳號的預設設定檔配對。

### 同步已暫停，或正在等待設定檔配對 {#sync-paused}

你在設定同步之後建立的設定檔尚未配對。Phi 會自行向你的帳號註冊它，完成後該設定檔的同步就會開始。同步面板中的**重試**會立即再試一次。如果暫停狀態一直沒有解除，請檢查網路連線，並確認你仍處於登入狀態，然後再按一次**重試**。

### 同步顯示需要注意 {#sync-needs-attention}

**上次的問題**會指出出了什麼問題。[每個問題代表什麼](#needs-attention)列出了所有問題以及對應的處理方式。

### 無法完成取代這部 Mac 的資料 {#replace-did-not-finish}

如果你選擇**使用你帳號的資料**後，設定流程因<strong>無法完成取代這部 Mac 的資料。</strong>而停止，請按一下**重試**。重試會從中斷的地方繼續，完成之前其他內容都不會變更。執行期間請讓 Phi 保持開啟；帳號很大時，可能需要幾分鐘。如果你關閉視窗，下一次設定會繼續同一個取代作業，如[稍後完成](#finish-later)中所述。

### 配對後，空間的名稱、圖示、顏色或主題改變了 {#account-values-replaced}

這是預期中的行為。當你把這部 Mac 上的空間配對到你帳號中的空間時，會以帳號的名稱、圖示、顏色和主題為準，而**檢視變更內容**會在你按一下**套用**之前顯示這一點。若想保留這部 Mac 的版本，請在那時按**上一頁**，並為該空間選擇**加入為新空間**：它之後就會以獨立的空間同步。配對套用後，這部 Mac 原本的設定值就不會保留，所以如果想要恢復，請手動重新設定該空間的樣式；這項變更也會同步到你的其他 Mac。

## 登出

登出你的 Phi 帳號後，那部 Mac 上的同步就會停止，在你重新登入之前，其他 Mac 的內容都不會傳過來。重新登入同一個帳號後，同步會從中斷的地方繼續，並補上錯過的內容；如果還有需要完成的步驟，同步面板會告訴你。切換到另一個帳號時，兩個帳號的資料永遠不會混在一起：每個帳號都有自己的同步資料和自己的配對資訊。

## 你的資料如何受到保護

- **離開你的 Mac 之前就已加密。** 金鑰由你的 Mac 建立，上傳的只有加密後的副本。同步服務會儲存它並轉交給你的其他 Mac，但無法將它解密。
- **光是登入還不足以讀取它。** 新的 Mac 只能透過已持有金鑰的 Mac 核准，或透過你的復原代碼取得金鑰。這也是為什麼遺失的代碼無法找回：設定流程中的<strong>忘記復原代碼？</strong>連結會說明你有哪些選擇，但沒有任何一種能讓代碼回來。
- **它仍然是我們替你保管的資料。** 加密副本存放在 Phinomenon 的同步服務上，所以同步也是 Phi 會傳送出去的內容之一。其他內容列在[隱私權與你的資料](/zh-Hant/privacy/)中，而[隱私權政策](https://phibrowser.com/privacy/)和[服務條款](https://phibrowser.com/terms/)是這一切的權威說明。

## 同步還是匯出 {#sync-or-export}

同步適合你會同時持續使用的多部 Mac。如果只是一次性搬到新的 Mac，或想自己保留一份副本，**說明**選單中的<strong>管理使用者資料 → 匯出使用者資料…</strong>是更合適的工具；請見[匯入與匯出](/zh-Hant/import-export/)。
