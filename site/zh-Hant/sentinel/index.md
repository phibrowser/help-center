# Phi Sentinel

Phi Sentinel 負責管理 Phi 在你 Mac 上的背景服務。助理所做的許多事都發生在瀏覽器視窗之外：執行排程任務、建立你的記憶、搜尋你連接的資料，以及把 AI 請求送到該去的地方。這些工作由一組在背景執行的服務完成，而 Phi Sentinel 讓它們保持正常運作。

它會隨 Phi Browser 一起安裝，平常你不需要對它做任何事。在 Phi Chat 的設定中，這些服務就叫做**背景服務**。

## 它的工作 {#what-it-does}

### 執行背景服務 {#running-background-services}

Phi Sentinel 內部有一個名為 **Runner** 的程序，它唯一的工作就是管理背景服務。它負責：

- **啟動並看顧服務**。它會在需要時啟動每項服務、定期檢查服務是否正常，並在出問題時重新啟動。
- **更新**。它會在背景下載並安裝服務的新版本。它會先檢查每次更新的簽章，如果新版本無法正常執行，就回到前一個版本。
- **傳遞你的設定**。它會把你在設定中做的選擇，例如[私有 AI](/zh-Hant/private-ai/) 中的任務來源，交給需要這些設定的服務。

Runner 只負責讓服務持續執行，不會處理你的內容：你的對話、頁面和資料都由服務本身處理，永遠不會經過 Runner。

它管理的服務包括：

- **助理服務**，保存你的對話和任務，並執行排程任務與背景任務。
- **記憶服務**，從你的瀏覽建立你的記憶。
- **資料索引服務**，為你連接的資料建立索引，讓資料搜尋找得到它們。
- **AI 閘道**，把每個 AI 請求送到你為它選擇的來源。預設是 Phi Cloud；開啟私有 AI 後，也可以是本機模型或你自己的供應商。
- **AI Guardrail**，在這部 Mac 上檢查文字中是否有敏感資訊。請見下方說明。
- **本機模型**，只有在你設定私有 AI 之後才會安裝並執行。

### 讓機密不進入記憶 {#ai-guardrail}

**AI Guardrail** 是在你 Mac 上執行的偵測服務。記憶服務在儲存新內容之前，會先請 AI Guardrail 檢查。如果發現密碼、API 金鑰、私密金鑰、復原詞組或復原碼之類的機密，整個項目都不會加入你的記憶。

- 檢查完全在這部 Mac 上進行。被檢查的內容不會送到任何地方。
- 它只會把機密排除在外，絕不改寫任何內容。姓名和電話號碼等一般個人資料會照常儲存，你可以在[記憶](/zh-Hant/memory/)中檢視和刪除它們。

### 保存你的資料 {#keeping-your-data}

這些服務會把資料保存在你 Mac 上的本機資料庫中：你的對話、你的任務及其執行記錄、你的記憶，以及你所連接資料的索引。

在 Phi Chat 的**設定 → 備份與更新**中，你可以：

- **匯出資料**，儲存一份設定和資料的副本，以便搬到另一部 Mac。不包含供應商的 API 金鑰。
- **本機快照**，在這部 Mac 上儲存一份日後可以回復的副本。快照永遠不會離開這部 Mac。

### 在瀏覽器關閉後讓任務繼續執行 {#keeping-tasks-running}

[排程任務](/zh-Hant/automation/#scheduled-tasks)必須依自己的排程執行，不論瀏覽器視窗是否開著。因為 Phi Sentinel 與瀏覽器分開執行，所以每隔幾小時查一次價，或你正在監看的頁面，在你關閉瀏覽器視窗後都會繼續進行。

## 查看背景服務的狀態 {#checking-status}

開啟 Phi Chat 的設定：

- **一般**會顯示背景服務是否正常執行、你使用的版本，並提供**重新啟動背景服務**。
- **服務**會顯示每項服務的狀態。當它顯示**一切運作正常**時，就不需要做任何事。
- **記錄**用於出了問題、你想回報的時候。按一下**診斷記錄**旁的**儲存**，Phi 會在你的「下載項目」資料夾中儲存一個 ZIP 檔，你可以把它傳送給 Phi 支援團隊。

在瀏覽器的**設定 → Phi 與 AI → Phi Sentinel** 中，你可以選擇是否要**登入 Mac 時啟動 Phi Sentinel**，以及是否要**用 Shift Shift Shift 召喚 Phi Chat**（請見 [Phi Chat](/zh-Hant/phi-chat/#opening-phi-chat)）。
