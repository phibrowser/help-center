# 常見問題

依主題分類的 Phi Browser 常見問題快速解答。想瞭解整體脈絡，以及 Phi 這樣設計背後的「為什麼」，請閱讀[指南](/zh-Hant/what-is-phi-browser/)。第一次使用 Phi Browser？請見[開始使用](/zh-Hant/get-started/)。

## 版面配置與導覽

::: details 三種版面配置模式是什麼？
Phi 有三種模式，在頁面空間和熟悉感之間取捨。**效能**把最多空間留給頁面，用垂直側邊欄容納分頁和書籤。**平衡**保留側邊欄，但在內容上方加上網址列。**舒適**最接近傳統瀏覽器，分頁在上方，網址列清楚可見。你會在新手引導時選擇一種，之後隨時可以更改。
:::

::: details 我該從哪種版面配置開始？
如果你正從 Chrome 或 Safari 轉換過來，先用**舒適**最容易上手。如果你想要有可見網址列的現代側邊欄瀏覽器，試試**平衡**。如果你想把頁面空間拉到最大，就用**效能**。完整的轉換指南請見[改用 Phi](/zh-Hant/switching-to-phi/)。
:::

::: details 為什麼用垂直側邊欄？
現代螢幕大多是寬而不高。閱讀、寫作或做研究時，最先不夠用的是垂直空間，所以垂直側邊欄更能善用現代顯示器的形狀，也為真正的頁面留下更多空間。
:::

## 空間與設定檔

::: details 空間和設定檔有什麼差別？
**空間**是側邊欄中的工作空間，有自己的名稱、圖示、顏色和書籤。**設定檔**是位於底下的隔離層：每個設定檔都有自己的 Cookie、歷史記錄、登入資訊和擴充功能。空間決定外觀和使用感受的組織方式；設定檔決定哪些東西彼此隔離。完整說明請見指南中的[空間與設定檔](/zh-Hant/spaces/)。
:::

::: details 一個設定檔可以有多個空間嗎？
可以。每個空間只屬於一個設定檔，但一個設定檔可以支撐多個空間。共用同一個設定檔的空間會共用相同的登入狀態。它們是否共用釘選分頁，取決於你選擇的釘選分頁範圍。想讓兩個空間完全隔離（包括 Cookie 和已登入的帳號），就給它們不同的設定檔。
:::

::: details 如何建立空間？
從側邊欄的空間列建立空間。幫它取個名字，並選擇它所屬的設定檔；如果這個空間需要完全獨立，也可以在那裡選擇**新增設定檔**。
:::

::: details 切換空間時會發生什麼事？
側邊欄的分頁、書籤和主題會切換成該空間的內容，Phi 也會帶出該空間的視窗（必要時會新開一個）。釘選分頁會依你在**設定 → 空間**中選擇的範圍（空間、設定檔或 App）而改變或保持顯示。
:::

::: details 每個空間都有自己的書籤和主題嗎？
是的。每個空間都有一組獨立的書籤，可以使用自己的顏色主題，也可以選擇**跟隨全域**。你還可以從空間的選單重新命名空間、更改它的圖示。
:::

::: details 什麼是網址規則？
網址規則會把符合條件的網站在一般空間、無痕模式或 Kiosk 中開啟，無論你在哪裡點選或輸入連結。規則可在**設定 → 導覽**中管理。你可以用網域後綴、完全相符的網域、「網域包含」，或主機加路徑前綴來比對。把規則設為**每次都詢問**，Phi 就不會默默導向，而是先詢問：**要在哪個空間開啟？**
多條規則同時符合時，以最精確的一條為準。
:::

::: details 刪除空間會發生什麼事？
刪除空間也會一併移除屬於它的書籤和網址規則。此操作無法復原。屬於該空間的空間範圍釘選分頁也會被移除；設定檔範圍和 App 範圍的釘選分頁會保留。移除空間並不會刪除設定檔，以及其中的 Cookie、歷史記錄和登入資訊。
:::

::: details 這和 Arc、Dia 有什麼不同？
Phi 把**空間**維持為可見的工作空間層，把**設定檔**維持為底下的隔離層。這與 Arc 的雙層模型接近，而 Dia 則更直接地把設定檔當成獨立視窗中的工作空間。完整比較請見[改用 Phi](/zh-Hant/switching-to-phi/)。
:::

## 無痕空間

::: details 什麼是無痕空間？
側邊欄中的私密空間。它會像其他空間一樣出現在空間列，但背後是一個存放在記憶體中的工作階段，關於它的任何內容都不會寫入磁碟。用**檔案 → 新增無痕空間**開啟；只開一個時名稱是**無痕**，同時開啟多個時會編號為**無痕 1**、**無痕 2**，依此類推。完整說明請見指南中的[無痕空間](/zh-Hant/incognito/)。
:::

::: details 無痕空間彼此會共用工作階段嗎？
會。所有開啟中的無痕空間共用同一個私密工作階段，所以在其中一個登入某個網站，其他無痕空間也會是登入狀態。這個工作階段與你的一般設定檔分開，也與傳統的**新增無痕視窗**分開，後者的工作階段絕不會與它混在一起。
:::

::: details 無痕空間中有哪些功能無法使用？
書籤和釘選分頁不會顯示也無法建立，助理對話和記憶按鈕無法使用，匯入瀏覽器資料會被封鎖，而且只有你允許在無痕模式中執行的擴充功能會生效。主題固定為 Phi 的深色無痕外觀；圖示可以更改，但這個選擇會隨空間一起消失。
:::

::: details 關閉無痕空間時會發生什麼事？
Phi 會先確認：**「這也會關閉這個無痕空間，確定要繼續嗎？」**（勾選**不要再詢問**之後就不再出現），接著關閉該空間的視窗，並把它從空間列移除。當最後一個無痕空間視窗關閉或 Phi 結束時，共用的私密工作階段就會被銷毀。你下載的檔案會留在 Mac 上。
:::

::: details 網址規則可以把網站導向無痕空間嗎？
可以。網址規則編輯器在你的一般空間和 Kiosk 之外，提供一個通用的**無痕**目標。規則絕不會指向特定的無痕空間，因為無痕空間只在開啟期間存在。當這類規則符合時，Phi 會使用現有的無痕空間，或視需要開啟一個新的。導向是單向的：規則絕不會把私密工作階段中的瀏覽拉回一般空間。
:::

::: details 擴充功能可以在無痕空間中使用嗎？
除非你逐一允許，否則不行，這一點與所有以 Chromium 為基礎的瀏覽器相同。私密工作階段一律建立在你的預設設定檔上，所以只有該設定檔的擴充功能能在其中執行。在預設設定檔的視窗中，從擴充功能選單選擇**管理擴充功能**（或輸入 `phi://extensions`），開啟該擴充功能的**詳細資料**，然後開啟**允許在無痕模式中執行**。安裝在其他設定檔上的擴充功能絕不會出現在無痕空間中，而且無法從私密工作階段內安裝新的擴充功能。
:::

::: details 時光機備份會包含無痕空間嗎？
不會。快照完全排除無痕空間，因為它們的工作階段本來就應該隨視窗一起消失，所以回復備份絕不會把無痕空間帶回來。
:::

## 書籤與分頁

::: details 為什麼書籤在 Phi 裡感覺不一樣？
Phi 把書籤當成使用中瀏覽工作空間的一部分，而不是一年打開兩次的隱藏檔案庫。儲存的頁面會留在側邊欄中，隨時可見、隨時可用，而不是埋在選單深處。
:::

::: details 舒適模式下書籤怎麼運作？
舒適模式的行為和 Chrome 很接近。若要顯示書籤列，請用**顯示方式 → 一律顯示書籤列**。選單列上也有**書籤**選單，在每一種版面配置模式中都可以使用。
:::

::: details 平衡和效能模式下書籤怎麼運作？
這些模式沒有傳統的書籤列。取而代之的是把分頁拖曳進側邊欄來加入書籤。側邊欄會成為你整理頁面的主要地方。
:::

::: details 為什麼分頁和書籤放在同一個側邊欄？
它們是同一件事的兩端：你在乎的頁面。分頁是你現在正在用的；書籤是你已經儲存的。把它們放在一起，反映了你在這兩種狀態之間不斷切換的實際情況。
:::

::: details 釘選分頁和書籤有什麼差別？
釘選分頁位於側邊欄頂端，放的是你長時間停留的頁面，例如常用工具或儀表板。書籤位於其下，儲存你想留待之後使用、但不需要一直開著的頁面。
:::

::: details 點選書籤時會發生什麼事？
它會在原位開啟：書籤在側邊欄的項目會直接變成它的即時分頁，而不是另外生出一個用完即丟的分頁。如果該書籤已經開啟，點選只會切換到那個分頁，不會再開第二份。關閉頁面後，書籤仍會留在側邊欄，隨時可以重新開啟。
:::

::: details 書籤和釘選分頁是以空間為單位嗎？
書籤一律以空間為單位，每個空間都有自己的一組。釘選分頁可以限定在單一空間、由使用同一個設定檔的空間共用，或整個 App 共用。範圍在**設定 → 空間**中選擇，預設值是**設定檔**。請見[書籤與釘選分頁](/zh-Hant/bookmarks/#choose-a-pinned-tab-scope)。
:::

::: details 如何釘選或取消釘選分頁？
在分頁上按右鍵選擇**釘選**，或把它拖曳到側邊欄頂端的釘選區。**取消釘選**會讓它回到分頁列表。釘選分頁可以拖曳重新排序，也可以用**釘選分割畫面**把雙欄配置保存為單一釘選項目。
:::

::: details 如何讓釘選分頁或書籤回到原本的頁面？
連按兩下釘選分頁，或點選以分頁形式開啟的書籤的網站圖示。若要保留目前的頁面，請按住 **Command（⌘）** 再連按兩下釘選分頁或點選書籤的網站圖示。目前的頁面會移到分頁列表成為獨立分頁，而釘選分頁或書籤則回到它原本的網址。
:::

::: details 這和 Arc 或 Dia 類似嗎？
類似。Phi 採用同樣的「活側邊欄」大方向：儲存的頁面保持可見，釘選的頁面位於頂端，同時保留自己的書籤樹和行為方式。轉換比較請見[改用 Phi](/zh-Hant/switching-to-phi/)，功能細節請見[書籤與釘選分頁](/zh-Hant/bookmarks/)。
:::

## 分割畫面與分頁群組

::: details 我該怎麼理解分頁、分割畫面和分頁群組？
分頁是你目前開啟的頁面。分割畫面讓兩個頁面並排顯示。分頁群組把相關頁面依專案或主題收在一起。
:::

::: details 什麼是分割畫面？
分割畫面讓你在同一個 Phi 視窗中把兩個頁面並排放置，適合邊讀邊寫、比較兩個頁面，或把說明文件放在網頁應用程式旁邊。
:::

::: details 如何建立分割畫面？
在分頁、書籤或釘選分頁上按右鍵，選擇**以分割畫面開啟**，或把分頁拖曳到目前的頁面上。你也可以按住 **Option（⌥）** 點選釘選分頁、書籤或網頁上的連結，Phi 就會在目前分頁旁以分割畫面開啟它。
:::

::: details 什麼是分頁群組？
分頁群組讓你把相關分頁收進一個有名稱的群組，很適合專案、旅行、研究主題或購物行程。
:::

::: details 分割畫面和分頁群組怎麼搭配使用？
它們就是設計來一起使用的：你可以在群組內使用分割畫面，也可以把分割的分頁移進或移出群組，讓相關工作維持有條理，而不是散落成一堆零散分頁。
:::

::: details 助理能理解分割畫面或整個分頁群組嗎？
能。從分割畫面發起對話時，Phi 可以使用兩個頁面的上下文；從分頁群組發起時，它可以使用整個群組的上下文，所以你可以直接跨相關頁面提問，不必先解釋你的配置。
:::

::: details 分頁群組和書籤是同一回事嗎？
不是。分頁群組整理的是你正在使用的頁面；書籤儲存的是留待之後使用的頁面。
:::

## AI 功能 {#ai-features}

::: details AI 預設是開啟的嗎？
是。Phi 出廠即預設啟用 AI 功能，因為它們是產品的核心部分。如果你偏好單純的瀏覽器，可以把它們關閉。
:::

::: details 可以關閉所有 AI 功能嗎？
可以，位置在**設定 → Phi AI**。關閉 AI 會關閉你的 AI 對話，並中斷所有外部資料連接器的連線。你的記憶仍會留在裝置上；若要一併清除，請使用記憶頁面上的清除選項，而且這項刪除是永久的。
:::

::: details AI 主要由哪些部分組成？
四個部分，各司其職：**記憶**、**助理**、**代理式**能力，以及**瀏覽器 Skill**。
:::

::: details 什麼是 Phi 記憶？
Phi 記憶是隨著時間從你的瀏覽行為建立上下文的系統，全程自動，不需要手動設定。
:::

::: details 我需要手動儲存記憶嗎？
不需要。記憶是自動的。Phi 會觀察相關的瀏覽行為，在背景為你建立上下文。
:::

::: details Phi 記憶儲存在哪裡？
就在你的裝置本機。本機優先的儲存方式是核心設計原則。
:::

::: details 我可以查看或管理 Phi 記住的內容嗎？
可以。你可以直接在 Phi 中檢視、管理和刪除你的記憶資料。
:::

::: details Phi 會把我的記憶傳送到它的伺服器嗎？
不會。記憶資料留在本機。語言模型可能會處理任務，但你的個人記憶不會被送出去儲存或用於訓練。
:::

::: details Phi 會用我的資料訓練 AI 模型嗎？
不會。Phi 不會用你的記憶資料、瀏覽上下文或 AI 互動來訓練模型。
:::

::: details 什麼是助理？
你在瀏覽器裡直接互動的夥伴。你會在新手引導時幫它取名字，它會為自己產生相配的頭像，之後你就用那個名字稱呼它，所以它有自己的身分，而不像一個千篇一律的聊天機器人。
:::

::: details 如何與助理交談？
點選**對話**按鈕：在效能模式中它位於側邊欄底部，在平衡和舒適模式中位於頁面標頭的右上角。或者在頁面上選取文字後按右鍵，選擇**向〔你的助理〕詢問…**，就能在上下文中詢問。
:::

::: details 助理能做什麼？
它可以回答問題、摘要內容、解釋頁面、協助處理任務，運用的上下文來自目前的分頁、你的 Phi 記憶，以及你連接的外部資料。
:::

::: details 「代理式」是什麼意思？
意思是這個 AI 不只會回答問題。它可以在瀏覽器裡採取行動、替你執行任務，從一次性的操作到重複執行的自動化都包括在內。
:::

::: details 什麼是隨選動作？
你提出要求時助理才執行的任務，例如替你瀏覽頁面或與網站互動。
:::

::: details 什麼是排程任務？
按照你定義的排程重複執行的自動化，例如監控某項商品的價格，或盯著某個頁面看有沒有變動。
:::

## Phi Sentinel

::: details 什麼是 Phi Sentinel？
Phi Sentinel 是 Phi Browser 的背景 AI 調度中心。它會執行排程任務並保存你的 AI 任務歷史記錄，常駐在 macOS 選單列運作。
:::

::: details 為什麼 Phi Sentinel 和瀏覽器分開？
這樣即使瀏覽器視窗已經關閉，排程任務和持續性的 AI 工作流程仍能繼續執行。
:::

::: details 為什麼要這樣設計？
讓瀏覽器保持輕量，同時維持一個常駐的自動化層，整個系統會更實用。
:::

## Phi Link

::: details 什麼是 Phi Link？
Phi Link 把 Phi Browser 連接到 Telegram，讓你在手機上使用你的助理，離開 Mac 時也能收到任務更新。
:::

::: details 如何設定 Phi Link？
兩種方式：使用官方 Phi Link 機器人，這是最簡單的方式，掃描 QR Code、再點一下就完成；或透過 BotFather 建立你自己的 Telegram 機器人，把它的權杖貼進 Phi 的設定。
:::

::: details Phi Link 能做什麼？
與你的助理對話、在任務成功或失敗時收到通知，以及在離開瀏覽器時接續工作流程。
:::

::: details Phi Link 用的是同一個助理身分嗎？
是。同一個助理身分會延續過去，讓桌面和手機的體驗一致；如果你使用自己的機器人，還可以進一步自訂。
:::

## 價格與供應情況

::: details Phi 是免費的嗎？
是，目前免費。Phi Browser 現階段可免費使用，AI 的用量也包含在內。
:::

::: details Phi 會永遠免費嗎？
大概不會一直是完全相同的形式。未來可能會為進階功能引入收費。
:::

## 隱私權與資料

::: details Phi 的隱私權模式是什麼？
Phi Browser 以本機優先的架構打造：Phi 記住的內容留在你的裝置上，也不會用於訓練。
:::

::: details Phi 絕對不會收集什麼？
Phi 絕不會收集你的記憶資料、你的 AI 互動或你的瀏覽上下文，也不會把它們用於訓練。

Phi 會傳送一小組永遠開啟的匿名計數（有多少安裝把 Phi 設為預設瀏覽器、使用空間、使用設定檔，以及發生過當機），另外只有在你主動開啟時，才會傳送詳細的使用統計資料和當機報告。請見 [Phi 會傳送的資料](/zh-Hant/privacy/#what-phi-does-send)。
:::

::: details 我的記憶存放在本機嗎？
是。你的記憶資料存放在你的裝置上，你可以檢視、管理和刪除它。
:::

::: details Phi 會販售我的瀏覽記錄，或用它訓練模型嗎？
不會。Phi 不會用源自瀏覽的記憶或 AI 互動來訓練模型，也不會販售你源自瀏覽的資料。
:::

::: details Phi 會收集使用統計資料嗎？
會。只有在**協助改善 Phi 的功能和效能**開關開啟時，Phi 才會把匿名使用統計資料傳送給 Phinomenon，而這個開關出廠時是開啟的。統計資料只與瀏覽器本身有關：哪些功能被使用、App 的效能表現如何。其中絕不包含你造訪的頁面、你的記憶或你的 AI 對話。報告帶有一個隨機的安裝識別碼，與你的 Phi 帳號完全無關。請見[隱私權與你的資料](/zh-Hant/privacy/#usage-statistics)。
:::

::: details 如何關閉使用統計資料？
開啟 `phi://settings`，在**你與 Phi** 區段關閉**協助改善 Phi 的功能和效能**，然後點選隨即出現的**重新啟動**按鈕讓變更生效。關閉這個開關也會刪除先前報告所附的隨機識別碼；之後若再開啟，Phi 會建立一個新的。
:::

## 時光機備份

::: details 什麼是 Phi 的時光機？
它是一道**版本回復**的安全網。在某些重大更新之前，Phi 會自動保存目前版本和資料的快照，讓你在新版本不合用時可以回到原狀。完整說明請見指南中的[時光機備份](/zh-Hant/time-machine/)。
:::

::: details 這是 Apple 的時光機嗎？
不是。它不會備份你的 Mac，與 macOS 上同名的功能無關。它只會把 Phi 回復到先前的版本。
:::

::: details 它會隨時備份我的瀏覽內容嗎？
不會。它不是連續備份，也不是排程備份。快照只會偶爾自動建立，時間點是在風險比平常高的更新之前，而且每次這類更新只建立一次。如果你想要一份由自己掌控的備份，請改用**匯出使用者資料**。
:::

::: details 快照包含哪些內容？
屬於前一個版本的 Phi 資料，也就是書籤、空間、釘選分頁、設定、記憶和瀏覽狀態，外加要回復到哪個 App 版本的記錄。App 本身會在回復時下載，因此回復後會得到一套前後一致的環境。
:::

::: details 快照儲存在哪裡？
就在你的 Mac 本機。它們不會上傳到雲端、不會綁定你的帳號，也無法移到另一部 Mac。
:::

::: details 如何回復？
打開**說明**選單，選擇**時光機備份**，挑選一份快照（依版本、組建編號和日期列出，例如 _Phi 1.6 (590)，2026.6.11_）。確認**回復**後，Phi 會下載先前的版本、替換目前的 App 和相對應的資料，然後重新啟動。回復期間需要網際網路連線。如果沒有任何快照，選單會顯示**沒有可用的備份**。
:::

::: details 這和匯出我的資料有什麼不同？
時光機會自動處理更新的回復。若要建立並保留你自己的備份，例如搬到新的 Mac 或留一份個人副本，請使用**說明**選單中的**管理使用者資料**（**匯出使用者資料…**、**匯入使用者資料…**）。
:::
