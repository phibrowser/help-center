# Phi Browser 快速技巧

本頁整理了在介面上較不容易發現的 Phi 手勢與快速鍵。這裡列出的鍵盤快速鍵皆為預設值，你可以在 **設定 → 快速鍵** 中變更。

## 快速鍵一覽

| 動作                   | 快速鍵或手勢                                                     |
| ---------------------- | ---------------------------------------------------------------- |
| 建立分割畫面           | 按住 Option (⌥) 並按一下分頁、釘選分頁、書籤或符合條件的網頁連結 |
| 在最近使用的分頁間切換 | Control (⌃) + Tab                                                |
| 以相反順序切換         | Control (⌃) + Shift (⇧) + Tab                                    |
| 拷貝目前頁面的網址     | Command (⌘) + Shift (⇧) + C                                      |
| 搜尋開啟中的分頁       | Command (⌘) + Shift (⇧) + A                                      |
| 移至上一個或下一個空間 | Command (⌘) + Option (⌥) + ← 或 →                                |
| 開啟前九個空間之一     | Control (⌃) + 1 到 9                                             |

## 建立分割畫面

- 按住 Option (⌥)，再按一下另一個分頁、群組中的分頁、釘選分頁、書籤，或符合條件的網頁連結，Phi 會把它放在目前頁面旁邊。
- 將單一分頁、釘選分頁或書籤拖曳到目前頁面的左側或右側。你放在哪一側，它就出現在哪一側。
- 把項目放到現有未釘選分割畫面的某個窗格上，即可取代該窗格。

## 回到儲存的網址

釘選分頁或書籤可能會從你原本儲存的網址瀏覽到別的頁面。你可以在不失去目前頁面的情況下回到原點。

- 按兩下釘選分頁，即可讓它回到儲存的網址。
- 按一下書籤的網站圖示，即可讓它回到儲存的網址。
- 使用上述任一手勢時按住 Command (⌘)，會先把目前頁面保留為獨立分頁，再回復儲存的網址。

## 使用群組總覽

按一下分頁群組的標題即可開啟群組總覽。它會顯示每個頁面的快照，分割畫面則合併顯示為一張卡片。

在群組總覽中，你可以切換到某個頁面、關閉頁面、建立新分頁，或更改群組的名稱與顏色。若在群組總覽開啟時使用網址列，新分頁會加入該群組。

將整個分頁群組拖曳到書籤區域，即可把它變成書籤資料夾。Phi 會保留其中分頁的順序並解散群組，但開啟中的分頁仍會維持開啟。

## 同時操作多個分頁與書籤

- 按住 Command (⌘) 並按一下一般分頁和書籤，可逐一選取。
- 按住 Shift (⇧) 並按一下，可選取一段範圍。
- 可用的動作包括建立分頁群組、把項目加入書籤資料夾、把它們移至或複製到另一個空間，以及關閉它們。
- 拖曳任一選取的項目即可移動整個選取範圍。分割畫面的兩側會保持在一起。
- 按下 Esc 鍵可取消選取。

## 切換、搜尋與拷貝

Control (⌃) + Tab 依照最近使用的順序切換，而不是視窗中分頁的排列順序。

- 按一次可在目前分頁與上一個分頁之間切換。
- 按住或連續按下，最多可顯示五個最近使用的分頁。
- 加上 Shift (⇧) 可反向瀏覽清單。
- 按下 Command (⌘) + Shift (⇧) + A 可搜尋所有開啟中的分頁。
- 按下 Command (⌘) + Shift (⇧) + C 可拷貝目前分頁的網址。

## 個人化每個空間

開啟 **設定 → 空間**，然後選擇一個空間。

- 從 Phi 內建的圖示組中挑選圖示，或使用表情符號。
- 選擇主題顏色並調整其飽和度。

每個空間都保留自己的圖示與主題。切換空間時，只會套用你為該空間選擇的外觀，不會改變其他空間。

## 在空間之間移動

- 按下 Command (⌘) + Option (⌥) + ← 或 → 可移至上一個或下一個空間。
- 按下 Control (⌃) + 1 到 9 可直接開啟前九個空間之一。

## 用網址規則安排網站去向

從選單列開啟 **空間 → 網址規則…**，或在 **設定 → 空間** 中開啟網址規則。規則可依 **網域後綴**、**網域**、**網域包含** 或 **網址** 比對。

比對成功的頁面可以送往一般空間或無痕空間。若希望 Phi 在移動頁面前先詢問你，請選擇 **每次都詢問**。多條規則同時符合時，以最具體的規則為準。

::: tip 空間路由不會隔離 Cookie
網址規則只決定頁面在哪裡開啟。若要讓 Cookie 與已登入的工作階段互相隔離，請把目標空間指派給不同的設定檔。
:::

## 用子母畫面讓影片持續顯示

當你切換分頁或空間時，Phi 可以把播放中的影片彈出顯示。請在 **設定 → 一般 → 自動子母畫面** 中選擇行為。

| 模式           | 行為                                                         |
| -------------- | ------------------------------------------------------------ |
| **關閉**       | 永不自動開啟子母畫面。手動子母畫面仍可使用。                 |
| **一般**       | 切換分頁或空間時，把播放中的影片彈出。                       |
| **停靠於邊緣** | 把播放中的影片彈出後，將視窗停靠在螢幕邊緣，直到你按一下它。 |

移動子母畫面視窗或調整其大小後，下次同一個網站開啟子母畫面時，Phi 會記住它的位置與大小。這項設定會依網站儲存在一般設定檔中；無痕空間不會保留。如果儲存時使用的顯示器已中斷連接，Phi 會改用預設位置。

要自行停靠開啟中的子母畫面視窗，請把指標移到視窗上，按一下標示為 **停靠至螢幕邊緣** 的向下箭頭。Phi 會把視窗收到最近的螢幕邊緣，並留下可見的把手。按一下把手即可讓視窗回來。即使自動子母畫面設為 **關閉**，這個控制項目也能使用。

## 向助理詢問你目前的工作

- 選取文字後按右鍵，選擇 **向 [你的助理] 詢問…**，即可把選取的內容帶進對話。
- 開啟助理時，預設會附加目前的分頁。如果該分頁屬於某個群組，Phi 可以附加整個群組。
- 分頁群組或分割畫面可以作為一個單位附加。

若想在不附加目前分頁的情況下開始對話，請在 **設定 → Phi AI → AI 側邊欄** 中關閉 **自動將目前分頁加入新對話作為上下文**。

當你使用 Phi Cloud 時，回答問題所需的內容會傳送給第三方模型供應商處理。使用私有 AI 時，內容會留在你的 Mac 上。詳情請參閱 [隱私權與你的資料](/zh-Hant/privacy/)。
