# 書籤與釘選分頁

在 Phi 裡，側邊欄就是你的工作區，而書籤和釘選分頁是你留住重要頁面的兩種方式。這一章比[版面配置與導覽](/zh-Hant/layouts/)更深入地說明它們的行為，先從最讓傳統瀏覽器使用者意外的一點說起：在 Phi 裡，書籤會就地開啟成分頁。

## 就地開啟的書籤

在傳統瀏覽器裡，書籤是一條「死」的連結：每按一次都會冒出一個新分頁，最後同一個頁面出現一堆重複。Phi 則把書籤當成活的項目。按一下，它就地開啟，側邊欄裡的同一個項目直接成為它的分頁。關閉頁面後，書籤仍留在原位，隨時可以再開。如果書籤已經開啟，再按只會切換到那個分頁，而不會做出第二份。

這正是 Arc 和 Dia 帶紅的概念：側邊欄裝的是活的東西，而不是一年才翻兩次的獨立檔案庫。Phi 沿用這個模式，同時保留真正的書籤階層（包含資料夾），所以書籤庫該有的組織能力一樣不少。

## 建立與整理書籤

- **建立書籤**：把分頁拖曳進側邊欄，或在分頁上按一下滑鼠右鍵並選擇**加入書籤**（在舒適模式中顯示為**加入書籤列**）。用**加入資料夾**可以直接把它放進某個資料夾。
- **用資料夾整理。** 書籤可以放進資料夾；想建立子資料夾，選擇**新增巢狀資料夾…**。
- **把分割畫面存成一個書籤。** 在分割畫面中，**將分割畫面加入書籤**會把兩個頁面存成單一項目，重新開啟時成對還原。
- **管理書籤**：透過它的右鍵選單，**拷貝連結**、**重新命名…**、**編輯…**、**在新分頁中開啟**、**以分割畫面開啟**和**刪除**。

書籤以你所在的空間為範圍。每個[空間](/zh-Hant/spaces/)都保有自己的一套書籤，工作空間存下的頁面不會弄亂個人空間。

## 釘選分頁

釘選分頁以網格排列在側邊欄頂端，留給那幾個你成天泡在裡面的頁面：信箱、儀表板、專案工具。它們是常駐的：關閉頁面後，釘選分頁仍留在網格中，按一下就能把頁面重新打開。

- **釘選分頁**：在分頁上按一下滑鼠右鍵並選擇**釘選**，或把它拖曳進釘選網格。從同一個選單選擇**取消釘選**，可把它放回分頁列表。
- **調整順序**：在網格中拖曳釘選分頁即可重新排列。
- **釘選分割畫面。** 使用**釘選分割畫面**可把雙窗格組合存成單一釘選項目，重新開啟時兩側一起回來；**取消釘選分割畫面**則會復原。

## 選擇釘選分頁範圍 {#choose-a-pinned-tab-scope}

打開**設定 → 空間**，用**釘選分頁範圍**選擇釘選分頁要共用到多廣。預設值是**設定檔**。

| 範圍       | 釘選分頁出現的位置                   |
| ---------- | ------------------------------------ |
| **空間**   | 每個空間各自擁有釘選分頁。           |
| **設定檔** | 使用同一個設定檔的空間共用釘選分頁。 |
| **App**    | 所有一般設定檔和空間共用釘選分頁。   |

無論選擇哪種範圍，無痕空間一律不顯示、也不允許釘選分頁。

變更範圍時，現有的釘選分頁也會搬進新的安排。改成較窄的範圍時，Phi 會把目前的釘選分頁複製到每一個既有的目的地，這些副本之後可以各自獨立修改。改成較寬的範圍時，Phi 會合併既有的各組：內容相同的副本合而為一，內容不同的版本則會保留。無論哪種變更，Phi 都會先顯示確認訊息。

書籤永遠以單一空間為範圍，釘選分頁的這項設定不影響書籤。這兩個層次如何搭配，請見[空間與設定檔](/zh-Hant/spaces/)。

## 回到原本的頁面

在釘選分頁或書籤裡沿著連結瀏覽，可能會讓它離開原本的網址。想回去時，在釘選分頁上按兩下，或按一下已開啟成分頁的書籤的網站圖示。

通往其他網站的連結完全不會移動這個分頁：Phi 會在浮動的 [Peek 檢視](/zh-Hant/peek/)面板中預覽它們，讓書籤或釘選分頁保住它所綁定的頁面。

想保留目前的頁面，請按住 **Command（⌘）**，再按兩下釘選分頁或按一下書籤的網站圖示。目前的頁面會移到分頁列表成為獨立分頁，而釘選分頁或書籤則回到原本的網址。

## 該用哪一個？

簡單的分工方式：

- **釘選分頁**是你成天使用的頁面：永遠在頂端、一按就到，並依你選擇的空間、設定檔或 App 範圍共用。
- **書籤**是你想留存的頁面：用資料夾整理、以單一空間為範圍，需要時就地開啟。

如果你正從 Arc 或 Dia 轉換過來，Phi 的「活」側邊欄、書籤和釘選分頁如何對應，請見[改用 Phi](/zh-Hant/switching-to-phi/)。想從其他瀏覽器或檔案匯入書籤，或把某個空間的書籤存回 HTML，請見[匯入與匯出](/zh-Hant/import-export/)。
