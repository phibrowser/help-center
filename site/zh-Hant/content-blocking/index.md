# 內容封鎖

Phi Browser 以 Chromium 為基礎，並使用 Brave 開源的內容篩選引擎。你可以分別控制是否封鎖廣告、追蹤器和 Cookie 橫幅。

## Phi 可以封鎖什麼

| 設定                 | 作用                                                   |
| -------------------- | ------------------------------------------------------ |
| **封鎖廣告**         | 封鎖符合規則的廣告和廣告請求。                         |
| **封鎖追蹤器**       | 封鎖符合規則的追蹤指令碼、信標和分析請求。             |
| **封鎖 Cookie 橫幅** | 隱藏符合規則的 Cookie 提示。Phi 不會替你選擇同意選項。 |

這三個開關預設為關閉。它們屬於某個[設定檔](/zh-Hant/spaces/)，因此不同設定檔可以使用不同的設定和篩選清單。

內容封鎖使用篩選清單中的規則。清單可以涵蓋一般廣告或追蹤器、Cookie 提示、特定地區的網站，也可以包含你新增的自訂規則。Phi 無法封鎖所有廣告或追蹤器，規則生效時也可能影響某些網站的運作。

## 開啟內容封鎖

1. 開啟**設定 → 設定檔**。
2. 選擇一個設定檔，找到**內容封鎖**。
3. 開啟需要的類別。
4. 如果 Phi 提示選擇篩選清單，請選取要使用的清單，再點按**完成**，下載已選取但尚未儲存在 Mac 上的清單。

之後，你可以隨時點按類別旁的規則選項來變更篩選清單。只有在你選擇下載操作時，Phi 才會下載清單。**更新已下載的清單**會重新取得已儲存在 Mac 上的清單。

在規則選擇器中點按**加入過濾器…**，即可透過 URL 加入清單或直接貼上規則。自訂清單會套用到該設定檔中的全部三個類別。

多個設定檔可以共用已下載的篩選清單。每個設定檔會分別儲存所選清單、自訂清單和網站例外。

## 為某個網站設定例外

開啟網址列選單，選擇**在此網站封鎖內容**，即可在目前設定檔中關閉或重新開啟目前網站的封鎖。這只會變更該設定檔對這個網站的例外設定，不會影響其他網站的封鎖類別。

無痕視窗中不會顯示這個選單項目。

## 網站無法正常運作時

有些網站需要的資源可能會被篩選清單封鎖。你可以在網址列選單中選擇**在此網站封鎖內容**來設定例外，然後重新載入頁面。也可以在**設定 → 設定檔**中關閉某個類別，或變更該類別使用的篩選清單。

篩選清單無法找出所有廣告、追蹤器或 Cookie 提示。Cookie 橫幅封鎖會隱藏符合規則的頁面元素，但不會替你接受 Cookie 或關閉同意提示。
