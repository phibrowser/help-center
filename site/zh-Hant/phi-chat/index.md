# Phi Chat

Phi Chat 是擁有獨立視窗的助理，在 Dock 中有自己的圖示，與你的瀏覽器視窗分開。它和側邊欄裡是同一位助理、同一批對話，只是版面更適合長時間的工作：右邊是完整大小的對話，左邊是你的對話列表。

想詢問眼前的頁面，還是在側邊欄裡問。想找一段較舊的對話、把所有對話集中在一處查看，或追蹤你的任務回報了什麼，就到 Phi Chat。

## 開啟 Phi Chat {#opening-phi-chat}

進入的方式有幾種：

- **從側邊欄**：按一下側邊欄頂端列中的**在 Phi Chat 中開啟**，把目前的對話帶過去。請見[把對話帶過去](#moving-a-conversation-over)。
- **從選單列**：按一下 [Phi Sentinel](/zh-Hant/sentinel/) 圖示，選擇**開啟 Phi Chat**。Phi Chat 在最前方時再選一次，就會隱藏視窗。這個項目上出現小紅點，表示助理傳來了你還沒讀過的內容。
- **用快速鍵**：這個快速鍵預設為關閉。在**設定 → Phi 與 AI → Phi Sentinel** 中開啟**用 Shift Shift Shift 召喚 Phi Chat**，之後在任何 App 中連按三次 Shift (⇧) 即可。它的作用和選單列項目相同，所以同樣的按鍵也能再把視窗隱藏。這個快速鍵透過 Phi Sentinel 運作，Phi Sentinel 需要 macOS 的「輔助使用」權限才能偵測按鍵，並會在你開啟快速鍵時要求這項權限。
- **從任務通知**：當任務回報了值得你注意的內容，Phi 可以顯示它自己的通知卡片，與 macOS 通知分開。卡片上的**檢視詳細資訊**按鈕會在 Phi Chat 中開啟那段對話。請見[自動化與 Phi Link](/zh-Hant/automation/#notifications)。
- **從 Dock 或 Finder**：開啟過 Phi Chat 之後，它也會以 App 的形式出現在 **Phi Apps** 資料夾中，這個資料夾位於你個人專屬資料夾裡的「應用程式」資料夾內，所以你可以把它留在 Dock 中。

Phi Chat 不需要開著瀏覽器視窗。如果 Phi 沒有在執行，開啟 Phi Chat 會在背景啟動 Phi，而不會開啟瀏覽器視窗。

## 把對話帶過去 {#moving-a-conversation-over}

在側邊欄中，當對話已經儲存，而且助理不在回覆途中時，**在 Phi Chat 中開啟**就可以使用。按一下它，會在 Phi Chat 中開啟那段對話、收合側邊欄，並讓側邊欄準備好開始新的對話。

按下去之前，有兩件事要知道：

- **未送出的文字會留在原處。** 如果你在側邊欄中輸入了內容或加入附件但還沒送出，Phi 會先詢問你再捨棄它們。這些內容不會帶到 Phi Chat。
- **已開啟的 Phi Chat 視窗會被沿用。** 如果 Phi Chat 已經開著，它會切換到這段對話，而不是再開一個視窗。你在那個視窗中尚未送出的內容，以及它還在撰寫中的回覆，都會遺失。

要反過來操作，請按一下 Phi Chat 頂端列中的**在側邊欄中開啟**。Phi 會在原本的空間和設定檔中，重新開啟這段對話最後使用的網頁，並在那個頁面的側邊欄中繼續對話。這段對話在 Phi Chat 中也會保持開啟。如果對話從未搭配網頁使用過，或它原本的空間或設定檔已不存在，這個按鈕就無法使用，把指標停在按鈕上會告訴你是哪一種情況。

## 來自每個設定檔的對話 {#conversations-from-every-profile}

對話屬於開始它時所在的[設定檔](/zh-Hant/spaces/)。側邊欄會把它們分開：在某個設定檔中，側邊欄顯示該設定檔的對話，加上任何不屬於設定檔的對話，其他設定檔的對話則一律不顯示。

Phi Chat 是唯一能顯示全部對話的地方。開啟對話列表上方的選單，選擇你要看的內容：

- **全部**，所有對話。
- **任務**，助理在其中建立過任務的對話。請見[任務與未讀對話](#tasks-and-unread-conversations)。
- **依設定檔**，可以選**未指定設定檔**或你的某個設定檔，設定檔會顯示為<strong>設定檔「工作」</strong>這樣的形式，以免和同名的分類混淆。
- **分類**，你建立的分類，加上**未分類**。

在這裡選擇設定檔只會篩選列表，絕不會把對話移到其他設定檔；在 Phi Chat 中開啟對話，也不會改變它所屬的設定檔。不屬於設定檔的對話，可以用它選單中的**移至設定檔**指定一個設定檔，但之後無法再把它移出來。

如果你刪除某個設定檔，它的對話會保留下來。這些對話會失去原本的分類，在 Phi Chat 中出現在**未分類**之下。如果當時 AI 功能是關閉的，這件事會在 AI 功能重新開啟後才發生。

## 尋找與整理對話

列表會先顯示最近有活動的對話，一次 50 段。按一下底部的**載入更多**可以看到更舊的對話。

- **搜尋**：使用列表頂端的放大鏡，或按下 Command (⌘) + K。搜尋比對的是對話標題，不是對話裡的訊息。
- **開始新的對話**：使用**新增對話**。送出第一則訊息後，它才會加入列表。
- **重新命名、歸類或刪除**：使用對話那一列上的 **…** 選單。**刪除**無法復原。
- **回到某個頁面**：使用同一個選單中的**回到最近的頁面**，運作方式和[側邊欄的版本](/zh-Hant/ai/#going-back-to-a-page)相同。

### 分類

分類是你為對話加上的自訂標籤，在你所有的設定檔之間共用。一段對話可以同時屬於好幾個分類。

- 建立分類：使用列表上方選單中的 **+** 按鈕，或任一**分類**子選單底部的**新增分類**，後者也會把你目前所在的對話歸入新分類。
- 在對話的 **…** 選單中，或在對話本身頂端列的選單中，從**分類**勾選或取消勾選分類。變更會在你按下的當下套用。
- 重新命名或刪除分類：在選單中選取該分類，再開啟它自己的選單。刪除分類不會刪除其中的對話。沒有任何分類的對話會移到**未分類**。

**未分類**是內建的。它收納所有沒有分類的對話，無法重新命名或刪除。

### 一次處理多段對話

若要一起處理多段對話，請從對話的 **…** 選單選擇**選取**，或按住 Command (⌘) 並按一下某一列。按住 Shift (⇧) 並按一下，可選取一段範圍。列表標頭會換成一條工具列，你可以在那裡**全選**、為整批選取的對話變更**分類**、**刪除**它們，或按一下**完成**（或按下 Esc 鍵）結束。

**全選**會選取目前已載入列表的對話。還在**載入更多**後面的對話不包含在內，所以你看到的數量就是實際會受影響的數量。

## 任務與未讀對話 {#tasks-and-unread-conversations}

當你請助理在背景或依排程做某件事時，任務會回報到你提出要求的那段對話中。Phi Chat 幫你跟上這些回報：

- **藍點和粗體標題**表示自從你上次開啟那段對話後，有任務回報到裡面。
- 標題後的**時鐘圖示**表示這段對話中有仍在運作的任務。
- **任務檢視**收納所有助理在其中建立過任務的對話。在任務開始與對話連結之前的對話，不會出現在這裡。

回報長什麼樣子、如何管理背後的任務，請見[自動化與 Phi Link](/zh-Hant/automation/#tasks-report-back-to-their-conversation)。

## 須知

- **Phi Chat 是 Phi Browser 的一部分。** 用 Command (⌘) + Q 或從它的選單結束 Phi Chat，只會關閉 Phi Chat，你的瀏覽器視窗會保持開啟。從瀏覽器視窗結束 Phi，則會連同 Phi Chat 一起關閉。
- **連結會在瀏覽器中開啟。** 你在 Phi Chat 中按一下的連結，會在瀏覽器視窗中、以你最後使用的設定檔開啟，並遵循你的[網址規則](/zh-Hant/spaces/#url-rules-route-matching-sites-automatically)。
- **關閉 AI 會關閉 Phi Chat。** 在**設定 → Phi 與 AI** 中關閉 AI 功能後，Phi Chat 會關閉，它的 App 會從 **Phi Apps** 資料夾中移除，而且無法開啟。你的對話不會被刪除，AI 功能重新開啟後就能再開啟 Phi Chat。
- **你的問題仍會送到模型。** Phi Chat 和側邊欄是同一位助理，所以你提出的問題處理方式相同。請見[你的問題去了哪裡](/zh-Hant/ai/#where-your-questions-go)。
