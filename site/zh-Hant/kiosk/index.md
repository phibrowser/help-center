# Kiosk

Kiosk 是為單一頁面準備的輕量視窗。它讓你把連結開在分頁和側邊欄之外，翻看內容，再決定它是否屬於你的某個空間。

Kiosk 適合那些可能有用、但還沒贏得固定位置的連結。「郵件」裡的一篇文章、「訊息」傳來的文件，或一個你想在不打斷手邊工作的情況下確認的連結，都可以待在自己的視窗裡。用完就關閉 Kiosk；想留下頁面，就把它移進某個空間。

Kiosk 是暫時性的，Phi 重新啟動後不會回來。

## 在 Kiosk 中開啟頁面

常見的開啟方式有三種：

| 連結所在位置                    | 做法                                                 |
| ------------------------------- | ---------------------------------------------------- |
| 在 Phi 的頁面上                 | 在連結上按右鍵，選擇**在 Kiosk 中開啟**。            |
| 在 Phi 的頁面上，且已啟用快速鍵 | 按住 Command 和 Option，再按一下連結。               |
| 在其他 App 中                   | 在**設定 → 導覽**中開啟**在 Kiosk 中開啟外部連結**。 |

從 Phi 頁面開啟的 Kiosk 會使用該頁面的設定檔。從其他 App 開啟的連結，則使用你最近使用的設定檔。

## 用網址規則開啟符合的連結

當通往某個網站的連結應該一律在 Kiosk 中開啟時，請使用網址規則。

1. 開啟**設定 → 導覽**。
2. 在**網址規則**之下，按一下**管理網址規則…**。
3. 為你想比對的網域或網址加入一條規則。
4. 選擇 **Kiosk** 作為目的地。

符合規則的連結現在會在 Kiosk 視窗中開啟。這很適合你想留在空間之外的網站；之後決定留下某個頁面時，再把它移進空間就好。

## 切換設定檔

目前的設定檔顯示在網址列的左側。

1. 按一下設定檔名稱。
2. 從選單選擇另一個設定檔。

Phi 會用你選擇的設定檔重新開啟目前頁面。由於每個設定檔有自己的 Cookie 和登入工作階段，你在網站上看到的帳號可能會不同。頁面上尚未送出的內容，例如表單中的文字，可能會在頁面重新載入時遺失。

## 在空間中開啟頁面

<strong>開啟於〔空間〕</strong>控制項目位於 Kiosk 工具列的右側。

- 按一下控制項目的主要部分，即可把頁面移進你在一般 Phi 視窗中最近使用的空間。
- 按一下箭頭並選擇空間，可把頁面移到其他地方。
- 使用預設快速鍵時，按下 **⌘O** 會執行主要動作，把頁面移進你目前的空間。

頁面會成為所選空間中的一般分頁。把它移到另一個空間可能會重新載入頁面，所以請先送出或儲存手邊的工作。

## 選擇 Kiosk 何時開啟

開啟**設定 → 導覽**，找到 **Kiosk**。

- **在 Kiosk 中開啟外部連結**會把「郵件」和「訊息」等 App 的連結送進各自的 Kiosk 視窗。關閉它，這些連結就會改在一般 Phi 視窗中開啟。
- **按住 ⌘⌥ 並點按連結時開啟 Kiosk** 讓你在 Phi 中按住 Command 和 Option 並按一下連結來開啟 Kiosk。不想讓這個手勢開啟 Kiosk 時，把它關閉即可。

這些開關都不會移除連結右鍵選單中的**在 Kiosk 中開啟**項目。
