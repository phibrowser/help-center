# Peek 檢視

Peek 是一個浮動面板，把另一個頁面顯示在你正在閱讀的頁面上方。沿著連結過去，看完那裡的內容，把它關掉，你就回到原點，也沒有多出需要清理的分頁。

Peek 可在**平衡**和**效能**模式中使用。舒適模式會改為把每個連結開成一般分頁。在無痕空間中，Peek 也是關閉的。

## 開啟 Peek

有三種方式可以開啟：

- **沿著書籤或釘選分頁中的連結出去。** 當書籤或釘選分頁中的連結通往其他網站時，Phi 會在 Peek 中預覽它，而不是讓那個分頁離開自己的頁面。停留在同一個網站的連結仍會照常就地前往。
- **按住 Shift 並按一下連結。** 這在任何一般分頁中都有效，不限於書籤和釘選分頁。
- **在連結上按右鍵，選擇「在 Peek 檢視中開啟連結」。** 效果與按住 Shift 並按一下相同，只是從頁面的右鍵選單觸發。

「其他網站」指的是不同的網域。同一個網站的子網域之間的移動，例如從一個 Google 服務換到另一個，視為同一個網站，照常就地開啟。不是網頁的連結，例如 `mailto:` 地址，永遠不會在 Peek 中開啟。

在分割畫面的窗格內，以及在 Peek 本身之中，不提供按住 Shift 並按一下的手勢，右鍵選單也沒有那個項目。在這些地方，連結會照平常的方式開啟。

## 面板內部

頁面會佔滿整個面板。面板右側的窄條上有三個控制項目：

| 控制項目           | 作用                                                                       |
| ------------------ | -------------------------------------------------------------------------- |
| **關閉**           | 關閉預覽和它的頁面。                                                       |
| **以分頁開啟**     | 把預覽變成一般分頁。頁面不會重新載入，捲動位置和你輸入過的內容都維持原狀。 |
| **以分割畫面開啟** | 把預覽放在它來源分頁的旁邊，成為雙窗格的分割畫面。                         |

## 關閉 Peek

以下任一操作都會收起預覽：

- 按下 **Esc** 或 **⌘W**。
- 按一下面板周圍的頁面。
- 前往**上一頁**或**下一頁**，或在網址列輸入網址。這兩者都代表「離開預覽」，所以 Peek 會關閉，底下的分頁停在原處。
- 按一下 Peek 來源的側邊欄項目或釘選分頁上的減號按鈕。
- 關閉 Peek 所屬的分頁。它的 Peek 會一起消失。

## 每個分頁一個 Peek

每個分頁都可以帶著自己的 Peek，而畫面上只會顯示你正在看的分頁的那一個。切換到其他分頁時，面板會跟著消失；切回來時它會回來，頁面維持你離開時的狀態。從同一個分頁再開啟一個 Peek，會取代原來那一個。

分頁帶著 Peek 期間，被預覽頁面的網站圖示會出現在該分頁側邊欄項目的末端，或以小標記的形式出現在釘選分頁的角落。把指標移到上面，它會變成減號按鈕，按一下即可關閉 Peek。

Peek 在重新啟動後仍會保留。Phi 回復你的工作階段時，Peek 會附在它原本所屬的分頁上一起回來。

## 停用 Peek

開啟**設定**，前往**導覽**分頁，使用 **Peek** 之下的**啟用 Peek 檢視**。它預設是開啟的。

停用 Peek 後，連結回到原本的行為：書籤或釘選分頁中的跨網站連結會開成新分頁，按住 Shift 並按一下會開啟新視窗，右鍵選單項目則會消失。當下已開啟的 Peek 會變成一般分頁，而不是直接消失。切換到舒適模式也會有同樣的效果。

想瞭解書籤和釘選分頁一開始如何與自己的頁面綁定，請見[書籤與釘選分頁](/zh-Hant/bookmarks/)。關於並排頁面和側邊欄工作方式的其餘部分，請見[版面配置與導覽](/zh-Hant/layouts/)。
