# 常见问题

Phi Browser 常见问题的简短回答，按主题分组。想了解全貌，以及 Phi 为什么这样设计，请读[指南](/zh-Hans/what-is-phi-browser/)。刚开始用 Phi Browser？看[开始使用](/zh-Hans/get-started/)。

## 布局与导航

::: details 三种布局模式是什么？
Phi 有三种模式，在屏幕空间和熟悉感之间取舍。**性能**模式把最多的空间留给页面，标签页和书签都放在垂直侧边栏里。**均衡**模式保留侧边栏，并在内容上方加一条地址栏。**舒适**模式最接近传统浏览器：标签页在顶部，地址栏可见。初始设置时选一种，之后随时可以更改。
:::

::: details 我该从哪种布局开始？
从 Chrome 或 Safari 迁移过来，先用**舒适**模式，过渡最顺。想要带可见地址栏的现代侧边栏浏览器，试试**均衡**模式。想让页面占据最大空间，用**性能**模式。完整的迁移指南见[迁移到 Phi](/zh-Hans/switching-to-phi/)。
:::

::: details 为什么用垂直侧边栏？
现代屏幕大多是宽而不高。阅读、写作或查资料时，最先不够用的是垂直空间。垂直侧边栏更贴合现代显示器的形状，也给页面本身留出更多空间。
:::

## 空间与个人资料

::: details 空间和个人资料有什么区别？
**空间**是侧边栏里的工作区，有自己的名称、图标、颜色和书签。**个人资料**是它下面的隔离层：每个个人资料有各自的 Cookie、历史记录、登录状态和扩展程序。空间决定东西看起来和用起来是什么样；个人资料决定什么被隔开。完整说明见指南中的[空间与个人资料](/zh-Hans/spaces/)。
:::

::: details 一个个人资料可以有多个空间吗？
可以。每个空间只属于一个个人资料，但一个个人资料可以支撑多个空间。共用一个个人资料的空间共享同一套登录状态；是否共享固定标签页，取决于你选择的固定标签页范围。要让两个空间彻底分开，包括 Cookie 和已登录的账号，就给它们不同的个人资料。
:::

::: details 怎么创建空间？
在侧边栏的空间栏里创建。起个名字，选择它属于哪个个人资料；如果这个空间需要完全独立，就在那里**新建个人资料**。
:::

::: details 切换空间时会发生什么？
侧边栏里的标签页、书签和主题会换成该空间的，Phi 会调出这个空间的窗口（没有的话就打开一个）。固定标签页是跟着换还是保持可见，取决于你在**设置 → 空间**里选的范围：空间、个人资料或应用。
:::

::: details 每个空间都有自己的书签和主题吗？
是的。每个空间都有独立的一套书签，可以用自己的颜色主题，也可以**跟随全局**。你还可以在空间的菜单里重命名空间、更换图标。
:::

::: details 什么是网址规则？
网址规则会把匹配的网站在常规空间、无痕或 Kiosk 中打开，不管你在哪里点击或输入链接。规则在**设置 → 导航**下管理。匹配方式有域名后缀、精确域名、「域名包含」，以及主机名加路径前缀。把规则设为**每次询问**，Phi 会先问你**在哪个空间打开？**，而不是静默跳转。多条规则同时匹配时，最具体的那条生效。
:::

::: details 删除空间会发生什么？
删除空间会一并删除属于它的书签和网址规则，而且无法撤销。属于该空间的空间级固定标签页也会被删除；个人资料级和应用级的固定标签页会保留。删除空间不会删除个人资料，它的 Cookie、历史记录和登录状态都还在。
:::

::: details 这和 Arc、Dia 有什么不同？
Phi 把**空间**作为可见的工作区层，把**个人资料**作为下面的隔离层。这和 Arc 的双层模型很接近；Dia 则更直接地把个人资料当作工作区，放在不同的窗口里。完整对比见[迁移到 Phi](/zh-Hans/switching-to-phi/)。
:::

## 无痕空间

::: details 什么是无痕空间？
侧边栏里的私密空间。它和其他空间一样出现在空间栏里，但背后是一个只存在于内存中的会话，不会有任何内容写入磁盘。用**文件 → 新建无痕空间**打开一个；只有一个时叫**无痕**，同时打开多个则按**无痕 1**、**无痕 2** 依次编号。完整说明见指南中的[无痕空间](/zh-Hans/incognito/)。
:::

::: details 无痕空间之间共享会话吗？
共享。所有打开的无痕空间共用同一个私密会话，在其中一个里登录某个网站，其他无痕空间里也就登录了。这个会话与你的常规个人资料分开，也与传统的**新建无痕式窗口**分开，后者的会话从不与它混用。
:::

::: details 无痕空间里哪些功能不可用？
书签和固定标签页不显示也不能创建，助手聊天和记忆按钮不可用，无法导入浏览器数据，只有你允许在无痕模式下运行的扩展程序才会生效。主题固定为 Phi 的深色无痕外观；图标可以改，但这个选择会随空间一起消失。
:::

::: details 关闭无痕空间时会发生什么？
Phi 会先问：**「这也会关闭此无痕空间，确定吗？」**（勾选**不再询问**后以后不再提示），然后关闭这个空间的窗口，并把它从空间栏中移除。最后一个无痕空间窗口关闭，或者 Phi 退出时，共享的私密会话就会被销毁。你下载的文件仍留在 Mac 上。
:::

::: details 网址规则能把网站送进无痕空间吗？
能。网址规则编辑器在常规空间和 Kiosk 之外还提供一个通用的**无痕**目标。规则不会指向某个具体的无痕空间，因为它们只在打开期间存在。这类规则匹配时，Phi 会使用一个现有的无痕空间，或按需新开一个。路由是单向的：规则不会把私密会话里的导航拉回常规空间。
:::

::: details 扩展程序能在无痕空间里用吗？
默认不能，需要逐个允许，和其他基于 Chromium 的浏览器一样。私密会话始终建立在你的默认个人资料上，所以只有该个人资料的扩展程序能在里面运行。在默认个人资料的窗口里，从扩展程序菜单选择**管理扩展程序**（或输入 `phi://extensions`），打开该扩展程序的**详情**，开启**在无痕模式下启用**。装在其他个人资料上的扩展程序不会出现在无痕空间里，私密会话内部也无法安装新的扩展程序。
:::

::: details 时间机器备份包含无痕空间吗？
不包含。快照会完全排除它们，因为它们的会话本来就该随窗口一起消失，所以恢复备份从不会把无痕空间带回来。
:::

## 书签与标签页

::: details 为什么 Phi 里的书签感觉不一样？
Phi 把书签当作当前浏览工作区的一部分，而不是一年只翻两次的隐藏归档。保存的页面一直留在侧边栏里，随时可见、随时能用，而不是埋在菜单深处。
:::

::: details 舒适模式下书签怎么用？
舒适模式的用法和 Chrome 很像。用**显示 → 始终显示书签栏**把书签栏调出来。菜单栏里还有一个**书签**菜单，所有布局模式下都有。
:::

::: details 均衡模式和性能模式下书签怎么用？
这两种模式没有传统的书签栏。把标签页拖进侧边栏，就是把它存为书签。侧边栏成了你整理页面的主要地方。
:::

::: details 为什么标签页和书签放在同一个侧边栏里？
它们是同一件事的两端：你在意的页面。标签页是你正在用的，书签是你保存下来的。放在一起，正对应你在这两种状态之间不断切换的习惯。
:::

::: details 固定标签页和书签有什么区别？
固定标签页位于侧边栏顶部，放你常驻的页面，比如常用工具或仪表盘。书签在它们下面，存放你想留着以后看、但不必一直开着的页面。
:::

::: details 点击书签会发生什么？
它会原地打开：书签在侧边栏里的条目直接变成它的活动标签页，而不是另开一个用完即弃的标签页。如果这个书签已经打开，点击只会切换到那个标签页，不会再开一份。关闭页面后，书签仍留在侧边栏里，随时可以重新打开。
:::

::: details 书签和固定标签页是按空间划分的吗？
书签始终按空间划分，每个空间有自己的一套。固定标签页可以只属于一个空间，也可以由使用同一个人资料的空间共享，或在整个应用范围内共享。范围在**设置 → 空间**里选择，默认是**个人资料**。见[书签与固定标签页](/zh-Hans/bookmarks/#choose-a-pinned-tab-scope)。
:::

::: details 怎么固定或取消固定标签页？
右键点按标签页并选择**固定**，或把它拖进侧边栏顶部的固定标签页网格。**取消固定**会把它放回标签页列表。固定标签页可以拖动排序；用**固定分屏**可以把双栏布局当作一个固定项保留。
:::

::: details 怎么让固定标签页或书签回到原始页面？
连按两次固定标签页，或者点按以标签页形式打开的书签的网站图标。想保留当前页面，就在连按固定标签页或点按书签网站图标时按住 **Command (⌘)**。当前页面会作为单独的标签页移到标签页列表，固定标签页或书签则回到原始网址。
:::

::: details 这和 Arc 或 Dia 类似吗？
类似。Phi 采用了同样的大思路：侧边栏是活的工作区，保存的页面始终可见，固定的页面排在顶部；同时保留自己的书签树和行为方式。迁移对比见[迁移到 Phi](/zh-Hans/switching-to-phi/)，功能细节见[书签与固定标签页](/zh-Hans/bookmarks/)。
:::

## 分屏视图与标签页组

::: details 标签页、分屏视图和标签页组之间该怎么理解？
标签页是你当前的页面。分屏视图把两个页面并排放在一起。标签页组把相关页面按项目或主题归拢到一起。
:::

::: details 什么是分屏视图？
分屏视图让你在同一个 Phi 窗口里把两个页面并排放置，适合边读边写、对比两个页面，或者把文档放在网页应用旁边。
:::

::: details 怎么创建分屏视图？
右键点按标签页、书签或固定标签页并选择**以分屏打开**，或者把一个标签页拖到当前页面上。也可以按住 **Option (⌥)** 点按固定标签页、书签或网页上的链接，Phi 会把它以分屏视图的形式打开在当前标签页旁边。
:::

::: details 什么是标签页组？
标签页组让你把相关的标签页收进一个有名字的组里，适合一个项目、一次旅行、一个研究主题或一轮购物。
:::

::: details 分屏视图和标签页组怎么配合？
它们就是为配合使用而设计的：你可以在组内使用分屏视图，也可以把分屏的标签页移进或移出组，让相关工作井井有条，而不是散落成零散的标签页。
:::

::: details 助手能理解分屏视图或整个标签页组吗？
能。在分屏视图里聊天时，Phi 可以同时使用两个页面的上下文；在标签页组里聊天时，可以使用整个组的上下文，所以你可以跨相关页面提问，不必解释自己的布局。
:::

::: details 标签页组和书签是一回事吗？
不是。标签页组整理的是你正在处理的页面；书签存放的是留待以后用的页面。
:::

## AI 功能 {#ai-features}

::: details AI 默认是开启的吗？
是的。Phi 自带 AI 功能，并且默认启用，因为它们是产品的核心部分。如果你更想要一个纯粹的浏览器，可以把它们关掉。
:::

::: details 能把所有 AI 功能都关掉吗？
能，入口是**设置 → Phi 与 AI**。关闭 AI 会关闭你的 AI 对话，并断开所有外部数据连接器。你的记忆仍留在设备上；想把它也清掉，用记忆页面上的清除选项，这个删除是永久性的。
:::

::: details AI 主要由哪些部分组成？
四个部分，各司其职：**记忆**、**助手**、**智能体式**（Agentic）能力和**浏览器 Skill**。
:::

::: details 什么是 Phi 记忆？
Phi 记忆是一套系统，随着时间推移从你的浏览行为中构建上下文，全程自动，不需要手动设置。
:::

::: details 我需要手动保存记忆吗？
不需要。记忆是自动的。Phi 会观察相关的浏览行为，在后台为你构建上下文。
:::

::: details Phi 记忆存在哪里？
在你的设备本地。本地优先的存储是核心设计原则。
:::

::: details 我能查看或管理 Phi 记住的内容吗？
能。你可以直接在 Phi 里查看、管理和删除你的记忆数据。
:::

::: details Phi 会把我的记忆发送到它的服务器吗？
不会。记忆数据留在本地。语言模型可能会处理任务，但你的个人记忆不会被发出去存储或用于训练。
:::

::: details Phi 会用我的数据训练 AI 模型吗？
不会。Phi 不会用你的记忆数据、浏览上下文或 AI 交互来训练模型。
:::

::: details 什么是助手？
你在浏览器里直接打交道的伙伴。初始设置时你给它取名，它为自己生成一个相配的头像，之后你就用这个名字叫它，所以它有自己的身份，而不像一个千篇一律的聊天机器人。
:::

::: details 怎么和助手对话？
点按**聊天**按钮：性能模式下它在侧边栏底部，均衡和舒适模式下在页面顶栏右上角。也可以在页面上选中文字，右键点按，选择**向 [你的助手] 询问…**，就地提问。
:::

::: details 助手能做什么？
它能回答问题、总结内容、讲解页面、帮你处理任务，依据的是当前标签页、你的 Phi 记忆和你接入的外部数据的上下文。
:::

::: details 「智能体式」（Agentic）是什么意思？
意思是 AI 不只会回答问题。它能在浏览器里采取行动，替你完成任务，从一次性操作到循环运行的自动化都包括在内。
:::

::: details 什么是按需操作？
你提出要求时助手执行的任务，比如替你浏览页面或与网站交互。
:::

::: details 什么是定时任务？
按你设定的时间表循环运行的自动化，比如监控某件商品的价格，或者盯着某个页面的变化。
:::

## Phi Sentinel {#phi-sentinel}

::: details 什么是 Phi Sentinel？
Phi Sentinel 是 Phi Browser 的后台 AI 编排器。它执行定时任务，保存你的 AI 任务历史记录，从 macOS 菜单栏运行。
:::

::: details 为什么 Phi Sentinel 和浏览器是分开的？
这样即使浏览器窗口关闭了，定时任务和持续运行的 AI 工作流也能继续。
:::

::: details 为什么这样设计？
让浏览器保持轻量，同时维持一个持续运行的自动化层，整个系统会更实用。
:::

## Phi Link

::: details 什么是 Phi Link？
Phi Link 把 Phi Browser 连到 Telegram，让你在手机上使用助手，离开 Mac 时也能收到任务进展。
:::

::: details 怎么设置 Phi Link？
两种方式：使用官方的 Phi Link 机器人，这是最省事的路径，扫一个二维码、点一下就完成；或者通过 BotFather 创建你自己的 Telegram 机器人，把它的令牌粘贴到 Phi 的设置里。
:::

::: details Phi Link 能做什么？
和助手聊天，在任务成功或失败时收到通知，离开浏览器也能继续工作流。
:::

::: details Phi Link 用的是同一个助手身份吗？
是的。同一个助手身份会延续到手机上，桌面和手机体验一致；如果用你自己的机器人，还可以做一些自定义。
:::

## 定价与可用性

::: details Phi 是免费的吗？
目前是。Phi Browser 现在可以免费使用，AI 用量也包含在内。
:::

::: details Phi 会永远免费吗？
大概不会一直保持完全相同的形式。将来可能会对高级功能收费。
:::

## 隐私与数据

::: details Phi 的隐私模型是什么？
Phi Browser 建立在本地优先的架构上：Phi 记住的内容留在你的设备上，不会用于训练。
:::

::: details Phi 肯定不会收集什么？
Phi 从不收集你的记忆数据、AI 交互或浏览上下文，也不会用它们训练模型。

Phi 会发送一个很小的、始终开启的匿名计数（有多少安装把 Phi 设为默认浏览器、使用了空间、使用了个人资料，以及发生过崩溃）；只有在你开启后，才会发送详细的使用情况统计信息和崩溃报告。见 [Phi 会发送什么](/zh-Hans/privacy/#what-phi-does-send)。
:::

::: details 我的记忆是存在本地的吗？
是的。你的记忆数据存放在你的设备上，你可以查看、管理和删除。
:::

::: details Phi 会出售我的浏览历史或用它训练吗？
不会。Phi 不会用源自浏览的记忆或 AI 交互来训练模型，也不会出售源自浏览的数据。
:::

::: details Phi 会收集使用情况统计信息吗？
会。只有在**帮助改进 Phi 的功能和性能**开关开启时，Phi 才会向 Phinomenon 发送匿名的使用情况统计信息，而这个开关出厂即为开启。统计的是浏览器本身：哪些功能被使用、应用运行表现如何。其中从不包含你访问的页面、你的记忆或你的 AI 对话。报告带有一个随机的安装标识符，和你的 Phi 账号没有任何关系。见[隐私与你的数据](/zh-Hans/privacy/#usage-statistics)。
:::

::: details 怎么关闭使用情况统计信息？
打开 `phi://settings`，找到**你与 Phi**，关闭其中的**帮助改进 Phi 的功能和性能**，然后点按随之出现的**重新启动**按钮让更改生效。关闭开关的同时也会删除附在你之前报告上的随机标识符；以后再打开，Phi 会生成一个新的。
:::

## 时间机器备份

::: details 什么是 Phi 的时间机器？
它是一张**版本回滚**安全网。在某些重大更新前，Phi 会自动保存当前版本和你的数据的快照，新版本不合适时可以退回去。完整说明见指南中的[时间机器备份](/zh-Hans/time-machine/)。
:::

::: details 这是 Apple 的时间机器吗？
不是。它不备份你的 Mac，和 macOS 里的同名功能没有关系。它只把 Phi 回滚到之前的版本。
:::

::: details 它会一直备份我的浏览数据吗？
不会。它不是持续备份，也不是定时备份。快照只会自动、偶尔地创建：在风险高于平常的更新之前，而且每次这样的更新只创建一次。想要一份由你掌控的备份，改用**导出用户数据**。
:::

::: details 快照包含什么？
属于上一个版本的 Phi 数据，也就是书签、空间、固定标签页、设置、记忆和浏览状态，外加一条记录，标明要恢复到哪个应用版本。应用本身在恢复时下载，所以回滚回来的是一套前后一致的配置。
:::

::: details 快照存在哪里？
在你的 Mac 本地。它们不会上传到云端，不绑定你的账号，也无法移到另一台 Mac 上。
:::

::: details 怎么回滚？
打开**帮助**菜单，选择**时间机器备份**，挑一个快照（按版本、构建号和日期列出，例如 _Phi 1.6 (590)，2026.6.11_）。确认**恢复**后，Phi 会下载之前的版本，替换当前应用和对应的数据，然后重新启动。恢复期间需要联网。没有快照时，菜单会显示**没有可用的备份**。
:::

::: details 这和导出我的数据有什么不同？
时间机器自动处理更新回滚。想自己创建并保留备份，比如换新 Mac 或留一份个人副本，用**帮助**菜单里的**管理用户数据**（**导出用户数据…**、**导入用户数据…**）。
:::
