# Phi Browser 实用技巧

本页汇总了 Phi 界面中不太容易发现的手势和快捷键。这里列出的是默认键盘快捷键。你可以在**设置 → 快捷键**中更改它们。

## 快捷操作一览

| 操作                         | 快捷键或手势                                                 |
| ---------------------------- | ------------------------------------------------------------ |
| 创建分屏视图                 | 按住 Option (⌥) 单击标签页、固定标签页、书签或适用的网页链接 |
| 在最近使用的标签页之间切换   | Control (⌃) + Tab                                            |
| 按相反顺序切换               | Control (⌃) + Shift (⇧) + Tab                                |
| 拷贝当前页面的网址           | Command (⌘) + Shift (⇧) + C                                  |
| 搜索打开的标签页             | Command (⌘) + Shift (⇧) + A                                  |
| 移到上一个或下一个空间       | Command (⌘) + Option (⌥) + ← 或 →                            |
| 打开前九个空间中的某一个空间 | Control (⌃) + 1 至 9                                         |

## 创建分屏视图

- 按住 Option (⌥)，然后单击另一个标签页、组内标签页、固定标签页、书签或适用的网页链接。Phi 会把它放在当前页面旁边。
- 将单个标签页、固定标签页或书签拖到当前页面左侧或右侧。拖到哪一侧，就会显示在哪一侧。
- 将项目拖到现有未固定分屏视图的某个窗格上，可以替换该窗格。

## 返回保存的网址

固定标签页或书签可能会离开你最初保存的网址。你可以在不丢失当前页面的情况下返回原始网址。

- 双击固定标签页，返回它保存的网址。
- 单击书签的网站图标，返回它保存的网址。
- 使用上述任一手势时按住 Command (⌘)，Phi 会先把当前页面保留为独立标签页，再恢复保存的网址。

## 使用标签页组概览

单击标签页组标题可打开标签页组概览。它会显示每个页面的快照，并把一个分屏视图显示为一张组合卡片。

在标签页组概览中，你可以切换或关闭页面、创建新标签页，以及更改组名和颜色。如果你在标签页组概览打开时使用地址栏，新标签页会加入该组。

将整个标签页组拖到书签区域，可以把它变成书签文件夹。Phi 会保留标签页顺序并解散标签页组，但已经打开的标签页会继续保持打开。

## 同时操作多个标签页和书签

- 按住 Command (⌘) 逐个单击普通标签页和书签，可以依次选中它们。
- 按住 Shift (⇧) 单击，可以选中一个范围。
- 可用操作包括创建标签页组、将项目加入书签文件夹、将它们移动或克隆到另一个空间，以及关闭它们。
- 拖动任意已选项目，可以移动整个选区。分屏视图的两个窗格会保持在一起。
- 按 Escape 清除选择。

## 切换、搜索和拷贝

Control (⌃) + Tab 按最近使用顺序切换，而不是按窗口中的标签页排列顺序切换。

- 按一次可在当前标签页和上一个标签页之间切换。
- 按住不放或反复按下，可以显示最多五个最近使用的标签页。
- 加按 Shift (⇧) 可按相反顺序浏览列表。
- 按 Command (⌘) + Shift (⇧) + A 搜索所有打开的标签页。
- 按 Command (⌘) + Shift (⇧) + C 拷贝当前标签页的网址。

## 个性化每个空间

打开**设置 → 空间**，然后选择一个空间。

- 从 Phi 的内置图标中选择一个图标，或使用表情符号。
- 选择主题颜色并调整饱和度。

每个空间都会保留自己的图标和主题。切换空间时，Phi 会应用你为该空间选择的外观，而不会更改其他空间。

## 在空间之间移动

- 按 Command (⌘) + Option (⌥) + ← 或 →，移到上一个或下一个空间。
- 按 Control (⌃) + 1 至 9，直接打开前九个空间中的某一个空间。

## 使用网址规则路由网站

从菜单栏打开**空间 → 网址规则…**，或从**设置 → 空间**打开网址规则。规则可以按**域名后缀**、**域名**、**域名包含**或**网址**进行匹配。

你可以将匹配结果发送到常规空间或无痕空间。如果希望 Phi 在移动页面前询问你，请选择**每次询问**。多条规则匹配时，最具体的一条优先。

::: tip 空间路由不会隔离 Cookie
网址规则只决定页面在哪里打开。要隔离 Cookie 和已登录会话，请将目标空间分配给不同的个人资料。
:::

## 让视频通过画中画保持可见

切换标签页或空间时，Phi 可以把正在播放的视频弹出为画中画窗口。你可以在**设置 → 通用 → 自动画中画**中选择相应行为。

| 模式           | 行为                                                         |
| -------------- | ------------------------------------------------------------ |
| **关闭**       | 不自动打开画中画。你仍然可以手动使用画中画。                 |
| **标准**       | 切换标签页或空间时，弹出正在播放的视频。                     |
| **停靠在边缘** | 弹出正在播放的视频，然后将窗口停靠到屏幕边缘，直到你单击它。 |

移动画中画窗口或调整其大小后，Phi 会在该网站下次打开画中画时记住窗口的位置和大小。常规个人资料会按网站保存这项设置，无痕空间不会保留。如果之前保存的显示器已断开连接，Phi 会使用默认位置。

要手动停靠已经打开的画中画窗口，请将指针移到窗口上，然后单击标有**停靠到屏幕边缘**的向下箭头。Phi 会将窗口收进最近的屏幕边缘，只留下一个可见把手。单击把手即可恢复窗口。即使自动画中画设为**关闭**，此控制项仍然可用。

## 就当前工作询问助理

- 选中网页文本，右键单击，然后选择**向［你的助理］询问…**，将所选内容带入对话。
- 打开助理时，默认会附加当前标签页。如果该标签页位于组中，Phi 可以附加整个组。
- 标签页组或分屏视图可以作为一个整体附加。

要在不附加当前标签页的情况下开始对话，请在**设置 → Phi AI → AI 侧边栏**中关闭**自动将当前标签页添加为新对话的上下文**。

使用 Phi Cloud 时，回答问题所需的内容会发送给第三方模型提供商处理。使用私有 AI 时，这些内容会留在你的 Mac 上。详情请参阅[隐私与数据](/zh-Hans/privacy/)。
