# Phi Browser 使用技巧

这一页收集了 Phi 中不太容易从界面上发现的手势和快捷键。这里列出的快捷键都是默认值，你可以在**设置 → 快捷键**中修改。

## 快捷键速查

| 操作                       | 快捷键或手势                                                     |
| -------------------------- | ---------------------------------------------------------------- |
| 创建分屏视图               | 按住 Option (⌥) 点按标签页、固定标签页、书签或符合条件的网页链接 |
| 在最近使用的标签页之间切换 | Control (⌃) + Tab                                                |
| 反向切换                   | Control (⌃) + Shift (⇧) + Tab                                    |
| 拷贝当前页面的网址         | Command (⌘) + Shift (⇧) + C                                      |
| 搜索已打开的标签页         | Command (⌘) + Shift (⇧) + A                                      |
| 前往上一个或下一个空间     | Command (⌘) + Option (⌥) + ← 或 →                                |
| 打开前九个空间之一         | Control (⌃) + 1 至 9                                             |

## 创建分屏视图

- 按住 Option (⌥)，点按另一个标签页、标签页组里的标签页、固定标签页、书签或符合条件的网页链接。Phi 会把它放到当前页面旁边。
- 把单个标签页、固定标签页或书签拖到当前页面的左侧或右侧。拖到哪一侧，它就出现在哪一侧。
- 把项目放到现有未固定分屏视图的某个窗格上，即可替换该窗格。

## 回到保存的网址

固定标签页或书签可能会离开你最初保存的网址。你可以回到那个网址，同时不丢失正在看的页面。

- 连按两次固定标签页，让它回到保存的网址。
- 点按书签的网站图标，让它回到保存的网址。
- 做这两种手势时按住 Command (⌘)，可以先把当前页面保留为单独的标签页，再恢复保存的网址。

## 使用标签页组概览

点按标签页组的标题即可打开标签页组概览。它显示每个页面的快照，一个分屏视图显示为一张合并的卡片。

在标签页组概览里，你可以切换到某个页面、关闭页面、新建标签页，或者修改组的名称和颜色。如果在概览打开时使用地址栏，新标签页会加入该组。

把整个标签页组拖到书签区域，它就变成一个书签文件夹。Phi 会保留标签页的顺序并解散这个组，但已打开的标签页仍然保持打开。

## 同时处理多个标签页和书签

- 按住 Command (⌘) 点按普通标签页和书签，逐个选中。
- 按住 Shift (⇧) 点按，选中一段范围。
- 可用的操作可能包括创建标签页组、把项目加入书签文件夹、移动或克隆到另一个空间，以及关闭它们。
- 拖动任意选中的项目即可移动整个选区。分屏视图的两侧会一起移动。
- 按 Escape 清除选择。

## 切换、搜索和拷贝

Control (⌃) + Tab 按最近使用的顺序切换，而不是按窗口中标签页的排列顺序。

- 按一次，在当前标签页和上一个标签页之间切换。
- 按住不放或连续按，最多显示五个最近使用的标签页。
- 加上 Shift (⇧)，按相反方向遍历列表。
- 按 Command (⌘) + Shift (⇧) + A 搜索所有已打开的标签页。
- 按 Command (⌘) + Shift (⇧) + C 拷贝当前标签页的网址。

## 为每个空间设置个性化外观

打开**设置 → 空间**，然后选择一个空间。

- 从 Phi 内置的图标集中选一个图标，或者使用表情符号。
- 选择主题颜色，并调整它的饱和度。

每个空间保留自己的图标和主题。切换空间时会应用你为该空间选择的外观，不影响其他空间。

## 在空间之间移动

- 按 Command (⌘) + Option (⌥) + ← 或 →，前往上一个或下一个空间。
- 按 Control (⌃) + 1 至 9，直接打开前九个空间之一。

## 用网址规则分配网站

从菜单栏打开**空间 → 网址规则…**，或在**设置 → 空间**中打开网址规则。规则可以按**域名后缀**、**域名**、**域名包含**或**网址**匹配。

匹配的页面可以发送到普通空间或无痕空间。如果希望 Phi 在移动页面前先问你，选择**每次询问**。多条规则同时匹配时，最具体的那条生效。

::: tip 空间分配不会隔离 Cookie
网址规则只决定页面在哪里打开。要让 Cookie 和登录会话彼此隔离，把目标空间分配到不同的个人资料。
:::

## 用画中画让视频保持可见

切换标签页或空间时，Phi 可以把正在播放的视频弹出成小窗口。在**设置 → 通用 → 自动画中画**下选择行为。

| 模式           | 行为                                                         |
| -------------- | ------------------------------------------------------------ |
| **关闭**       | 从不自动打开画中画。手动画中画仍然可用。                     |
| **普通**       | 切换标签页或空间时，弹出正在播放的视频。                     |
| **停靠在边缘** | 弹出正在播放的视频，然后把窗口停靠在屏幕边缘，直到你点按它。 |

移动或调整画中画窗口后，Phi 会记住它的位置和大小，下次该网站打开画中画时沿用。这项记录按网站保存在普通个人资料中，无痕空间不会保留。如果保存时所用的显示器已断开连接，Phi 会使用默认位置。

要自己停靠一个已打开的画中画窗口，把指针移到窗口上，点按标有**停靠到屏幕边缘**的向下箭头。Phi 会把窗口收到最近的屏幕边缘，并留下一个可见的手柄。点按手柄即可让窗口回来。即使自动画中画设为**关闭**，这个控制项也能用。

## 向助手询问当前工作

- 选中文本，右键点按，选择**问问 [你的助手]…**，把选中内容带进对话。
- 打开助手时默认附加当前标签页。如果该标签页在某个组里，Phi 可以附加整个组。
- 标签页组或分屏视图可以作为一个整体附加。

要在不附加当前标签页的情况下开始对话，在**设置 → Phi 与 AI → AI 侧边栏**下关闭**自动将当前标签页添加为新对话的上下文**。

使用 Phi Cloud 时，回答问题所需的内容会发送给第三方模型提供商处理。使用私有 AI 时，内容留在你的 Mac 上。详情见[隐私与你的数据](/zh-Hans/privacy/)。
