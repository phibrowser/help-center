# Peek 视图

Peek 是一个浮动面板，把一个页面显示在你正在阅读的页面上方。点开链接，看完内容，关掉面板，你就回到了原来的地方，没有多余的标签页要收拾。

Peek 在**均衡**和**性能**模式下可用。舒适模式改为把每个链接都作为普通标签页打开。无痕空间里 Peek 同样处于关闭状态。

## 打开 Peek

打开它有三种方式：

- **从书签或固定标签页点开链接**。书签或固定标签页里的链接指向另一个网站时，Phi 会在 Peek 中预览它，而不是让这个标签页离开自己的页面。留在同一网站内的链接照常原地跳转。
- **按住 Shift 点按链接**。这在任何普通标签页里都有效，不限于书签和固定标签页。
- **右键点按链接，选择「在 Peek 视图中打开链接」**。效果与按住 Shift 点按相同，入口在页面的右键菜单里。

「另一个网站」指的是不同的域名。同一网站的子域名，例如从一个 Google 服务跳到另一个，算作同一网站，照常原地打开。不是网页的链接，例如 `mailto:` 地址，永远不会在 Peek 中打开。

在分屏视图的窗格里，以及在 Peek 内部，按住 Shift 点按和右键菜单项都不提供。在这些地方，链接按原本的方式打开。

## 面板内部

页面边到边地撑满面板。面板右侧的窄条里排着三个控制项：

| 控制项           | 作用                                                                       |
| ---------------- | -------------------------------------------------------------------------- |
| **关闭**         | 关闭预览及其页面。                                                         |
| **以标签页打开** | 把预览变成普通标签页。页面不会重新加载，滚动位置和你输入的内容都保持原样。 |
| **以分屏打开**   | 把预览放到它来源的标签页旁边，组成双栏分屏视图。                           |

## 关闭 Peek

以下任意一种方式都能收起预览：

- 按 **Escape** 或 **⌘W**。
- 点按面板周围的页面。
- 触发**后退**或**前进**，或在地址栏输入地址。这两种操作在 Phi 看来都是「离开预览」，所以 Peek 会关闭，下面的标签页停在原处。
- 点按 Peek 来源的侧边栏条目或固定标签页上的减号按钮。
- 关闭 Peek 来源的标签页。它的 Peek 会一起消失。

## 每个标签页一个 Peek

每个标签页都可以带自己的 Peek，而屏幕上只显示当前标签页的那一个。切到别的标签页，面板随之消失；切回来，它带着你离开时的页面一起回来。在同一个标签页里打开第二个 Peek 会替换掉第一个。

标签页带着 Peek 期间，被预览页面的网站图标会出现在该标签页侧边栏条目的末尾，或以小角标的形式出现在固定标签页的一角。指针悬停在上面时，它会变成一个减号按钮，点按即可关闭 Peek。

Peek 在重新启动后仍会保留。Phi 恢复会话时，Peek 会重新附在它所属的标签页上。

## 关闭 Peek 功能

打开**设置**，切换到**导航**部分，在 **Peek** 下使用**启用 Peek 视图**。它默认开启。

关闭 Peek 后，链接回到朴素的行为：书签或固定标签页里的跨站链接会作为新标签页打开，按住 Shift 点按会打开新窗口，右键菜单项则消失。当时已经打开的 Peek 会变成普通标签页，而不是直接消失。切换到舒适模式的效果相同。
