# 迁移到 Phi

如果你正从 Chrome、Safari、Arc 或 Dia 迁移到 Phi，本指南会先说明思维方式上的变化。其他功能指南仍会深入介绍各个领域；本页为你提供一张迁移地图。

## 从 Chrome 或 Safari 迁移

请从**舒适模式**开始。它保留了最熟悉的形态：标签页位于顶部、地址栏始终可见，整体布局接近传统浏览器。侧边栏仍然存在，但你无需从第一天起就完全改用侧边栏工作方式。

熟悉基础操作后，如果你想使用现代侧边栏浏览器，同时保留可见的地址栏，可以试试**均衡模式**。当你希望为页面留出最大空间，并已习惯将侧边栏作为主要导航区域时，再切换到**性能模式**。

学习 Phi 最快的方法，是先把它当作普通浏览器来用：正常浏览、打开标签页、固定几个页面、保存几项书签，再就你正在阅读的页面向助理提问。实际使用比文字解释更容易让你理解 Phi。

- [书签与固定标签页](/zh-Hans/bookmarks/)：保存在 Phi 中的页面如何运作。
- [隐私与数据](/zh-Hans/privacy/)：如果你想在启用 AI 功能前了解本地优先的数据模型。

## 从 Arc 迁移

如果你喜欢 Arc 的侧边栏模式，Phi 应该会让你感到熟悉，但两者的细节有所不同。

Arc 和 Phi 都将工作区层与隔离层分开。在 Phi 中，**空间**是侧边栏中可见的工作区，而**个人资料**则承载其下的 Cookie、历史记录、登录状态和扩展程序。一个个人资料可以支持多个空间，因此你可以创建多个共享同一登录会话的工作区。

Phi 的**网址规则**受到 Arc Air Traffic Control 的启发：匹配的网站可以在你指定的空间中打开，也可以每次询问你要在哪里打开。具体实现由 Phi 自己完成，但目标相同：自动把链接放进正确的上下文。

书签方面最大的区别，是 Phi 保留了包含文件夹的完整书签树。Arc 放弃了传统书签，转而使用固定标签页和 Favorites；Phi 则同时保留这两种思路。书签始终在侧边栏中井然有序，并像实时标签页一样就地打开。固定标签页位于顶部，适合你经常使用的页面；你可以选择让它们属于一个空间、一个个人资料或整个应用。

Phi 没有与 Arc Peek 对应的功能。从固定标签页打开链接时，会在该标签页内正常跳转。

- [书签与固定标签页](/zh-Hans/bookmarks/)：活书签和可配置的固定标签页作用范围。
- [主题与外观](/zh-Hans/themes/)：每个空间的颜色和全局主题。

## 从 Dia 迁移

Dia 和 Phi 都不再局限于传统的顶部标签栏浏览器模式，但两者的工作区模型不同。

Dia 将个人资料本身作为工作区概念，每个个人资料会在单独的窗口中打开。Phi 则在**个人资料**之上保留了**空间**这一层。这意味着你可以在一个窗口中单击一次就切换上下文，同时在需要隔离 Cookie、登录状态、历史记录或扩展程序时继续使用不同的个人资料。

Dia 保留了书签，但主要通过命令栏呈现。Phi 则让书签与标签页、固定标签页一起，在侧边栏中保持可见和有序。Phi 中的书签会就地打开为实时标签页，而不是再创建一个临时标签页。

Phi 的固定标签页沿用了现代侧边栏浏览器普及的“应用位于顶部”模式。它们是你常用页面的持久入口，并会跟随个人资料出现在所有共享该配置的空间中。

- [空间与个人资料](/zh-Hans/spaces/)：Phi 为什么将可见工作区与账户隔离分开。
- [书签与固定标签页](/zh-Hans/bookmarks/)：侧边栏中的活页面模型。
