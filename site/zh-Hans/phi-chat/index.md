# Phi Chat

Phi Chat 是在独立窗口中的助手，有自己的程序坞图标，与你的浏览器窗口分开。它和侧边栏里是同一个助手、同一批对话，只是布局更适合较长的工作：右侧是完整尺寸的对话区，左侧是你的对话列表。

侧边栏仍然是你就眼前页面提问的地方。想找一段较早的对话、在一个地方看到全部内容，或者跟进任务汇报了什么，就去 Phi Chat。

## 打开 Phi Chat {#opening-phi-chat}

打开它的方式有几种：

- **从侧边栏**：点按侧边栏顶栏中的**在 Phi Chat 中打开**，把当前对话转过去。见[把对话转到 Phi Chat](#moving-a-conversation-over)。
- **从菜单栏**：点按 [Phi Sentinel](/zh-Hans/sentinel/) 图标，选择**打开 Phi Chat**。Phi Chat 位于最前面时再次选择这一项，会隐藏窗口。这一项上的小红点表示助手发布了你还没读的内容。
- **用快捷键**：这个快捷键默认关闭。在**设置 → Phi 与 AI → Phi Sentinel** 下打开**用 Shift Shift Shift 召唤 Phi Chat**，然后在任何应用中连按三次 Shift (⇧)。它的作用和菜单栏中的那一项相同，所以同样的按键也会再次隐藏窗口。这个快捷键通过 Phi Sentinel 运行，Phi Sentinel 需要 macOS 辅助功能权限才能察觉按键，你打开快捷键时它会请求这项权限。
- **从任务通知**：当任务汇报了值得你注意的内容时，Phi 可以显示它自己的通知卡片，与 macOS 通知是分开的。卡片上的**查看详情**按钮会在 Phi Chat 中打开那段对话。见[自动化与 Phi Link](/zh-Hans/automation/#notifications)。
- **从程序坞或访达**：你打开过一次 Phi Chat 之后，它也会作为一个应用出现在 **Phi Apps** 文件夹中，这个文件夹位于你个人文件夹里的「应用程序」文件夹内，所以你可以把它保留在程序坞中。

Phi Chat 不需要打开浏览器窗口。如果 Phi 没有在运行，打开 Phi Chat 会在后台启动 Phi，不会打开浏览器窗口。

## 把对话转到 Phi Chat {#moving-a-conversation-over}

在侧边栏中，只有当对话已经保存、助手也不在回复过程中时，**在 Phi Chat 中打开**才可用。点按它会在 Phi Chat 中打开这段对话，收起侧边栏，并让侧边栏准备好开始新对话。

点按之前，有两点需要知道：

- **未发送的内容会留在原处**：如果你在侧边栏里输入了文字或添加了附件但还没发送，Phi 会先询问你再丢弃它们。它们不会带到 Phi Chat。
- **已打开的 Phi Chat 窗口会被复用**：如果 Phi Chat 已经打开，它会切换到这段对话，而不是再打开一个窗口。你在那个窗口里还没发送的内容，以及它正在写的回复，都会丢失。

要反过来操作，点按 Phi Chat 顶栏中的**在侧边栏中打开**。Phi 会在原来的空间和个人资料中，重新打开这段对话上次使用的网页，并在该页面的侧边栏中继续这段对话。这段对话在 Phi Chat 中也保持打开。如果这段对话从未在网页上使用过，或者它原来的空间或个人资料已不存在，这个按钮就不可用，将指针悬停在按钮上会告诉你是哪种情况。

## 所有个人资料的对话 {#conversations-from-every-profile}

对话属于它开始时所在的[个人资料](/zh-Hans/spaces/)。侧边栏把它们分开显示：在某个个人资料中，它显示该个人资料的对话，加上完全不属于任何个人资料的对话，不显示你其他个人资料的任何对话。

Phi Chat 是唯一显示全部对话的地方。打开对话列表上方的菜单，选择要看的内容：

- **全部**：所有对话。
- **任务**：助手在其中创建过任务的对话。见[任务和未读对话](#tasks-and-unread-conversations)。
- **按个人资料**：**无个人资料**，或你的某个个人资料，显示为<strong>个人资料「工作」</strong>这样的形式，以免和同名的分类混淆。
- **分类**：你创建的分类，以及**未分类**。

在这里选择个人资料只会筛选列表。它永远不会把对话移到另一个个人资料，在 Phi Chat 中打开对话也不会改变它所属的个人资料。不属于任何个人资料的对话，可以通过它菜单中的**移动到个人资料**指定一个个人资料，但之后没有办法再把它移出来。

如果你删除一个个人资料，它的对话会保留下来。这些对话会失去各自的分类，出现在 Phi Chat 的**未分类**下。如果删除时 AI 功能处于关闭状态，这一步会在 AI 功能重新开启后发生。

## 查找和整理对话

列表把最近有活动的对话排在前面，每次显示 50 个。点按底部的**加载更多**查看更早的对话。

- **搜索**：点按列表顶部的放大镜，或按 Command (⌘) + K。搜索匹配的是对话标题，不是对话里的消息。
- **开始新对话**：点按**新建对话**。发送第一条消息后，它才会加入列表。
- **重命名、归类或删除**对话：使用对话所在行的 **…** 菜单。**删除**无法撤销。
- **回到某个页面**：使用同一菜单中的**回到最近的页面**，它的作用和[侧边栏中的同名选项](/zh-Hans/ai/#going-back-to-a-page)一样。

### 分类

分类是你自己给对话加的标签，在你所有个人资料之间共用。一段对话可以同时属于多个分类。

- 创建分类：点按列表上方菜单中的 **+** 按钮，或任何**分类**子菜单底部的**新建分类**，后者还会把你当前所在的对话归入新分类。
- 在对话的 **…** 菜单或对话自己顶栏菜单的**分类**中勾选或取消勾选分类。点按即生效。
- 要重命名或删除分类，在菜单中选中它，然后打开它自己的菜单。删除分类不会删除其中的对话。没有任何分类的对话会移到**未分类**。

**未分类**是内置的。它收纳所有没有分类的对话，不能重命名或删除。

### 同时处理多个对话

要一起处理多个对话，从某个对话的 **…** 菜单中选择**选择**，或按住 Command (⌘) 键点按某一行。按住 Shift 键点按可以选中一个范围。列表标题会被一条操作栏取代，你可以在上面**全选**、为整个选择更改**分类**、**删除**它们，或点按**完成**（或按 Escape）结束。

**全选**选中的是列表中当前已加载的对话。仍在**加载更多**之后的对话不包括在内，所以你看到的数量就是确切会受影响的数量。

## 任务和未读对话 {#tasks-and-unread-conversations}

当你让助手在后台或按计划做某件事时，任务会汇报到你提出要求的那段对话中。Phi Chat 帮你跟上这些汇报：

- **蓝点和粗体标题**：表示自你上次打开以来，有任务向这段对话汇报过。
- **时钟图标**：出现在标题后面，表示这段对话中有仍在生效的任务。
- **任务**视图：汇集助手在其中创建过任务的所有对话。任务与对话关联起来之前的对话不会出现在这里。

汇报是什么样子，以及如何管理背后的任务，见[自动化与 Phi Link](/zh-Hans/automation/#tasks-report-back-to-their-conversation)。

## 需要了解的事项

- **Phi Chat 是 Phi Browser 的一部分**：用 Command (⌘) + Q 或从它的菜单退出 Phi Chat，只会关闭 Phi Chat，你的浏览器窗口保持打开。从浏览器窗口退出 Phi，也会关闭 Phi Chat。
- **链接在浏览器中打开**：在 Phi Chat 中点按的链接会在浏览器窗口中打开，使用你上次使用的个人资料，并遵循你的[网址规则](/zh-Hans/spaces/#url-rules-route-matching-sites-automatically)。
- **关闭 AI 会关闭它**：在**设置 → Phi 与 AI** 中关闭 AI 功能后，Phi Chat 会关闭，它的应用会从 **Phi Apps** 文件夹中移除，并且无法打开。你的对话不会被删除，AI 功能重新开启后就可以再次打开 Phi Chat。
- **你的问题仍会发送给模型**：Phi Chat 和侧边栏是同一个助手，所以你提的问题会以同样的方式处理。见[你的问题去了哪里](/zh-Hans/ai/#where-your-questions-go)。
