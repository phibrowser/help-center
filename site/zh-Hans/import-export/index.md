# 导入与导出

Phi 可以从其他浏览器导入书签和浏览历史，既可以直接读取已安装浏览器的数据，也可以使用你已有的文件。它还可以将某个空间的书签导出为标准 HTML 文件。本页会介绍两个方向的操作，并明确说明每种文件会带入哪些内容。

如果你刚开始使用 Phi，只想先了解总体迁移方式，请阅读[迁移到 Phi](/zh-Hans/switching-to-phi/)，之后再回到这里查看细节。

## 两种导入方式

有两个入口，都会打开同一个**浏览器数据**导入界面：

- <strong>首次启动期间。</strong>设置 Phi 的引导流程会邀请你导入数据。
- <strong>之后随时导入。</strong>打开 **Phi** 菜单（Apple 菜单旁的粗体应用菜单），选择**从其他浏览器导入…**。

导入界面提供四种来源：**从 Chrome 导入**、**从 Safari 导入**、**从 Arc 导入**和**从文件导入**。Chrome、Safari 和 Arc 选项会直接读取已安装浏览器的数据，并允许你选择要导入的数据类型。下面的章节会更详细地介绍**从文件导入**。

导入内容会进入你发起操作时所在的[空间](/zh-Hans/spaces/)。书签会加入该空间的书签树，历史记录则会加入浏览历史。无法在[无痕模式](/zh-Hans/incognito/)中导入；请先切换到常规空间或窗口。

::: tip 从 Safari 导入前请先退出 Safari
如果使用**从 Safari 导入**，请先退出 Safari。Safari 会将部分近期活动保留在内存中，只有关闭时才会完整写入磁盘；在它仍运行时导入，可能遗漏最新的书签和历史记录。**从文件导入**不受影响，因为它读取的是你已经导出的快照。
:::

## 从文件导入

选择**从文件导入**，单击**选取文件…**，然后选取文件。Phi 接受三类文件，并根据文件本身决定如何处理。此选项不提供数据类型复选框；文件中包含什么，就导入什么。处理期间会显示**正在从文件导入数据…**。

### 每种文件会导入什么

| 文件                     | 扩展名          | 导入内容               |
| ------------------------ | --------------- | ---------------------- |
| **书签 HTML**            | `.html`、`.htm` | 仅书签                 |
| **Safari 历史记录 JSON** | `.json`         | 仅浏览历史             |
| **Safari 导出归档**      | `.zip`          | 同时导入书签和历史记录 |

**书签 HTML** 是所有主流浏览器都能导出的标准「Netscape 书签」格式，包括 Chrome、Safari、Firefox、Edge 和 Phi 本身。导入后，书签会添加到当前空间的**已导入**文件夹中，便于统一查找或删除。

**Safari 历史记录 JSON** 和 **Safari 导出归档**都来自 Safari 的<strong>文件 → 导出 → 导出浏览数据…</strong>功能。Safari 会生成一个 `.zip` 归档；如果你已经解压，也可以直接选择其中的 `History.json` 文件。

- **Safari 导出归档**（`.zip`）是最简单的选择：选中后，Phi 会一次性导入书签和历史记录。
- 单独的 **Safari 历史记录 JSON** 只导入历史记录。

### 会导入和不会导入的内容

- <strong>仅书签和历史记录。</strong>通过此路径绝不会导入密码、支付卡或 Safari 也能导出的其他项目。未经询问就带入这类敏感数据并不合适，因此即使 Safari 归档包含它们，Phi 也会跳过。
- <strong>一个损坏文件不会阻塞其余内容。</strong>在 `.zip` 中，Phi 会读取所有可用的书签和历史记录文件，并跳过无法读取的项目，例如无关文件或损坏条目。
- <strong>分段历史记录会完整导入。</strong>Safari 有时会把大型历史记录拆成多个文件（`History.json`、`History-0001.json` 等），Phi 会全部导入。
- <strong>重复导入不会不断堆积副本。</strong>导入的历史记录会像其他浏览器导入一样合并到现有记录中，因此两次导入同一文件不会成倍增加访问记录。
- <strong>大型或损坏文件会被安全处理。</strong>Phi 会限制单个文件或归档的读取量，避免异常庞大或格式错误的文件卡住浏览器，并会直接跳过它。
- <strong>没有可导入内容时也会正常结束。</strong>如果文件中没有 Phi 可用的内容，导入会正常完成，而不会停滞或报错。

## 导出书签

Phi 可以将**当前空间**的书签导出为 HTML 文件。打开**书签**菜单，选择**导出书签…**，然后选择保存位置。Phi 会建议类似 `Phi-Bookmarks-<Space>-<date>.html` 的文件名。

- 文件使用上述标准 **Netscape 书签**格式，因此可以顺利导入 Chrome、Safari、Firefox、Edge，也可以通过**从文件导入**重新导入 Phi。
- 导出只包括当前所在空间。由于书签[按空间划分](/zh-Hans/bookmarks/)，若要保存另一个空间的书签，请先切换空间再导出。
- 当前空间没有书签时，<strong>导出书签…</strong>会呈灰色；无痕空间也不提供此功能，因为无痕空间从不保存书签树。
- 配对两个页面的[分屏](/zh-Hans/layouts/)书签会被写成两个普通条目，以便标准格式表示。

### 往返迁移

先将某个空间的书签导出为 HTML，再使用**从文件导入**将它们导入另一个空间、另一个个人资料，或另一台 Mac 上的 Phi。这通常是将一组书签复制到不同个人资料或两台 Mac 之间最快的方法。

## 导出全部数据（不只是书签）

<strong>导出书签…</strong>只会导出书签。要把你的全部 Phi 数据（空间、个人资料、历史记录等）备份为单个文件，请改用**帮助**菜单中的**管理用户数据 → 导出用户数据…**。这才是迁移到新 Mac 或保留完整个人副本的工具；它与 Phi 自动回退快照的关系请参阅[时间机器备份](/zh-Hans/time-machine/#exporting-your-own-data)。
