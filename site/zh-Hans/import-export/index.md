# 导入与导出

Phi 可以从其他浏览器带入书签和浏览历史记录，既能直接读取已安装的浏览器，也能读取你手头已有的文件。它还能把某个空间的书签导出为标准 HTML 文件。本页讲这两个方向，并逐一说明每种文件会带进来什么。

如果你刚接触 Phi，只想先看迁移概览，先读 [迁移到 Phi](/zh-Hans/switching-to-phi/)，需要细节时再回到这里。

## 两种导入入口

入口有两个，打开的都是同一个**浏览器数据**导入界面：

- **首次运行时**：初始设置流程会在你配置 Phi 的过程中提议导入。
- **之后任何时候**：打开 **Phi** 菜单（苹果菜单旁边加粗显示的 App 菜单），选择**从其他浏览器导入…**。

导入界面提供四个来源：**从 Chrome**、**从 Safari**、**从 Arc** 和**从文件**。Chrome、Safari 和 Arc 这三项直接读取已安装浏览器的数据，并让你挑选要带过来的数据类型。下面几节详细介绍**从文件**。

导入的内容会落在你执行导入时所在的 [空间](/zh-Hans/spaces/)：书签并入该空间的书签树，历史记录并入你的浏览历史记录。在 [无痕空间](/zh-Hans/incognito/) 中无法导入，请先切换到常规空间或窗口。

::: tip 从 Safari 导入前先退出 Safari
如果使用**从 Safari**，请先退出 Safari。Safari 会把一部分最近的活动留在内存里，直到退出时才完整写入磁盘，所以在它仍在运行时导入，可能会漏掉最新的书签和历史记录。**从文件**不受此影响，它读取的是你已经导出好的快照。
:::

## 从文件导入

选择**从文件**，点按**选择文件…**，然后选中文件。Phi 接受三种文件，并根据文件本身决定怎么处理。这个选项没有数据类型复选框，文件里有什么就导入什么。导入过程中你会看到**正在从文件导入数据…**。

### 每种文件分别导入什么

| 文件                     | 扩展名          | 导入内容           |
| ------------------------ | --------------- | ------------------ |
| **书签 HTML**            | `.html`、`.htm` | 仅书签             |
| **Safari 历史记录 JSON** | `.json`         | 仅浏览历史记录     |
| **Safari 导出归档**      | `.zip`          | 书签**和**历史记录 |

**书签 HTML** 是标准的「Netscape 书签」格式，所有主流浏览器都能导出，包括 Chrome、Safari、Firefox、Edge，以及 Phi 自己。导入后，其中的书签会放进当前空间的**已导入**文件夹，集中在一起，之后查找或删除都方便。

**Safari 历史记录 JSON** 和 **Safari 导出归档**都来自 Safari 的同一项功能：**文件 → 导出 → 将浏览数据导出到文件…**。Safari 生成的是一个 `.zip` 归档；如果你已经解压，也可以直接选中其中的 `History.json` 文件。

- **Safari 导出归档**（`.zip`）最省事：选中它，Phi 一步导入书签和历史记录。
- 单独的 **Safari 历史记录 JSON** 只导入历史记录。

### 哪些会导入，哪些不会

- **只导入书签和历史记录**：Safari 还能导出密码、银行卡等其他项目，但这条路径从不导入它们。不经询问就带入这类敏感数据并不合适，所以即使 Safari 归档里包含这些文件，Phi 也会跳过。
- **一个坏文件不会拖住其余内容**：在 `.zip` 里，Phi 会读取每一个能读的书签和历史记录文件，跳过读不了的，比如无关文件或损坏的条目。
- **多段历史记录完整导入**：Safari 有时会把大体量的历史记录导出拆成多个文件（`History.json`、`History-0001.json` 等），Phi 会全部导入。
- **重复导入不会堆出重复项**：导入的历史记录会像任何浏览器导入一样合并进你现有的历史记录，同一个文件导两次不会让访问次数翻倍。
- **超大或损坏的文件会被安全处理**：Phi 限制了从单个文件或归档读取的数据量，异常大或格式错误的文件卡不住浏览器，Phi 会直接跳过它。
- **没有可导入内容时也能正常结束**：如果文件里没有 Phi 能用的内容，导入会正常结束而不报错，不会卡住。

## 导出书签

Phi 可以把**当前空间**的书签导出为一个 HTML 文件。打开**书签**菜单，选择**导出书签…**，再选择保存位置。Phi 会建议一个类似 `Phi-Bookmarks-<Space>-<date>.html` 的文件名。

- 导出的文件就是上面说的标准 **Netscape 书签**格式，可以顺利导入 Chrome、Safari、Firefox、Edge，也可以通过**从文件**导回 Phi。
- 导出只覆盖你当前所在的空间。书签是 [按空间划分](/zh-Hans/bookmarks/) 的，要保存另一个空间的书签，切换空间后再导出一次。
- 当前空间没有书签时，**导出书签…** 呈灰色不可用；在无痕空间中它也不可用（无痕空间从不保存书签树）。
- [分屏](/zh-Hans/layouts/) 书签把两个页面存为一条，导出时会写成两条普通条目，因为标准格式无法表示成对的页面。

### 导出再导入

把某个空间的书签导出为 HTML，再用**从文件**导回来，目标可以是另一个空间、另一个个人资料，或者另一台 Mac 上的 Phi。要在个人资料之间或两台 Mac 之间复制一套书签，这通常是最快的办法。

## 导出全部数据（不只是书签）

**导出书签…** 只导出书签。要把你的全部 Phi 数据（空间、个人资料、历史记录等）备份成一个文件，改用**帮助**菜单里的**管理用户数据 → 导出用户数据…**。那才是换新 Mac 或留一份完整个人副本时该用的工具；它与 Phi 自动回滚快照的关系，见 [时间机器备份](/zh-Hans/time-machine/#exporting-your-own-data)。
