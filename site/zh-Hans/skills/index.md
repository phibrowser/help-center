# 浏览器技能

浏览器技能是一组交给助理的可复用指令。把一个多步骤任务教给它一次，之后只需一句请求就能触发完整流程，不必每次重新说明所有步骤。经常发生的工作会变成助理知道如何完成的事情。

有些技能是实用的一次性操作，例如显示当前页面的二维码、将页面保存为 PDF、获取 YouTube 字幕；另一些则封装了你经常执行的较长流程。无论哪种，重点都一样：描述一次，反复使用。

::: tip 与 phi-browser skill 不是同一回事
本页介绍的**浏览器技能**，是你在 Phi 内部交给助理的指令。<strong>[phi-browser skill](/zh-Hans/phi-browser-skill/)</strong>则完全不同：它是一个让 Claude Code 等外部 AI 智能体从终端操控 Phi 的软件包。同一个词有两种含义，因此要明确区分：浏览器技能存在于浏览器中，phi-browser skill 存在于你的智能体中。
:::

## 内置技能和你自己的技能

技能分为两类：

- **内置技能**：由 Phi 提供和维护，开箱可用。
- **你自己的技能**：根据个人工作方式创建。

内置技能需要主动启用。你可以浏览全部技能，并把需要的项目加入技能库，而不是一次性全部开启。

## 技能库

**技能**页面用于统一管理。请从**新标签页右上角**的菜单打开；最近对话和小组件也位于同一个菜单中，然后选择**技能**。

页面顶部会重点展示精选的内置技能，下方可以浏览完整集合。你可以按**全部**、**内置**、**用户创建**或**已启用**筛选，也可以按名称搜索。这里最接近一个展示助理能力的画廊。

对于任意技能，你可以：

- 将内置技能**添加**到技能库，并在以后移除；移除后随时可以重新添加。
- **启用或停用**技能而无需移除，以决定哪些技能当前处于活动状态。
- **查看**技能的完整详情，在使用前准确了解它会做什么。

## 创建自己的技能

你不受内置集合限制。Phi 包含一个**技能创建器**，可以根据任务描述帮助你设计并保存新技能，因此创建技能本身也是一项可以直接提出请求的技能。你自己的技能只是用个人语言写成的普通指令，可以随着工作习惯变化随时编辑或删除。

## 在对话中使用技能

技能通过助理运行，不会自行执行。技能启用后，当你的请求与它的用途相符时，助理可以主动选择使用。你也可以在编写消息时自行从技能列表中选择，包括从[新标签页的提问框](/zh-Hans/new-tab/)中选择，以明确指定要使用哪一项技能。

## 技能可以采取行动，因此要像亲自操作一样审慎

技能不只是获取和总结信息。填写表单、发布内容或操作网站的技能，是在你的浏览器和会话中以你的身份行动，因此会带来两项后果。

任何有实际后果的操作仍由你负责，例如购买、发送消息或提交表单。启用技能前请先阅读其具体行为，这正是**查看**详情的用途。

而且部分网站不欢迎自动化。Reddit 是一个广为人知的例子：被判定为自动化操作的账户可能受到限制或封禁，决定权属于网站，而不属于我们。如果技能会操作类似网站，你需要自行承担账户风险。详情请参阅[phi-browser skill](/zh-Hans/phi-browser-skill/)。
