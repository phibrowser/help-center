# 浏览器 Skill

一个浏览器 Skill 就是一条交给助手的可重复使用的指令。把一个多步骤任务教给它一次，之后一句请求就能触发整个流程，不用每次都把步骤讲一遍。一件反复出现的工作，变成了助手本来就会做的事。

有些 Skill 是实用的一次性动作：显示当前页面的二维码、把页面存为 PDF、抓取 YouTube 视频的转写文稿。另一些则封装了你经常执行的较长流程。无论哪种，要点都一样：描述一次，永久复用。

::: tip 和 phi-browser skill 不是一回事
**浏览器 Skill** 是本页的主题：你在 Phi 里交给助手的指令。**[phi-browser skill](/zh-Hans/phi-browser-skill/)** 是完全不同的东西，它是一个软件包，让 Claude Code 这样的外部 AI 智能体从你的终端驱动 Phi。同一个词，两种含义，所以我们把它们分开：浏览器 Skill 住在浏览器里，phi-browser skill 住在你的智能体里。
:::

## 内置 Skill 和你自己的 Skill

Skill 有两种：

- **内置 Skill**：由 Phi 提供和维护，拿来就能用。
- **你自己的 Skill**：你按自己的工作方式创建的。

内置 Skill 需要主动添加。它们放在那里供你浏览，你把想要的加进自己的库，而不是一开始就全部开启。

## Skill 库

**Skill** 页面是管理这一切的地方。从**新标签页右上角**的菜单打开它，也就是存放最近对话和小组件的那个菜单，然后选择 **Skill**。

页面顶部是精选的内置 Skill，下方可以浏览完整列表。按**全部**、**内置**、**用户创建**或**已启用**筛选，或按名称搜索。这里最能一览你的助手能做什么。

对任何 Skill，你都可以：

- **添加**一个内置 Skill 到你的库，之后也可以移除。随时可以再加回来。
- **启用或禁用**一个 Skill 而不移除它，由你决定哪些处于活动状态。
- **查看**一个 Skill 的完整详情，在使用前确切了解它会做什么。

## 创建你自己的 Skill

你不限于内置那一套。Phi 包含一个 **Skill 生成器**，可以根据你对任务的描述帮你设计并保存新的 Skill，所以创建 Skill 本身也是一个可以直接开口请求的 Skill。你自己的 Skill 就是用你自己的话写的普通指令，随着习惯变化，你随时可以编辑或删除。

## 在聊天中使用 Skill

Skill 通过助手运行，不会自行运行。Skill 启用后，当你的请求符合它的用途时，助手会自己去用它。你也可以自己把某个 Skill 带进对话：写消息时从 Skill 列表里选择，包括在[新标签页的提问框](/zh-Hans/new-tab/)里，适合你想明确指定用哪一个的时候。

## Skill 会执行操作，要像对待自己的操作一样谨慎

Skill 能做的不只是抓取和总结。一个会填表单、发帖或在网站里操作的 Skill，是以你的身份、从你的浏览器、带着你的登录状态在做这些事。由此有两点。

任何有后果的事仍然算在你头上：一次购买、一条发出的消息、一份提交的表单。启用一个 Skill 前先读一读它会做什么，**查看**详情就是为此而设的。

另外，有些网站不欢迎自动化。Reddit 是众所周知的例子，被判定为自动化的账号会被限制或封禁，而这个决定权在他们，不在我们。如果一个 Skill 在这样的网站上操作，你是在拿自己的账号承担这个风险。更多说明见 [phi-browser skill](/zh-Hans/phi-browser-skill/)。
