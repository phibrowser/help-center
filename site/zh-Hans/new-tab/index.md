# 新标签页与小组件

Phi 会用个性化主页取代标准的新标签页。每个新标签页都会显示问候语、一个用于搜索或提问的输入框，以及由你自行排列的小组件网格。它会自动跟随你的[主题以及浅色／深色选择](/zh-Hans/themes/)。

## 你的新标签页

- **问候语**：根据 Phi 对你的了解生成的个性化欢迎语，会随时间变化。你可以分享它，也可以围绕它与助理对话。
- **一个输入框，同时搜索或提问**：输入内容即可搜索网页、向助理提问或直接访问网址。你可以[附加标签页](/zh-Hans/ai/#chat-with-tabs)或文件，也可以将技能带入对话。
- **快速入口**：从右上角菜单访问最近的对话、小组件和[技能](/zh-Hans/skills/)库。

由于搜索框与助理相连，新标签页通常是发起搜索、提问或任务最快的地方，无需先打开单独的对话。助理能做什么，请参阅[认识你的助理](/zh-Hans/ai/)。

## 小组件

小组件是固定在新标签页上的小卡片，例如时钟、天气、最常访问的网站、专注计时器等。你可以决定显示哪些小组件以及它们的位置。

### 内置小组件

- **一目了然**：时钟（任意时区的当地时间和日期）、天气（某个地点的当前状况）、每日一句，以及每日图片（从你最近的记忆主题中选取的氛围图片）。
- **工具**：番茄专注计时器、货币转换器和快速翻译。
- **快捷方式**：常用网站（你访问最多的网站）和 GitHub stars（代码仓库的 star 趋势）。
- **你的活动**：最近阅读（你最近读过的页面）、热门帖子（来自 Hacker News 或 Reddit 等来源的热门内容），以及总结近期活动的日报和周报。

### 添加和排列小组件

从右上角的**小组件**菜单，或向下滚动时出现的**自定义**按钮打开小组件库。然后：

- **将小组件拖到页面上**进行固定。
- 使用已固定小组件的菜单来**移动和调整大小**、**刷新**数据、**编辑**或**删除**。

布局会保存在你的设备上，因此每次打开新标签页时都会保持一致。

### 了解你的小组件

小组件库会根据 Phi 记住的内容推荐一些初始选项，部分小组件也会以同样方式个性化内容，例如显示你确实会再次访问的页面。你还可以直接在对话中要求助理为你**创建自定义小组件**，或**改进**现有小组件。

这建立在 Phi 其他功能所用的同一本地优先记忆之上：小组件引用的内容会留在你的设备上，并由你掌控。详情请参阅[隐私与数据](/zh-Hans/privacy/)。
