# 新标签页与小组件

Phi 用一个个性化的主页取代了标准的新标签页。每次打开新标签页，你都会看到一句问候语、一个既能搜索又能提问的输入框，以及一组由你自己排布的小组件。它会自动跟随你的[主题与浅色或深色外观](/zh-Hans/themes/)。

## 你的新标签页

- **问候语**，一段个性化的欢迎语，会随时间变化，来自 Phi 对你的了解。你可以分享它，也可以就它和助手聊聊。
- **一个框，既能搜索也能提问**，输入内容即可搜索网页、向助手提问，或直接前往某个网址，都在同一个地方完成。你可以[附加标签页](/zh-Hans/ai/#chat-with-tabs)或文件，也可以把 Skill 带进对话。
- **快捷入口**，从右上角的菜单打开最近的对话、你的小组件和 [Skill 库](/zh-Hans/skills/)。

因为搜索框直接连着你的助手，新标签页往往是开始一件事最快的地方，无论是搜索、提问还是交办任务，都不用先另开一个对话。它能做什么，见[认识你的助手](/zh-Hans/ai/)。

## 小组件

小组件是你固定在新标签页上的小卡片：时钟、天气、最常访问的网站、专注计时器等等。显示哪些、放在哪里，都由你决定。

### 内置小组件

- **概览**，时钟（任意时区的本地时间和日期）、天气（某个地点的当前天气）、每日一句，以及每日一图（取材于你近期记忆主题的氛围图片）。
- **工具**，番茄钟专注计时器、汇率换算和快速翻译。
- **快捷方式**，最常访问的网站（你访问最多的网站）和 GitHub Star（某个仓库的 Star 趋势）。
- **你的活动**，最近阅读（你最近读过的页面）、热门帖子（来自 Hacker News、Reddit 等来源的热门内容），以及总结你近期活动的日报和周报。

### 添加和排布小组件

从右上角的**小组件**菜单打开小组件库，或者点按滚动时出现的**自定义**按钮。然后：

- **把小组件拖到页面上**即可固定。
- 通过已固定小组件的菜单，可以对它**移动和调整大小**、**刷新**它的数据、**编辑**或**删除**它。

布局保存在你的设备上，所以每次打开新标签页看到的都一样。

### 懂你的小组件

小组件库会根据 Phi 对你的记忆推荐几个小组件作为起点；有些小组件也会用同样的方式个性化自己的内容，比如把你真正会回访的页面放到前面。你还可以在对话里直接让助手**创建自定义小组件**，或**优化**现有的小组件。

这和 Phi 的其他部分建立在同一套本地优先的记忆上：小组件所依赖的数据留在你的设备上，由你掌控。详情见[隐私与你的数据](/zh-Hans/privacy/)。
