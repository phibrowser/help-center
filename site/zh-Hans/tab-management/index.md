# 管理标签页与书签

Phi 允许你一次选中多个项目，当作一批来处理。你可以右键点按所选项目执行批量操作，也可以把它们一起拖动，重新整理常规标签页、分屏视图、书签和书签文件夹，而不必逐个移动。

## 选中多个项目

两种修饰键都可以用来建立选择：

- **按住 Command (⌘) 键点按**某个标签页或书签，可以把它加入选择或从选择中移除。当前标签页会自动包含在内，所以按住 Command 键点按另一个标签页会同时选中两者。
- **按住 Shift 键点按**另一个项目，可以选中它与起点之间的连续范围。

在侧边栏中，范围可以包含可见的标签页、书签、书签文件夹，以及已展开的标签页组或文件夹里的内容。折叠的标签页组或文件夹里隐藏的项目不会被包含。分屏视图算作一个可见项目，所以它的两个窗格始终在一起。

在舒适布局中，同样的 Command 点按和 Shift 点按手势也适用于横向标签栏里的标签页。书签的多选功能在均衡和性能布局的侧边栏中可用。

## 处理所选项目

右键点按任意高亮项目即可打开批量菜单。Phi 会根据你选中的内容调整可用操作，有些操作只在选中的是标签页、书签或兼容的混合项目时才会出现。

| 操作                            | 作用                                                 |
| ------------------------------- | ---------------------------------------------------- |
| **复制标签页**                  | 在当前空间打开所选页面的副本。                       |
| **拷贝链接**                    | 把所选页面的网址作为列表拷贝。                       |
| **以分屏打开**                  | 把恰好两个兼容的所选项目并排放置。                   |
| **添加到书签 / 添加到文件夹**   | 保存所选标签页，或把所选书签整理到指定位置。         |
| **将标签页添加到新标签页组**    | 用兼容的所选项目创建一个标签页组。                   |
| **将标签页移到标签组**          | 把兼容的所选项目移入已有的标签页组。                 |
| **移到空间**                    | 把所选项目转移到另一个空间，并从当前空间移除。       |
| **克隆到空间**                  | 在另一个空间创建一份副本，原有选择保持不动。         |
| **关闭标签页 / 关闭其他标签页** | 关闭所选常规标签页，或关闭选择之外的所有常规标签页。 |
| **删除书签 / 文件夹 / 项目**    | 经确认后永久删除所选的已保存项目。                   |

## 拖动多个项目来整理

建立选择后，拖动任意一个高亮项目，整个选择会一起移动。拖动预览会显示有多少可见项目正在移动。如果你拖动的是一个未选中的项目，Phi 会清除这批选择，只移动那一个。

放到哪里，决定会发生什么：

- **在标签页列表内**：一起重排所选标签页，或把它们放进某个标签页组。
- **在书签区域内**：重排所选书签和文件夹，或放到某个文件夹上以移入其中。
- **从标签页到书签**：把所选标签页放到书签区域或某个书签文件夹上，即可保存到那里。
- **从书签到标签页**：把所选书签页面放到标签页列表或标签页组里，它们会作为标签页打开并归入其中。
- **混合选择**：当目标位置支持每一个所选项目时，标签页和书签可以一起移动。

拖动期间分屏视图保持在一起。包含书签文件夹的选择会留在书签区域：对于无法保留文件夹的标签页列表和标签页组目标，Phi 会拒绝放置，而不是把选择拆开。

## 把项目移动或克隆到另一个空间

想让所选项目离开当前空间，用**移到空间**；想让两个空间都有同样的标签页或书签，用**克隆到空间**。

两种操作都能处理常规标签页、分屏视图、书签和书签文件夹的兼容组合。转移时 Phi 会让分屏窗格保持在一起，并保留书签的组织结构。目标空间从操作的子菜单中选择。

当前空间和无痕空间不会出现在目标列表中。在无痕状态下浏览时，空间转移操作也不可用。

## 退出多选

按 **Escape**，或正常点按某个项目切换到它，即可退出多选。在侧边栏中，点按空白区域也会清除选择。大多数批量操作完成后会自动清除选择。

想了解项目存放在哪里，见 [空间与个人资料](/zh-Hans/spaces/)。书签如何原地打开、固定标签页如何工作，见 [书签与固定标签页](/zh-Hans/bookmarks/)。
