# 管理标签页与书签

Phi 允许你选择多个项目并将其作为一个批次处理。你可以右键单击所选项目执行批量操作，也可以拖动它们来重新整理普通标签页、分屏浏览、书签和书签文件夹，无需逐个移动。

## 选择多个项目

使用以下任一修饰键来建立选择：

- <strong>Command-单击（⌘-单击）</strong>标签页或书签，将该项目加入选择或从选择中移除。当前活动标签页会自动包含在内，因此 Command-单击另一个标签页会同时选中两者。
- **Shift-单击**另一个项目，选择它与起始项目之间连续的范围。

在侧边栏中，范围可以包括可见的标签页、书签、书签文件夹，以及已展开的分组或文件夹内容。折叠分组或文件夹内部隐藏的项目不会被包含。分屏浏览会被视为一个可见项目，因此其中两个窗格会保持在一起。

在舒适布局中，同样可以对水平标签栏中的标签页使用 Command-单击和 Shift-单击。在均衡和性能布局中，可以从侧边栏多选书签。

## 处理所选项目

右键单击任一高亮项目可打开批量菜单。Phi 会根据所选内容调整可用操作，因此某些操作只会针对标签页、书签或兼容的混合选择出现。

| 操作                           | 作用                                                     |
| ------------------------------ | -------------------------------------------------------- |
| **复制标签页**                 | 在当前空间中打开所选页面的副本。                         |
| **复制链接**                   | 将所选页面的网址复制为列表。                             |
| **以分屏打开**                 | 将恰好两个兼容的所选项目并排放置。                       |
| **添加到书签／添加到文件夹**   | 保存所选标签页，或将所选书签整理到指定位置。             |
| **将标签页添加到新分组**       | 使用兼容的所选项目创建标签页组。                         |
| **将标签页移到分组**           | 将兼容的所选项目移入现有标签页组。                       |
| **移到空间**                   | 将所选项目转移到另一个空间，并从当前空间移除。           |
| **克隆到空间**                 | 在另一个空间创建副本，同时将原始项目留在当前空间。       |
| **关闭标签页／关闭其他标签页** | 关闭所选普通标签页，或关闭所选范围之外的所有普通标签页。 |
| **删除书签／文件夹／项目**     | 确认后永久删除所选的已保存项目。                         |

## 拖动多个项目进行整理

建立选择后，拖动任一高亮项目即可移动整个选择。拖动预览会显示正在移动多少个可见项目。如果开始拖动一个未选中的项目，Phi 会清除批量选择，只移动该项目。

放置位置决定了具体操作：

- <strong>在标签页列表内：</strong>一起重新排列所选标签页，或将它们放入标签页组。
- <strong>在书签区域内：</strong>一起重新排列所选书签和文件夹，或将它们放到某个文件夹上以移入其中。
- <strong>从标签页拖到书签：</strong>将所选标签页放入书签区域或书签文件夹以保存。
- <strong>从书签拖到标签页：</strong>将所选书签页面放入标签页列表或标签页组，以标签页方式打开并整理。
- <strong>混合选择：</strong>当目标位置支持所有选中项目时，标签页和书签可以一起移动。

拖动过程中，分屏浏览会保持完整。包含书签文件夹的选择只能留在书签区域；对于无法保留该文件夹的标签页列表或标签页组目标，Phi 会拒绝放置，而不会拆散选择。

## 将项目移动或克隆到另一个空间

如果所选项目应离开当前空间，请使用**移到空间**。如果希望相同标签页或书签同时存在于两个空间，请使用**克隆到空间**。

这两项操作都能处理普通标签页、分屏浏览、书签和书签文件夹组成的兼容混合选择。Phi 会保持分屏的两个窗格在一起，并在转移过程中保留书签结构。请从操作的子菜单中选择目标空间。

当前空间和无痕空间不会作为目标显示。在无痕模式中浏览时，空间转移操作也不可用。

## 退出多选

按 **Escape**，或正常单击某个项目以切换到它并退出多选。在侧边栏中，单击空白区域也会清除选择。完成大多数批量操作后，选择会自动清除。

要进一步了解项目存放在哪里，请参阅[空间与个人资料](/zh-Hans/spaces/)。要了解书签如何就地打开以及固定标签页如何运作，请参阅[书签与固定标签页](/zh-Hans/bookmarks/)。
