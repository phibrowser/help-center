# 记忆

记忆是助手了解你的方式。正是这一部分，把一个你在使用的浏览器变成一个理解你的浏览器，让助手不必在你每次提问时都从零开始。

它的不同之处在于学习的来源。大多数助手只知道你在聊天框里输入的内容。Phi 的记忆学习的是你浏览时实际做的事：你阅读、比较、反复回访和正在处理的内容。这是「记住一段对话」和「理解一个人」的区别。知道你花了一下午比较云服务商，或者两周前刚换了新工作，正是这类上下文让帮助贴合你本人，而不是千篇一律。

## 它如何学习

记忆是自动的，在后台安静运行。你不需要教它任何东西，也不用替自己的浏览器做无偿的数据录入。随着你一天天使用，它会逐渐建立起一幅图景：什么对你重要、你总是回到哪里、哪些任务和话题反复出现。

它还会从这些活动里提取关于你的小而具体的事实：你的兴趣、工作、目标，以及你打交道的工具和人。这些叫做**观察记录**，合在一起构成助手对你的当前理解。

近期的行为比偶然做过一次的事情更有分量。相关性会随时间衰减：当前的习惯胜过几个月前的一次偶然绕路，所以这幅图景会跟上你的生活，而不是固定在你的过去。

## Nebula

记忆学到的东西不是黑盒。**Nebula** 是当前的记忆可视化视图，取代了旧的 Memory Galaxy 体验。它把 Phi 学到的内容变成一张像星空一样的图谱，由一条条记忆和一个个聚类组成，你可以在其中探索塑造助手上下文的主题、地点、话题和活动模式。你可以逐一查看助手记下了什么、这些片段之间如何关联，而不用凭信任接受。

你随时可以打开记忆查看。在新标签页上，搜索框正下方就有一个入口。在浏览器本身里，位置取决于你的[布局模式](/zh-Hans/layouts/)：**性能**和**均衡**布局中在**左下角**，**舒适**布局中移到**右上角**。

## 助手如何使用它

当你向助手提问、让它总结页面或交给它一项任务时，它会把记住的关于你的信息和你眼前的内容结合起来，无论那是当前标签页还是整个[分屏视图或标签页组](/zh-Hans/layouts/)。正因如此，它才能给出贴合你的回答，你不用每次重新解释自己的情况。记忆还会为个性化的[新标签页与小组件](/zh-Hans/new-tab/)提供内容，它知道的东西会以有用的形式出现，而不是藏起来。关于如何找到助手并和它对话，见[认识你的助手](/zh-Hans/ai/)。

## 由你掌控

记忆建立的一切都存在你的设备本地，由你掌控。具体来说，你可以：

- 直接在 Phi 里**查看、管理和删除**它记住的任何内容。
- **关闭某个网站的记忆收集**，如果有些页面你不希望它从中学习。
- **导入和导出**你的记忆，它是可携带的，真正属于你，而不是被锁在里面。

你的记忆绝不会用于训练 AI 模型。关于你的数据存放在哪里、Phi 收集和不收集什么，见[隐私与你的数据](/zh-Hans/privacy/)。[关闭 AI](/zh-Hans/privacy/#turning-ai-off) 并不会清除你的记忆。如果你也想把它清掉，在记忆页面上删除，而且这一删除是永久的。

## Phi 之外的记忆：Anamnesis

同一套记忆系统也单独发布，面向（还）没有使用 Phi Browser 的人。**Anamnesis** 是一个独立的扩展程序，适用于 Chrome 和基于 Chromium 的浏览器，从你的浏览活动中建立同样鲜活的本地浏览器记忆。

它遵循同样的原则：你的记忆属于你、跟着你走，你随时可以查看、编辑、删除或导出。你使用自己的 API 密钥，助手直接与你选择的模型提供商通信。Phi 不在中间经手，也不会把你的记忆存到服务器上。因为导出的记忆是可携带的，你随时可以把它带进 Phi Browser 或其他 AI 服务。更多信息见 [phibrowser.com/anamnesis](https://phibrowser.com/anamnesis/)。
