# 记忆

记忆是助理了解你的方式。它让你所使用的浏览器逐渐成为理解你的浏览器，使助理不必在每次收到问题时都从零开始。

不同之处在于它从哪里学习。大多数助理只知道你在对话框中输入的内容。Phi 的记忆则从你的实际浏览行为中学习：你阅读、比较、反复访问和处理的内容。这是“记住一段对话”和“理解一个人”之间的区别。知道你花了一下午比较云服务商，或两周前刚开始一份新工作，正是让帮助变得个性化而非千篇一律的上下文。

## 它如何学习

记忆会在后台自动、安静地工作。你无需专门教它，也不必为了自己的浏览器无偿录入数据。日常使用过程中，它会逐渐理解什么对你重要、你反复关注什么，以及哪些任务和主题经常出现。

它还会从这些活动中提取关于你的具体小事实，包括兴趣、工作、目标，以及你接触的工具和人员。这些信息称为**观察**，共同构成助理对你的工作性理解。

近期活动的权重高于一次性的旧活动。相关性会随时间衰减：当前习惯会胜过几个月前的一次偏离，让这幅图景跟随你的生活变化，而不会被过去固定住。

## Nebula

记忆学到的内容并不是黑箱。**Nebula** 是当前的可视化记忆界面，取代了旧版 Memory Galaxy。它把 Phi 学到的内容呈现为类似星空的记忆和聚类地图，让你探索构成助理上下文的主题、地点、话题和活动模式。你可以直接查看助理捕捉到了什么，以及各部分如何关联，而不必盲目信任。

你可以随时打开记忆查看。在新标签页中，入口位于搜索框下方。在浏览器中，位置取决于[布局模式](/zh-Hans/layouts/)：**性能**和**均衡**模式位于**左下角**，**舒适**模式则位于**右上角**。

## 助理如何使用记忆

当你向助理提问、要求总结页面或委派任务时，它会把对你的记忆与当前眼前的内容一起使用；当前内容可以是一个标签页，也可以是整个[分屏浏览或标签页组](/zh-Hans/layouts/)。正因如此，它能给出适合你的答案，而无需你每次重新解释自己的情况。记忆也会驱动个性化的[新标签页及其小组件](/zh-Hans/new-tab/)，让它了解的内容真正发挥作用，而不是隐藏在后台。有关如何找到助理并与它对话，请参阅[认识你的助理](/zh-Hans/ai/)。

## 保持掌控

记忆建立的所有内容都保存在你的本地设备上，并由你掌控。具体而言，你可以：

- 直接在 Phi 中**查看、管理和删除**它记住的任何内容。
- 对不希望它学习的页面，**关闭特定网站的记忆收集**。
- **导入和导出**记忆，让它真正属于你且可以迁移，而不是被锁在产品中。

你的记忆绝不会用于训练 AI 模型。要了解数据保存在哪里，以及 Phi 会收集和不会收集什么，请参阅[隐私与数据](/zh-Hans/privacy/)。请注意，[关闭 AI](/zh-Hans/privacy/#turning-ai-off)不会清除记忆。如果也想删除记忆，请在记忆页面中操作；删除后无法恢复。

## Phi 之外的记忆：Anamnesis

同一套记忆系统也可以独立使用，面向尚未使用 Phi Browser 的用户。**Anamnesis** 是适用于 Chrome 和 Chromium 浏览器的独立扩展，可以从浏览活动中建立同样鲜活、存储在本地的浏览器记忆。

它遵循相同原则：记忆属于你并与你同在，你可以随时查看、编辑、删除或导出。你需要提供自己的 API 密钥，因此助理会直接与你选择的模型提供商通信。Phi 不会居中转发，也不会将记忆存到服务器。导出的记忆可以迁移，你可以随时将它带入 Phi Browser 或其他 AI 服务。详情请访问 [phibrowser.com/anamnesis](https://phibrowser.com/anamnesis/)。
