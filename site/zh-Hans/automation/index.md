# 自动化与 Phi Link

「智能体式」（Agentic）的意思是，Phi 的 AI 不只会回答问题。它可以在浏览器里采取行动，替你完成任务，某些情况下还能持续运行下去。它有三种工作方式：**立即**执行（按需操作）、**在后台**运行（后台任务），以及**按计划**运行（定时任务）。

## 按需操作

按需操作是助手在你提出要求时执行的任务。Phi 不会把步骤列出来让你照着做，而是自己动手：在当前标签页或新标签页里浏览页面、与网站交互、完成多步骤的工作，你在一旁看着它做。

遇到有实际后果的操作，它不会径直执行，而是先暂停，请你**确认**后再继续。确认提示只有「确认」和「拒绝」两个选项，并按该步骤的风险高低做了标记，让你始终掌握真正要紧的操作。

## 后台任务

有时你不想坐在那里盯着看。智能体可以把一项请求变成在后台运行的**任务**，它会一直工作，不占用你的对话，也不占用你的注意力。

任务：

- 只在你**明确要求**时才会启动；
- 自行运行，你可以继续浏览网页，也可以关闭对话；
- 遇到有风险的步骤会暂停，请你**确认**；
- 会**汇报到你提出要求的那段对话中**，见[下文](#tasks-report-back-to-their-conversation)；
- 始终使用那段对话的语言撰写汇报。如果你想换一种语言，告诉助手即可。

## 定时任务 {#scheduled-tasks}

定时任务是按你设定的时间表反复运行的自动化。比如，Phi 可以每隔几小时查看一次某件商品的价格，监视某个页面有没有变化，或者自动重复另一项基于浏览器的任务。它们本质上就是会重复的后台任务，由 [Phi Sentinel](/zh-Hans/sentinel/) 维持运行，即使浏览器窗口已经关闭也不例外。在这里，Phi 不太像一个带 AI 功能的浏览器，更像一个在你不看着的时候也持续工作的常驻系统。

### 关注页面

设置定时任务最快的方法，是在网页上任意位置右键点按（不要点在选中的文字或链接上），然后选择**让 [你的助手] 关注此页面**。侧边栏会打开一段新对话，助手会读取页面，然后一次一个地问你几个问题：你为什么要关注它、什么样的变化值得告诉你、多久检查一次，以及（如果你愿意）怎样汇报、什么时候停止。

然后它会设置一个定时任务，汇报时机为**仅有变化时**。第一次检查会把页面当前的样子作为起点汇报给你，之后的检查只在有内容发生变化时才会出声。以后要修改、暂停或删除这项关注，在同一段对话里提出即可。

## 任务会汇报到它所在的对话 {#tasks-report-back-to-their-conversation}

在对话中创建的任务，每次运行完成或失败后，都会以助手回复的形式把结果发回那段对话。这段对话会被标记为未读并移到列表顶部，[Phi Chat](/zh-Hans/phi-chat/#tasks-and-unread-conversations) 会在它的**任务**视图中汇集所有这类对话。

每条汇报上方有一条信息栏，显示任务名称、运行序号，以及这次运行是**已完成**还是**失败**。它的 **…** 菜单中有：

- **立即运行**：马上再运行一次任务；
- **停止在此对话中汇报**：任务继续运行，但不再向这段对话发送汇报。使用后，这一项会变为**恢复在此对话中汇报**。

### 管理任务

当一段对话中有任务时，它的顶栏会出现一个带数字的时钟按钮。点按它会打开一个面板，为每项任务显示：

- 它的状态，比如**运行中**、**已启用**（它的时间表仍在运行）、**已暂停**、**已停止**（满足了它的停止条件）、**已结束**或**手动**（它没有时间表）；
- 它的时间表、下次运行时间，以及停止时间（如果它有停止条件）；
- **在此对话中汇报**开关；
- **汇报时机**：**每次运行**，或**仅有变化时**，后者在没有新发现时保持安静。无论选哪一项，失败都会汇报。

任务的 **…** 菜单中有**立即运行**，以及**暂停定时运行**或**恢复定时运行**。

这个面板不能编辑或删除任务。要修改任务的内容或删除任务，在任务所在的对话中告诉助手，或者使用 Phi Sentinel 中的**任务**页面。

### Phi 没有运行时

任务只能在 Phi 运行时运行。如果你的 Mac 关机或处于睡眠状态，或者 Phi 已退出，某次运行可能会错过或被中途打断。Phi 再次启动后：

- 每两小时或更频繁运行一次的任务会直接进入下一次运行，那次运行会说明哪些内容没有检查到；
- 对于其他任务，Phi 会在任务所在的对话中询问是否现在运行一次。汇报会显示**未运行**或**被中断**，下方有**立即运行**和**忽略**按钮，你也可以用自己的话回答。

当任务的下一次定时运行到来时，或者对没有时间表的任务而言，一天之后，这个询问就会撤回。

### 通知 {#notifications}

当汇报发到一段你没有打开的对话中时，Phi 还可以显示一张通知卡片，上面有任务名称和汇报的开头部分。这张卡片是 Phi 自己的，不是 macOS 通知。只有当汇报看起来值得打扰你时，它才会这样做，所以没有新发现的检查会保持安静。**查看详情**会在 [Phi Chat](/zh-Hans/phi-chat/) 中打开那段对话。

## 由你掌控

智能体的设计原则是在你知情的前提下行动，而不是背着你行动。它会在有实际后果的操作前请你确认；任务只在你要求时才启动，遇到有风险的步骤会暂停等待确认；你随时可以暂停任务的时间表、让它停止汇报，或者让助手修改或删除它。关于你的数据存放在哪里、AI 如何处理，请看[隐私与你的数据](/zh-Hans/privacy/)。

智能体按你的指示所做的事，是以你的身份、从你的浏览器、用你的账号完成的。有些网站不欢迎自动化。Reddit 就是众所周知的例子，被检测为自动化的账号会受到限制或被封禁。如果某项任务要通过这类网站完成，这个风险由你承担。

## Phi Sentinel

定时任务需要在浏览器窗口关闭后继续运行。**Phi Sentinel** 就是让这一点成为可能的后台应用，它位于 macOS 菜单栏，同时还承载私有 AI，也就是把部分 AI 放在你自己的 Mac 上运行的选项。完整介绍请看 [Phi Sentinel](/zh-Hans/sentinel/)。

## Phi Link {#phi-link}

**Phi Link** 把 Phi 接入 Telegram，让你在手机上也能使用助手，离开 Mac 时也能收到更新。有了它，你可以：

- 在手机上和助手聊天；
- 收到任务运行完成后的结果；
- 离开浏览器后继续推进工作流。

设置方式有两种：

- **官方 Phi Link 机器人**，最省事的路径：扫描二维码，一键完成设置，然后就可以用了。
- **你自己的 Telegram 机器人**，适合想要更多控制权的人：通过 Telegram 的 BotFather 创建一个机器人，生成令牌，再粘贴到 Phi 的设置里。这样你可以自定义机器人的名字和头像。

两种方式下助手的身份保持一致，所以桌面和手机上的体验是连贯的。
