# 自动化与 Phi Link

「智能体式」意味着 Phi 的 AI 不只会回答问题。它可以在浏览器中采取操作、替你执行任务，并在某些情况下持续工作。它有三种工作方式：**立即**行动（按需操作）、**在后台**运行（Shadow 任务），以及**按计划**运行（定时任务）。

## 按需操作

按需操作是助理在你提出要求时执行的任务。它不只是告诉你应当遵循哪些步骤，而是会亲自完成工作：浏览页面、与网站交互，并在当前或新标签页中完成多步骤任务，同时让你看到执行过程。

遇到有实际后果的操作时，它不会擅自继续，而是先暂停并要求你**确认**。确认或拒绝提示会标示该步骤的风险程度，让重要操作始终由你把关。

## 后台任务

有时你不想坐着观看。智能体可以让任务**脱离对话并在后台运行**，这称为 **Shadow 任务**（Shadow Task）。它会继续工作，而不会占用你的对话或注意力。

后台任务：

- 只有在你**明确要求**后台执行时才会启动；
- 自行运行，因此你可以继续浏览或关闭对话；
- 遇到有风险的步骤时会暂停并要求你**确认**；
- 在 Phi Sentinel 的**任务**页面报告进度、结果和生成的文件，因此结果不会自行回到对话中；
- **完成时通知你**，搭配手机上的 [Phi Link](#phi-link) 尤其方便；
- 可以在运行期间**取消**，或在完成后**再次运行**。

## 定时任务 {#scheduled-tasks}

定时任务是按照你定义的计划重复运行的自动化。例如，Phi 可以每隔几小时监控商品价格、观察页面变化，或自动重复其他基于浏览器的任务。它们本质上是会重复的后台任务，由 [Phi Sentinel](/zh-Hans/sentinel/) 维持运行，即使浏览器窗口已经关闭也不受影响。此时 Phi 更像一个在你没有关注时仍持续工作的系统，而不只是一款带 AI 功能的浏览器。

## 保持掌控

智能体的设计目标是在你知情的情况下行动，而不是背着你操作。遇到有实际后果的行为时，它会先要求确认；后台任务只有在你要求时才启动，并会在有风险的步骤暂停等待确认；你也可以随时停止正在运行的任务。有关数据保存位置和 AI 处理方式，请参阅[隐私与数据](/zh-Hans/privacy/)。

## Phi Sentinel

定时任务需要在浏览器窗口关闭后继续运行。**Phi Sentinel** 是常驻 macOS 菜单栏的后台应用，负责实现这一点，同时也托管私有 AI，让部分 AI 可以在你的 Mac 上运行。详情请参阅 [Phi Sentinel](/zh-Hans/sentinel/)。

## Phi Link {#phi-link}

**Phi Link** 将 Phi 与 Telegram 连接，让你可以从手机使用助理，并在离开 Mac 时收到更新。通过它，你可以：

- 从手机与助理对话；
- 在任务成功或失败时收到通知；
- 离开浏览器后继续工作流程。

有两种设置方式：

- **官方 Phi Link 机器人**：最简单的方式。扫描二维码，一键完成设置即可。
- **你自己的 Telegram 机器人**：如需更大控制权，可通过 Telegram BotFather 创建机器人、生成令牌，并粘贴到 Phi 设置中。这样可以自定义机器人的名称和头像。

同一个助理身份会延续到手机，因此桌面端和移动端的体验保持一致。
