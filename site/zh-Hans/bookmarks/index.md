# 书签与固定标签页

在 Phi 里，侧边栏就是你的工作区，书签和固定标签页是留住重要页面的两种方式。本章在 [布局与导航](/zh-Hans/layouts/) 的基础上进一步讲它们的行为，先从最让传统浏览器用户意外的一点说起：在 Phi 里，书签会原地打开为标签页。

## 原地打开的书签

传统浏览器里的书签只是一个死链接：每次点按都会新开一个标签页，同一个页面很快就攒出一堆重复。Phi 把书签当作活的条目。点按一下，它就在原地打开，侧边栏里的这一条本身就变成了正在浏览的标签页。关掉页面，书签仍留在原处，随时可以再打开。如果这个书签已经打开，再点按只会切换到那个标签页，不会再开一份。

这正是 Arc 和 Dia 带火的思路：侧边栏里放的是活的东西，而不是一个一年只翻两次的独立归档。Phi 沿用了这个模型，同时保留了真正的书签树，文件夹也在，所以书签归档带来的组织能力你一样不少。

## 创建与整理书签

- **创建书签**：把标签页拖动到侧边栏，或右键点按标签页并选择**添加到书签**（舒适模式下显示为**添加到书签栏**）。用**添加到文件夹**可以直接放进某个文件夹。
- **用文件夹整理**：书签可以放进文件夹；要建子文件夹，选择**新建嵌套文件夹…**。
- **把分屏存成一个书签**：在分屏视图中，**将分屏添加到书签**会把两个页面存为一条书签，打开时两页一起恢复。
- **管理书签**：书签的右键菜单里有**拷贝链接**、**重命名…**、**编辑…**、**在新标签页中打开**、**以分屏打开**和**删除**。

书签只属于你当前所在的空间。每个 [空间](/zh-Hans/spaces/) 都有自己的一套书签，工作空间里存的页面不会混进个人空间。

## 固定标签页

固定标签页以网格形式排在侧边栏顶部，放的是你天天泡在里面的那几个页面：邮箱、仪表盘、项目工具。它们是常驻的：页面关掉后，固定标签页仍留在网格里，点按一下页面就会重新打开。

- **固定一个标签页**：右键点按标签页并选择**固定**，或直接把它拖动到固定网格中。同一菜单里的**取消固定**会把它放回标签页列表。
- **调整顺序**：在网格中拖动固定标签页即可重新排列。
- **固定一个分屏**：**固定分屏**会把双栏布局作为一个固定项保存，打开时两侧一起恢复；**取消固定分屏**则将其撤销。

## 选择固定标签页的范围 {#choose-a-pinned-tab-scope}

打开**设置 → 空间**，用**固定标签页范围**选择固定标签页的共享范围。默认是**个人资料**。

| 范围         | 固定标签页出现在哪里                         |
| ------------ | -------------------------------------------- |
| **空间**     | 每个空间各有一套固定标签页。                 |
| **个人资料** | 使用同一个人资料的空间共享固定标签页。       |
| **App**      | 所有常规个人资料和空间共享同一套固定标签页。 |

无痕空间从不显示也不允许固定标签页，无论你选择哪种范围。

更改范围时，Phi 也会把现有的固定标签页迁移到新的安排里。改成更窄的范围时，Phi 会把当前的固定标签页复制到每个已有的目标位置，之后这些副本可以各自独立修改。改成更宽的范围时，Phi 会合并现有的几套：未改动的副本合而为一，已经不同的版本则各自保留。两种更改前 Phi 都会先弹出确认。

书签始终只属于一个空间，固定标签页的这项设置不影响书签。这些层级如何配合，见 [空间与个人资料](/zh-Hans/spaces/)。

## 回到原始页面

在固定标签页或书签里点开链接，可能会让它离开原本的网址。要回去，连按两次固定标签页，或点按已作为标签页打开的书签的网站图标。

想保留当前页面，就在连按两次固定标签页或点按书签网站图标时按住 **Command (⌘)**。当前页面会作为一个单独的标签页移到标签页列表，固定标签页或书签则回到原始网址。

## 两者怎么选

分工很清楚：

- **固定标签页**：你天天用的页面，始终在顶部，一次点按就到，并按你选的空间、个人资料或 App 范围共享。
- **书签**：你想留着的页面，按文件夹整理，只属于一个空间，需要时原地打开。

如果你从 Arc 或 Dia 迁移过来，Phi 的活侧边栏、书签和固定标签页与它们有何异同，见 [迁移到 Phi](/zh-Hans/switching-to-phi/)。要从其他浏览器或文件导入书签，或把某个空间的书签导出为 HTML，见 [导入与导出](/zh-Hans/import-export/)。
