# 书签与固定标签页

在 Phi 中，侧边栏就是你的工作区，而书签和固定标签页是保留重要页面的两种方式。本章会比[布局与导航](/zh-Hans/layouts/)更深入地介绍它们的行为，先从许多传统浏览器用户最意外的一点说起：在 Phi 中，书签会就地打开为标签页。

## 就地打开的书签

在传统浏览器中，书签只是一个静态链接：每次单击都会创建新标签页，最终让同一页面出现多个副本。Phi 则将书签视为一个活条目。单击书签时，它会就地打开，让侧边栏中的同一条目成为实时标签页。关闭页面后，书签仍会原样留在原处，随时可以再次打开。如果书签已经打开，再次单击只会激活对应标签页，而不会创建第二份副本。

这是 Arc 和 Dia 普及的一种理念：侧边栏放置的是持续活动的内容，而不是一年只打开两次的独立档案。Phi 沿用了这一模式，同时保留包含文件夹的真实书签树，因此你仍能获得传统书签库的整理能力。

## 创建和整理书签

- **创建书签**：将标签页拖入侧边栏，或右键单击标签页并选择**添加到书签**（在舒适模式中显示为**添加到书签栏**）。使用**添加到文件夹**可直接放入某个文件夹。
- <strong>使用文件夹整理。</strong>书签可以嵌套在文件夹中，也可以通过<strong>新建子文件夹…</strong>创建子文件夹。
- <strong>将分屏保存为一个书签。</strong>在分屏视图中选择**将分屏添加到书签**，可把两个页面保留为一个条目，今后同时重新打开。
- **管理书签**：右键菜单提供**拷贝链接**、**重命名…**、**编辑…**、**在新标签页中打开**、**以分屏打开**和**删除**。

书签的作用范围是当前空间。每个[空间](/zh-Hans/spaces/)保留自己的书签，因此工作空间保存的页面不会挤满个人空间。

## 固定标签页

固定标签页以网格形式位于侧边栏顶部，适合你长期使用的少数页面，例如邮箱、仪表盘或项目工具。它们是持久入口：即使关闭页面，固定标签页仍会留在网格中，再次单击即可重新打开。

- **固定标签页**：右键单击并选择**固定**，或将标签页拖入固定网格。从同一菜单中选择**取消固定**可将它放回普通标签页列表。
- **重新排序**：在网格中拖动固定标签页。
- <strong>固定分屏。</strong>选择**固定分屏**可将双栏布局保留为一个固定项目，并在以后同时重新打开两侧；**取消固定分屏**会撤销此设置。

## 选择固定标签页的作用范围 {#choose-a-pinned-tab-scope}

打开**设置 → 空间**，然后通过**固定标签页范围**选择固定标签页的共享范围。默认范围是**个人资料**。

| 作用范围     | 固定标签页出现的位置                   |
| ------------ | -------------------------------------- |
| **空间**     | 每个空间都有自己的固定标签页。         |
| **个人资料** | 使用同一个人资料的空间共享固定标签页。 |
| **应用**     | 所有常规个人资料和空间共享固定标签页。 |

无论选择哪种作用范围，无痕空间都不会显示或允许使用固定标签页。

更改作用范围时，Phi 也会把现有固定标签页移入新的结构。改为更窄的作用范围时，Phi 会将当前固定标签页复制到每个已有的目标位置，之后你可以分别更改这些副本。改为更宽的作用范围时，Phi 会合并现有集合。未更改的副本会合并为一项，不同版本则都会保留。无论采用哪种更改，Phi 都会先显示确认提示。

书签始终只属于一个空间。固定标签页设置不会影响书签。有关这两层的关系，请参阅[空间与个人资料](/zh-Hans/spaces/)。

## 返回原始页面

在固定标签页或书签中打开链接，可能会让它离开原始网址。要返回原始页面，请双击固定标签页，或单击已作为标签页打开的书签的网站图标。

如果想保留当前页面，请在双击固定标签页或单击书签图标时按住 **Command (⌘)**。当前页面会作为独立标签页移到标签页列表，而固定标签页或书签会返回原始网址。

## 应该使用哪一种？

可以这样简单区分：

- **固定标签页**是你长期使用的页面，始终位于顶部，一次单击即可打开，并按你选择的空间、个人资料或应用作用范围共享。
- **书签**是你想保留的页面，可以用文件夹整理，只属于一个空间，并在需要时就地打开。

如果你从 Arc 或 Dia 迁移，请参阅[迁移到 Phi](/zh-Hans/switching-to-phi/)，了解 Phi 的活侧边栏、书签和固定标签页有何异同。要从其他浏览器或文件导入书签，或将某个空间的书签导出为 HTML，请参阅[导入与导出](/zh-Hans/import-export/)。
