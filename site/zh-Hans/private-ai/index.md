# 私有 AI

Phi 的 AI 功能默认由 **Phi Cloud** 处理。**私有 AI** 让你逐项决定每类 AI 任务由谁来处理：可以留在 Phi Cloud，可以交给下载到这台 Mac 上的模型，也可以交给你自己连接的 AI 提供商，比如 Ollama、LM Studio、OpenAI 或 OpenRouter。

私有 AI 默认关闭。不打开它，Phi 的所有 AI 功能照常工作，全部使用 Phi Cloud。

## 助手、Phi Cloud 和 AI 提供商 {#assistant-phi-cloud-and-providers}

这三个概念容易混在一起，先分清楚：

- **助手**就是你命名的那位，它是 Phi 的智能体（agent）。它理解你的要求，决定要做什么：查看页面、运行浏览器 Skill、在浏览器里操作、创建任务。无论用哪个模型，助手都是同一个，你的对话、记忆和任务也不会因此改变。
- **模型**是助手思考时借用的「大脑」。助手每走一步，都要把需要的内容发给一个模型，由模型给出回答。
- **AI 来源**决定这个模型在哪里运行。来源有三类：
  - **Phi Cloud**：Phi 内置的 AI 服务。它不是智能体，也不是一个具体的模型，而是 Phi 替你接入并管理的一组云端模型。它使用你的 Phi 登录，不需要 API 密钥，也不需要你选择模型。
  - **本地模型**：下载到这台 Mac 上、在这台 Mac 上运行的模型。
  - **你的提供商**：你自己连接的 AI 服务，用你自己的地址、账号或 API 密钥。

所以，Phi Cloud 和 Ollama、OpenAI 处在同一个位置，都是「助手用哪里的模型」的一个选项。区别在于 Phi Cloud 是内置的、开箱即用，其他来源需要你自己配置。

### 几种来源的区别 {#comparing-sources}

|                   | Phi Cloud                                                  | 本地模型                     | 你的本地提供商（Ollama、LM Studio）     | 你的云端提供商（OpenAI、OpenRouter、Codex 等） |
| ----------------- | ---------------------------------------------------------- | ---------------------------- | --------------------------------------- | ---------------------------------------------- |
| 需要准备什么      | 无，登录 Phi 即可                                          | 一键设置，自动下载           | 自己安装并运行 Ollama 或 LM Studio      | 该服务的账号或 API 密钥                        |
| 内容发往哪里      | 经 Phi 中转，发给 Phi 选用的模型提供商                     | 不离开这台 Mac               | 你指定的地址，通常就是这台 Mac 或局域网 | 直接从你的 Mac 发给该服务                      |
| 以谁的身份        | Phi 的账号，模型提供商不知道你是谁                         | 不涉及                       | 不涉及                                  | 你自己的账号或密钥                             |
| 费用              | 包含在 Phi 中，受[用量额度](/zh-Hans/ai/#usage-limits)限制 | 免费，占用本机内存和算力     | 免费，占用运行它的电脑                  | 按该服务的价格计费                             |
| 计入 Phi 用量额度 | 是                                                         | 否                           | 否                                      | 否                                             |
| 断网能否使用      | 否                                                         | 能                           | 本机运行时能                            | 否                                             |
| 回答质量          | 稳定，适合所有任务                                         | 取决于模型大小，一般弱于云端 | 取决于你选的模型                        | 取决于你选的模型                               |

Phi Cloud 如何处理你的内容，见[隐私与你的数据](/zh-Hans/privacy/)。使用你自己的云端提供商时，适用的是该服务自己的隐私政策。

## Phi 什么时候会用你的提供商 {#when-phi-uses-your-provider}

只是添加一个提供商，什么都不会改变。要让 Phi 用上它，下面两个条件都要满足：

1. 在**私有 AI → AI 任务**里，把某一类任务的来源选成这个提供商的某个模型。
2. **私有 AI** 开关处于打开状态。

没有改过来源的任务，继续使用 Phi Cloud。关闭私有 AI 后，所有任务立即回到 Phi Cloud，但你的选择会被保留，再次打开时直接恢复，不需要重新设置。

## 按任务选择来源 {#choosing-a-source-for-each-task}

私有 AI 不是全有或全无，而是按任务分别设置。页面顶部会显示有几类任务没有使用 Phi Cloud，例如**私有运行的 AI 任务：2 / 4**。

| AI 任务      | 包括什么                           | 可以选的来源                               |
| ------------ | ---------------------------------- | ------------------------------------------ |
| **对话**     | 侧边栏和 Phi Chat 中的回复         | Phi Cloud、本地模型、你的提供商、Codex     |
| **记忆**     | 浏览记忆和摘要等后台工作           | Phi Cloud、本地模型、你的提供商、Codex     |
| **网页任务** | 助手在浏览器里操作、执行自动化任务 | Phi Cloud、本地模型、你的提供商、Codex     |
| **数据搜索** | 搜索你连接的数据                   | 只能选 Phi Cloud 或 Phi 下载的本地搜索模型 |

另外还有几项：

- **视觉模型回退**：你给某项任务选的模型不能看图片时，图片交给这里指定的模型处理。默认是**未配置**。
- **AI 标签页整理**：由 macOS 的 Apple 智能负责，不能更改。这台 Mac 不支持 Apple 智能时，这一项不会显示。
- **图片生成**始终使用 Phi Cloud。

切换某项任务的来源时，Phi 会先用这个模型做一次测试。测试不通过，会恢复为之前的来源并告诉你原因。

对话改用非 Phi Cloud 的来源后，对话窗口会提示**你正在使用 Private AI**，因为回答质量可能和在线模型不同。

## 开启私有 AI {#turning-on-private-ai}

可以从两个地方进入私有 AI 设置：

- 在 [Phi Chat](/zh-Hans/phi-chat/) 中点按顶栏的设置（齿轮）按钮，选择**私有 AI**。
- 在浏览器中打开**设置 → Phi 与 AI → Phi Sentinel → 私有 AI**，它会打开 Phi Chat 中的同一个页面。

第一次打开开关时，Phi 会检查这台 Mac 能不能运行本地模型：

- **符合条件**：设置窗口会列出要下载的大小、运行时大约占用多少内存，以及哪些任务会改到这台 Mac 上运行。点按**开始设置**后，Phi 会依次安装本地运行时、下载模型、启动并验证。整个过程可以**最小化**到后台进行，完成前所有 AI 功能继续使用 Phi Cloud。
- **不符合条件**：窗口会说明原因。你仍然可以点按**使用你自己的 AI 服务**，只连接自己的提供商，不使用本地模型。

### 配置要求 {#requirements}

| 项目     | 要求                                   |
| -------- | -------------------------------------- |
| 芯片     | Apple 芯片。Intel Mac 不能运行本地模型 |
| 内存     | 至少 16GB                              |
| 可用磁盘 | 至少 10GB，并且至少比下载大小多出 2GB  |

只连接你自己的提供商（比如局域网里另一台电脑上的 Ollama，或 OpenAI）时，没有这些硬件要求。

### 一键设置会装什么 {#what-setup-installs}

目前，一键设置会下载两个模型，运行时共占用约 7GB 内存：

- **Gemma 4 E4B（4 位量化）**，负责**记忆**。
- **BGE-M3**，负责**数据搜索**。

**对话**和**网页任务**会继续使用 Phi Cloud。这两类任务要求模型能可靠地理解长上下文并调用工具，Phi 只在本地有 200 亿参数以上的模型时，才会自动把它们放到本机。随设置下载的 Gemma 是 40 亿参数的轻量模型，适合后台工作，不适合承担对话。你仍然可以在 **AI 任务**里手动把对话改成它，前提是通过测试。设置完成时，窗口会明确告诉你哪些任务在这台 Mac 上运行。

一键设置后，记忆用来查找相关内容的索引仍然在 Phi Cloud 上建立。如果你希望它也在本机完成，在**数据搜索**里手动选一次本地模型，两者会一起改到本机。

## 连接 Ollama 或 LM Studio {#connecting-ollama-or-lm-studio}

Ollama 和 LM Studio 都是在自己电脑上运行开源模型的免费工具。Phi 已经内置了这两个提供商，默认地址分别是 `http://127.0.0.1:11434`（Ollama）和 `http://127.0.0.1:1234/v1`（LM Studio）。

1. 安装并打开 Ollama 或 LM Studio，下载一个模型（见[推荐模型](#recommended-models)）。
   - Ollama：在终端运行 `ollama pull <model>`，例如 `ollama pull gpt-oss:20b`。
   - LM Studio：在应用内搜索并下载模型，然后在 **Developer** 页面启动本地服务器。
2. 在 Phi Chat 中打开**设置 → AI 提供商**，选择 **Ollama** 或 **LM Studio**。
3. 打开**使用此提供商**。如果服务运行在局域网的另一台电脑上，把**基础 URL** 改成那台电脑的地址。
4. 点按**加载**，读取它已有的模型。在**模型允许范围**中选择**全部允许**，或**仅允许所选**并勾选要用的模型。
5. 选择一个模型，点按**测试**，看到连接成功的提示后点按**保存修改**。
6. 回到**私有 AI**，在 **AI 任务**里把要改的任务（比如**对话**）选成这个模型。
7. 打开**私有 AI** 开关。

其他兼容 OpenAI 接口的服务，用**添加自定义提供商**连接，填写名称、基础 URL，需要时再填 API 密钥。

几点提示：

- 基础 URL 可以是 `http` 或 `https`。API 密钥是可选的，本地服务通常不需要。发往 `http` 地址的密钥是明文传输的，所以只要服务不在你自己的 Mac 或局域网上，请使用 `https`。
- Ollama 或 LM Studio 必须一直开着。电脑睡眠或应用退出后，对应的任务会按[回退设置](#when-a-local-source-is-unavailable)处理。
- 网页任务和较长的对话会带上很多内容。如果回答不完整，或者助手没能完成操作，可以把上下文长度调大一些，比如 32K：Ollama 在它的设置中调整 **Context length**，LM Studio 在加载模型时设置 **Context Length**。上下文越长，占用的内存越多。
- 让局域网里的其他电脑访问 Ollama，需要在那台电脑上让 Ollama 监听局域网地址（`OLLAMA_HOST=0.0.0.0`）。

## 推荐模型 {#recommended-models}

开源模型更新很快，下面的型号只是举例，同级别的新模型一样可以用。选模型时最重要的是两点：模型要足够大，内存要放得下。模型运行时占用的内存大致等于它的下载大小，再加上几 GB，同时还要给 macOS 和其他应用留出空间。

| 你的 Mac 内存 | 建议                                                                                                                          |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 16GB          | 使用一键设置，让记忆和数据搜索在本机运行，对话和网页任务留在 Phi Cloud。这个内存放不下适合对话的大模型                        |
| 32GB          | 可以在本机运行 200 亿参数级别的对话模型，例如 **gpt-oss-20b**（Ollama：`gpt-oss:20b`）或 **Qwen3 30B**（Ollama：`qwen3:30b`） |
| 64GB          | 可以选 300 亿参数级别、更稳定的模型，例如 **Qwen3 32B**（Ollama：`qwen3:32b`），也能留出更长的上下文                          |
| 128GB 及以上  | 可以运行 1000 亿参数级别的模型，例如 **gpt-oss-120b**（Ollama：`gpt-oss:120b`），效果更接近云端模型                           |

按任务来看：

- **对话、网页任务**：选 200 亿参数以上、支持工具调用（function calling）的模型。网页任务对工具调用要求最高，小模型常常会失败。
- **视觉模型回退**：选能读图片的模型，例如 Gemma 3 12B（Ollama：`gemma3:12b`）或 Qwen2.5-VL 7B（Ollama：`qwen2.5vl:7b`）。
- **记忆**：一键设置的 Gemma 已经够用，一般不需要更换。
- **数据搜索**：只能用 Phi 下载的本地搜索模型，或 Phi Cloud。

本地模型再大，通常也比不上 Phi Cloud 使用的前沿模型。如果你更看重回答质量而不是数据不出本机，把对话和网页任务留在 Phi Cloud 是合理的选择。

## 本地来源不可用时 {#when-a-local-source-is-unavailable}

本地模型、Ollama 或 LM Studio 没有响应时，Phi 按**当本地或自托管来源不可用时**的设置处理：

- **自动回退到 Phi Cloud（默认）**：受影响的任务暂时改用 Phi Cloud，AI 功能不中断。这意味着这段时间里，相关内容会发到云端。
- **暂停受影响的 AI 功能（绝不向云端发送数据）**：受影响的功能暂停，直到本地来源恢复。

如果你开私有 AI 是为了让内容不离开这台 Mac，请选择第二项。

这项设置只对本地和自托管来源生效。OpenAI、OpenRouter、Codex 等云端提供商出错时，不会自动换成 Phi Cloud。

出现问题时，私有 AI 页面会显示**需要处理**，可以点按**重启本地服务**。

## 使用 Codex {#using-codex}

如果你订阅了 ChatGPT，并且在这台 Mac 上用 Codex 登录过，可以把这份订阅当作 AI 提供商。在**设置 → AI 提供商 → Codex** 中点按**连接**即可。Phi 直接使用 Codex 已经保存的登录，不复制你的凭据。

- 需要先安装 Codex，并在终端运行 `codex login` 完成登录。保存在「钥匙串」中的登录 Phi 无法读取。
- Codex 可以用于对话、记忆、网页任务和视觉模型回退，不能用于数据搜索。
- Codex 的用量计入你的 ChatGPT 订阅额度。额度用完或登录失效时，Phi 不会自动换成其他来源。

## 关闭和重置 {#turning-off-and-resetting}

- **关闭私有 AI**：关掉开关，所有任务立即回到 Phi Cloud。下载的模型和你的选择都会保留。
- **移除一个提供商**：在它的页面点按**移除提供商**，用到它的任务会回到 Phi Cloud。
- **重置**：在**高级设置**中选择**重置 AI 设置**，会把所有任务改回 Phi Cloud、清除你的提供商配置和 API 密钥，并删除本地模型。
