# 时间机器备份

时间机器是 Phi 为更新准备的安全网。在某些重大更新之前，Phi 会自动保存当前版本和你的数据的快照，这样如果新版本不符合预期，你可以回滚到之前的版本。它专为那些一次改动很多的少数更新而设。

## 它是什么，不是什么

Phi 的时间机器是**版本回滚**功能，不是通用备份工具。有几样东西很容易和它混淆：

- 它**不是** Apple 的时间机器。它不备份你的 Mac，和同名的系统功能毫无关系。
- 它**不是**对浏览数据的持续、定时备份。Phi 不会每天做快照，也不让你挑任意时间点。快照是自动创建的，偶尔才有，恰在风险高于平常的更新之前。

如果你要的是自己掌控的备份，比如迁移到新 Mac，或在折腾之前留一份副本，请改用**导出用户数据**（见下方[导出你自己的数据](#exporting-your-own-data)）。

## 快照何时创建

时间机器快照不由你手动发起。Phi 在启动进入符合条件的更新之前自动创建，而且每次这样的更新只创建一次。大多数更新根本不会触发。快照一旦存在，就会记录属于上一版本的 Phi 数据，也就是你的书签、空间、固定标签页、设置、记忆和浏览状态，并记下它对应的应用版本，这样回滚恢复的是一套一致的配置，而不是版本错配的混合体。应用本身不存在快照里，恢复时才会下载。

快照**存放在你的 Mac 本地**。它们不会上传到云端，不和你的账号绑定，也无法移到另一台 Mac。

## 回滚到之前的版本

1. 打开**帮助**菜单，找到**时间机器备份**。
2. 每个可用快照按版本、构建号和日期列出，例如 _Phi 1.6 (590)，2026.6.11_。没有快照时，菜单显示**没有可用的备份**。
3. 选择你要的快照。Phi 会弹出确认对话框**要恢复时间机器备份吗？**，并说明 _Phi 将退出并执行恢复，当前的应用和所选用户数据将被替换。_
4. 选择**恢复**。Phi 下载之前的版本，替换当前应用和对应的数据，然后重新启动进入恢复后的版本。

因为回滚要下载之前的版本，恢复期间需要联网。恢复过程的设计目标是要么完成，要么在被打断时安全回退，所以恢复中途退出或崩溃不会让 Phi 处于损坏状态。

## 导出你自己的数据 {#exporting-your-own-data}

时间机器负责更新回滚。想要一份由你创建、按你的方式保存的备份，用**帮助**菜单里的**管理用户数据**：

- **导出用户数据…**：把你的 Phi 数据保存为单个文件，放在哪里都行。
- **导入用户数据…**：用你之前导出的文件替换当前的 Phi 数据，然后重新启动。

迁移到新 Mac 或留一份个人副本，用这个才对；这部分正是时间机器有意不覆盖的。

## 与 Phi 其他部分的关系

时间机器快照包含[空间与个人资料](/zh-Hans/spaces/)和[记忆](/zh-Hans/memory/)背后的数据，所以回滚会把它们恢复到快照时的样子。一切都留在你的 Mac 上，符合[隐私与你的数据](/zh-Hans/privacy/)中描述的 Phi 本地优先原则。
