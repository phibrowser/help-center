# 时间机器备份

时间机器是 Phi 针对更新提供的安全网。在某些重大更新之前，Phi 会自动保存当前版本和数据的快照。如果新版本不符合预期，你可以回退到之前使用的版本。它专门用于少数一次改变较多内容的更新。

## 它是什么，又不是什么

Phi 的时间机器是**版本回退**功能，而不是通用备份工具。它很容易与以下两种概念混淆：

- 它**不是** Apple 时间机器，不会备份你的 Mac，也与同名系统功能无关。
- 它**不是**持续定时备份浏览数据的工具。Phi 不会每天创建快照，也不允许选择任意时间点。只有在风险高于平常的更新之前，才会偶尔自动创建快照。

如果你想要一份自行掌控的备份，用于迁移到新 Mac 或在尝试新功能前保留副本，请改用**导出用户数据**（参阅下方[导出自己的数据](#exporting-your-own-data)）。

## 何时创建快照

你无法手动启动时间机器快照。Phi 只会在准备启动符合条件的更新之前自动创建，而且每次这类更新只创建一次。大多数更新完全不会触发快照。快照会捕获属于旧版本的 Phi 数据，包括书签、空间、固定标签页、设置、记忆和浏览状态，并记录它对应的应用版本，使回退可以恢复一致的环境，而不是不匹配的混合状态。应用本身不会保存在快照中，而是在恢复期间下载。

快照**只保存在你的本地 Mac 上**，不会上传到云端，不与账号绑定，也无法移动到另一台 Mac。

## 回退到旧版本

1. 打开**帮助**菜单，找到**时间机器备份**。
2. 每个可用快照会按版本、构建号和日期列出，例如 _Phi 1.6 (590)，2026.6.11_。如果没有快照，菜单会显示**没有可用的备份**。
3. 选择所需快照。Phi 会显示「要恢复时间机器备份吗？」确认提示，并说明 Phi 将退出并执行恢复，当前应用和选定的用户数据会被替换。
4. 选择**恢复**。Phi 会下载旧版本，替换当前应用和对应数据，再以恢复后的版本重新启动。

由于回退需要获取旧版本，恢复期间必须连接互联网。恢复过程的设计保证操作要么完成，要么在中断后安全恢复，因此即使中途退出或崩溃，也不会让 Phi 留在损坏状态。

## 导出自己的数据 {#exporting-your-own-data}

时间机器负责更新回退。若要创建并按自己的方式保存备份，请使用**帮助**菜单中的**管理用户数据**：

- <strong>导出用户数据…</strong>将 Phi 数据保存为一个可以存放在任意位置的文件。
- <strong>导入用户数据…</strong>会使用之前导出的文件替换当前 Phi 数据，然后重新启动。

这是迁移到新 Mac 或保留个人副本时应使用的工具，而这些场景正是时间机器有意不覆盖的部分。

## 它与 Phi 其他功能的关系

时间机器快照包含[空间与个人资料](/zh-Hans/spaces/)和[记忆](/zh-Hans/memory/)背后的数据，因此回退后，这些内容会恢复到快照创建时的状态。所有内容都留在 Mac 上，与[隐私与数据](/zh-Hans/privacy/)介绍的本地优先方式一致。
