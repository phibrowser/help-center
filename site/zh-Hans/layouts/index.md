# 布局与导航

Phi 围绕垂直侧边栏和多种布局模式来组织浏览。如果你从 Chrome 或 Safari 迁移而来，这是最大的变化，也是最值得优先熟悉的部分。

## 为什么使用垂直侧边栏？

现代屏幕大多宽而不高。水平方向通常空间充足，垂直空间却最先不够用，尤其是在阅读、写作、研究或使用网页应用时。垂直侧边栏更符合现代显示器的形状，也能为实际页面留出更多空间。

## 布局模式

Phi 提供三种布局模式，让你自行决定屏幕空间在内容与浏览器控件之间如何分配。首次使用时会让你选择一种，并且之后可以随时更改。

- **性能**：为页面留出最多空间。标签页和书签位于垂直侧边栏中，内容区域不显示地址栏。
- **均衡**：保留垂直侧边栏，同时在内容上方加入地址栏，在空间效率与熟悉感之间取得平衡。
- **舒适**：最接近传统浏览器，标签页位于顶部，地址栏始终可见，布局类似 Chrome。标签页移到水平标签栏后，侧边栏不再承担主要的日常导航。

### 应该从哪一种开始？

- 从 Chrome 或 Safari 迁移：先用**舒适**。
- 喜欢现代侧边栏浏览器：先用**均衡**。
- 希望页面空间最大化：使用**性能**。

更完整的迁移建议请参阅[迁移到 Phi](/zh-Hans/switching-to-phi/)。

## 标签页、固定标签页和书签

在 Phi 中，标签页、固定标签页和书签都位于侧边栏，因为它们其实是同一件事的不同状态：你在意的页面。**标签页**是现在打开的页面，**固定标签页**位于顶部，适合你长期使用的页面，**书签**位于下方，用来保留你想收藏的页面。可以这样简单理解：**固定标签页是你常驻的页面；书签是你想保留的页面。**

要了解书签如何就地打开为标签页，以及如何固定和整理页面，请参阅[书签与固定标签页](/zh-Hans/bookmarks/)。有关 Arc 和 Dia 的迁移说明，请参阅[迁移到 Phi](/zh-Hans/switching-to-phi/)。

## 分屏视图

分屏视图会在同一个窗口中并排显示两个页面，适合边读边写、比较两个页面，或将文档放在网页应用旁边，免去来回切换。

要创建分屏视图，请右键单击标签页、书签或固定标签页并选择**以分屏打开**，或者将标签页拖到当前页面上。你也可以按住 **Option (⌥)** 并单击固定标签页、书签或网页中的链接，Phi 会在分屏视图中将它打开在当前标签页旁边。

## 标签页组

标签页组会将相关标签页收进一个有名称的分组中。当多个页面属于同一个项目、旅行计划、研究主题或购物过程时，这会很有用。

分屏视图和标签页组可以配合使用：你可以在组内使用分屏视图，也可以将分屏标签页移入或移出分组，让相关工作保持有序，而不是散落成独立标签页。

可以这样区分：**分屏视图用于比较和多任务处理；标签页组用于整理任务、项目或主题。**

## 助理能够理解你的布局

从分屏视图中发起对话时，Phi 可以使用两个页面的上下文。从标签页组中发起对话时，它可以使用整个分组的上下文，让你无需解释页面之间的关系，就能针对多个相关页面提问。（提示：使用 **ctrl+tab** 在最近使用的标签页之间循环切换，使用 **ctrl+shift+tab** 反向切换。）
