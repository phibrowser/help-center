# 布局与导航

Phi 的浏览体验围绕竖向侧边栏和几种布局模式展开。如果你从 Chrome 或 Safari 迁移过来，这是最大的变化，也最值得先花时间适应。

## 为什么用竖向侧边栏

现在的屏幕大多是宽屏。横向空间通常很充裕，纵向空间才是先用完的那一种，阅读、写作、查资料或在网页应用里工作时尤其明显。竖向侧边栏更贴合现代显示器的形状，给页面本身留出更多空间。

## 布局模式

Phi 提供三种布局模式，让你决定屏幕空间更多留给内容还是留给浏览器控件。首次设置时选一种，之后随时可以更改。

- **性能**，把最多的空间留给页面。标签页和书签都放在竖向侧边栏里，内容区域上方不显示地址栏。
- **均衡**，保留竖向侧边栏，同时在内容上方加回地址栏。它介于空间效率和熟悉感之间。
- **舒适**，最接近传统浏览器：标签页在顶部，地址栏可见，整体布局接近 Chrome。标签页移到横向标签栏后，侧边栏就退出日常导航。

### 该从哪种开始

- 从 Chrome 或 Safari 迁移：先用**舒适**。
- 偏好现代的侧边栏浏览器：先用**均衡**。
- 想要最大的页面空间：用**性能**。

更多迁移建议见[迁移到 Phi](/zh-Hans/switching-to-phi/)。

## 标签页、固定标签页与书签

在 Phi 里，标签页、固定标签页和书签一起放在侧边栏中，因为它们本质上是同一件事的不同阶段：你在意的页面。**标签页**是当前打开的页面；**固定标签页**放在顶部，留给你常驻的页面；**书签**放在下方，留给你想保存的页面。可以这样记：**固定标签页是你常驻的页面，书签是你想保存的页面。**

书签如何原位打开为标签页，以及如何固定和整理页面，见[书签与固定标签页](/zh-Hans/bookmarks/)。Arc 和 Dia 的迁移说明见[迁移到 Phi](/zh-Hans/switching-to-phi/)。

## 分屏视图

分屏视图把两个页面并排放在同一个窗口里，适合边读边写、对比两个页面，或者把文档放在网页应用旁边，不用来回切换。

要创建分屏，右键点按标签页、书签或固定标签页，选择**以分屏打开**，或者把标签页拖到当前页面上。也可以按住 **Option (⌥)** 键再点按固定标签页、书签或网页上的链接，Phi 会在当前标签页旁边以分屏视图打开它。

## 标签页组

标签页组把相关的标签页收进一个有名字的组里，几个页面同属一个项目、一次旅行、一个研究主题或一轮购物时很方便。

分屏视图和标签页组是配合设计的：你可以在组内使用分屏视图，也可以把分屏中的标签页移进或移出某个组，让相关工作保持归类，而不是散落成零散的标签页。

分工很简单：**分屏视图用于对比和多任务，标签页组用于整理一项任务、项目或主题。**

## 助手理解你的布局

在分屏视图里聊天时，Phi 可以同时使用两个页面的上下文。在标签页组里聊天时，它可以使用整个组的上下文，你可以直接跨相关页面提问，不必解释自己的布局。（技巧：用 **ctrl+tab** 在最近的标签页之间循环切换，用 **ctrl+shift+tab** 反向切换。）
