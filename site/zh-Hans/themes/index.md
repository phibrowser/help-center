# 主题与外观

Phi 允许你设置浏览器的外观，包括颜色**主题**以及**浅色或深色**选择；这些设置会应用到整个浏览器，而不只是某一个页面。选定外观后，窗口、侧边栏和新标签页都会随之改变。

这些控件位于**设置 → 通用**。

## 选择主题

在**主题**下，**颜色**一栏提供多组带名称的预设，并以色块显示。每组都是完整配色方案，分别包含浅色和深色版本，因此无论选择哪种外观，主题都能正确呈现。

颜色旁边的**不透明度**滑块控制彩色层在窗口中显现的程度。向上调整会增加色彩，向下调整则更接近纯色外观。

## 浅色、深色或跟随系统

**外观**与主题颜色是两个独立选项。在**颜色外观**下，你可以选择：

- **系统**：跟随 macOS 设置并随之切换。
- **浅色**：始终使用浅色外观。
- **深色**：始终使用深色外观。

无论选择哪种模式，主题本身的风格都会保留；此选项只决定显示主题的哪一个版本。

## 主题会应用到哪里

主题会应用到整个浏览器，而不只是单一界面：

- **窗口**：工具栏、地址栏和标签页会采用主题颜色。**不透明度**滑块决定色彩的强弱。
- **侧边栏**：选中和悬停的标签页会采用主题色。
- **新标签页**：你的[新标签页](/zh-Hans/new-tab/)会自动跟随同一主题，与浏览器其他区域保持一致；更改主题后，它也会随之重新着色。
- **网页上选中的文本**：默认情况下，在网页上选中文本时，选区会带有主题色。如果更希望网页保留原生选区颜色，请在主题设置中关闭**将主题应用于网页文本选中效果**。
