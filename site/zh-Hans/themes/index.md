# 主题与外观

Phi 让你决定浏览器的样子：一套颜色**主题**，再加上**浅色或深色**的选择。这个设置作用于整个浏览器，而不只是某一个界面。选好一次，窗口、侧边栏和新标签页都会跟着变。

这些控制项在**设置 → 通用**中。

## 选择主题

在**主题**下，**颜色**一行提供一组有名字的预设，以色块形式显示。每个预设都是一套完整的配色方案，自带浅色和深色两个版本，无论你用哪种外观都能正常显示。

颜色旁边有一个**不透明度**滑块，控制这层颜色在窗口上显现的程度。想要更多颜色就往上调，想接近素色就往下调。

## 浅色、深色或跟随系统

**外观**是独立于主题颜色的另一项选择。在**颜色外观**下你可以选：

- **系统**，跟随 macOS 的设置，并随之切换。
- **浅色**，始终浅色。
- **深色**，始终深色。

无论哪种模式，你选的主题都保持自己的风格；这一项只决定你看到的是它的哪个版本。

## 主题会出现在哪里

主题应用于整个浏览器，而不是某一个界面：

- **窗口**，工具栏、地址栏和标签页都会带上主题颜色。**不透明度**滑块决定这层色调的强弱。
- **侧边栏**，选中和悬停的标签页会带上主题色。
- **新标签页**，你的[新标签页](/zh-Hans/new-tab/)会自动跟随同一主题，与浏览器其他部分保持一致；换了主题，它也会一起重绘。
- **网页上选中的文本**，默认情况下，在网页上选中文本时，选区会染上你的主题色。如果你希望网页保留自己原生的选区颜色，在主题设置里关闭**将主题应用于网页文本选中效果**。
