# 开始使用

Phi Browser 运行在 macOS 上（Apple 芯片，macOS 14 或更高版本）。用下面任一方式安装，然后走完首次运行。

## 安装 Phi

### 从官网下载

打开 [Phi 下载页](https://phibrowser.com/download/)，下载 `.dmg` 文件并打开，把 Phi 拖到「应用程序」文件夹。

### 用 Homebrew 安装

如果你使用 [Homebrew](https://brew.sh/)，用这条命令安装 Phi：

```sh
brew install --cask phibrowser/tap/phi
```

这条命令会自动添加 `phibrowser/tap` 这个 tap，并安装 Phi 的 cask。更新由 Phi 自己处理，你不需要通过 Homebrew 升级。

## 首次运行

第一次打开 Phi 时，首次运行引导会带你完成设置：

- **选择布局模式**，性能、均衡或舒适。之后随时可以更改，所以选一个听起来最接近你现在浏览习惯的就好。各模式的含义见[布局与导航](/zh-Hans/layouts/)。
- **认识你的助手**，进入浏览器后，新标签页顶部会出现一条横幅，邀请你认识自己的助手：给它起个名字，它会为自己生成一个相配的头像，从而拥有自己的身份，而不是一个千篇一律的聊天机器人。你也可以先跳过，之后再回来。
- **登录，或不登录先体验**，用 Phi 账号登录后会开启 AI 功能和浏览器记忆。你也可以选择**不登录也能体验 Phi**，之后再登录；见[稍后登录](#signing-in-later)。
- **AI 默认开启**，登录后，Phi 的 AI 功能开箱即用。如果你更想要一个纯粹的浏览器，之后可以在**设置 → Phi 与 AI** 里关闭。

## 稍后登录 {#signing-in-later}

如果你选择了**不登录也能体验 Phi**，你可以照常浏览，但 Phi 的 AI 功能和浏览器记忆会一直关闭，直到你登录为止。你随时可以从以下任一位置登录：

- **设置 → 访客**，这里会显示你正在未登录使用 Phi，并提供一个登录按钮。
- **设置 → Phi 与 AI**，这里会有一条提示：「登录后即可使用 AI 功能」。
- **任意 AI 功能本身**，打开任意一项 AI 功能，Phi 会显示「登录后即可使用 Phi AI」，并附一个打开登录页的按钮。

登录后，你固定的标签页和书签会一起跟过来。

## 从其他浏览器迁移？

如果你习惯了 Chrome 或 Safari，先用**舒适模式**，过渡最平顺。想看面向 Chrome、Safari、Arc 和 Dia 用户的完整迁移地图，请读[迁移到 Phi](/zh-Hans/switching-to-phi/)。
