# 开始使用

Phi Browser 支持 macOS（Apple 芯片、macOS 14 或更高版本）。任选下列一种方式安装，然后完成首次启动。

## 安装 Phi

### 从官方网站下载

前往 [Phi 下载页面](https://phibrowser.com/download/)，下载 `.dmg` 文件，打开它，然后将 Phi 拖入「应用程序」文件夹。

### 使用 Homebrew 安装

如果你使用 [Homebrew](https://brew.sh/)，请运行：

```sh
brew install --cask phibrowser/tap/phi
```

这条命令会自动添加 `phibrowser/tap` 并安装 Phi cask。更新由 Phi 自行处理，因此无需通过 Homebrew 升级。

## 首次启动

第一次打开 Phi 时，引导流程会帮助你完成设置：

- **选择布局模式**：性能、均衡或舒适。你可以随时更改，所以先选择最接近当前浏览习惯的模式即可。各模式的含义请参阅[布局与导航](/zh-Hans/layouts/)。
- **认识你的助理**：进入浏览器后，新标签页顶部会出现一条横幅，邀请你认识自己的助理。你可以为它取名，它会为自己生成相配的头像，从而拥有独立身份，而不是像一个通用聊天机器人。你也可以跳过这一步，稍后再回来设置。
- **AI 默认开启**：Phi 的 AI 功能开箱即用。如果你更喜欢纯粹的浏览器，可以稍后在**设置 → Phi AI** 中将其关闭。

## 从其他浏览器迁移？

如果你习惯 Chrome 或 Safari，可以先使用**舒适模式**，过渡会最轻松。有关 Chrome、Safari、Arc 和 Dia 的完整迁移说明，请参阅[迁移到 Phi](/zh-Hans/switching-to-phi/)。
