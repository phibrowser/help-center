# 内容拦截

Phi Browser 基于 Chromium，并使用 Brave 开源的内容过滤引擎。你可以分别控制是否拦截广告、跟踪器和 Cookie 横幅。

## Phi 可以拦截什么

| 设置                 | 作用                                                   |
| -------------------- | ------------------------------------------------------ |
| **拦截广告**         | 拦截规则匹配到的广告和广告请求。                       |
| **拦截跟踪器**       | 拦截规则匹配到的跟踪脚本、信标和分析请求。             |
| **拦截 Cookie 横幅** | 隐藏规则匹配到的 Cookie 提示。它不会替你选择同意选项。 |

这三个开关默认关闭，需要时再开启。它们属于某个[个人资料](/zh-Hans/spaces/)，所以不同个人资料可以使用不同设置和过滤列表。

内容拦截使用过滤列表中的规则。列表可以针对常见广告或跟踪器、Cookie 提示、特定地区的网站，也可以包含你添加的自定义规则。Phi 无法拦截所有广告或跟踪器，规则生效时也可能影响某些网站的表现。

## 开启内容拦截

1. 打开**设置 → 个人资料**。
2. 选择一个个人资料，找到**内容拦截**。
3. 开启你需要的类别。
4. 如果 Phi 提示选择过滤列表，请选中要使用的列表，然后点按**完成**，下载所选但尚未保存在 Mac 上的列表。

之后，你可以随时点按类别旁的规则选项来更改过滤列表。只有你主动选择下载操作时，Phi 才会下载列表。**更新已下载的列表**会重新获取已保存在 Mac 上的列表。

在规则选择器中点按**添加过滤器…**，即可通过 URL 添加列表或直接粘贴规则。自定义列表会用于该个人资料中的全部三个类别。

已下载的过滤列表可以由多个个人资料共用。每个个人资料会分别保存所选列表、自定义列表和网站例外。

## 为某个网站设置例外

打开地址栏菜单，选择**在此网站上拦截内容**，即可在当前个人资料中关闭或重新开启当前网站的拦截。这只会更改该个人资料对这个网站的例外设置，不会影响其他网站上的拦截类别。

无痕窗口中不会显示此菜单项。

## 网站无法正常使用时

有些网站需要的资源可能会被过滤列表拦截。你可以在地址栏菜单中选择**在此网站上拦截内容**来设置例外，然后重新加载页面。也可以在**设置 → 个人资料**中关闭某个类别，或更改该类别使用的过滤列表。

过滤列表无法识别所有广告、跟踪器或 Cookie 提示。Cookie 横幅拦截会隐藏匹配到的页面元素，但不会替你接受 Cookie 或关闭同意提示。
