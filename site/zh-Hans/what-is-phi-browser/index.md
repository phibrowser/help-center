# 什么是 Phi Browser？

Phi Browser 是懂你的浏览器，也能替你把事情完成。

它是一款面向 macOS 的智能浏览器，基于 Chromium 引擎构建，并采用原生 macOS 界面。其核心代码开源，你的数据以本地存储为先，而且 AI 功能已包含在内。Phi 可免费使用，AI 用量由我们承担。它会了解你的工作方式、预判你的需求，并替你处理日常任务。

这些指南会介绍 Phi 的整体设计以及背后的思考。如果你只想快速找到具体答案，请参阅[常见问题](/zh-Hans/faq/)。

## 为 macOS 而生

Phi 支持搭载 Apple 芯片（M1 或更新型号）且运行 macOS 14 或更高版本的 Mac。它与 macOS 自然融合：原生界面、垂直侧边栏，以及三种布局模式，让你自行决定页面内容和浏览器控件各占多少空间。

第一次使用 Phi？请先阅读[开始使用](/zh-Hans/get-started/)，完成安装和首次启动，然后通过[布局与导航](/zh-Hans/layouts/)熟悉界面。

## 由四个部分组成的浏览器 AI

登录后，Phi 的 AI 会直接启用。它不是一个含糊笼统的「AI」功能，而是由四个各司其职的部分组成：

- <strong>[记忆](/zh-Hans/memory/)</strong>会根据你的浏览方式安静地建立上下文，让助理无需你专门教导便能理解你。
- **助理**是一个由你亲自命名的对话伙伴，你可以向它提问并委派工作。
- **智能体任务**会实际替你执行操作，包括一次性操作、后台任务和自行运行的定时工作。
- <strong>[浏览器技能](/zh-Hans/skills/)</strong>是助理可以按需运行的可复用工作流程。

阅读[认识你的助理](/zh-Hans/ai/)，了解记忆、对话和技能；阅读[自动化与 Phi Link](/zh-Hans/automation/)，了解智能体任务以及如何从手机使用 Phi。

## 你的数据始终属于你

Phi 采用本地优先的设计。Phi 记住的内容保存在你的 Mac 上，绝不会用于训练 AI 模型，并始终由你掌控。你可以查看、管理和删除这些内容。

在依赖这套机制之前，还有另一面值得了解：助理回答问题时，生成答案所需的内容会发送给你所选模型的提供商，因为模型只有获得这些内容才能作答。数据会经过我们的服务转发，但不会被存储。如果你希望这些内容完全不离开 Mac，[Phi Sentinel](/zh-Hans/sentinel/) 可以在本地运行模型。

详情请参阅[隐私与数据](/zh-Hans/privacy/)。
