# 什么是 Phi Browser？

Phi Browser 是懂你的浏览器，也是替你把事办成的浏览器。

它是一款面向 macOS 的智能浏览器，基于 Chromium 引擎，配有原生 macOS 界面。核心开源，数据本地优先，AI 已包含在内。Phi 免费使用，AI 用量由我们承担。它会学习你的工作方式，预判你的需要，替你处理琐碎的日常任务。

这组指南帮你建立整体认识，并说明 Phi 这样设计背后的考量。想要快速、具体的答案，请看[常见问题](/zh-Hans/faq/)。

## 为 macOS 而生

Phi 运行在搭载 Apple 芯片的 Mac（M1 及更新机型）上，需要 macOS 14 或更高版本。它在 Mac 上毫不违和：原生界面、垂直侧边栏，以及三种布局模式可选，由你决定把多少空间留给网页，多少留给浏览器控件。

刚接触 Phi？先从[开始使用](/zh-Hans/get-started/)安装并走完首次运行，再到[布局与导航](/zh-Hans/layouts/)熟悉界面。

## 一个浏览器，四个 AI 部分

Phi 的 AI 内置在浏览器里，登录后即为开启状态。它不是一个笼统的「AI」，而是四个各司其职的部分：

- **[记忆](/zh-Hans/memory/)**，在后台默默从你的浏览方式中积累上下文，让助手无需你教就能理解你。
- **助手**，一个由你亲自命名的聊天伙伴，你可以向它提问，也可以把工作交给它。
- **智能体任务**，真正替你做事，从一次性操作到自行运行的后台任务和定时任务。
- **[浏览器 Skill](/zh-Hans/skills/)**，助手可以随时按需运行的可复用工作流。

关于记忆、如何与助手对话以及 Skill，请读[认识你的助手](/zh-Hans/ai/)；关于智能体任务和在手机上使用 Phi，请读[自动化与 Phi Link](/zh-Hans/automation/)。

## 你的数据归你所有

Phi 是本地优先的。Phi 记住的内容保存在你的 Mac 上，绝不会用于训练 AI 模型，并且始终由你掌控。你可以查看、管理和删除它。

这件事还有另一半，最好在你依赖它之前就知道：助手回答问题时，回答所需的内容会发送给你选择的模型提供商，因为模型只有拿到内容才能作答。这些内容经我们中转，但不会被存储。如果你希望它完全不离开你的 Mac，可以改用 [Phi Sentinel](/zh-Hans/sentinel/) 在本地运行模型。

详情见[隐私与你的数据](/zh-Hans/privacy/)。
