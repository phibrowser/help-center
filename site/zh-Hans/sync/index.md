# 同步

同步让 Phi 自己的数据在每一台登录了同一个 Phi 账号的 Mac 上保持一致。在一台 Mac 上保存书签或给空间改名，其他 Mac 上也会收到这个更改。每台 Mac 都要你亲自设置后才会开启同步，而且它的设计让我们无法读取它传输的内容：所有数据在上传前都会在你的 Mac 上加密，所用的密钥只有你的 Mac 持有。

本页介绍的一切都在**设置 → 同步**里。

## 哪些内容会同步 {#what-syncs}

| 内容                       | 详情                                                                                                                                                                   |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **空间**                   | 名称、图标、颜色、主题，以及每个空间属于哪个个人资料。                                                                                                                 |
| **个人资料**               | 个人资料名称，以及每个个人资料包含哪些空间。                                                                                                                           |
| **书签和文件夹**           | 每个空间的书签，连同它们的文件夹和排列顺序。                                                                                                                           |
| **固定标签页**             | 固定标签页，按你在**设置 → 空间**里选定的范围同步。                                                                                                                    |
| **网址规则**               | 把匹配的网站分流到某个空间、无痕或 Kiosk 的规则。                                                                                                                      |
| **受支持的设置**           | 布局模式、外观、主题和选中文本着色、书签栏和完整网址设置、**新标签页行为**（按 ⌘T 时打开什么）、无痕空间关闭警告、自动画中画、固定标签页范围，以及哪个空间是默认空间。 |
| **浏览数据（按个人资料）** | 浏览历史记录、浏览器自身的偏好设置（例如默认搜索引擎），以及扩展程序和它们同步的设置。                                                                                 |

::: warning 删除也会同步
在一台 Mac 上删除某个空间或个人资料，它会从所有与之同步的 Mac 上一并删除，书签也包括在内。Phi 会在确认对话框里说明这一点，所以确认之前请先读一读。
:::

有些内容是特意留在原处的：

- **密码、Cookie 和自动填充。** 它们从不进入同步。Phi 没有自己的密码管理器；你通过[智能体密码管理器](/zh-Hans/agent-passwords/)连接的密码库属于其提供商，按该提供商的条款同步。
- **打开的标签页。** 普通的打开标签页不会在另一台 Mac 上重新创建。固定标签页会。
- **Phi Chat 和记忆。** 你和助手的对话留在你进行对话的那台 Mac 上，[记忆](/zh-Hans/memory/)也是如此。
- **无痕空间**，以及智能体工作所在的空间。它们的任何内容都不会同步。把网站分流到无痕的网址规则仍然是一条规则，所以它会像其他规则一样同步。
- **键盘快捷键。** 你在**设置 → 快捷键**里设定的内容只留在你设定它的那台 Mac 上。
- **绑定在单台 Mac 上的设置**，包括 AI 和智能体设置。

## 开始之前

- **每台 Mac 上都登录 Phi 账号。** 没有账号时，这个面板只提供**登录以在设备间同步**。如果你当初选择了不登录先体验，见[稍后登录](/zh-Hans/get-started/#signing-in-later)。
- **官方的 Phi 版本。** 同步通过 Phinomenon 的同步服务运行，你用开源代码自行构建的 Phi 无法使用它。

## 设置你的第一台 Mac {#set-up-your-first-mac}

1. 打开**设置 → 同步**，点按**在此设备上设置同步**。窗口会说明接下来会发生什么；点按**继续**。
2. **保存你的恢复代码。** Phi 会生成一个恢复代码，并且只显示一次：27 个字符，每五个一组。点按**拷贝**，把它存放在安全的地方，例如密码管理器，然后点按**我已保存**。
3. **确认你的恢复代码。** Phi 会让你输入刚才保存的代码。连字符、空格和字母大小写都不影响。如果你没有保存，点按**返回**：Phi 会再次显示同一个代码，让你现在保存。代码核对通过之前同步不会开启，所以你不会等到以后才发现它根本没存下来。如果你在这一步关闭窗口，下次打开设置或重新启动时，Phi 会再次询问，但那时**返回**已经没有了，因为窗口关闭后代码不会被保留。
4. **Phi 会自行设置同步。** 在第一台 Mac 上，账户里还没有可以匹配的内容，所以没有需要你填写的匹配页面。Phi 会把这台 Mac 的个人资料和空间添加到账户中，并在此期间显示**正在设置同步…**。如果 Phi 无法读取账户里的全部内容，它会改为显示[添加另一台 Mac](#add-another-mac)中的匹配页面。
5. 设置完成后，面板会在这台 Mac 上传期间显示**正在进行首次同步**，之后显示**已是最新**。

::: warning 恢复代码只显示一次
这个代码在你的 Mac 上生成，从不发送给我们，所以我们无法再次显示它、发送替代代码或重置它。要添加另一台 Mac，你需要这个代码，或者一台已经设置好的 Mac。两者都丢失的话，没有人能解锁你账户里的加密副本，我们也不能。如果代码已经丢失，见[忘记了恢复代码？](#forgot-your-recovery-code)
:::

## 添加另一台 Mac {#add-another-mac}

1. 登录同一个 Phi 账号，打开**设置 → 同步**，点按**在此设备上设置同步**，然后点按**继续**。
2. 在**将此设备添加到你的账户**页面，选择这台 Mac 的加入方式：
   - **请求另一台设备批准。** Phi 会显示一个短代码并等待。在一台已经设置好的 Mac 上打开**设置 → 同步**：这个请求会出现在**设备**下，带有同样的代码和过期时间。核对两边的代码一致后点按**批准**；如果这个请求不在你的预期之中，就点按**拒绝**。这个代码用来识别新 Mac，不是机密，所以在电话里念出来也没问题。请求被拒绝或过期后，会提供**尝试其他方式**。
   - **输入恢复代码。** 输入你在第一台 Mac 上保存的代码。
3. **选择这台 Mac 的同步方式。** 如果你的账户里已经有数据，而这台 Mac 上也有它自己的数据，Phi 会询问<strong>这台 Mac 要如何同步？</strong>并显示双方各有哪些内容：
   - **将这台 Mac 与你的账户合并**，标有**推荐**。你会在接下来的步骤里逐一匹配个人资料和空间，双方的书签、固定标签页和网址规则都会保留。
   - **使用你账户的数据**。这台 Mac 的空间、书签、固定标签页、网址规则和已同步的设置会被替换为你账户中的数据，你账户中没有的个人资料会从这台 Mac 上删除。只有这台 Mac 会更改，而且此操作无法撤销。选择它之前，请先阅读[使用你账户的数据](#use-your-accounts-data)。

   如果一台 Mac 上除了默认个人资料和默认空间之外没有其他内容，也没有书签、固定标签页或网址规则，就不会看到这一步。没有任何选项可以用这台 Mac 的数据覆盖你的账户。

4. **匹配你的个人资料。** Phi 会把这台 Mac 上的个人资料与你账户里的个人资料配对，并就无法匹配的那些询问你。这台 Mac 的默认个人资料始终与你账户的默认个人资料匹配：它所在的行直接显示那个账户个人资料，没有可供选择的菜单。对这里的其他每个个人资料，选择**分配给**某个账户个人资料，或者选择**注册为新个人资料**。账户里在这台 Mac 上没有对应项的个人资料会列在**未认领的账户个人资料**下，点按**在这台 Mac 上创建**即可添加它们。如果某个选择会违反这条默认个人资料规则，Phi 会提示**这台 Mac 的默认个人资料只能与账户的默认个人资料匹配。请检查匹配项后重试。**
5. **匹配你的空间。** 为这台 Mac 上的每个空间选取它对应的账户空间，或者选择**添加为新空间**。**全部添加为新空间**会一次处理所有尚未决定的空间，名称完全相同的空间会自动为你选好。账户里有而这台 Mac 上没有的空间会显示在**将从你的账户添加的空间**下，完成时会被创建。这台 Mac 上的任何内容都不会被删除。点按**完成**。
6. **查看将发生的更改**，只有在这台 Mac 上的某些内容会被覆盖时才会出现。如果你把这里的某个空间与账户里的空间匹配，账户中的名称、图标、颜色和主题会替换这台 Mac 上的值，这个空间还可能移到它在账户中所属的个人资料。这台 Mac 上的标签页、书签、固定标签页和网址规则不受影响。要保留这台 Mac 上的值，点按**返回**，改为把那个空间添加为新空间。点按**应用**开始同步。如果没有任何内容会被覆盖，点按**完成**后同步就会立即开始。

Phi 只会显示需要询问你的页面。没有需要询问的内容时，例如在一台只有默认数据的 Mac 上，它会自行完成并显示**正在设置同步…**，你账户的个人资料和空间随后会出现在这台 Mac 上。

Phi 统计你的空间时，加载账户可能需要长达两分钟，而且必须联网：没有缓存副本可以退而使用。选择**将这台 Mac 与你的账户合并**时，同步开始后，两台 Mac 上的书签、固定标签页和网址规则都会保留，任何一边的内容都不会丢失。

### 使用你账户的数据 {#use-your-accounts-data}

如果你不想保留 Phi 在这台 Mac 上的内容，例如一台只用来测试的 Mac，就选择这个选项。Phi 会先删除这台 Mac 上的 Phi 数据，再下载你账户的数据。

- **从这台 Mac 移除：** 默认空间以外的空间，它们打开的标签页也会关闭；书签、固定标签页、网址规则和已同步的设置；以及你账户中没有的每个个人资料，连同它的历史记录、扩展程序和网站数据。
- **保留：** 这台 Mac 的默认个人资料，以及名称与你账户中某个个人资料相同的个人资料，会保留它们的历史记录、扩展程序和网站数据。你的账户和你的其他 Mac 不受影响。

点按**继续**后，Phi 会询问<strong>要替换这台 Mac 上的内容吗？</strong>并列出将移除和将下载的内容。点按**替换这台 Mac 的数据**继续。Phi 会显示**正在替换这台 Mac 的数据…**，窗口会一直保持打开，直到替换完成。之后，你账户的数据会随首次同步到达，面板显示**正在进行首次同步**；如果账户很大，这可能需要几分钟。如果替换因错误而停止，见[无法完成替换这台 Mac 的数据](#replace-did-not-finish)。

::: warning 替换无法撤销
Phi 不会保留它所删除内容的副本。如果你想要一份副本，先选择**稍后完成**，用<strong>帮助 → 管理用户数据 → 导出用户数据…</strong>导出（见[导入与导出](/zh-Hans/import-export/)和[同步还是导出](#sync-or-export)），然后再回到设置流程。要保留某个本地个人资料，请改为选择**将这台 Mac 与你的账户合并**。
:::

### 设置无法加载你的账户时 {#setup-cannot-load-account}

设置流程会先读取你的账户，然后才显示任何选项。读取失败时，窗口会说明原因并提供**重试**：

- **未能及时加载你账户的空间。请检查网络连接后重试。** 通常是账户很大，或者网络连接很慢。
- **同步目前不可用，因此无法加载你账户中的空间。** Phi 目前无法连接同步服务。请确认你已联网并且仍处于登录状态，然后重试。
- <strong>无法加载你账户的个人资料。请检查网络连接后重试。</strong>或者**无法加载你账户的空间。请检查网络连接后重试。**
- 标为**目前无法读取**的账户个人资料：Phi 会在后台持续重试，设置的其余部分仍可正常进行。
- **无法在这台 Mac 上读取你账户的默认个人资料，因此目前无法替换这台 Mac 的数据。** 在能读取之前，**使用你账户的数据**无法进行。请选择**将这台 Mac 与你的账户合并**，或选择**稍后完成**后再试。

### 稍后完成 {#finish-later}

同步方式这一步和匹配页面上都有**稍后完成**。选择它或关闭窗口后，这台 Mac 会继续在本地浏览：什么都不会同步，面板显示**未配对**，Phi 也不会自行重新打开设置流程。准备好后回到**设置 → 同步**，点按**继续设置**。Phi 会在那时重新加载你的账户，所以之前未完成的选择不会保留，同步方式也包括在内：下次设置时会默认选中**将这台 Mac 与你的账户合并**。

已经开始的替换是例外。一旦 Phi 开始替换这台 Mac 的数据，离开并不会取消它。如果替换中途停止（例如因为出错或 Phi 退出），而你关闭了窗口，下次打开设置时会直接进入<strong>要替换这台 Mac 上的内容吗？</strong>页面，没有**返回**，点按**替换这台 Mac 的数据**会从中断处继续。那里仍然提供**将此设备从同步中移除…**；选择它会让这台 Mac 不再同步，替换尚未移除的内容会留在这台 Mac 上。

## 忘记了恢复代码？ {#forgot-your-recovery-code}

没有人能再次显示你的恢复代码，也没有人能为同一份同步数据生成新的代码，我们也不能。你还能做什么，取决于你的情况。**输入你的恢复代码**页面上的<strong>忘记了恢复代码？</strong>链接会打开这一部分。

### 你还在设置第一台 Mac

如果你在**确认你的恢复代码**页面，并且还没有关闭设置窗口，点按**返回**。Phi 会再次显示同一个代码。保存它，点按**我已保存**，然后输入它进行确认。

Phi 2.14 及更早版本没有**返回**按钮。如果你关闭了窗口或重新启动了 Phi，代码也已经没有了：Phi 会一直要求你输入它，却无法显示它。无论哪种情况，如有需要先更新 Phi，然后按下文所述，用[重置同步](#reset-sync)从头开始。

### 另一台 Mac 仍设置着同步

你不需要这个代码。在新的 Mac 上选择**请求另一台设备批准**，然后在已设置好的 Mac 上批准这个请求；见[添加另一台 Mac](#add-another-mac)。你现有的几台 Mac 会继续同步。

这个代码仍然无法再次显示或替换。请至少保留一台设置了同步的 Mac：只要还有一台，你就可以不用代码添加 Mac。

### 这是你唯一的 Mac，或者你想从头开始

在那台 Mac 上使用[重置同步](#reset-sync)。它会将这台 Mac 从同步中移除，并删除为你的账户存储的所有同步数据。你的本地浏览数据会保留在这台 Mac 上，之后，任何仍为该账户设置着同步的其他 Mac 都会显示[重新设置同步](#set-up-sync-again)。然后按照[设置你的第一台 Mac](#set-up-your-first-mac)，在这台 Mac 上从头设置同步。Phi 会生成一个新的恢复代码；点按**我已保存**之前，先把它保存好。

**重置同步**只会出现在账户上最后一台设置了同步的 Mac 上。如果你想在其他 Mac 仍设置着同步时从头开始，先把其他每一台 Mac 都从同步中移除。

### 你手上没有任何一台设置了同步的 Mac

如果代码已经丢失，而你手上也没有任何一台设置了同步的 Mac，你账户里的加密副本就无法解锁，你不能，我们也不能。尚未设置同步的 Mac 也无法重置账户的同步，所以无法从它那里从头开始。这也包括在设置了同步的状态下丢失或被抹掉的 Mac：它仍然算作已设置，而且无法从另一台 Mac 上移除。

## 查看同步状态 {#check-sync-status}

同步面板顶部显示当前的状态：

- **已是最新**、**正在同步…**，或者首次同步进行期间的**正在进行首次同步**。
- **已离线**，并附有一条提示，说明联网后会同步更改。Phi 会继续使用本地数据工作，等这台 Mac 重新联网后再发送你的更改。
- **同步已暂停。** 这台 Mac 上有某个个人资料还没有设置同步，通常是你在设置之后才创建的那个。面板会列出它在等待的个人资料及原因。Phi 会自行注册它们并持续重试，点按**重试**可以立即重试。见[同步已暂停](#sync-paused)。
- **需要注意。** 有地方出错了。下方会出现一行**部分内容需要注意。请查看详细信息并检查网络连接。**，**上次问题**会指出最近的问题及其发生时间。见[每个问题的含义](#needs-attention)。

状态下方，**这台 Mac 上次成功同步的时间**显示这台 Mac 最近一次完成同步是在什么时候。**正在等待个人资料加载**表示 Phi 还没有读取到这台 Mac 的个人资料列表。它会自行持续尝试，五分钟后状态会变为**需要注意**。

如果你更改了固定标签页范围（无论是在这台 Mac 上还是在另一台 Mac 上），可能会出现一行**固定标签页范围更改尚未应用**，并附有尝试次数和原因：**正在从其他浏览器迁移**、**无法访问本地浏览器数据**或**无法在这台 Mac 上保存固定标签页**。这表示这台 Mac 还没有把它的固定标签页移到新的范围。Phi 会自行持续重试，同步的其余部分照常进行。如果这一行一直不消失，请重新启动 Phi；如果仍然不消失，请通过窗口右上角菜单中的**反馈**发送反馈。

### 每个问题的含义 {#needs-attention}

**上次问题**会显示以下其中一项。它会一直保留，直到下一次完整结束的同步将它清除。

| 上次问题                          | 含义                                                                  | 你要做什么                                                                     |
| --------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| **登录已过期**                    | 同步服务不再接受这台 Mac 的登录。                                     | 重新登录你的 Phi 账号。                                                        |
| **无网络连接**                    | 这台 Mac 无法连接同步服务。                                           | 无需操作。联网后，下一次同步成功时它会自行消失。                               |
| **服务器错误**                    | 同步服务返回了错误。                                                  | 无需操作。下一次同步成功时它会自行消失。                                       |
| **服务器拒绝了更改**              | 同步服务拒绝了这台 Mac 的部分更改，例如在与另一台 Mac 多次冲突之后。  | 点按**立即同步**。如果问题再次出现，请重新启动 Phi；仍然存在的话，请发送反馈。 |
| **无法读取这台 Mac 上的数据**     | Phi 无法读取它自己在这台 Mac 上的部分数据。                           | 点按**立即同步**。如果问题再次出现，请重新启动 Phi；仍然存在的话，请发送反馈。 |
| **无法在这台 Mac 上保存同步状态** | Phi 无法保存它对哪些内容已同步的记录。                                | 点按**立即同步**。如果问题再次出现，请重新启动 Phi；仍然存在的话，请发送反馈。 |
| **部分同步数据无法读取**          | 你账户中的某些内容无法在这台 Mac 上读取。                             | 点按**立即同步**。如果问题再次出现，请重新启动 Phi；仍然存在的话，请发送反馈。 |
| **正在等待个人资料配对**          | 部分同步项目要等到这台 Mac 上的某个个人资料与你的账户配对后才能处理。 | 等待 Phi 设置好这个个人资料，或者在面板显示**同步已暂停**时点按**重试**。      |
| **需要重新设置同步**              | 你账户中的同步数据已被重置，这台 Mac 的设置与它不再匹配。             | 点按**重新设置同步**。见[重新设置同步](#set-up-sync-again)。                   |

已暂存的项目（见[详细信息](#sync-details)）也可能让状态停留在**需要注意**，而不显示问题名称。见[固定标签页被暂存](#held-pinned-tabs)。

### 详细信息 {#sync-details}

**详细信息**会列出你的个人资料，每个个人资料都附有其浏览数据的状态，然后每一类 Phi 数据各占一行：**设置**、**空间**、**书签**、**固定标签页**和**网址规则**。每一类的那一行描述它最近一次有更改的同步，以及那是多久以前：

| 计数         | 统计的内容                                                                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **已接收**   | 这台 Mac 从你的账户收到的更改。                                                                                                                                                      |
| **已发送**   | 这台 Mac 上传的更改。                                                                                                                                                                |
| **等待发送** | 这台 Mac 上尚未上传的更改。之后的同步会发送它们。                                                                                                                                    |
| **已暂存**   | 这台 Mac 已收到但暂时无法应用的项目。Phi 会保留它们，直到可以应用为止，例如一个所属个人资料或空间尚未在这台 Mac 上配对的固定标签页。属于另一个固定标签页范围的固定标签页不计算在内。 |

**等待发送**和**已暂存**只在不为零时显示。没有最近更改的类别会显示**最近没有更改**。

### 立即同步 {#sync-now}

**立即同步**会让这台 Mac 马上同步所有内容。你很少需要用到它：另一台 Mac 有更改时，Phi 会收到通知，它也会自行检查，但最多每分钟一次。**立即同步**会跳过这段等待。同步在等待或运行期间，按钮会显示进度，它的悬停提示会说明正在等待什么，例如**正在等待所有个人资料可用**。

你发起的同步没有完成时，状态下方会有一行说明，直到你再次点按为止：

- 如果这次同步期间记录了问题，显示上表中该问题的名称。
- **同步未完成**：同步停止了，但没有具体问题。请稍后再试。如果它在某一台 Mac 上反复出现，见[固定标签页被暂存](#held-pinned-tabs)。
- **无法开始同步。请稍后再试。**：这台 Mac 完全无法开始同步。

同步完成时不会添加这一行，**这台 Mac 上次成功同步的时间**会更新为新的时间。

## 设备

**设备**部分列出你账户上设置好的每一台 Mac，并标出**这台 Mac**；如果有 Mac 正在等待加入，也会列出来，附带它的代码、**批准**、**拒绝**和请求的过期时间。要批准请求，这台 Mac 必须已经登录，并且自己的设置已经完成。

每台 Mac 只能在自己的同步面板里移除它自己。目前还没有办法移除一台你已经不再拥有的 Mac：丢失的 Mac 会留在账户上，只要它仍处于登录状态，就会继续接收更改。如果你还能操作它，退出登录就能阻止这一点。

## 将 Mac 从同步中移除 {#remove-a-mac-from-sync}

在**设置 → 同步**的**移除**下，点按**将这台 Mac 从同步中移除**这一行上的<strong>移除…</strong>，然后点按**移除此设备**确认。如果这台 Mac 上的设置尚未完成，设置窗口底部会改为提供<strong>将此设备从同步中移除…</strong>。

- 这台 Mac 停止同步，同步服务会吊销它，它的同步设置、密钥以及个人资料和空间的匹配信息都会从这台 Mac 上清除。
- 你浏览的一切都会保留：空间、书签、历史记录和固定标签页完整保留，你也仍然登录着你的账号。
- 你的其他 Mac 不受影响，彼此之间继续同步。
- 要让这台 Mac 重新加入，再次开始设置，通过批准或恢复代码加入。

当这台 Mac 是账户上唯一一台设置了同步的 Mac 时，这一行会变为**重置同步**，因为移除最后一台 Mac 也会删除账户的同步数据。见[重置同步](#reset-sync)。

::: warning 移除不会更换你账户的密钥
移除一台 Mac 会让它不再收到任何新内容，但不会更改你账户的加密密钥，也无法收回那台 Mac 已经同步到的内容。它上面已有的内容会一直留在上面。
:::

### 重置同步 {#reset-sync}

当这台 Mac 是你账户上唯一一台设置了同步的 Mac 时，**移除**部分会显示**重置同步**，并带有一个<strong>重置…</strong>按钮。重置会将这台 Mac 从同步中移除，并删除为此账户存储的所有同步数据，让你可以从头开始，例如在丢失恢复代码之后。

1. 在**设置 → 同步**的**移除**下，点按<strong>重置…</strong>。
2. Phi 会询问<strong>要删除此账户的所有同步数据吗？</strong>点按**删除所有同步数据**确认。此操作无法撤销。

- 所有设备都会从同步中移除，同步服务器上为此账户存储的所有内容都会被删除。
- 你的本地浏览数据会保留在这台 Mac 上：空间、书签、历史记录和固定标签页都会保留，你也仍然登录着你的账号。
- 任何仍为此账户设置着同步的其他 Mac 都会显示[重新设置同步](#set-up-sync-again)。
- 要再次使用同步，需要从头设置。Phi 会生成一个新的恢复代码。

如果你从设置窗口移除这台 Mac，而它恰好是最后一台，Phi 会提示：<strong>这是最后一台设置了同步的设备。你可以将其移除并删除为此账户存储的所有同步数据，或者先在另一台设备上设置同步。</strong>然后提供<strong>移除此设备并删除所有同步数据…</strong>，它会要求同样的确认。

如果在此期间有另一台 Mac 加入了账户，就不会删除任何内容。Phi 会提示<strong>此后已有另一台设备加入了此账户，因此没有删除任何内容。你可以改为将这台 Mac 从同步中移除。</strong>这一行也会变回**将这台 Mac 从同步中移除**。

## 重新设置同步 {#set-up-sync-again}

如果面板显示**该账户的同步数据已更改。Phi 数据的同步已暂停。**，说明你账户里的同步数据已被重置，这台 Mac 的设置与它不再匹配。在你采取行动之前，Phi 的数据会停止同步；重试或重新启动都无法解决。点按**重新设置同步**并确认。Phi 会清除这台 Mac 的同步设置和匹配信息，保留你的本地浏览数据和账户里的内容，然后带你重新走一遍设置流程，包括通过批准或恢复代码加入。

账户的最后一台 Mac 使用了**重置同步**之后，某台 Mac 上也会出现这个提示，因为它当初设置同步时所用的同步数据已被删除。

## 故障排除 {#troubleshooting}

### 第二台 Mac 没有收到我的键盘快捷键或打开的标签页 {#missing-shortcuts-and-open-tabs}

这是正常的。**设置 → 快捷键**里的键盘快捷键从不同步，普通的打开标签页也不会同步：只有固定标签页会。AI 和智能体设置也留在各自的 Mac 上。请在每台需要它们的 Mac 上分别设置。见[哪些内容会同步](#what-syncs)。

### 一台 Mac 显示「同步未完成」并暂存了固定标签页 {#held-pinned-tabs}

一台 Mac 显示**同步未完成**，它在**详细信息**中的**固定标签页**一行显示**已暂存**和一个数字，而另一台 Mac 显示**已是最新**。**已暂存**表示这台 Mac 收到了无法放置的固定标签页，因为它们所属的个人资料或空间在这里没有配对。

通常的原因是，设置时两台 Mac 的默认个人资料没有相互匹配。在 Phi 2.12 上配对的 Mac 可能会出现这种情况。从 Phi 2.13 起，设置流程总是将默认个人资料与你账户的默认个人资料匹配。

目前的解决方法是：在暂存了固定标签页的那台 Mac 上，[将这台 Mac 从同步中移除](#remove-a-mac-from-sync)，然后按照[添加另一台 Mac](#add-another-mac)重新设置。如果 Phi 询问这台 Mac 要如何同步，选择**将这台 Mac 与你的账户合并**。在此过程中，书签、历史记录和其他所有内容都会保留在这台 Mac 上，它的默认个人资料也会与你账户的默认个人资料匹配。

### 同步已暂停，或正在等待个人资料配对 {#sync-paused}

你在设置同步之后创建的个人资料还没有配对。Phi 会自行将它注册到你的账户，完成后这个个人资料的同步就会开始。同步面板中的**重试**可以立即重试。如果暂停一直没有解除，请检查网络连接，并确认你仍处于登录状态，然后再次点按**重试**。

### 同步显示「需要注意」 {#sync-needs-attention}

**上次问题**会指出出了什么问题。[每个问题的含义](#needs-attention)列出了所有问题以及相应的处理方法。

### 无法完成替换这台 Mac 的数据 {#replace-did-not-finish}

如果你选择**使用你账户的数据**后，设置流程停止并显示**无法完成替换这台 Mac 的数据。**，点按**重试**。重试会从中断处继续，在完成之前，其他内容都不会更改。运行期间请保持 Phi 打开；如果账户很大，可能需要几分钟。如果你关闭了窗口，下次设置会继续同一个替换，如[稍后完成](#finish-later)中所述。

### 空间在匹配后更改了名称、图标、颜色或主题 {#account-values-replaced}

这是正常的。当你把这台 Mac 上的空间与账户中的空间匹配时，以账户中的名称、图标、颜色和主题为准，**查看将发生的更改**会在你点按**应用**之前显示这一点。要保留这台 Mac 上的版本，在那一步点按**返回**，为该空间选择**添加为新空间**：它之后会作为一个独立的空间同步。匹配一旦应用，这台 Mac 上原来的值就不会保留，所以如果你想要回它们，请手动重新设置这个空间的样式；这个更改也会同步到你的其他 Mac。

## 退出登录

退出 Phi 账号会停止那台 Mac 上的同步，在你重新登录之前，其他 Mac 上的任何内容都不会到达。重新登录同一个账号后，同步会从中断的地方继续，并补上错过的内容；如果还有需要完成的步骤，同步面板会告诉你。切换到另一个账号绝不会把两者混在一起：每个账号都有自己的同步数据和自己的匹配信息。

## 你的数据如何受到保护

- **离开你的 Mac 之前就已加密。** 密钥由你的 Mac 生成，上传的只有加密副本。同步服务负责存储它并把它交给你的其他 Mac；它无法解密。
- **仅仅登录并不足以读取它。** 新的 Mac 只能通过已持有密钥的 Mac 批准，或者通过你的恢复代码，才能拿到密钥。这也是丢失的代码无法找回的原因：设置流程中的<strong>忘记了恢复代码？</strong>链接会说明你有哪些选择，但没有一种能把代码找回来。
- **它仍然是我们替你保管的数据。** 加密副本存放在 Phinomenon 的同步服务上，所以同步是 Phi 会发送的内容之一。[隐私与你的数据](/zh-Hans/privacy/)列出了其他内容，而[隐私政策](https://phibrowser.com/privacy/)和[条款](https://phibrowser.com/terms/)是这一切的权威说明。

## 同步还是导出 {#sync-or-export}

同步适用于你同时在用的几台 Mac。如果只是一次性迁移到新 Mac，或者想自己留一份副本，**帮助**菜单里的<strong>管理用户数据 → 导出用户数据…</strong>是更合适的工具；见[导入与导出](/zh-Hans/import-export/)。
