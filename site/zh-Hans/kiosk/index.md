# Kiosk

Kiosk 是只装一个页面的轻量窗口。它让你在标签页和侧边栏之外打开链接，翻一翻内容，再决定它是否属于你的某个空间。

Kiosk 适合那些可能有用、但还没挣得常驻位置的链接。「邮件」里的一篇文章、「信息」里的一份文档，或者一个你想看看又不想打断手头工作的链接，都可以待在自己的窗口里。看完就关掉 Kiosk；想留下，就把页面移进某个空间。

Kiosk 是临时的，Phi 重新启动后不会回来。

## 在 Kiosk 中打开页面

常见的打开方式有三种：

| 链接在哪里                      | 怎么做                                               |
| ------------------------------- | ---------------------------------------------------- |
| 在 Phi 的页面上                 | 右键点按链接，选择**在 Kiosk 中打开**。              |
| 在 Phi 的页面上，且已启用快捷键 | 按住 Command 和 Option，然后点按链接。               |
| 在其他应用里                    | 在**设置 → 导航**下开启**在 Kiosk 中打开外部链接**。 |

从 Phi 页面打开的 Kiosk 使用该页面的个人资料。从其他应用打开的链接使用你上次使用的个人资料。

## 用网址规则打开匹配的链接

当指向某个网站的链接应该始终在 Kiosk 中打开时，用一条网址规则。

1. 打开**设置 → 导航**。
2. 在**网址规则**下，点按**管理网址规则…**。
3. 为想匹配的域名或网址添加一条规则。
4. 把目标选为 **Kiosk**。

匹配这条规则的链接此后都会在 Kiosk 窗口中打开。想让某些网站一直留在空间之外、以后再决定是否把页面移进去时，这个办法很合适。

## 切换个人资料

当前个人资料显示在地址栏左侧。

1. 点按个人资料名称。
2. 从菜单中选择另一个个人资料。

Phi 会用你选的个人资料重新打开当前页面。你在网站上看到的账号可能会变，因为每个个人资料都有自己的 Cookie 和登录会话。页面上尚未提交的内容，例如表单里的文字，可能会随页面重新加载而丢失。

## 在空间中打开页面

**在 [空间] 中打开**控制项位于 Kiosk 工具栏右侧。

- 点按控制项的主体部分，把页面移入你在常规 Phi 窗口中上次使用的空间。
- 点按箭头并选择一个空间，把页面移到别处。
- 使用默认快捷键时，按 **⌘O** 执行主操作，把页面移入当前空间。

页面会成为所选空间里的一个普通标签页。移到另一个空间可能会重新加载页面，所以先提交或保存手头的内容。

## 选择 Kiosk 何时打开

打开**设置 → 导航**，找到 **Kiosk** 部分。

- **在 Kiosk 中打开外部链接**会把来自「邮件」「信息」等应用的链接送进各自的 Kiosk 窗口。关闭它，这些链接就会在常规 Phi 窗口中打开。
- **按住 ⌘⌥ 点按链接时打开 Kiosk**让你在 Phi 里按住 Command 和 Option 点按链接。如果不想让这个手势打开 Kiosk，就把它关掉。

这两个开关都不会从链接的右键菜单里移除**在 Kiosk 中打开**一项。
