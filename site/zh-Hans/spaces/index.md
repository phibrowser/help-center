# 空间与个人资料

空间和个人资料让你在一个浏览器里维持几个互不干扰的世界：工作和生活、一个副业、一位客户、一个研究主题，都不必来回切换窗口，也不用反复登录和退出登录。它们是分工不同的两层，Phi 让一层直接叠在另一层之上，把关系保持得很简单。

## 两层结构

- **空间**是侧边栏里的工作区。它有自己的名称、图标和颜色，也有自己的书签。切换空间时，侧边栏会围绕你手头的任务重新布置。
- **个人资料**是底下的隔离层。每个个人资料都有自己的 Cookie、历史记录、登录状态和扩展程序，所以两个个人资料可以同时用不同账号登录同一个网站。

这个关系是单向的：**每个空间只属于一个个人资料，而一个个人资料可以承载多个空间**。共用同一个个人资料的空间共享同样的登录状态。固定标签页的可见范围可以配置，可以跟随空间、个人资料或整个应用，但这不改变个人资料的隔离。

可以这样记：**空间决定外观和感受，个人资料决定底层哪些东西彼此隔开。**

## 空间里有什么

- **名称、图标和颜色**。从 Phi 内置的图标集里选，或者用一个 emoji，让每个空间在侧边栏里一眼就能认出来。
- **自己的书签**。每个空间都有一套独立的书签，工作空间里保存的页面不会挤进个人空间。
- **自己的主题（可选）**。空间可以用自己的配色主题，也可以跟随全局主题。切换到该空间时会应用它的主题，窗口就和你所处的场景相符。
- **固定标签页**遵循**设置 → 空间**里选定的范围。可以每个空间各有一套，也可以让共用同一个个人资料的空间共享，或者让所有常规个人资料和空间共用一套。详见[书签与固定标签页](/zh-Hans/bookmarks/#choose-a-pinned-tab-scope)。

## 创建、切换和管理空间

- 在侧边栏的空间栏里**创建**空间。给它起名，选择它属于哪个个人资料；如果这个空间需要完全独立，也可以就地新建一个**新个人资料**。
- 在侧边栏里点按一下，即可在空间之间**切换**。侧边栏的标签页、书签和主题会随之改变；如果该空间的窗口尚未打开，Phi 会重新打开它。
- 从空间的菜单里**重命名**，或者**更改图标** / **更改主题**。选择**跟随全局**可以取消该空间单独设置的主题。
- 从同一个菜单里**删除**空间，或者从菜单栏选择**空间 → 删除空间…**。删除空间会连同属于它的书签和网址规则一起移除，且无法撤销。如果固定标签页范围是**空间**，那个空间的固定标签页也会被移除；范围为个人资料或整个应用的固定标签页不受影响。
- **没有固定的默认空间**。任何空间都可以删除，包括你第一次打开 Phi 时它创建的那一个。唯一的规则是，Phi 始终至少保留一个常规空间（所有个人资料一起算），所以只剩最后一个空间时不会提供**删除**。先创建另一个空间，再删除你不想要的那个。无痕空间不计入这一个：它们只会被关闭，不会被删除。

## 网址规则：自动分流匹配的网站 {#url-rules-route-matching-sites-automatically}

**网址规则**匹配某个网站，然后在常规空间、无痕或 Kiosk 中打开它，无论你在哪里点击或输入这个链接。

从菜单栏的**空间**菜单打开**网址规则…**，或者打开**设置 → 导航**并点按**管理网址规则…**。每条规则按以下方式之一匹配：

- **域名后缀**，`figma.com` 及其所有子域名。
- **域名**，一个确切的主机名，例如 `www.example.com`。
- **域名包含**，主机名中含有某个词，例如 `git`。
- **网址**，主机名加路径前缀，例如 `example.com/team`。

规则可以指向常规空间、**无痕**或 **Kiosk**。**无痕**会把匹配的网站分流进[无痕空间](/zh-Hans/incognito/)，需要时新建一个。**Kiosk** 会把每个匹配的页面在空间之外的轻量窗口中打开。这些窗口如何工作，见 [Kiosk](/zh-Hans/kiosk/)。

把规则设为**每次询问**，就不再静默分流。匹配的链接打开时，Phi 会弹出选择器**在哪个空间打开？**，由你来挑。当前空间会被标出，你也可以让页面留在原处。多条规则都能匹配时，最具体的那条胜出（路径长的优先于路径短的，确切主机名优先于通配）。

## 无痕空间：不留痕迹的空间

浏览时如果什么都不想留下，用**文件 → 新建无痕空间**就能直接在侧边栏空间栏里打开一个私密空间。它的工作区体验和别的空间一样，但背后是一个内存中的会话，而不是个人资料：没有书签，没有固定标签页，没有 AI，也不会向磁盘写入任何东西。关闭它就销毁了这个会话。完整说明见[无痕空间](/zh-Hans/incognito/)。

## 与 Phi 其他部分的关系

空间建立在[布局与导航](/zh-Hans/layouts/)介绍的侧边栏工作区之上，各空间的颜色与[主题与外观](/zh-Hans/themes/)使用同一套调色板。如果你从 Arc 或 Dia 迁移，可以看看[迁移到 Phi](/zh-Hans/switching-to-phi/)里的迁移对比。由于个人资料隔离了 Cookie 和历史记录，助手能看到的内容也限于你当前所在的个人资料。你的数据如何处理，见[隐私与你的数据](/zh-Hans/privacy/)。
