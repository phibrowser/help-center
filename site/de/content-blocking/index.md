# Inhaltsblockierung

Phi basiert auf Chromium und nutzt Braves quelloffene Engine zur Inhaltsfilterung. Du kannst Werbung, Tracker und Cookie-Banner getrennt voneinander blockieren.

## Was Phi blockieren kann

| Einstellung                  | Wirkung                                                                                |
| ---------------------------- | -------------------------------------------------------------------------------------- |
| **Werbung blockieren**       | Blockiert passende Werbung und Werbeanfragen.                                          |
| **Tracker blockieren**       | Blockiert passende Tracking-Skripte, Beacons und Analyseanfragen.                      |
| **Cookie-Banner blockieren** | Blendet passende Cookie-Hinweise aus. Es wählt keine Einwilligungsoption für dich aus. |

Die drei Schalter sind zunächst ausgeschaltet. Sie gehören zu einem [Profil](/de/spaces/), sodass du für verschiedene Profile unterschiedliche Einstellungen und Filterlisten verwenden kannst.

Die Inhaltsblockierung nutzt Regeln aus Filterlisten. Eine Liste kann allgemeine Werbung oder Tracker, Cookie-Hinweise, Websites aus bestimmten Regionen oder eigene Regeln abdecken. Phi kann nicht jede Werbung oder jeden Tracker blockieren. Manche Websites verhalten sich anders, wenn eine Regel greift.

## Inhaltsblockierung einschalten

1. Öffne **Einstellungen → Profile**.
2. Wähle ein Profil und suche nach **Inhaltsblockierung**.
3. Schalte die gewünschten Kategorien ein.
4. Wenn Phi dich auffordert, Filterlisten auszuwählen, markiere die gewünschten Listen und klicke auf **Fertig**, um ausgewählte Listen herunterzuladen, die noch nicht auf deinem Mac liegen.

Über die Regelauswahl neben einer Kategorie kannst du die Listen jederzeit ändern. Ein Download startet erst, wenn du eine Download-Aktion auswählst. **Heruntergeladene Listen aktualisieren** ruft die aktuelle Version bereits geladener Listen ab.

Wähle in der Regelauswahl **Filter hinzufügen…**, um eine Liste per URL hinzuzufügen oder Regeln direkt einzufügen. Eine eigene Liste gilt für alle drei Kategorien dieses Profils.

Heruntergeladene Filterlisten können von mehreren Profilen gemeinsam genutzt werden. Jedes Profil hat eigene Listenauswahlen, eigene Listen und Website-Ausnahmen.

## Eine Website ausnehmen

Öffne das Menü in der Adressleiste und wähle **Inhaltsblockierung auf dieser Website**, um die Blockierung für die aktuelle Website im aktiven Profil ein- oder auszuschalten. Damit änderst du nur die Ausnahme dieses Profils für die Website. Die Kategorien bleiben auf anderen Websites unverändert.

In Inkognito-Fenstern ist dieser Menüpunkt nicht verfügbar.

## Wenn eine Website nicht richtig funktioniert

Manche Websites benötigen eine Ressource, die eine Filterliste blockiert. Wähle im Menü der Adressleiste **Inhaltsblockierung auf dieser Website**, um eine Ausnahme einzurichten, und lade die Seite anschließend neu. Du kannst auch eine Kategorie ausschalten oder ihre Filterlisten unter **Einstellungen → Profile** ändern.

Filterlisten erkennen nicht jede Werbung, jeden Tracker und jeden Cookie-Hinweis. Die Cookie-Banner-Blockierung blendet passende Seitenelemente aus. Sie akzeptiert keine Cookies und schließt keine Einwilligungsabfrage für dich.
