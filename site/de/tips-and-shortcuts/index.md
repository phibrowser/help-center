# Schnelle Tipps für Phi Browser

Diese Seite sammelt Gesten und Kurzbefehle in Phi, die sich nicht direkt aus der Oberfläche erschließen. Die gezeigten Tastaturkurzbefehle sind die Standardbelegung. Du kannst sie unter **Einstellungen → Tastaturkurzbefehle** ändern.

## Kurzbefehle im Überblick

| Aktion                                                                                  | Kurzbefehl oder Geste                                                                                                     |
| --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Split View erstellen                                                                    | Mit gedrückter Wahltaste (⌥) auf einen Tab, einen angehefteten Tab, ein Lesezeichen oder einen geeigneten Weblink klicken |
| Link in einem Peek als Vorschau anzeigen                                                | Mit gedrückter Umschalttaste (⇧) auf einen Weblink klicken                                                                |
| Zwischen zuletzt benutzten Tabs wechseln                                                | Ctrl-Taste (⌃) + Tab                                                                                                      |
| In umgekehrter Reihenfolge wechseln                                                     | Ctrl-Taste (⌃) + Umschalttaste (⇧) + Tab                                                                                  |
| URL der aktuellen Seite kopieren                                                        | Befehlstaste (⌘) + Umschalttaste (⇧) + C                                                                                  |
| Offene Tabs durchsuchen                                                                 | Befehlstaste (⌘) + Umschalttaste (⇧) + A                                                                                  |
| Die ganze Seite aufnehmen                                                               | Befehlstaste (⌘) + Umschalttaste (⇧) + 1                                                                                  |
| Einen ausgewählten Bereich aufnehmen                                                    | Befehlstaste (⌘) + Umschalttaste (⇧) + 2                                                                                  |
| Zum vorherigen oder nächsten Space wechseln                                             | Befehlstaste (⌘) + Wahltaste (⌥) + ← oder →                                                                               |
| Einen der ersten neun Spaces öffnen                                                     | Ctrl-Taste (⌃) + 1 bis 9                                                                                                  |
| Ein neues Kiosk-Fenster aus jeder App öffnen, wenn der globale Kurzbefehl aktiviert ist | Befehlstaste (⌘) + Wahltaste (⌥) + N                                                                                      |
| Eine Kiosk-Seite oder einen Peek als Tab in einem Space öffnen                          | Befehlstaste (⌘) + O                                                                                                      |
| Das Menü zur Space-Auswahl in Kiosk öffnen                                              | Befehlstaste (⌘) + Umschalttaste (⇧) + O                                                                                  |
| Phi Chat aus jeder App öffnen oder ausblenden, wenn der Kurzbefehl aktiviert ist        | Dreimal die Umschalttaste (⇧) drücken                                                                                     |

Aktiviere den globalen Kiosk-Kurzbefehl unter **Einstellungen → Navigation → Kiosk**. Um die Tastenkombination zu ändern, bearbeite **Neues Kiosk-Fenster** unter **Einstellungen → Tastaturkurzbefehle → Ablage**.

Der Phi Chat-Kurzbefehl ist standardmäßig aus. Schalte ihn mit **Phi Chat mit Umschalt Umschalt Umschalt aufrufen** unter **Einstellungen → Phi & KI → Phi Sentinel** ein. Andere Tasten lassen sich dafür nicht festlegen. Siehe [Phi Chat](/de/phi-chat/#opening-phi-chat).

Die beiden Kurzbefehle zum Öffnen in einem Space kannst du unter **Einstellungen → Tastaturkurzbefehle → Kiosk & Peek** ändern. Details findest du unter [Kiosk](/de/kiosk/) und [Peek-Ansicht](/de/peek/).

## Split View erstellen

- Halte die Wahltaste (⌥) gedrückt und klicke auf einen anderen Tab, einen Tab in einer Gruppe, einen angehefteten Tab, ein Lesezeichen oder einen geeigneten Weblink. Phi platziert die Seite neben deiner aktuellen.
- Ziehe einen einzelnen Tab, einen angehefteten Tab oder ein Lesezeichen an die linke oder rechte Seite der aktuellen Seite. Die gewählte Seite bestimmt, wo er erscheint.
- Lege ein Element auf einem Bereich eines bestehenden, nicht angehefteten Split View ab, um diesen Bereich zu ersetzen.

## Zur gesicherten URL zurückkehren

Ein angehefteter Tab oder ein Lesezeichen kann sich von der ursprünglich gesicherten URL wegbewegen. Du kannst zurückkehren, ohne die gerade geöffnete Seite zu verlieren.

- Doppelklicke auf einen angehefteten Tab, um ihn zu seiner gesicherten URL zurückzubringen.
- Klicke auf das Favicon eines Lesezeichens, um es zu seiner gesicherten URL zurückzubringen.
- Halte bei einer der beiden Gesten die Befehlstaste (⌘) gedrückt, damit die aktuelle Seite als eigener Tab geöffnet bleibt, bevor die gesicherte URL wiederhergestellt wird.

## Die Gruppenübersicht verwenden

Klicke auf die Kopfzeile einer Tab-Gruppe, um die Gruppenübersicht zu öffnen. Sie zeigt einen Schnappschuss jeder Seite; ein Split View erscheint dabei als eine kombinierte Karte.

Aus der Gruppenübersicht heraus kannst du zu einer Seite wechseln, eine Seite schließen, einen neuen Tab erstellen oder Name und Farbe der Gruppe ändern. Verwendest du die Adressleiste, während die Gruppenübersicht geöffnet ist, tritt der neue Tab dieser Gruppe bei.

Ziehe eine ganze Tab-Gruppe in den Lesezeichenbereich, um sie in einen Lesezeichenordner zu verwandeln. Phi behält die Reihenfolge ihrer Tabs und löst die Gruppe auf, aber die offenen Tabs bleiben geöffnet.

## Mit mehreren Tabs und Lesezeichen arbeiten

- Klicke bei gedrückter Befehlstaste (⌘) auf reguläre Tabs und Lesezeichen, um sie einzeln auszuwählen.
- Klicke bei gedrückter Umschalttaste (⇧), um einen Bereich auszuwählen.
- Zu den möglichen Aktionen gehören: eine Tab-Gruppe erstellen, Elemente zu einem Lesezeichenordner hinzufügen, sie in einen anderen Space bewegen oder klonen und sie schließen.
- Ziehe ein beliebiges ausgewähltes Element, um die ganze Auswahl zu bewegen. Die beiden Seiten eines Split View bleiben zusammen.
- Drücke die Esc-Taste, um die Auswahl aufzuheben.

## Wechseln, suchen und kopieren

Ctrl-Taste (⌃) + Tab folgt der Reihenfolge der zuletzt benutzten Tabs, nicht der Anordnung der Tabs im Fenster.

- Drücke den Kurzbefehl einmal, um zwischen dem aktuellen und dem vorherigen Tab zu wechseln.
- Halte ihn gedrückt oder drücke ihn mehrmals, um bis zu fünf zuletzt benutzte Tabs anzuzeigen.
- Nimm die Umschalttaste (⇧) hinzu, um die Liste rückwärts zu durchlaufen.
- Drücke Befehlstaste (⌘) + Umschalttaste (⇧) + A, um alle offenen Tabs zu durchsuchen.
- Drücke Befehlstaste (⌘) + Umschalttaste (⇧) + C, um die URL des aktuellen Tabs zu kopieren.

## Jeden Space personalisieren

Öffne **Einstellungen → Spaces** und wähle einen Space aus.

- Wähle ein Symbol aus Phis integriertem Satz oder verwende ein Emoji.
- Wähle eine Designfarbe und passe ihre Sättigung an.

Jeder Space behält sein eigenes Symbol und Design. Beim Wechseln der Spaces gilt das Erscheinungsbild, das du für den jeweiligen Space gewählt hast, ohne dass sich die anderen ändern.

## Zwischen Spaces wechseln

- Drücke Befehlstaste (⌘) + Wahltaste (⌥) + ← oder →, um zum vorherigen oder nächsten Space zu wechseln.
- Drücke Ctrl-Taste (⌃) + 1 bis 9, um direkt einen der ersten neun Spaces zu öffnen.

## Websites mit URL-Regeln lenken

Öffne **Spaces → URL-Regeln…** in der Menüleiste, oder öffne **Einstellungen → Navigation** und klicke auf **URL-Regeln verwalten…**. Eine Regel kann nach **Domain-Suffix**, **Domain**, **Domain enthält** oder **URL** greifen.

Schicke Treffer in einen regulären Space, in Inkognito oder in Kiosk. Wähle **Jedes Mal fragen**, wenn Phi vor dem Verschieben der Seite nachfragen soll. Passen mehrere Regeln, gewinnt die spezifischste.

::: tip Routing in reguläre Spaces isoliert keine Cookies
Eine Website in einen regulären Space zu lenken isoliert weder ihre Cookies noch ihre angemeldete Sitzung. Weise die Ziel-Spaces unterschiedlichen Profilen zu, wenn du diese Trennung willst.
:::

## Videos mit Bild-in-Bild im Blick behalten

Phi kann ein laufendes Video in ein schwebendes Fenster herauslösen, wenn du den Tab oder Space wechselst. Wähle das Verhalten unter **Einstellungen → Erweitert → Automatisches Bild-in-Bild**.

| Modus              | Verhalten                                                                                    |
| ------------------ | -------------------------------------------------------------------------------------------- |
| **Aus**            | Bild-in-Bild nie automatisch öffnen. Manuelles Bild-in-Bild funktioniert weiterhin.          |
| **Normal**         | Laufende Videos beim Wechsel von Tab oder Space herauslösen.                                 |
| **Am Rand parken** | Laufende Videos herauslösen und das Fenster am Bildschirmrand parken, bis du darauf klickst. |

Bewege ein Bild-in-Bild-Fenster oder ändere seine Größe, und Phi merkt sich Position und Größe für das nächste Mal, wenn diese Website Bild-in-Bild öffnet. Gespeichert wird das pro Website in einem regulären Profil; Inkognito-Spaces behalten es nicht. Ist das gespeicherte Display nicht mehr angeschlossen, verwendet Phi die Standardplatzierung.

Um ein offenes Bild-in-Bild-Fenster selbst zu parken, bewege den Zeiger darüber und klicke auf den Abwärtspfeil mit der Beschriftung **Am Bildschirmrand andocken**. Phi schiebt das Fenster an den nächstgelegenen Bildschirmrand und lässt einen Griff sichtbar. Klicke auf den Griff, um das Fenster zurückzuholen. Dieses Bedienelement funktioniert auch dann, wenn automatisches Bild-in-Bild auf **Aus** steht.

## Hintergrundmedien mit dem MiniPlayer steuern

Der MiniPlayer erscheint unten in der Seitenleiste, wenn unterstützte Audio- oder Videoinhalte in einem Hintergrund-Tab wiedergegeben werden, auch wenn du zu einem anderen Space wechselst. Bei stummgeschalteten Medien erscheint der MiniPlayer nicht automatisch. Der MiniPlayer wird ausgeblendet, wenn du zum Quell-Tab zurückkehrst, wenn dieser Tab in Split View sichtbar ist oder wenn sein Video in Bild-in-Bild läuft.

Mit dem MiniPlayer kannst du die Wiedergabe starten oder pausieren und Titel überspringen. Klicke auf das Website-Symbol, um zum Quell-Tab zurückzukehren. Klicke auf die Lautsprechertaste, um den Lautstärkeregler anzuzeigen. Halte beim Klicken die Wahltaste (⌥) gedrückt, um den Ton stummzuschalten oder die Stummschaltung aufzuheben. Wenn mehrere Hintergrund-Tabs Medien enthalten, wische auf dem MiniPlayer nach links oder rechts, um die Quelle zu wechseln.

Erweitere den MiniPlayer, um Mediendetails zu sehen, zu einer anderen Stelle im Titel zu springen oder Bild-in-Bild zu öffnen. Welche Details und Bedienelemente verfügbar sind, hängt davon ab, was die Website unterstützt.

Wähle einen Modus unter **Einstellungen → Erweitert → MiniPlayer**:

| Modus               | Verhalten                                                                                                                                             |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Aus**             | Der MiniPlayer erscheint nicht automatisch.                                                                                                           |
| **Automatisch**     | Der MiniPlayer beginnt kompakt und wird erweitert, wenn du den Zeiger darüber bewegst oder er Tastaturfokus erhält. Dies ist die Standardeinstellung. |
| **Immer erweitert** | Der MiniPlayer wird erweitert angezeigt, sobald unterstützte Hintergrundmedien verfügbar sind.                                                        |
| **Immer kompakt**   | Der MiniPlayer bleibt kompakt.                                                                                                                        |

## Bildschirmfotos aufnehmen und bearbeiten

Wähle **Ablage → Bildschirmfoto der ganzen Seite aufnehmen** oder drücke Befehlstaste (⌘) + Umschalttaste (⇧) + 1, um die aktuelle Webseite einschließlich der Inhalte außerhalb des sichtbaren Bereichs aufzunehmen.

Wähle **Ablage → Bildschirmfoto eines Bereichs aufnehmen…** oder drücke Befehlstaste (⌘) + Umschalttaste (⇧) + 2. Ziehe dann, um einen Teil der Seite auszuwählen. Scrolle beim Ziehen mit der Maus oder dem Trackpad, oder halte den Zeiger nahe an einem Seitenrand, um die Auswahl über den sichtbaren Bereich hinaus zu erweitern. Lass los, um die Aufnahme zu machen, oder drücke die Esc-Taste, um abzubrechen.

Dies sind die Standardkurzbefehle. Du kannst sie unter **Einstellungen → Tastaturkurzbefehle → Ablage** ändern.

Nach der Aufnahme kopiert Phi das ursprüngliche Bildschirmfoto als PNG in die Zwischenablage und öffnet den Bildeditor.

Im Bildeditor kannst du dein Bildschirmfoto beschneiden, darauf zeichnen, Text und Formen hinzufügen oder einzelne Bereiche verpixeln.

Klicke auf **Exportieren…**, um dein bearbeitetes Bild als PNG, JPG oder PDF zu sichern.

## Den Assistenten zu deiner aktuellen Arbeit befragen

- Wähle Text aus, klicke mit der rechten Maustaste darauf und wähle **[dein Assistent] zu … fragen**, um die Auswahl in eine Unterhaltung zu übernehmen.
- Beim Öffnen des Assistenten wird der aktuelle Tab standardmäßig angehängt. Liegt dieser Tab in einer Gruppe, kann Phi die ganze Gruppe anhängen.
- Eine Tab-Gruppe oder ein Split View lässt sich als eine Einheit anhängen.

Um Unterhaltungen ohne angehängten aktuellen Tab zu beginnen, schalte **Aktuellen Tab automatisch als Kontext zu neuen Unterhaltungen hinzufügen** unter **Einstellungen → Phi & KI → KI-Seitenleiste** aus.

Wenn du Phi Cloud verwendest, werden die Inhalte, die zur Beantwortung deiner Frage nötig sind, zur Verarbeitung an einen externen Modellanbieter gesendet. Mit Private KI bleiben sie auf deinem Mac. Details stehen unter [Datenschutz & deine Daten](/de/privacy/).
