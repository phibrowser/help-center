# Themes & Erscheinungsbild

In Phi legst du fest, wie der Browser aussieht: ein Farb-**Theme** plus die Wahl zwischen **hell und dunkel**, und beides gilt für den ganzen Browser statt für einen einzelnen Bildschirm. Wähle einen Look einmal, und Fenster, Seitenleiste und dein neuer Tab folgen ihm.

Diese Einstellmöglichkeiten findest du unter **Einstellungen → Allgemein**.

## Ein Theme wählen

Unter **Theme** bietet die Zeile **Farbe** eine Reihe benannter Voreinstellungen, dargestellt als Farbfelder. Jede ist ein vollständiges Farbschema mit eigener heller und dunkler Version, ein Theme sieht also in jedem Erscheinungsbild richtig aus.

In Phis Auswahl wird **Pure** als weißes Farbfeld mit dem blauen Akzent als Auswahlring angezeigt. Die Tabelle oben zeigt die tatsächlichen Akzentfarben, die das Theme an den übrigen Stellen verwendet.

Neben den Farben steuert ein Regler **Deckkraft**, wie stark die Farbebene durch das Fenster scheint. Dreh die Tönung höher für mehr Farbe oder niedriger für einen schlichteren Eindruck.

## Hell, dunkel oder System

Das **Erscheinungsbild** ist eine von der Theme-Farbe getrennte Wahl. Unter **Farbdarstellung** kannst du wählen:

- **System**, folgt deiner macOS-Einstellung und wechselt mit ihr.
- **Hell**, immer hell.
- **Dunkel**, immer dunkel.

Dein gewähltes Theme behält in beiden Modi seinen Charakter; diese Wahl bestimmt nur, welche Version du siehst.

## Wo das Theme sichtbar wird

Ein Theme wird im ganzen Browser angewendet, nicht auf einer einzelnen Fläche:

- **Das Fenster.** Symbolleiste, Adressleiste und Tabs nehmen die Theme-Farbe an. Der Regler **Deckkraft** legt fest, wie kräftig diese Tönung ist.
- **Die Seitenleiste.** Ausgewählte Tabs und Tabs unter dem Zeiger übernehmen das Theme.
- **Der neue Tab.** Dein [neuer Tab](/de/new-tab/) folgt automatisch demselben Theme und passt damit zum Rest des Browsers; wechselst du das Theme, färbt er sich mit allem anderen um.
- **Ausgewählter Text auf Webseiten.** Standardmäßig färbt das Markieren von Text auf einer Seite die Auswahl mit deiner Theme-Farbe ein. Sollen Seiten lieber ihre eigene, native Auswahlfarbe behalten, schalte **Theme auf Textauswahl auf Webseiten anwenden** in den Theme-Einstellungen aus.
