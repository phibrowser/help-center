# Erste Schritte

Phi Browser läuft auf macOS (Apple Silicon, macOS 14 oder neuer). Installiere ihn auf einem der beiden Wege unten und geh dann den ersten Start durch.

## Phi installieren

### Von der offiziellen Website laden

Öffne die [Phi-Downloadseite](https://phibrowser.com/download/), lade die `.dmg`-Datei, öffne sie und ziehe Phi in deinen Ordner „Programme“.

### Mit Homebrew installieren

Wenn du [Homebrew](https://brew.sh/) verwendest, installiere Phi mit:

```sh
brew install --cask phibrowser/tap/phi
```

Das fügt automatisch den Tap `phibrowser/tap` hinzu und installiert das Phi-Cask. Updates übernimmt Phi selbst, du musst also nicht über Homebrew aktualisieren.

## Erster Start

Beim ersten Öffnen von Phi hilft dir das Onboarding beim Einrichten:

- **Wähle einen Layout-Modus**, Performance, Ausgewogen oder Komfortabel. Du kannst das jederzeit ändern; nimm also, was am ehesten dazu passt, wie du heute surfst. Was die einzelnen Modi bedeuten, steht unter [Layouts & Navigation](/de/layouts/).
- **Lerne deinen Assistenten kennen**, sobald du im Browser bist, lädt dich ein Banner oben im neuen Tab dazu ein: Gib ihm einen Namen, und er erzeugt einen passenden Avatar für sich selbst, sodass er eine eigene Identität hat, statt sich wie ein generischer Chatbot anzufühlen. Du kannst das auch überspringen und später nachholen.
- **KI ist standardmäßig an**, die KI-Funktionen von Phi sind ab Werk aktiviert. Du kannst sie später in **Einstellungen → Phi AI** abschalten, wenn du einen schlichten Browser bevorzugst.

## Du wechselst von einem anderen Browser?

Wenn du Chrome oder Safari gewohnt bist, starte mit dem Modus **Komfortabel**, das ist der leichteste Übergang. Eine ausführlichere Umstiegshilfe für alle, die von Chrome, Safari, Arc oder Dia kommen, findest du unter [Umstieg auf Phi](/de/switching-to-phi/).
