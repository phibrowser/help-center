# よくある質問

Phi Browserについてよくある質問への簡潔な答えを、トピック別にまとめています。全体像や、Phiがこう作られている「理由」については[ガイド](/ja/what-is-phi-browser/)をお読みください。Phi Browserは初めてですか？[はじめに](/ja/get-started/)をご覧ください。

## レイアウトとナビゲーション

::: details 3つのレイアウトモードとは何ですか？
Phiには、画面スペースと馴染みやすさのどちらを優先するかが異なる3つのモードがあります。**パフォーマンス**はページに最も広いスペースを与え、タブとブックマークには縦型サイドバーを使います。**バランス**はサイドバーを保ちつつ、コンテンツの上にURLバーを追加します。**ゆったり**は従来のブラウザに最も近い見た目で、上部にタブが並び、URLバーが常に表示されます。オンボーディングでいずれかを選び、いつでも変更できます。
:::

::: details 最初はどのレイアウトを選べばよいですか？
ChromeやSafariから乗り換える場合は、いちばん移行しやすい**ゆったり**から始めてください。アドレスバーが見えるモダンなサイドバーブラウザが欲しいなら**バランス**を試してください。ページのスペースを最大限に使いたいなら**パフォーマンス**を使ってください。より詳しい移行ガイドは[Phiへの乗り換え](/ja/switching-to-phi/)をご覧ください。
:::

::: details なぜ縦型サイドバーなのですか？
現代の画面のほとんどは横に広く、縦には広くありません。読む、書く、調べるといった作業で最初に足りなくなるのは縦のスペースです。縦型サイドバーは現代のディスプレイの形状をより有効に使い、実際のページにより多くの場所を残します。
:::

## スペースとプロファイル

::: details スペースとプロファイルの違いは何ですか？
**スペース**は、独自の名前、アイコン、カラー、ブックマークを持つサイドバー上のワークスペースです。**プロファイル**はその下にある分離レイヤーで、プロファイルごとに独自のCookie、履歴、ログイン情報、拡張機能を持ちます。スペースは見た目と使い心地を整え、プロファイルは何を分離しておくかを決めます。全体像はガイドの[スペースとプロファイル](/ja/spaces/)をご覧ください。
:::

::: details 1つのプロファイルに複数のスペースを持てますか？
はい。各スペースはちょうど1つのプロファイルに属しますが、1つのプロファイルが複数のスペースを支えることができます。プロファイルを共有するスペース同士は、同じログイン情報を共有します。固定タブを共有するかどうかは、選択した固定タブの範囲によって決まります。Cookieやログイン中のアカウントまで含めて2つのスペースを完全に分けたい場合は、別々のプロファイルを割り当ててください。
:::

::: details スペースはどうやって作成しますか？
サイドバーのスペースストリップからスペースを作成します。名前を付けて、所属するプロファイルを選びます。スペースを完全に分離したい場合は、その場で**新しいプロファイル**を作成することもできます。
:::

::: details スペースを切り替えると何が起こりますか？
サイドバーのタブ、ブックマーク、テーマがそのスペースに合わせて切り替わり、Phiはそのスペースのウインドウを前面に出します（必要なら新しく開きます）。固定タブは、**設定 → スペース**で選択したスペース、プロファイル、アプリのいずれの範囲かに応じて、切り替わるか、表示されたままになります。
:::

::: details スペースごとに独自のブックマークとテーマがありますか？
はい。どのスペースも独立したブックマークのセットを持ち、独自のカラーテーマを使うことも、**グローバルに従う**（Follow Global）を選ぶこともできます。スペースのメニューから名前の変更やアイコンの変更もできます。
:::

::: details URLルールとは何ですか？
URLルールは、リンクをどこでクリックしても、どこに入力しても、一致するサイトを通常のスペース、シークレット、またはKioskで開きます。管理は**設定 → ナビゲーション**から行います。マッチングは、ドメインのサフィックス、ドメインの完全一致、「ドメインに含まれる」、ホストとパスのプレフィックスの組み合わせで指定できます。ルールを**毎回確認する**に設定すると、黙って振り分ける代わりに「**どのスペースで開きますか？**」という確認が表示されます。複数のルールが一致した場合は、最も具体的なルールが優先されます。
:::

::: details スペースを削除するとどうなりますか？
スペースを削除すると、そのスペースに属するブックマークとURLルールも削除されます。この操作は取り消せません。そのスペースに属するスペース範囲の固定タブも削除されますが、プロファイル範囲とアプリ範囲の固定タブは残ります。スペースを削除しても、プロファイルとそのCookie、履歴、ログイン情報が削除されることはありません。
:::

::: details ArcやDiaとはどう違いますか？
Phiは、目に見えるワークスペースのレイヤーとして**スペース**を、その下の分離レイヤーとして**プロファイル**を保っています。これはArcの2層モデルに近い考え方です。一方Diaは、プロファイルをより直接的に、別々のウインドウのワークスペースとして使います。詳しい比較は[Phiへの乗り換え](/ja/switching-to-phi/)をご覧ください。
:::

## シークレットスペース

::: details シークレットスペースとは何ですか？
サイドバー上のプライベートなスペースです。ほかのスペースと同じようにスペースストリップに表示されますが、セッションはメモリ上だけに存在し、ディスクには何も書き込まれません。**ファイル → 新しいシークレットスペース**で開きます。1つだけのときは「シークレット」という名前になり、複数開くと「シークレット 1」「シークレット 2」のように番号が付きます。全体像はガイドの[シークレットスペース](/ja/incognito/)をご覧ください。
:::

::: details シークレットスペース同士はセッションを共有しますか？
はい。開いているすべてのシークレットスペースは1つのプライベートセッションを共有します。あるサイトに1つのスペースでログインすると、ほかのスペースでもそのサイトにログインした状態になります。このセッションは通常のプロファイルとは別で、従来の**新しいシークレットウインドウ**のセッションとも決して混ざりません。
:::

::: details シークレットスペースでは何が使えませんか？
ブックマークと固定タブは表示されず、作成もできません。アシスタントのチャットとメモリボタンは利用できず、ブラウザデータのインポートはブロックされ、シークレットでの実行を許可した拡張機能だけが有効になります。テーマはPhiのダークなシークレット用の外観に固定されます。アイコンは変更できますが、その選択はスペースと共に消えます。
:::

::: details シークレットスペースを閉じるとどうなりますか？
Phiは「**この操作を行うと、このシークレットスペースも閉じられます。よろしいですか？**」と確認し（**今後確認しない**にチェックを入れると、以降は表示されません）、そのスペースのウインドウを閉じて、ストリップから取り除きます。最後のシークレットスペースのウインドウが閉じるか、Phiが終了すると、共有プライベートセッションは破棄されます。ダウンロードしたファイルはMacに残ります。
:::

::: details URLルールでサイトをシークレットスペースに送れますか？
はい。URLルールのエディタには、通常のスペースやKioskに加えて汎用の**シークレット**という送り先が1つ用意されています。シークレットスペースは開いている間しか存在しないため、ルールが特定のシークレットスペースを指すことはありません。そうしたルールが一致すると、Phiは開いているシークレットスペースを使うか、必要に応じて新しく開きます。ルーティングは一方通行で、ルールがプライベートセッション内のナビゲーションを通常のスペースへ引き戻すことはありません。
:::

::: details シークレットスペースで拡張機能は動きますか？
個別に許可しない限り動きません。これはほかのChromiumベースのブラウザと同じです。プライベートセッションは常にデフォルトのプロファイルの上に構築されるため、そこで実行できるのはそのプロファイルの拡張機能だけです。デフォルトのプロファイルのウインドウで、拡張機能メニューから**拡張機能を管理**を選び（または`phi://extensions`と入力し）、その拡張機能の**詳細**を開いて「**シークレット モードでの実行を許可する**」をオンにします。ほかのプロファイルにインストールされた拡張機能がシークレットスペースに表示されることはなく、プライベートセッションの中から新しい拡張機能をインストールすることもできません。
:::

::: details シークレットスペースはTime Machineバックアップに含まれますか？
いいえ。スナップショットには一切含まれません。シークレットスペースのセッションはウインドウと共に消えるように設計されているため、バックアップを復元してもシークレットスペースが戻ることはありません。
:::

## ブックマークとタブ

::: details Phiのブックマークはなぜ違う感じがするのですか？
Phiはブックマークを、年に2回しか開かない隠れたアーカイブではなく、アクティブなブラウジングワークスペースの一部として扱います。保存したページはメニューの奥に埋もれず、サイドバーに見えたまま、いつでもアクセスできます。
:::

::: details ゆったりモードでブックマークはどう機能しますか？
ゆったりモードの動作はChromeによく似ています。**表示 → ブックマークバーを常に表示**でブックマークバーを表示できます。メニューバーには**ブックマーク**メニューもあり、こちらはどのレイアウトモードでも利用できます。
:::

::: details バランスモードとパフォーマンスモードでブックマークはどう機能しますか？
これらのモードには従来のブックマークバーがありません。代わりに、タブをサイドバーへドラッグしてブックマークします。サイドバーがページを整理する中心的な場所になります。
:::

::: details なぜタブとブックマークが同じサイドバーにあるのですか？
どちらも同じもの、つまり「あなたが気にかけているページ」の両端だからです。タブは今使っているページ、ブックマークは保存してあるページです。両者を一緒に置いておくのは、あなたがその2つの状態を絶えず行き来しているからです。
:::

::: details 固定タブとブックマークの違いは何ですか？
固定タブはサイドバーの最上部にあり、お気に入りのツールやダッシュボードのような、いつも使っているページのための場所です。ブックマークはその下にあり、アクティブにしておかなくても後で使いたいページを保存しておきます。
:::

::: details ブックマークをクリックすると何が起こりますか？
その場で開きます。使い捨てのタブを新しく増やすのではなく、ブックマークのサイドバー項目そのものが、開いているタブに変わります。すでに開いている場合は、2つ目のコピーを作らず、そのタブがアクティブになるだけです。ページを閉じてもブックマークはサイドバーに残り、いつでも開き直せます。
:::

::: details ブックマークと固定タブはスペースごとですか？
ブックマークは常にスペースごとで、各スペースが独自のセットを持ちます。固定タブは、1つのスペースに限定するか、同じプロファイルを使うスペース間で共有するか、アプリ全体で共有するかを選べます。範囲は**設定 → スペース**で選択します。デフォルトは**プロファイル**です。[ブックマークと固定タブ](/ja/bookmarks/#choose-a-pinned-tab-scope)をご覧ください。
:::

::: details タブを固定または固定解除するにはどうすればよいですか？
タブを右クリックして**タブを固定**を選ぶか、サイドバー上部の固定グリッドへドラッグします。**固定を解除**でタブリストに戻ります。固定タブはドラッグで並べ替えられ、**分割表示を固定**を使えば、2ペインの構成を1つの固定項目として保てます。
:::

::: details 固定タブやブックマークを元のページに戻すには？
固定タブをダブルクリックするか、タブとして開いているブックマークのファビコンをクリックします。現在のページを残したい場合は、**Command**（⌘）を押しながら固定タブをダブルクリックするか、ブックマークのファビコンをクリックします。現在のページは別のタブとしてタブリストへ移り、固定タブまたはブックマークは元のURLに戻ります。
:::

::: details ArcやDiaと似ていますか？
はい。Phiも同じ大きな考え方、つまり保存したページが見えたままで、固定したページが最上部に並ぶ「生きたサイドバー」という発想を採用しつつ、独自のブックマークツリーと動作を保っています。移行の比較は[Phiへの乗り換え](/ja/switching-to-phi/)、機能の詳細は[ブックマークと固定タブ](/ja/bookmarks/)をご覧ください。
:::

## 分割表示とタブグループ

::: details タブ、分割表示、タブグループはどう考えればよいですか？
タブは今見ているページです。分割表示は2つのページを並べて配置します。タブグループは、関連するページをプロジェクトやトピックごとにまとめます。
:::

::: details 分割表示とは何ですか？
分割表示は、同じPhiのウインドウの中で2つのページを隣り合わせに配置する機能です。読みながら書く、2つのページを比較する、Webアプリの隣にドキュメントを置いておく、といった使い方に便利です。
:::

::: details 分割表示はどうやって作成しますか？
タブ、ブックマーク、固定タブを右クリックして**分割表示で開く**を選ぶか、タブを現在のページの上へドラッグします。**Option**（⌥）を押しながら固定タブ、ブックマーク、Webページ上のリンクをクリックする方法もあります。Phiは現在のタブの隣に分割表示で開きます。
:::

::: details タブグループとは何ですか？
タブグループは、関連するタブを1つの名前付きグループにまとめる機能です。プロジェクト、旅行、リサーチのテーマ、買い物などに便利です。
:::

::: details 分割表示とタブグループはどのように連携しますか？
両者は一緒に使うことを前提に設計されています。グループの中で分割表示を使うことも、分割したタブをグループへ出し入れすることもでき、関連する作業がばらばらのタブとして漂うことなく整理されたままになります。
:::

::: details アシスタントは分割表示やタブグループ全体を理解できますか？
はい。分割表示からチャットすると、Phiは両方のページのコンテキストを使えます。タブグループからなら、グループ全体のコンテキストを使えます。自分の作業環境を説明しなくても、関連ページをまたいで質問できます。
:::

::: details タブグループはブックマークと同じですか？
いいえ。タブグループは今まさに作業中のページを整理するもので、ブックマークは後で使うためにページを保存するものです。
:::

## AI機能 {#ai-features}

::: details AIはデフォルトでオンですか？
はい。PhiはAI機能を有効にした状態で出荷されます。AIが製品の中核だからです。プレーンなブラウザとして使いたい場合はオフにできます。
:::

::: details AI機能をすべてオフにできますか？
はい、**設定 → Phi AI**でオフにできます。AIをオフにすると、AIとの会話は終了し、接続中の外部データコネクタは切断されます。メモリはデバイス上に残ります。メモリまで消去したい場合はメモリページの消去オプションを使いますが、その削除は元に戻せません。
:::

::: details 主なAIコンポーネントは何ですか？
それぞれ役割の異なる4つの要素、**メモリ**、**アシスタント**、**エージェント**機能、**ブラウザスキル**です。
:::

::: details Phiのメモリとは何ですか？
Phiのメモリは、時間の経過とともにあなたのブラウジング行動からコンテキストを組み立てるシステムです。自動的に動作し、手動のセットアップは要りません。
:::

::: details メモリは手動で保存する必要がありますか？
いいえ。メモリは自動です。Phiが関連するブラウジング行動を観察し、バックグラウンドであなたのためにコンテキストを組み立てます。
:::

::: details Phiのメモリはどこに保存されますか？
デバイス上にローカルで保存されます。ローカルファーストの保存は、中核となる設計原則です。
:::

::: details Phiが何を記憶しているか確認・管理できますか？
はい。メモリデータはPhiの中で直接、表示、管理、削除できます。
:::

::: details Phiはメモリをサーバーに送信しますか？
いいえ。メモリデータはローカルに保たれます。言語モデルがタスクを処理することはありますが、あなた個人のメモリが保存やトレーニングのために外部へ送られることはありません。
:::

::: details Phiは私のデータをAIモデルのトレーニングに使いますか？
いいえ。Phiがあなたのメモリデータ、ブラウジングのコンテキスト、AIとのやり取りをモデルのトレーニングに使うことはありません。
:::

::: details アシスタントとは何ですか？
ブラウザの中で直接やり取りする相棒です。オンボーディングで名前を付けると、それに合わせたアバターを自分で生成し、以降はその名前で呼びかけることになります。汎用のチャットボットのような存在ではなく、固有のアイデンティティを持ちます。
:::

::: details アシスタントとはどうやって話しますか？
**チャット**ボタンをクリックします。パフォーマンスモードではサイドバーの下部に、バランスモードとゆったりモードではページヘッダーの右上にあります。または、ページ上のテキストを選択して右クリックし、「**…について[アシスタント名]に質問**」を選ぶと、文脈の中でそのまま質問できます。
:::

::: details アシスタントは何ができますか？
質問への回答、コンテンツの要約、ページの説明、タスクの手伝いができます。その際、現在のタブ、Phiのメモリ、接続した外部データのコンテキストを活用します。
:::

::: details 「エージェント的」とはどういう意味ですか？
AIが質問に答える以上のことをできる、という意味です。ブラウザの中で操作を実行し、単発のアクションから繰り返しの自動化まで、あなたの代わりにタスクをこなせます。
:::

::: details オンデマンドのアクションとは何ですか？
頼んだときにアシスタントが実行するタスクです。ページを移動したり、あなたに代わってWebサイトを操作したりします。
:::

::: details スケジュールされたタスクとは何ですか？
自分で決めたスケジュールで繰り返し実行される自動化です。たとえば、商品の価格を監視したり、ページの変更を見張ったりできます。
:::

## Phi Sentinel

::: details Phi Sentinelとは何ですか？
Phi Sentinelは、Phi BrowserのバックグラウンドAIオーケストレーターです。スケジュールされたタスクを実行し、AIタスクの履歴を保持し、macOSのメニューバーから動作します。
:::

::: details なぜPhi Sentinelはブラウザと分かれているのですか？
ブラウザのウインドウを閉じても、スケジュールされたタスクや継続的なAIワークフローが動き続けられるようにするためです。
:::

::: details なぜこのような設計なのですか？
ブラウザを軽量に保ちながら、永続的な自動化レイヤーを維持するほうが、システム全体として実用的だからです。
:::

## Phi Link

::: details Phi Linkとは何ですか？
Phi LinkはPhi BrowserをTelegramにつなぎます。スマートフォンからアシスタントを使ったり、Macから離れているときにタスクの更新を受け取ったりできます。
:::

::: details Phi Linkはどうやって設定しますか？
方法は2つあります。公式のPhi Linkボットを使うのが最も手軽で、QRコードをスキャンして1クリックで完了します。もう1つは、BotFatherで自分のTelegramボットを作成し、そのトークンをPhiの設定に貼り付ける方法です。
:::

::: details Phi Linkで何ができますか？
アシスタントとチャットし、タスクの成功や失敗の通知を受け取り、ブラウザから離れたままワークフローを続けられます。
:::

::: details Phi Linkでも同じアシスタントですか？
はい。同じアシスタントのアイデンティティがそのまま引き継がれ、デスクトップとスマートフォンで一貫した体験になります。自分のボットを使う場合はカスタマイズも可能です。
:::

## プライバシーとデータ

::: details Phiのプライバシーモデルはどのようなものですか？
Phi Browserはローカルファーストのアーキテクチャを軸に作られています。Phiが記憶する内容はあなたのデバイス上に保たれ、トレーニングには使われません。
:::

::: details Phiが決して収集しないものは何ですか？
Phiがあなたのメモリデータ、AIとのやり取り、ブラウジングのコンテキストを収集することはなく、これらをトレーニングに使うこともありません。

Phiが送信するのは、常時有効な小さな匿名カウント（Phiをデフォルトに設定しているインストール数、スペースの利用、プロファイルの利用、そしてクラッシュが起きたこと）と、あなたがオンにした場合に限り送られる、詳細な使用統計およびクラッシュレポートです。[Phiが送信するもの](/ja/privacy/#what-phi-does-send)をご覧ください。
:::

::: details メモリはローカルに保存されますか？
はい。メモリデータはあなたのデバイス上にあり、表示、管理、削除ができます。
:::

::: details Phiは閲覧履歴を売ったりトレーニングに使ったりしますか？
いいえ。Phiがブラウジング由来のメモリやAIとのやり取りをモデルのトレーニングに使うことはなく、ブラウジング由来のデータを販売することもありません。
:::

::: details Phiは使用統計を収集しますか？
はい。「**Phi の機能とパフォーマンスの向上に協力する**」スイッチがオンの間だけ、Phiは匿名の使用統計をPhinomenonに送信します。このスイッチは有効な状態で出荷されます。統計の対象はブラウザ自体、つまりどの機能が使われ、アプリがどう動作しているかです。訪問したページ、メモリ、AIとの会話が含まれることはありません。レポートには、Phiアカウントとは無関係のランダムなインストール識別子が付きます。[プライバシーとあなたのデータ](/ja/privacy/#usage-statistics)をご覧ください。
:::

::: details 使用統計はどうすればオフにできますか？
`phi://settings`を開き、「**あなたと Phi**」セクションの「**Phi の機能とパフォーマンスの向上に協力する**」をオフにして、表示される**再起動**ボタンをクリックすると変更が反映されます。スイッチをオフにすると、それまでのレポートに付いていたランダムな識別子も削除されます。後で再びオンにした場合、Phiは新しい識別子を作成します。
:::

## Time Machineバックアップ

::: details PhiのTime Machineとは何ですか？
**バージョンのロールバック**のためのセーフティネットです。特定の大きなアップデートの前に、Phiは現在のバージョンとデータのスナップショットを自動的に保存します。新しいリリースが合わなかったときに、そこへ戻ることができます。全体像はガイドの[Time Machineバックアップ](/ja/time-machine/)をご覧ください。
:::

::: details これはAppleのTime Machineですか？
いいえ。Macのバックアップは行わず、同じ名前のmacOSの機能とは無関係です。Phiを以前のバージョンに戻すことだけを行います。
:::

::: details ブラウジングを常時バックアップするのですか？
いいえ。継続的なバックアップでも、スケジュールされたバックアップでもありません。スナップショットは自動的に、しかもごくたまにしか作成されません。通常よりリスクの高いアップデートの直前に、そのようなアップデートごとに1回だけです。自分で管理できるバックアップが欲しい場合は、代わりに**ユーザーデータを書き出す**を使ってください。
:::

::: details スナップショットには何が含まれますか？
以前のバージョンに属するPhiのデータです。つまり、ブックマーク、スペース、固定タブ、設定、メモリ、ブラウジングの状態、そしてどのアプリバージョンを復元するかの記録です。アプリ本体は復元時にダウンロードされるため、ロールバックすると一貫したセットアップに戻ります。
:::

::: details スナップショットはどこに保存されますか？
Macのローカルに保存されます。クラウドにはアップロードされず、アカウントにも紐付かず、別のMacへ移すこともできません。
:::

::: details ロールバックするにはどうすればよいですか？
**ヘルプ**メニューを開いて**Time Machineバックアップ**を選び、スナップショットを選択します（バージョン、ビルド、日付の順で、*Phi 1.6 (590)、2026.6.11*のように一覧表示されます）。**復元**で確定すると、Phiは以前のバージョンをダウンロードし、現在のアプリと対応するデータを置き換えて再起動します。復元中はインターネット接続が必要です。スナップショットが1つもない場合、メニューには**利用できるバックアップがありません**と表示されます。
:::

::: details データの書き出しとはどう違いますか？
Time Machineはアップデートのロールバックを自動で扱います。新しいMacへの移行や個人的なコピーの保管のために、自分でバックアップを作成して保持するには、**ヘルプ**メニューの**ユーザーデータを管理**（「**ユーザーデータを書き出す…**」と「**ユーザーデータを読み込む…**」）を使います。
:::
