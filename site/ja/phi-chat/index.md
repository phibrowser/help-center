# Phi Chat

Phi Chatは、ブラウザのウインドウとは別の、専用のウインドウで動くアシスタントです。Dockにも専用のアイコンがあります。サイドバーと同じアシスタント、同じ会話を、腰を据えた作業向けに配置したもので、右側に大きなチャット、左側に会話の一覧が並びます。

目の前のページについて尋ねる場所は、これまでどおりサイドバーです。Phi Chatは、以前の会話を探したり、すべてを1か所で見渡したり、タスクから届いた報告を追ったりするための場所です。

## Phi Chatを開く {#opening-phi-chat}

開き方はいくつかあります。

- **サイドバーから。** サイドバーのトップバーにある**Phi Chatで開く**をクリックすると、今の会話をそのまま移せます。[会話を移す](#moving-a-conversation-over)をご覧ください。
- **メニューバーから。** [Phi Sentinel](/ja/sentinel/)のアイコンをクリックし、**Phi Chatを開く**を選びます。Phi Chatが前面にあるときにもう一度選ぶと、ウインドウが隠れます。この項目に小さな赤い点が付いているときは、まだ読んでいない投稿がアシスタントから届いています。
- **ショートカットで。** ショートカットはデフォルトでオフです。**設定 → PhiとAI → Phi Sentinel**で**Shift Shift ShiftでPhi Chatを呼び出す**をオンにすると、どのアプリからでもShift (⇧)キーを3回押して開けます。動きはメニューバーの項目と同じで、同じキーをもう一度押すとウインドウが隠れます。このショートカットはPhi Sentinelを通じて動作します。Phi Sentinelがキーの入力を検知するにはmacOSのアクセシビリティの許可が必要で、ショートカットをオンにしたときに許可を求めます。
- **タスクの通知から。** タスクが知らせる価値のあることを報告すると、Phiが独自の通知カードを表示することがあります。これはmacOSの通知とは別のものです。カードの**詳細を表示**ボタンを押すと、その会話がPhi Chatで開きます。[自動化とPhi Link](/ja/automation/#notifications)をご覧ください。
- **DockやFinderから。** 一度Phi Chatを開くと、ホームフォルダ内のアプリケーションフォルダにある**Phi Apps**フォルダにもアプリとして表示されるので、Dockに置いておくことができます。

Phi Chatは、ブラウザのウインドウが開いていなくても使えます。Phiが起動していない場合、Phi Chatを開くと、ブラウザのウインドウを開かずにPhiがバックグラウンドで起動します。

## 会話を移す {#moving-a-conversation-over}

サイドバーの**Phi Chatで開く**は、会話が保存され、アシスタントが返答の途中でないときに使えるようになります。クリックすると、その会話がPhi Chatで開き、サイドバーは折りたたまれ、サイドバーでは新しい会話を始められる状態になります。

クリックする前に知っておきたいことが2つあります。

- **送信していない内容は移りません。** サイドバーで何かを入力したり添付ファイルを追加したりして、まだ送信していない場合、Phiはそれを破棄してよいか確認します。それらはPhi Chatには引き継がれません。
- **開いているPhi Chatのウインドウが再利用されます。** Phi Chatがすでに開いている場合は、2つ目のウインドウを開くのではなく、そのウインドウがこの会話に切り替わります。そのウインドウで送信していなかった内容と、書きかけだった返答は失われます。

逆方向に移すには、Phi Chatのトップバーにある**サイドバーで開く**をクリックします。Phiは、その会話で最後に使われたWebページを、元のスペースとプロファイルで開き直し、そのページのサイドバーで会話を続けます。会話はPhi Chatでも開いたままです。会話が一度もWebページと一緒に使われていない場合や、元のスペースまたはプロファイルがもう存在しない場合、このボタンは使えません。ボタンにポインタを重ねると、どちらが理由かが表示されます。

## すべてのプロファイルの会話 {#conversations-from-every-profile}

会話は、それを始めた[プロファイル](/ja/spaces/)に属します。サイドバーでは会話がプロファイルごとに分かれていて、あるプロファイルでは、そのプロファイルの会話と、どのプロファイルにも属さない会話だけが表示され、ほかのプロファイルの会話は表示されません。

Phi Chatは、そのすべてを表示する唯一の場所です。会話一覧の上にあるメニューを開いて、表示する内容を選びます。

- **すべて**、すべての会話。
- **タスク**、アシスタントがタスクを作成した会話。[タスクと未読の会話](#tasks-and-unread-conversations)をご覧ください。
- **プロファイル別**、**プロファイルなし**か、いずれかのプロファイル。プロファイルは、同じ名前のカテゴリと区別できるよう<strong>プロファイル「仕事」</strong>のように表示されます。
- **カテゴリ**、自分で作ったカテゴリと**未分類**。

ここでプロファイルを選んでも、一覧が絞り込まれるだけです。会話が別のプロファイルに移ることはなく、Phi Chatで会話を開いても、その会話が属するプロファイルは変わりません。プロファイルに属さない会話は、メニューの**プロファイルに移動**でプロファイルに割り当てられますが、割り当てた後にプロファイルから外す方法はありません。

プロファイルを削除しても、その会話は残ります。会話はカテゴリを失い、Phi Chatの**未分類**に表示されます。削除したときにAI機能がオフだった場合は、AI機能がオンに戻った時点でそうなります。

## 会話を探して整理する

一覧には、最近やり取りした会話から順に、50件ずつ表示されます。それより前の会話は、一番下の**さらに読み込む**をクリックすると表示されます。

- **検索**は、一覧の上部にある虫眼鏡から行うか、Command (⌘) + Kを押します。検索の対象は会話のタイトルで、会話の中のメッセージは対象になりません。
- **新しい会話を始める**には、**新しいチャット**を使います。最初のメッセージを送信した時点で一覧に加わります。
- **名前の変更、分類、削除**は、会話の行にある<strong>…</strong>メニューから行います。**削除**は元に戻せません。
- **ページに戻る**には、同じメニューの**最後のページに戻る**を使います。動きは[サイドバー版](/ja/ai/#going-back-to-a-page)と同じです。

### カテゴリ

カテゴリは、会話に付ける自分用のラベルで、すべてのプロファイルで共通です。1つの会話を複数のカテゴリに入れることもできます。

- カテゴリを作るには、一覧の上にあるメニューの<strong>+</strong>ボタンを使うか、任意の**カテゴリ**サブメニューの一番下にある**新しいカテゴリ**を使います。後者では、開いている会話もそのカテゴリに入ります。
- 会話の<strong>…</strong>メニュー、またはチャットのトップバーにあるメニューの**カテゴリ**で、カテゴリのチェックを付けたり外したりします。変更はクリックした時点で反映されます。
- カテゴリの名前を変えたり削除したりするには、メニューでそのカテゴリを選び、カテゴリ自身のメニューを開きます。カテゴリを削除しても、その中の会話は削除されません。カテゴリが1つもなくなった会話は**未分類**に移ります。

**未分類**は組み込みのカテゴリです。カテゴリのない会話がすべてここに集まり、名前の変更や削除はできません。

### 複数の会話をまとめて操作する

複数の会話をまとめて操作するには、会話の<strong>…</strong>メニューから**選択**を選ぶか、Command (⌘)キーを押しながら行をクリックします。Shift (⇧)キーを押しながらクリックすると、範囲で選択できます。一覧のヘッダーがバーに置き換わり、**すべて選択**、選択した会話全体の**カテゴリ**の変更、**削除**ができます。終えるときは**完了**をクリックするか、Escキーを押します。

**すべて選択**で選ばれるのは、一覧に現在読み込まれている会話です。**さらに読み込む**の先にある会話は含まれないので、表示される件数がそのまま操作の対象になります。

## タスクと未読の会話 {#tasks-and-unread-conversations}

バックグラウンドやスケジュールで何かをするようアシスタントに頼むと、そのタスクは頼んだ会話に報告を返します。Phi Chatでは、そうした報告を次のように追えます。

- **青い点と太字のタイトル**は、最後にその会話を開いてから、タスクが報告を投稿したことを示します。
- **時計のアイコン**がタイトルの後ろにある会話には、まだ動いているタスクがあります。
- **タスク**ビューには、アシスタントがタスクを作成した会話がすべて集まります。タスクが会話にひも付けられるようになる前の会話は、ここには表示されません。

報告の見た目と、その報告を出しているタスクの管理方法は、[自動化とPhi Link](/ja/automation/#tasks-report-back-to-their-conversation)で説明しています。

## 知っておきたいこと

- **Phi ChatはPhi Browserの一部です。** Command (⌘) + QまたはメニューからPhi Chatを終了しても、閉じるのはPhi Chatだけで、ブラウザのウインドウは開いたままです。ブラウザのウインドウからPhiを終了すると、Phi Chatも閉じます。
- **リンクはブラウザで開きます。** Phi Chatでクリックしたリンクは、最後に使ったプロファイルのブラウザウインドウで、[URLルール](/ja/spaces/#url-rules-route-matching-sites-automatically)に従って開きます。
- **AIをオフにすると閉じます。** **設定 → PhiとAI**でAI機能をオフにすると、Phi Chatは閉じ、そのアプリは**Phi Apps**フォルダから削除され、開けなくなります。会話は削除されず、AI機能をオンに戻せば、またPhi Chatを開けます。
- **質問はやはりモデルに送られます。** Phi Chatはサイドバーと同じアシスタントなので、質問の扱いも同じです。[質問の行き先](/ja/ai/#where-your-questions-go)をご覧ください。
