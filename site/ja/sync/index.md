# 同期

同期を使うと、同じPhiアカウントにサインインしているすべてのMacで、Phi自身のデータを同じ状態に保てます。あるMacでブックマークを保存したりスペースの名前を変更したりすると、その変更がほかのMacにも届きます。同期は各Macで設定するまでオフのままです。また、同期で運ばれる内容を当社が読めないように作られています。すべてのデータはアップロードされる前にMac上で暗号化され、その鍵を持っているのはあなたのMacだけです。

ここで説明する操作はすべて**設定 → 同期**にあります。

## 同期されるもの {#what-syncs}

| 項目                               | 詳細                                                                                                                                                                                                                                        |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **スペース**                       | 名前、アイコン、カラー、テーマ、各スペースが属するプロファイル。                                                                                                                                                                            |
| **プロファイル**                   | プロファイル名と、各プロファイルに属するスペース。                                                                                                                                                                                          |
| **ブックマークとフォルダ**         | すべてのスペースのブックマーク。フォルダと並び順も含みます。                                                                                                                                                                                |
| **固定タブ**                       | **設定 → スペース**で選んだ範囲に従った固定タブ。                                                                                                                                                                                           |
| **URLルール**                      | 一致したサイトをスペース、シークレット、Kioskに振り分けるルール。                                                                                                                                                                           |
| **対応する設定**                   | レイアウトモード、外観、テーマと選択時の色合い、ブックマークバーと完全なURLの表示に関する設定、**新しいタブの動作**（⌘Tで開くもの）、シークレットを閉じるときの警告、自動ピクチャー イン ピクチャー、固定タブの範囲、デフォルトのスペース。 |
| **閲覧データ（プロファイルごと）** | 閲覧履歴、デフォルトの検索エンジンなどのブラウザ自体の設定、拡張機能とその同期される設定。                                                                                                                                                  |

::: warning 削除も同期されます
あるMacでスペースやプロファイルを削除すると、そのMacと同期しているすべてのMacから、ブックマークを含めて削除されます。確認ダイアログにもその旨が表示されるので、確定する前によく読んでください。
:::

意図的に、その場にとどまるものもあります。

- <strong>パスワード、Cookie、自動入力。</strong>これらが同期に含まれることはありません。Phiは独自のパスワードマネージャーを持っていません。[エージェントのパスワードマネージャー](/ja/agent-passwords/)を通じて接続する保管庫はそのプロバイダのものであり、そのプロバイダの条件に従って同期されます。
- <strong>開いているタブ。</strong>通常の開いているタブは、別のMacで再現されません。固定タブは再現されます。
- <strong>Phi Chatとメモリ。</strong>アシスタントとの会話は、その会話をしたMacにとどまります。[メモリ](/ja/memory/)も同様です。
- **シークレットスペース**と、エージェントが作業するスペース。これらからは何も同期されません。ただし、サイトをシークレットに送るURLルールもルールであることに変わりはないので、ほかのルールと同じように同期されます。
- <strong>キーボードショートカット。</strong>**設定 → ショートカット**で設定した内容は、設定したMacにとどまります。
- **1台のMacに結び付いた設定**。AIとエージェントの設定もこれに含まれます。

## 始める前に

- <strong>各MacでサインインしたPhiアカウント。</strong>アカウントがないと、このパネルには**サインインしてデバイス間で同期**しか表示されません。アカウントなしで試すことを選んだ場合は、[後からログインする](/ja/get-started/#signing-in-later)をご覧ください。
- <strong>公式のPhiビルド。</strong>同期はPhinomenonの同期サービスを通じて行われます。オープンソースのコードから自分でビルドしたPhiでは利用できません。

## 最初のMacを設定する {#set-up-your-first-mac}

1. **設定 → 同期**を開き、**このデバイスで同期を設定**をクリックします。これから行うことの説明がウインドウに表示されるので、**続ける**をクリックします。
2. **復旧コードを保存**します。Phiが復旧コードを作成し、一度だけ表示します。5文字ずつのグループに分かれた27文字のコードです。**コピー**をクリックしてパスワードマネージャーなどの安全な場所に保管し、**保存しました**をクリックします。
3. **復旧コードを確認**します。保存したコードの入力を求められます。ダッシュ、スペース、大文字と小文字の違いは問われません。保存していなかった場合は**戻る**をクリックします。同じコードがもう一度表示されるので、ここで保存できます。コードが確認できるまで同期はオフのままなので、実は保存できていなかったと後で気付くことはありません。ここでウインドウを閉じた場合は、次に設定を開いたときか再起動したときに、Phiがもう一度確認を求めます。ただし、その時点では**戻る**は表示されません。ウインドウを閉じると、コードは保持されないためです。
4. **Phiが自動的に同期を設定**します。最初のMacではアカウントに対応付ける相手がまだないため、入力する対応付けのページはありません。PhiはこのMacのプロファイルとスペースをアカウントに追加し、その間<strong>同期を設定中…</strong>と表示します。アカウント内のすべてを読み取れなかった場合は、代わりに[別のMacを追加する](#add-another-mac)の対応付けのページが表示されます。
5. 設定が完了すると、このMacがアップロードしている間、パネルには**初回同期が進行中**と表示され、その後**最新の状態**に変わります。

::: warning 復旧コードは一度しか表示されません
コードはあなたのMac上で作られ、当社に送信されることはありません。そのため、当社がコードを再表示したり、代わりのコードを送ったり、リセットしたりすることはできません。別のMacを追加するには、コードか、すでに設定済みのMacのどちらかが必要です。両方を失うと、アカウント内の暗号化されたコピーは誰にもロック解除できません。当社も例外ではありません。すでにコードを失くしている場合は、[復旧コードを忘れた場合](#forgot-your-recovery-code)をご覧ください。
:::

## 別のMacを追加する {#add-another-mac}

1. 同じPhiアカウントにサインインし、**設定 → 同期**を開いて**このデバイスで同期を設定**をクリックし、**続ける**をクリックします。
2. **このデバイスをアカウントに追加**で、このMacの参加方法を選びます。
   - **別のデバイスに承認をリクエスト**。Phiが短いコードを表示して待機します。すでに設定済みのMacで**設定 → 同期**を開くと、**デバイス**の下に、同じコードと有効期限とともにリクエストが表示されます。2つのコードが一致することを確かめてから**承認**をクリックします。心当たりのないリクエストなら**拒否**をクリックします。このコードは新しいMacを識別するためのもので、秘密の情報ではないため、電話で読み上げても問題ありません。拒否されたリクエストや期限が切れたリクエストでは、**別の方法を試す**を選べます。
   - **復旧コードを入力**。最初のMacで保存したコードを入力します。
3. **このMacの同期方法を選び**ます。アカウントにすでにデータがあり、このMacにも独自のデータがある場合、Phiは<strong>このMacをどのように同期しますか？</strong>と尋ね、それぞれの側にあるものを表示します。
   - **このMacをアカウントと統合**（**おすすめ**と表示されています）。次のステップでプロファイルとスペースを1つずつ対応付けます。双方のブックマーク、固定タブ、URLルールは保持されます。
   - **アカウントのデータを使用**。このMacのスペース、ブックマーク、固定タブ、URLルール、同期される設定がアカウントのデータに置き換えられ、アカウントにないプロファイルはこのMacから削除されます。変更されるのはこのMacだけで、この操作は取り消せません。選ぶ前に[アカウントのデータを使用](#use-your-accounts-data)をご覧ください。

   デフォルトのプロファイルとデフォルトのスペースしかなく、ブックマーク、固定タブ、URLルールもないMacでは、このステップは表示されません。このMacのデータでアカウントを上書きするオプションはありません。

4. **プロファイルを対応付け**ます。Phiは、このMacのプロファイルとアカウント内のプロファイルを組み合わせ、組み合わせられなかったものについて確認を求めます。このMacのデフォルトのプロファイルは、常にアカウントのデフォルトのプロファイルと対応付けられます。その行にはそのアカウントのプロファイルが表示され、選択メニューはありません。ほかの各プロファイルについて、アカウントのプロファイルへの**割り当て**か、**新規として登録**を選びます。このMacに対応するものがないアカウント内のプロファイルは**未割り当てのアカウントのプロファイル**の下に表示され、**このMacに作成**で追加できます。選択がデフォルトのプロファイルのルールに反する場合は、Phiが<strong>このMacのデフォルトのプロファイルは、アカウントのデフォルトのプロファイルとのみ対応付けできます。対応付けを確認して、もう一度お試しください。</strong>と表示します。
5. **スペースを対応付け**ます。このMacの各スペースについて、それがアカウントのどのスペースにあたるかを選ぶか、**新規として追加**を選びます。**すべて新規として追加**を選ぶと、未決定のスペースがまとめて決まります。名前が完全に一致するスペースは自動的に選ばれます。このMacにないアカウント内のスペースは**アカウントから追加されるスペース**の下に表示され、完了したときに作成されます。このMac上のものが削除されることはありません。**完了**をクリックします。
6. **変更される内容を確認**します。この画面は、このMac上の何かが上書きされる場合にだけ表示されます。このMacのスペースをアカウント内のスペースと対応付けた場合、このMacの名前、アイコン、カラー、テーマはアカウントのもので置き換えられ、スペースがアカウント内で属しているプロファイルに移動することもあります。このMac上のタブ、ブックマーク、固定タブ、URLルールには影響しません。このMacの値を残したい場合は、**戻る**で戻り、そのスペースを新規として追加してください。**適用**をクリックすると同期が始まります。上書きされるものがない場合は、**完了**をクリックした時点で同期が始まります。

アカウントの読み込みには、Phiがスペースを数える間、最大で2分ほどかかることがあります。また、読み込みには接続が必要です。代わりに使えるキャッシュされたコピーはありません。**このMacをアカウントと統合**を選んだ場合は、同期が始まると両方のMacのブックマーク、固定タブ、URLルールが保持されるため、どちらの側のものも失われません。

### アカウントのデータを使用 {#use-your-accounts-data}

このMacにあるPhiのデータを残す必要がないときに選びます。たとえば、テストにしか使っていないMacです。PhiはまずこのMacのPhiデータを削除し、それからアカウントのデータをダウンロードします。

- **このMacから削除される項目**：デフォルトのスペース以外のスペース（開いているタブも閉じられます）、ブックマーク、固定タブ、URLルール、同期される設定、そしてアカウントにないすべてのプロファイルとその履歴、拡張機能、サイトデータ。
- **保持されるもの**：このMacのデフォルトのプロファイルと、アカウント内のプロファイルと名前が一致するプロファイルは、履歴、拡張機能、サイトデータを含めて残ります。アカウントとほかのMacには影響しません。

**続ける**をクリックすると、Phiが<strong>このMacのデータを置き換えますか？</strong>と尋ね、削除されるものとダウンロードされるものを一覧表示します。**このMacのデータを置き換え**をクリックすると実行されます。Phiは<strong>このMacのデータを置き換え中…</strong>と表示し、完了するまでウインドウは開いたままになります。その後、最初の同期でアカウントのデータが届き、パネルには**初回同期が進行中**と表示されます。アカウントが大きい場合は数分かかることがあります。置き換えがエラーで止まった場合は、[このMacのデータの置き換えを完了できない場合](#replace-did-not-finish)をご覧ください。

::: warning 置き換えは取り消せません
Phiは削除したもののコピーを保持しません。コピーが必要な場合は、先に**あとで完了**を選び、<strong>ヘルプ → ユーザーデータを管理 → ユーザーデータを書き出す…</strong>で書き出してから（[インポートとエクスポート](/ja/import-export/)と[同期か書き出しか](#sync-or-export)をご覧ください）、設定に戻ってください。ローカルのプロファイルを残したい場合は、代わりに**このMacをアカウントと統合**を選んでください。
:::

### 設定でアカウントを読み込めない場合 {#setup-cannot-load-account}

設定では、選択肢を表示する前にアカウントを読み込みます。読み込みに失敗すると、ウインドウにその理由と**再試行**が表示されます。

- <strong>アカウントのスペースを時間内に読み込めませんでした。接続を確認して、再試行してください。</strong>アカウントが大きいか、接続が遅いことが原因です。
- <strong>同期が現在利用できないため、アカウントのスペースを読み込めませんでした。</strong>Phiが現在、同期に接続できません。オンラインで、サインインしたままであることを確認してから、再試行してください。
- **アカウントのプロファイルを読み込めませんでした。接続を確認して、再試行してください。**、または**アカウントのスペースを読み込めませんでした。接続を確認して、再試行してください。**
- **現在は読み取れません**と表示されたアカウントのプロファイル。Phiはバックグラウンドで再試行を続け、設定のほかの部分はそのまま使えます。
- <strong>アカウントのデフォルトのプロファイルをこのMacで読み取れないため、現在このMacのデータを置き換えることはできません。</strong>読み取れるようになるまで、**アカウントのデータを使用**は実行できません。**このMacをアカウントと統合**を選ぶか、**あとで完了**を選んでからもう一度お試しください。

### あとで完了 {#finish-later}

**あとで完了**は、同期方法のステップと対応付けのページに表示されます。これを選ぶかウインドウを閉じると、このMacはローカルのままブラウジングを続けます。何も同期されず、パネルには**未ペアリング**と表示され、Phiが自動的に設定を再び開くことはありません。準備ができたら**設定 → 同期**に戻り、**設定を続ける**をクリックします。その時点でPhiはアカウントを読み込み直すため、途中だった選択は保持されません。同期方法も同様で、次の設定は**このMacをアカウントと統合**が選択された状態で始まります。

ただし、すでに始まった置き換えは例外です。PhiがこのMacのデータの置き換えを始めた後は、途中で離れても取り消されません。エラーやPhiの終了などで置き換えが止まり、ウインドウを閉じた場合は、次に設定を開くと<strong>このMacのデータを置き換えますか？</strong>に直接進みます。**戻る**はなく、**このMacのデータを置き換え**をクリックすると止まったところから再開します。そこでも<strong>このデバイスを同期から削除…</strong>は選べます。選ぶと、置き換えでまだ削除されていなかったものが残ったまま、このMacは同期から外れます。

## 復旧コードを忘れた場合 {#forgot-your-recovery-code}

復旧コードを再表示することも、同じ同期データ用に新しいコードを作ることも、誰にもできません。当社も例外ではありません。まだできることは、状況によって異なります。**復旧コードを入力**ページの<strong>復旧コードをお忘れですか?</strong>リンクを開くと、このセクションが表示されます。

### 最初のMacをまだ設定している場合

**復旧コードを確認**の画面で、設定ウインドウをまだ閉じていなければ、**戻る**をクリックします。同じコードがもう一度表示されます。コードを保存して**保存しました**をクリックし、確認のためにコードを入力します。

Phi 2.14以前には**戻る**ボタンがありません。また、ウインドウを閉じたりPhiを再起動したりした場合も、コードは失われています。Phiはコードの入力を求め続けますが、コードを表示することはできません。どちらの場合も、必要であればPhiをアップデートしてから、下で説明する[同期のリセット](#reset-sync)で最初からやり直してください。

### 同期が設定されている別のMacがある場合

コードは必要ありません。新しいMacで**別のデバイスに承認をリクエスト**を選び、設定済みのMacでリクエストを承認します。[別のMacを追加する](#add-another-mac)をご覧ください。手元のMacでは、同期がそのまま動作し続けます。

それでも、コードを再表示したり置き換えたりすることはできません。同期が設定されたMacを少なくとも1台は残しておいてください。1台でも残っていれば、コードがなくてもMacを追加できます。

### このMacしかない場合、または最初からやり直したい場合

そのMacで[同期のリセット](#reset-sync)を行います。リセットすると、そのMacが同期から削除され、アカウントに保存されているすべての同期データが削除されます。ローカルの閲覧データはそのMacに残ります。このアカウントで同期が設定されたままのほかのMacがあれば、その後そのMacには[同期をもう一度設定](#set-up-sync-again)と表示されます。そのうえで、[最初のMacを設定する](#set-up-your-first-mac)の手順に従って、このMacで同期を最初から設定します。Phiが新しい復旧コードを作成するので、**保存しました**をクリックする前に保存してください。

**同期をリセット**が表示されるのは、アカウントで同期が設定されている最後のMacだけです。ほかのMacがまだ設定されている状態で最初からやり直したい場合は、先にそれぞれのMacを同期から削除してください。

### 同期が設定されたMacが手元に1台もない場合

コードを失い、手元に同期が設定されたMacが1台もない場合、アカウント内の暗号化されたコピーはロック解除できません。あなたにも当社にもできません。同期がまだ設定されていないMacでは、アカウントの同期をリセットすることもできないため、そのMacから最初からやり直す方法はありません。設定済みのまま紛失または消去したMacしかない場合も、これに当てはまります。そのMacは引き続き設定済みとして扱われ、別のMacから削除することはできません。

## 同期の状態を確認する {#check-sync-status}

同期パネルの上部に、現在の状態が表示されます。

- **最新の状態**、**同期中…**、または最初の同期の実行中は**初回同期が進行中**。
- **オフライン**。接続すると変更が同期されることが併記されます。Phiはローカルのデータで動作を続け、Macがオンラインに戻った時点で変更を送信します。
- <strong>同期を一時停止中。</strong>このMacのプロファイルの中に、まだ同期が設定されていないものがあります。多くは、同期を設定した後に作成したプロファイルです。パネルには、待機しているプロファイルとその理由が表示されます。Phiは自動的にそれらを登録して再試行を続け、**再試行**をクリックするとすぐに試行します。[同期を一時停止中の場合](#sync-paused)をご覧ください。
- <strong>対応が必要。</strong>何かが失敗しています。その下に<strong>一部のコンテンツに対応が必要です。詳細と接続を確認してください。</strong>という行が表示され、**最後の問題**に直近の問題とその発生時刻が表示されます。[各問題の意味](#needs-attention)をご覧ください。

状態の下の**このMacで最後に成功した同期**には、このMacが最後に同期を完了した日時が表示されます。**プロファイルの読み込みを待機中**は、PhiがまだこのMacのプロファイルの一覧を読み取れていないという意味です。Phiは自動的に試行を続け、5分たつと状態が**対応が必要**に変わります。

このMacまたは別のMacで固定タブの範囲を変更した場合、**固定タブの適用範囲の変更はまだ反映されていません**という行が、試行回数と理由とともに表示されることがあります。理由は、**他のブラウザからの移行を実行中**、**ローカルのブラウザデータを利用できません**、**このMacに固定タブを保存できませんでした**のいずれかです。このMacは、まだ固定タブを新しい範囲に移していません。Phiは自動的に再試行を続け、同期のほかの部分は続行されます。この行が消えない場合はPhiを再起動し、それでも消えない場合は、ウインドウ右上のメニューにある**フィードバック**からフィードバックを送信してください。

### 各問題の意味 {#needs-attention}

**最後の問題**には、次のいずれかが表示されます。完全に完了した次の同期で解消されるまで、表示は残ります。

| 最後の問題                                  | 意味                                                                                           | 対処                                                                                                                    |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **サインインの期限切れ**                    | 同期サービスが、このMacのサインインを受け付けなくなっています。                                | Phiアカウントにもう一度サインインします。                                                                               |
| **接続なし**                                | このMacが同期サービスに接続できませんでした。                                                  | 何もする必要はありません。オンラインになった後、次に同期が成功したときに解消されます。                                  |
| **サーバエラー**                            | 同期サービスがエラーを返しました。                                                             | 何もする必要はありません。次に同期が成功したときに解消されます。                                                        |
| **サーバが変更を拒否**                      | 同期サービスが、このMacの変更の一部を拒否しました。別のMacとの競合が繰り返された場合などです。 | **今すぐ同期**をクリックします。再び表示される場合はPhiを再起動し、それでも続く場合はフィードバックを送信してください。 |
| **このMacのデータを読み取れませんでした**   | Phiが、このMac上にある自身のデータの一部を読み取れませんでした。                               | **今すぐ同期**をクリックします。再び表示される場合はPhiを再起動し、それでも続く場合はフィードバックを送信してください。 |
| **このMacに同期状態を保存できませんでした** | Phiが、何が同期済みかの記録を保存できませんでした。                                            | **今すぐ同期**をクリックします。再び表示される場合はPhiを再起動し、それでも続く場合はフィードバックを送信してください。 |
| **一部の同期データを読み取れませんでした**  | アカウント内の何かを、このMacで読み取れませんでした。                                          | **今すぐ同期**をクリックします。再び表示される場合はPhiを再起動し、それでも続く場合はフィードバックを送信してください。 |
| **プロファイルのペアリングを待機中**        | 同期された項目の一部が、このMacのプロファイルがアカウントとペアリングされるのを待っています。  | Phiがプロファイルを設定するのを待つか、パネルに**同期を一時停止中**と表示されているときに**再試行**をクリックします。   |
| **同期の再設定が必要**                      | アカウント内の同期データがリセットされ、このMacの設定と合わなくなっています。                  | **同期をもう一度設定**をクリックします。[同期をもう一度設定する](#set-up-sync-again)をご覧ください。                    |

[詳細](#sync-details)で説明している保留中の項目があると、問題の名前がなくても状態が**対応が必要**のままになることがあります。[固定タブが保留されている場合](#held-pinned-tabs)をご覧ください。

### 詳細 {#sync-details}

**詳細**には、各プロファイルとその閲覧データの状態が表示され、続いてPhiのデータの種類ごとに、**設定**、**スペース**、**ブックマーク**、**固定タブ**、**URLルール**の行が表示されます。各種類の行には、変更があった直近の同期の内容と、それがどれくらい前だったかが表示されます。

| 件数         | 数えるもの                                                                                                                                                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **受信済み** | このMacがアカウントから受け取った変更。                                                                                                                                                                                     |
| **送信済み** | このMacがアップロードした変更。                                                                                                                                                                                             |
| **送信待ち** | このMacでまだアップロードされていない変更。後の同期で送信されます。                                                                                                                                                         |
| **保留中**   | このMacが受信したものの、まだ適用できない項目。Phiは適用できるようになるまで保持します。たとえば、プロファイルやスペースがこのMacでペアリングされていない固定タブです。別の固定タブの範囲に属する固定タブは数えられません。 |

**送信待ち**と**保留中**は、0でないときだけ表示されます。最近の変更がない種類には**最近の変更なし**と表示されます。

### 今すぐ同期 {#sync-now}

**今すぐ同期**は、このMacにすべてをすぐに同期するよう指示します。これが必要になることはめったにありません。ほかのMacで何かが変更されるとPhiに通知が届き、Phi自身も確認していますが、その間隔は最短でも1分です。**今すぐ同期**を使うと、この待ち時間を省けます。同期の待機中や実行中はボタンに進行状況が表示され、ツールチップには、**すべてのプロファイルが利用可能になるのを待機中**など、何を待っているかが表示されます。

自分で始めた同期が完了しなかった場合は、もう一度クリックするまで、状態の下の行にその旨が表示されます。

- その同期中に問題が記録された場合は、上の表にある問題の名前。
- 特定の問題がないまま同期が止まった場合は、**同期が完了しませんでした**。しばらくしてからもう一度お試しください。1台のMacで繰り返し起こる場合は、[固定タブが保留されている場合](#held-pinned-tabs)をご覧ください。
- このMacで同期をまったく開始できなかった場合は、**同期を開始できませんでした。しばらくしてからもう一度お試しください。**

完了した同期では行は追加されず、**このMacで最後に成功した同期**が新しい日時に更新されます。

## デバイス

**デバイス**セクションには、アカウントで設定済みのすべてのMacが一覧表示され、**このMac**には印が付きます。参加を待っているMacがあれば、そのコード、**承認**と**拒否**、リクエストの有効期限も表示されます。承認するには、このMacがサインインしていて、このMac自身の設定が完了している必要があります。

各Macが削除できるのは自分自身だけで、その操作は自分の同期パネルから行います。手元にないMacを削除する方法は、まだありません。紛失したMacはアカウントに残り、サインインしている限り変更を受信し続けます。そのMacにまだアクセスできるなら、サインアウトすれば受信は止まります。

## Macを同期から削除する {#remove-a-mac-from-sync}

**設定 → 同期**の**削除**で、**このMacを同期から削除**の行にある<strong>削除…</strong>をクリックし、**このデバイスを削除**で確定します。このMacで設定が完了していない場合は、代わりに設定ウインドウの下部に<strong>このデバイスを同期から削除…</strong>が表示されます。

- このMacは同期を停止し、同期サービスはこのMacの登録を取り消します。このMacの同期設定、鍵、プロファイルとスペースの対応付けは、このMacから消去されます。
- ブラウジングしていた内容はすべて残ります。スペース、ブックマーク、履歴、固定タブはそのまま保持され、アカウントへのサインインも維持されます。
- ほかのMacは影響を受けず、互いに同期を続けます。
- このMacを戻すには、もう一度設定を始め、承認か復旧コードで参加します。

このMacが、アカウントで同期が設定されている唯一のMacである場合、この行は代わりに**同期をリセット**になります。最後のMacを削除すると、アカウントの同期データも削除されるためです。[同期をリセットする](#reset-sync)をご覧ください。

::: warning 削除してもアカウントの鍵は変わりません
Macを削除すると、そのMacは新しいものを受信しなくなります。しかし、アカウントの暗号化の鍵は変わらず、そのMacがすでに同期したものを取り戻すこともできません。そのMacにあったものは、そのMacに残ります。
:::

### 同期をリセットする {#reset-sync}

このMacが、アカウントで同期が設定されている唯一のMacである場合、**削除**セクションには**同期をリセット**と<strong>リセット…</strong>ボタンが表示されます。リセットすると、このMacが同期から削除され、このアカウントに保存されているすべての同期データが削除されます。復旧コードを失くした後などに、最初からやり直すための操作です。

1. **設定 → 同期**の**削除**で、<strong>リセット…</strong>をクリックします。
2. <strong>このアカウントの同期データをすべて削除しますか？</strong>と表示されます。**同期データをすべて削除**をクリックして確定します。この操作は取り消せません。

- すべてのデバイスが同期から削除され、このアカウントについて同期サーバに保存されているものはすべて削除されます。
- ローカルの閲覧データはこのMacに残ります。スペース、ブックマーク、履歴、固定タブは保持され、アカウントへのサインインも維持されます。
- このアカウントで同期が設定されたままのほかのMacには、[同期をもう一度設定](#set-up-sync-again)と表示されます。
- 同期を再び使うには、最初から設定し直します。Phiが新しい復旧コードを作成します。

設定ウインドウからこのMacを削除しようとして、それが最後のMacだった場合は、Phiが<strong>同期が設定されている最後のデバイスです。このデバイスを削除してこのアカウントの同期データをすべて削除することも、先に別のデバイスで同期を設定することもできます。</strong>と知らせます。そのうえで<strong>このデバイスを削除して同期データをすべて削除…</strong>が表示され、これを選ぶと同じ確認が求められます。

その間に別のMacがアカウントに参加していた場合、何も削除されません。Phiに<strong>その後、別のデバイスがこのアカウントに参加したため、何も削除されませんでした。代わりに、このMacを同期から削除できます。</strong>と表示され、行は**このMacを同期から削除**に戻ります。

## 同期をもう一度設定する {#set-up-sync-again}

パネルに<strong>アカウントの同期データが変更されています。Phiデータの同期は一時停止中です。</strong>と表示された場合は、アカウント内の同期データがリセットされ、このMacの設定と合わなくなっています。対処するまでPhiのデータは同期されず、再試行や再起動では解消されません。**同期をもう一度設定**をクリックして確定します。PhiはこのMacの同期設定と対応付け情報を消去し、ローカルの閲覧データとアカウント内の内容は保持したまま、承認や復旧コードによる参加も含めて、もう一度設定の手順を案内します。

アカウントの最後のMacで**同期をリセット**が使われた後も、Macにはこの表示が出ます。そのMacの設定のもとになった同期データが削除されているためです。

## トラブルシューティング {#troubleshooting}

### 2台目のMacにキーボードショートカットや開いているタブが届かない {#missing-shortcuts-and-open-tabs}

これは想定どおりの動作です。**設定 → ショートカット**のキーボードショートカットは同期されず、通常の開いているタブも同期されません。同期されるのは固定タブだけです。AIとエージェントの設定も各Macにとどまります。使いたいMacごとに設定してください。[同期されるもの](#what-syncs)をご覧ください。

### 1台のMacで同期が完了せず、固定タブが保留されている {#held-pinned-tabs}

1台のMacに**同期が完了しませんでした**と表示され、**詳細**の**固定タブ**の行に件数とともに**保留中**と表示される一方で、もう1台のMacには**最新の状態**と表示されます。**保留中**は、このMacが受信した固定タブを配置できないことを意味します。その固定タブが属するプロファイルやスペースが、このMacでペアリングされていないためです。

よくある原因は、2台のMacのデフォルトのプロファイルが、設定時に互いに対応付けられなかったことです。Phi 2.12でペアリングしたMacは、この状態になっている場合があります。Phi 2.13以降、設定では常にデフォルトのプロファイルがアカウントのデフォルトのプロファイルと対応付けられます。

現時点で解決するには、固定タブを保留しているMacで[Macを同期から削除](#remove-a-mac-from-sync)し、[別のMacを追加する](#add-another-mac)の手順でもう一度設定します。このMacの同期方法を尋ねられたら、**このMacをアカウントと統合**を選びます。この間も、ブックマーク、履歴、そのほかのすべてはMacに残り、デフォルトのプロファイルはアカウントのデフォルトのプロファイルと対応付けられます。

### 同期を一時停止中、またはプロファイルのペアリングを待機中 {#sync-paused}

同期を設定した後に作成したプロファイルは、まだペアリングされていません。Phiは自動的にそのプロファイルをアカウントに登録し、完了するとそのプロファイルの同期が始まります。同期パネルの**再試行**をクリックすると、すぐに試行します。一時停止が解消されない場合は、接続とサインインの状態を確認してから、もう一度**再試行**をクリックしてください。

### 対応が必要と表示される {#sync-needs-attention}

**最後の問題**に、何が問題だったかが表示されます。すべての問題とその対処方法は、[各問題の意味](#needs-attention)に一覧があります。

### このMacのデータの置き換えを完了できない {#replace-did-not-finish}

**アカウントのデータを使用**を選んだ後に、設定が<strong>このMacのデータの置き換えを完了できませんでした。</strong>で止まった場合は、**再試行**をクリックします。再試行すると中断した箇所から再開し、完了するまでほかの内容は変更されません。実行中はPhiを開いたままにしてください。アカウントが大きい場合は数分かかることがあります。ウインドウを閉じた場合は、[あとで完了](#finish-later)で説明しているとおり、次の設定で同じ置き換えが続行されます。

### 対応付けた後にスペースの名前、アイコン、カラー、テーマが変わった {#account-values-replaced}

これは想定どおりの動作です。このMacのスペースをアカウント内のスペースと対応付けると、アカウントの名前、アイコン、カラー、テーマが優先されます。**適用**をクリックする前に、**変更される内容を確認**にそのことが表示されます。このMacの値を残したい場合は、その時点で**戻る**で戻り、そのスペースに**新規として追加**を選びます。そのスペースは別のスペースとして同期されます。対応付けが適用された後は、このMacの以前の値は保持されないため、元に戻したい場合はスペースのスタイルを手動で変更してください。その変更はほかのMacにも同期されます。

## サインアウト

Phiアカウントからサインアウトすると、そのMacでの同期は止まり、もう一度サインインするまでほかのMacからは何も届きません。同じアカウントにサインインし直すと、同期は中断したところから再開し、その間に届かなかった分に追いつきます。まだ完了していないことがあれば、同期パネルに表示されます。別のアカウントに切り替えても、2つのアカウントが混ざることはありません。アカウントごとに、同期されたデータと対応付けが別々に保たれます。

## データの保護のしかた

- <strong>Macを離れる前に暗号化されます。</strong>鍵を作るのはあなたのMacで、アップロードされるのは暗号化されたコピーだけです。同期サービスはそれを保管してほかのMacに渡しますが、復号することはできません。
- <strong>サインインしただけでは読めません。</strong>新しいMacが鍵を受け取れるのは、すでに鍵を持っているMacから承認されたときか、復旧コードを使ったときだけです。そのため、失くしたコードを取り戻すこともできません。設定画面の<strong>復旧コードをお忘れですか?</strong>リンクではできることを説明していますが、どの方法でもコードは戻りません。
- <strong>それでも当社が預かるデータです。</strong>暗号化されたコピーはPhinomenonの同期サービスに保管されるため、同期はPhiが送信するものの1つです。そのほかのものは[プライバシーとデータ](/ja/privacy/)に一覧があり、すべてについての正式な内容は[プライバシーポリシー](https://phibrowser.com/privacy/)と[利用規約](https://phibrowser.com/terms/)に定められています。

## 同期か書き出しか {#sync-or-export}

同期は、並行して使い続けるMacのためのものです。新しいMacへの一度きりの移行や、自分で保管するコピーには、**ヘルプ**メニューの<strong>ユーザーデータを管理 → ユーザーデータを書き出す…</strong>のほうが適しています。[インポートとエクスポート](/ja/import-export/)をご覧ください。
