# Phi Sentinel

Phi Sentinelは、Mac上でPhiのバックグラウンドサービスを管理します。アシスタントが行うことの多くは、ブラウザウインドウの外で行われています。スケジュール済みタスクの実行、メモリの構築、接続したデータの検索、そしてAIリクエストを適切な送り先に届けることです。こうした作業はバックグラウンドで動く一連のサービスが担っていて、Phi Sentinelはそれらのサービスが正しく動き続けるようにします。

Phi SentinelはPhi Browserと一緒にインストールされ、普段は何もする必要はありません。Phi Chatの設定では、これらのサービスは**バックグラウンドサービス**という名前で表示されます。

## 役割 {#what-it-does}

### バックグラウンドサービスを動かす {#running-background-services}

Phi Sentinelの中には**Runner**というプロセスがあり、その唯一の仕事はバックグラウンドサービスの管理です。Runnerが担うのは次のことです。

- <strong>起動と見守り。</strong>必要になったときに各サービスを起動し、正常に動いているかを定期的に確認し、問題が起きたら再起動します。
- <strong>アップデート。</strong>サービスの新しいバージョンをバックグラウンドでダウンロードしてインストールします。各アップデートの署名を先に確認し、新しいバージョンが正しく動かない場合は以前のバージョンに戻します。
- <strong>設定の受け渡し。</strong>[プライベートAI](/ja/private-ai/)のタスクごとのソースなど、設定で選んだ内容を、それを必要とするサービスに渡します。

Runnerが行うのは、サービスを動かし続けることだけです。あなたのコンテンツは扱いません。会話、ページ、データはサービス自身が処理し、Runnerを経由することはありません。

管理されるサービスには、次のものがあります。

- **アシスタントサービス**、会話とタスクを保持し、スケジュール済みタスクとバックグラウンドタスクを実行します。
- **メモリサービス**、ブラウジングからメモリを作成します。
- **データインデックスサービス**、接続したデータをインデックス化し、データ検索で見つけられるようにします。
- **AI Gateway**、各AIリクエストを、そのリクエストに選ばれたソースへ送ります。デフォルトではPhi Cloudで、プライベートAIをオンにすると、ローカルモデルや自分のプロバイダーにもできます。
- **AI Guardrail**、このMac上で、テキストに機密情報が含まれていないかを確認します。詳しくは下記をご覧ください。
- **ローカルモデル**、プライベートAIをセットアップした後にだけインストールされ、実行されます。

### 秘密情報をメモリに入れない {#ai-guardrail}

**AI Guardrail**は、Mac上で動く検出サービスです。メモリサービスは新しい内容を保存する前に、AI Guardrailにチェックを依頼します。パスワード、APIキー、秘密鍵、リカバリーフレーズ、リカバリーコードなどの秘密情報が見つかると、その項目全体がメモリから除外されます。

- チェックは完全にこのMac上で行われます。チェックされる内容がどこかに送られることはありません。
- 秘密情報を除外するだけで、内容を書き換えることはありません。名前や電話番号などの一般的な個人情報は通常どおり保存され、[メモリ](/ja/memory/)で確認したり削除したりできます。

### データを保持する {#keeping-your-data}

各サービスは、データをMac上のローカルデータベースに保持します。会話、タスクとその実行履歴、メモリ、接続したデータのインデックスです。

Phi Chatの**設定 → バックアップとアップデート**では、次のことができます。

- **データのエクスポート**、設定とデータのコピーを保存し、別のMacに移せます。プロバイダーのAPIキーは含まれません。
- **ローカルスナップショット**、後から戻れるコピーをこのMacに保存します。スナップショットがこのMacの外に出ることはありません。

### ブラウザを閉じた後もタスクを動かし続ける {#keeping-tasks-running}

[スケジュール済みタスク](/ja/automation/#scheduled-tasks)は、ブラウザウインドウが開いているかどうかに関係なく、自分のスケジュールで実行される必要があります。Phi Sentinelはブラウザとは別に動くため、数時間ごとの価格チェックも、見張っているページも、ブラウザウインドウを閉じた後も動き続けます。

## バックグラウンドサービスの状態を確認する {#checking-status}

Phi Chatで設定を開きます。

- **一般**には、バックグラウンドサービスが正常に動いているかどうかと、使用中のバージョンが表示され、**バックグラウンドサービスを再起動**もあります。
- **サービス**には、各サービスの状態が表示されます。**すべて正常に動作しています**と表示されていれば、何もする必要はありません。
- **ログ**は、問題が起きて報告したいときに使います。**診断ログ**の横にある**保存**をクリックすると、PhiがZIPファイルを「ダウンロード」フォルダに保存します。そのファイルをPhiのサポートに送れます。

ブラウザの**設定 → PhiとAI → Phi Sentinel**では、**MacにログインしたときにPhi Sentinelを起動**するかどうかと、**Shift Shift ShiftでPhi Chatを呼び出す**かどうかを選べます（[Phi Chat](/ja/phi-chat/#opening-phi-chat)を参照）。
