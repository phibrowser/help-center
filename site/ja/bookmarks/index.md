# ブックマークと固定タブ

Phiではサイドバーがワークスペースであり、大事なページを手元に置いておく方法がブックマークと固定タブの2つです。この章では、[レイアウトとナビゲーション](/ja/layouts/)より一歩踏み込んで両者の挙動を説明します。まずは、従来のブラウザから移ってきた多くの人が驚く点、つまりPhiではブックマークがその場でタブとして開く、という話からです。

## その場で開くブックマーク

従来のブラウザのブックマークは動かないリンクです。クリックするたびに新しいタブが増え、同じページの重複だらけになります。Phiはその代わりに、ブックマークを生きたエントリとして扱います。クリックするとその場で開き、サイドバーのそのエントリ自体が、開いているタブになります。ページを閉じてもブックマークは元の場所にそのまま残り、いつでもまた開けます。すでに開いているブックマークをクリックした場合は、2つ目の複製を作らず、そのタブをアクティブにするだけです。

これはArcとDiaが広めた考え方です。サイドバーに並ぶのは生きたもので、年に2回しか開かない別置きのアーカイブではありません。Phiはこのモデルに従いつつ、フォルダを含む本物のブックマークツリーも維持しているので、ブックマークアーカイブならではの整理のしやすさも失われません。

## ブックマークの作成と整理

- **ブックマークの作成**：タブをサイドバーへドラッグするか、タブを右クリックして**ブックマークに追加**を選びます（ゆったりモードでは**ブックマークバーに追加**という表示になります）。**フォルダに追加**を使えば、直接フォルダの中に保存できます。
- **フォルダで整理**：ブックマークはフォルダに入れ子で収められ、「**新しいサブフォルダ…**」でサブフォルダを作れます。
- **分割表示を1つのブックマークとして保存**：分割表示から**分割表示をブックマークに追加**を選ぶと、2つのページが1つのエントリとして保存され、開くとペアがまとめて戻ってきます。
- **ブックマークの管理**：右クリックメニューから**リンクをコピー**、**名前を変更…**、**編集…**、**新しいタブで開く**、**分割表示で開く**、**削除**を選べます。

ブックマークの範囲は、今いるスペースです。各[スペース](/ja/spaces/)が独自のセットを持つため、仕事用スペースで保存したページがプライベート用スペースに紛れ込むことはありません。

## 固定タブ

固定タブはサイドバー最上部にグリッドで並びます。メール、ダッシュボード、プロジェクト管理ツールなど、一日中そこにいるような少数のページのための場所です。固定タブは永続的で、ページを閉じてもグリッドに残り、クリックすればまたページが開きます。

- **タブの固定**：タブを右クリックして**タブを固定**を選ぶか、固定タブのグリッドへドラッグします。同じメニューの**固定を解除**で、タブリストに戻ります。
- **並べ替え**：グリッド内でドラッグして固定タブを並べ替えられます。
- **分割表示の固定**：**分割表示を固定**を選ぶと、2ペインの構成が1つの固定項目になり、開くと両側がまとめて戻ってきます。**分割表示の固定を解除**で元に戻ります。

## 固定タブの範囲を選ぶ {#choose-a-pinned-tab-scope}

**設定 → スペース**を開き、**固定タブの範囲**で、固定タブをどこまで共有するかを選びます。デフォルトは**プロファイル**です。

| 範囲             | 固定タブが表示される場所                                     |
| ---------------- | ------------------------------------------------------------ |
| **スペース**     | スペースごとに独自の固定タブを持ちます。                     |
| **プロファイル** | 同じプロファイルを使うスペース間で固定タブを共有します。     |
| **アプリ**       | すべての通常のプロファイルとスペースで固定タブを共有します。 |

どの範囲を選んでも、シークレットスペースに固定タブが表示されることはなく、固定もできません。

範囲を変更すると、既存の固定タブも新しい構成へ移されます。狭い範囲へ変更すると、Phiは現在の固定タブを既存の各移動先へコピーし、それぞれのコピーは以後独立して変更できます。広い範囲へ変更すると、Phiは既存のセットを統合します。変更されていないコピーは1つにまとまり、内容の異なるバージョンはそのまま残ります。どちらの変更でも、実行前にPhiが確認を表示します。

ブックマークの範囲は常に1つのスペースで、固定タブの設定の影響を受けません。この2つのレイヤーの組み合わせ方は[スペースとプロファイル](/ja/spaces/)をご覧ください。

## 元のページに戻る

固定タブやブックマークの中でリンクをたどると、元のURLから離れてしまうことがあります。戻るには、固定タブをダブルクリックするか、タブとして開いているブックマークのファビコンをクリックします。

別のサイトへ向かうリンクの場合、タブが動くことはありません。Phiがフローティングの[Peekビュー](/ja/peek/)パネルでプレビューを表示するため、ブックマークや固定タブは、結び付いているページをそのまま保ちます。

今見ているページを残したい場合は、**Command（⌘）キー**を押しながら、固定タブをダブルクリックするか、ブックマークのファビコンをクリックします。現在のページは別のタブとしてタブリストへ移り、固定タブやブックマークは元のURLに戻ります。

## 使い分けの目安

役割分担はシンプルです。

- **固定タブ**は、いつも使っているページのためのもの。常に最上部にあってワンクリックで開け、選んだスペース、プロファイル、アプリのいずれかの範囲で共有されます。
- **ブックマーク**は、取っておきたいページのためのもの。フォルダで整理され、1つのスペースに属し、必要なときにその場で開きます。

ArcやDiaから乗り換える場合は、Phiの生きたサイドバー、ブックマーク、固定タブがどう対応するかを[Phiへの乗り換え](/ja/switching-to-phi/)で確認してください。ほかのブラウザやファイルからブックマークを取り込む方法と、スペースのブックマークをHTMLに書き出す方法は、[インポートとエクスポート](/ja/import-export/)をご覧ください。
