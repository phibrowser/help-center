# 自動化とPhi Link

「エージェント的（Agentic）」とは、PhiのAIが質問に答える以上のことをできる、という意味です。ブラウザの中で行動し、あなたの代わりにタスクをこなし、場合によってはそれを続けていきます。動き方は3つあります。**いま**動く（オンデマンドのアクション）、**バックグラウンドで**動く（バックグラウンドタスク）、**スケジュールに沿って**動く（スケジュール済みタスク）です。

## オンデマンドのアクション

オンデマンドのアクションは、あなたが頼んだときにアシスタントが実行するタスクです。あなたがなぞるための手順を説明するのではなく、Phi自身が作業を進めます。現在のタブまたは新しいタブの中で、ページを移動し、ウェブサイトを操作し、複数ステップの仕事を完了するところを、あなたはそのまま見ていられます。

結果に影響が及ぶ操作を、そのまま進めてしまうことはありません。実行前に一時停止し、あなたの**承認**を求めます。ステップのリスクの度合いが示されたシンプルな「承認/拒否」のプロンプトが表示されるため、重要なアクションには必ずあなたが関与できます。

## バックグラウンドタスク

じっと見ていたくないときもあります。エージェントは依頼を、バックグラウンドで動く**タスク**にできます。会話もあなたの注意も占有せずに作業を続けます。

タスクの動きは次のとおりです。

- 開始されるのは、あなたが**明示的に頼んだ**ときだけです。
- 単独で動くので、あなたはブラウジングを続けることも、会話を閉じることもできます。
- リスクのあるステップに行き当たると、一時停止してあなたの**承認**を求めます。
- 頼んだ**会話に報告を返します**。[後述](#tasks-report-back-to-their-conversation)をご覧ください。
- その会話の言語で書き続けます。別の言語にしたい場合は、アシスタントに頼んでください。

## スケジュール済みタスク {#scheduled-tasks}

スケジュール済みタスクは、あなたが決めたスケジュールで繰り返し動く自動化です。たとえば、商品の価格を数時間おきに監視する、ページの変化を見張る、その他のブラウザ上のタスクを自動で繰り返す、といったことができます。実体は「繰り返すバックグラウンドタスク」で、ブラウザのウインドウを閉じていても[Phi Sentinel](/ja/sentinel/)が動かし続けます。ここまで来ると、PhiはAI機能付きのブラウザというより、あなたが見ていない間も働き続ける常駐のシステムに近づきます。

### ページをウォッチする

いちばん手早く設定する方法は、Webページ上の任意の場所（選択したテキストやリンクの上以外）を右クリックし、**［アシスタント名］にこのページをウォッチしてもらう**を選ぶことです。サイドバーが新しい会話で開き、アシスタントがページを読んだうえで、いくつかの質問を1つずつしてきます。ウォッチする理由、何があれば知らせてほしいか、どのくらいの頻度で確認するか、さらに希望があれば、報告のしかたといつ終えるかです。

そのうえで、**変更があったときのみ**報告するスケジュール済みタスクを設定します。最初の確認では、起点として今のページの状態を報告し、それ以降の確認では、何かが変わったときにだけ知らせます。後からウォッチを変更、一時停止、削除したいときは、同じ会話で頼んでください。

## タスクは会話に報告を返す {#tasks-report-back-to-their-conversation}

会話の中で作成されたタスクは、実行が完了または失敗するたびに、アシスタントからの返信としてその会話に報告を投稿します。会話は未読になって一覧の先頭に移り、[Phi Chat](/ja/phi-chat/#tasks-and-unread-conversations)の**タスク**ビューには、こうした会話がすべて集まります。

各報告の上には、タスクの名前、何回目の実行か、**完了**か**失敗**かを示すストリップがあります。その<strong>…</strong>メニューには次の項目があります。

- **今すぐ実行**、タスクをすぐにもう一度実行します。
- **ここへの報告を停止**、タスクは動き続けますが、この会話には投稿しなくなります。使った後は**ここへの報告を再開**に変わります。

### タスクを管理する

会話にタスクがあると、トップバーに件数付きの時計ボタンが表示されます。これを押すとパネルが開き、タスクごとに次の内容が表示されます。

- 状態。**実行中**、**有効**（スケジュールがまだ続いている）、**一時停止中**、**停止**（終了条件を満たした）、**終了**、**手動**（スケジュールがない）などです。
- スケジュール、次回の実行時刻、終了条件がある場合は終了する時期。
- **この会話に報告する**スイッチ。
- **報告する内容**。**すべての実行**か、新しい変化がないときは何も報告しない**変更があったときのみ**を選べます。失敗はどちらの場合も報告されます。

タスクの<strong>…</strong>メニューには、**今すぐ実行**と、**スケジュールを一時停止**または**スケジュールを再開**があります。

このパネルでは、タスクの編集や削除はできません。タスクの内容を変えたり削除したりするには、そのタスクの会話でアシスタントに頼むか、Phi Sentinelの**タスク**ページを使ってください。

### Phiが起動していなかったとき

タスクが動けるのは、Phiが起動している間だけです。Macの電源が切れていたりスリープしていたり、Phiを終了していたりすると、実行が抜けたり途中で打ち切られたりすることがあります。Phiが再び起動すると、次のようになります。

- 2時間に1回以上の頻度で動くタスクは、次の実行に進み、その実行で確認できなかった分について触れます。
- それ以外のタスクについては、今すぐ1回実行するかどうかを、Phiがそのタスクの会話で尋ねます。報告には**未実行**または**中断**と表示され、その下に**今すぐ実行**と**無視**のボタンが並びます。自分の言葉で答えることもできます。

この問いかけは、タスクの次の予定実行が来た時点で取り下げられます。スケジュールがないタスクでは、1日後に取り下げられます。

### 通知 {#notifications}

開いていない会話に報告が届くと、Phiはタスクの名前と報告の冒頭を載せた通知カードを表示することもあります。このカードはPhi独自のもので、macOSの通知ではありません。表示するのは、作業を中断してでも知らせる価値がありそうな報告のときだけなので、新しい発見がなかった確認では何も表示されません。**詳細を表示**を押すと、その会話が[Phi Chat](/ja/phi-chat/)で開きます。

## 主導権を保つ

エージェントは、あなたの知らないところではなく、あなたが把握しているもとで動くように作られています。結果に影響が及ぶアクションの前には承認を求めます。タスクは頼んだときにだけ始まり、リスクのあるステップでは確認のために一時停止します。タスクのスケジュールの一時停止、報告の停止、アシスタントへの変更や削除の依頼は、いつでもできます。データの保存場所とAIの扱いについては[プライバシーとデータ](/ja/privacy/)をご覧ください。

あなたの指示でエージェントが行うことは、あなたのブラウザから、あなたのアカウントを使って、あなたとして行われます。自動化を歓迎しないサイトもあります。よく知られているのはRedditで、自動化と判定されたアカウントは制限や停止の対象になります。そうしたサイトを通じて動くタスクの場合、そのリスクを負うのはあなたです。

## Phi Sentinel

スケジュール済みタスクは、ブラウザのウインドウを閉じた後も動き続ける必要があります。それを可能にするのが、macOSのメニューバーにいるバックグラウンドアプリ**Phi Sentinel**です。Phi Sentinelは、AIの一部を自分のMacの上で実行する選択肢であるプライベートAIもホストします。全体像は[Phi Sentinel](/ja/sentinel/)をご覧ください。

## Phi Link {#phi-link}

**Phi Link**はPhiをTelegramにつなぎ、スマートフォンからアシスタントを使えるようにします。Macから離れているときも、状況の更新を受け取れます。できることは次のとおりです。

- スマートフォンからアシスタントとチャットする。
- 完了したタスクの実行結果を受け取る。
- ブラウザから離れた場所でワークフローを続ける。

セットアップの方法は2つあります。

- **公式のPhi Linkボット**、いちばん手軽な方法です。QRコードをスキャンし、ワンクリックでセットアップを終えれば完了です。
- **自分のTelegramボット**、より細かく管理したい方向けです。TelegramのBotFatherでボットを作成し、トークンを発行して、Phiの設定に貼り付けます。ボットの名前とアバターを自分好みにできます。

アシスタントのアイデンティティはそのまま引き継がれるため、デスクトップでもスマートフォンでも一貫した体験になります。
