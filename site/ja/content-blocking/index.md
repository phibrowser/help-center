# コンテンツブロック

Phi は Chromium をベースとしており、Brave のオープンソースのコンテンツフィルタリングエンジンを使用します。広告、トラッカー、Cookie バナーは個別にブロックできます。

## Phi がブロックできるもの

| 設定                       | 内容                                                                               |
| -------------------------- | ---------------------------------------------------------------------------------- |
| **広告をブロック**         | ルールに一致する広告と広告リクエストをブロックします。                             |
| **トラッカーをブロック**   | 一致するトラッキングスクリプト、ビーコン、分析リクエストをブロックします。         |
| **Cookieバナーをブロック** | 一致する Cookie の通知を非表示にします。Phi が同意の選択肢を選ぶことはありません。 |

3 つのスイッチは初期状態ではオフです。[プロファイル](/ja/spaces/)ごとに設定するため、プロファイルごとに異なる設定やフィルターリストを使えます。

コンテンツブロックでは、フィルターリストのルールを使います。一般的な広告やトラッカー、Cookie の通知、地域のサイトを対象にするリストのほか、自分で追加したルールも使えます。すべての広告やトラッカーをブロックできるわけではなく、ルールによって一部のサイトの動作が変わることがあります。

## コンテンツブロックを有効にする

1. **設定 → プロファイル**を開きます。
2. プロファイルを選び、**コンテンツブロック**を開きます。
3. 有効にするカテゴリを選びます。
4. フィルターリストの選択を求められたら、使うリストを選び、**完了**をクリックして、Mac にまだない選択済みリストをダウンロードします。

カテゴリの横にあるルール選択から、いつでもリストを変更できます。リストはダウンロード操作を選んだときにダウンロードされます。**ダウンロード済みのリストを更新**すると、Mac にあるリストの最新版を取得します。

ルール選択で<strong>フィルタを追加…</strong>を選ぶと、URL を指定してリストを追加するか、ルールを直接貼り付けられます。自分で追加したリストは、そのプロファイルの 3 つのカテゴリすべてに適用されます。

ダウンロードしたフィルターリストは複数のプロファイルで共有できます。リストの選択、自分で追加したリスト、サイトの例外はプロファイルごとに保存されます。

## 1 つのサイトでコンテンツを許可する

アドレスバーのメニューを開き、**このサイトでのコンテンツブロック**を選ぶと、現在のプロファイルで表示中のサイトのブロックをオフまたはオンにできます。変更されるのはそのプロファイルにおけるサイトの例外だけです。他のサイトではカテゴリが引き続き有効です。

このメニュー項目はシークレットウィンドウでは使えません。

## サイトが正しく動作しない場合

フィルターリストがブロックするリソースを必要とするサイトがあります。アドレスバーのメニューで**このサイトでのコンテンツブロック**を選んで例外を設定し、ページを再読み込みしてください。**設定 → プロファイル**でカテゴリをオフにしたり、使用するリストを変更したりすることもできます。

フィルターリストですべての広告、トラッカー、Cookie の通知を見つけられるわけではありません。Cookie バナーのブロックは一致するページ要素を非表示にしますが、Cookie への同意や通知の終了を代わりに行うことはありません。
