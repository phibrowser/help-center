# タブとブックマークの管理

Phiでは複数の項目を選択して、1つのまとまりとして扱えます。選択範囲を右クリックして一括操作を実行することも、ドラッグして通常のタブ、分割表示、ブックマーク、ブックマークフォルダをまとめて整理し直すこともでき、項目を1つずつ動かす必要はありません。

## 複数の項目を選択する

選択には、次のどちらかの修飾キーを使います。

- **Commandキー（⌘）を押しながらクリック**すると、そのタブやブックマークを選択に追加したり、選択から外したりできます。アクティブなタブは自動的に選択に含まれるため、別のタブをCommandキーを押しながらクリックすると、2つとも選択された状態になります。
- **Shiftキーを押しながらクリック**すると、起点からその項目までの連続した範囲をまとめて選択できます。

サイドバーでは、表示中のタブ、ブックマーク、ブックマークフォルダ、展開されているグループやフォルダの中身を範囲に含められます。折りたたまれたグループやフォルダの中に隠れている項目は含まれません。分割表示は1つの表示項目として扱われるため、2つのペインが離ればなれになることはありません。

ゆったりレイアウトでは、水平のタブバーに並ぶタブにも同じCommandクリックとShiftクリックの操作が使えます。ブックマークの複数選択は、バランスとパフォーマンスの各レイアウトでサイドバーから行えます。

## 選択した項目を操作する

ハイライトされた項目のどれかを右クリックすると、一括操作メニューが開きます。Phiは選択内容に応じて表示する操作を変えるため、タブだけ、ブックマークだけ、または互換性のある組み合わせのときにしか現れない操作もあります。

| 操作                                    | 内容                                                                     |
| --------------------------------------- | ------------------------------------------------------------------------ |
| **タブを複製**                          | 選択したページのコピーを現在のスペースで開きます。                       |
| **リンクをコピー**                      | 選択したページのURLをリストとしてコピーします。                          |
| **分割表示で開く**                      | 互換性のある選択項目がちょうど2つのとき、左右に並べて表示します。        |
| **ブックマークに追加 / フォルダに追加** | 選択したタブを保存するか、選択したブックマークを指定の場所に整理します。 |
| **タブを新しいグループに追加**          | 互換性のある選択項目からタブグループを作成します。                       |
| **タブをグループに移動**                | 互換性のある選択項目を既存のタブグループへ移動します。                   |
| **スペースに移動**                      | 選択内容を別のスペースへ移し、現在のスペースからは取り除きます。         |
| **スペースに複製**                      | 元の選択内容はそのままに、別のスペースへコピーを作成します。             |
| **タブを閉じる / ほかのタブを閉じる**   | 選択した通常のタブを閉じるか、選択外のすべての通常のタブを閉じます。     |
| **ブックマーク/フォルダ/項目を削除**    | 確認のうえで、選択した保存済み項目を完全に削除します。                   |

## 複数の項目をドラッグして整理する

選択を作ったら、ハイライトされた項目のどれかをドラッグすると、選択全体が動きます。ドラッグ中のプレビューには、移動している表示項目の数が示されます。選択されていない項目をドラッグし始めた場合は、Phiは選択を解除し、その項目だけを移動します。

ドロップする場所によって、動作が決まります。

- **タブリストの中**：選択したタブをまとめて並べ替えるか、タブグループの中にドロップします。
- **ブックマークエリアの中**：選択したブックマークとフォルダを並べ替えるか、フォルダにドロップして中へ移動します。
- **タブからブックマークへ**：選択したタブをブックマークエリアやブックマークフォルダにドロップすると、そこに保存されます。
- **ブックマークからタブへ**：選択したブックマークのページをタブリストやタブグループにドロップすると、タブとして開いて整理できます。
- **混在した選択**：移動先が選択したすべての項目に対応している場合、タブとブックマークを一緒に動かせます。

ドラッグ中も分割表示はひとまとまりのままです。ブックマークフォルダを含む選択はブックマークエリアの中にとどまります。フォルダを保てないタブリストやタブグループへのドロップは、選択をばらばらにする代わりに、Phiが受け付けません。

## 別のスペースへ移動・複製する

選択した項目を現在のスペースから移したいときは**スペースに移動**を、同じタブやブックマークを両方のスペースに置きたいときは**スペースに複製**を使います。

どちらの操作も、通常のタブ、分割表示、ブックマーク、ブックマークフォルダの互換性のある組み合わせを扱えます。移動の際、Phiは分割表示のペインをひとまとまりに保ち、ブックマークの整理状態も維持します。移動先は各操作のサブメニューから選びます。

現在のスペースとシークレットスペースは、移動先として表示されません。また、シークレットでブラウズしている間は、スペースへの移動・複製の操作自体が使えません。

## 複数選択を終了する

**Esc**キーを押すか、いずれかの項目を普通にクリックしてそれに切り替えると、複数選択が終了します。サイドバーでは、空いている場所をクリックしても選択が解除されます。ほとんどの一括操作は、完了すると自動的に選択を解除します。

項目がどこに属するかについては[スペースとプロファイル](/ja/spaces/)を、ブックマークがその場で開く仕組みと固定タブの挙動については[ブックマークと固定タブ](/ja/bookmarks/)をご覧ください。
