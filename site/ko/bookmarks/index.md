# 북마크와 고정 탭

Phi에서 사이드바는 작업 공간이고, 북마크와 고정 탭은 중요한 페이지를 간직하는 두 가지 방법이에요. 이 장은 [레이아웃과 탐색](/ko/layouts/)보다 한 걸음 더 들어가 두 기능의 동작을 살펴봐요. 전통적인 브라우저에서 넘어온 많은 사람이 놀라는 지점부터 시작할게요. Phi에서는 북마크가 제자리에서 탭으로 열려요.

## 제자리에서 열리는 북마크

전통적인 브라우저에서 북마크는 죽은 링크예요. 클릭할 때마다 새 탭이 생기고, 결국 같은 페이지의 복사본이 쌓여요. Phi는 북마크를 살아 있는 항목으로 다뤄요. 클릭하면 제자리에서 열리고, 사이드바의 그 항목이 곧 살아 있는 탭이 돼요. 페이지를 닫아도 북마크는 원래 자리에 그대로 남아 다시 열릴 준비를 하고 있어요. 이미 열려 있는 북마크를 클릭하면 복사본을 하나 더 만드는 대신 그 탭이 활성화돼요.

Arc와 Dia가 널리 알린 아이디어예요. 사이드바에는 살아 있는 것들이 담기고, 일 년에 두 번 들르는 별도의 보관함이 아니에요. Phi는 이 모델을 따르면서도 폴더를 포함한 진짜 북마크 트리를 유지해서, 북마크 보관함이 주는 정리 능력도 그대로 누릴 수 있어요.

## 북마크 만들기와 정리하기

- **북마크 만들기**: 탭을 사이드바로 드래그하거나, 탭을 오른쪽 클릭하고 **북마크에 추가**를 선택하세요(여유 모드에서는 **북마크 바에 추가**로 표시돼요). **폴더에 추가**를 사용하면 바로 폴더 안에 넣을 수 있어요.
- **폴더로 정리하기**: 북마크는 폴더 안에 겹겹이 정리할 수 있고, <strong>새 하위 폴더…</strong>로 하위 폴더를 만들 수 있어요.
- **분할을 북마크 하나로 저장하기**: Split View에서 **분할을 북마크에 추가**를 선택하면 두 페이지가 하나의 항목으로 저장되고, 열면 두 페이지가 함께 다시 열려요.
- **북마크 관리하기**: 오른쪽 클릭 메뉴에서 **링크 복사**, **이름 변경…**, **편집…**, **새 탭에서 열기**, **분할로 열기**, **삭제**를 사용할 수 있어요.

북마크는 지금 있는 스페이스에 속해요. [스페이스](/ko/spaces/)마다 자기만의 세트를 유지해서, 업무 스페이스에 저장한 페이지가 개인 스페이스를 어지럽히지 않아요.

## 고정 탭

고정 탭은 사이드바 맨 위에 격자 형태로 자리 잡아요. 메일, 대시보드, 프로젝트 도구처럼 늘 머무는 몇 안 되는 페이지를 위한 공간이에요. 고정 탭은 사라지지 않아요. 페이지를 닫아도 격자에 그대로 남고, 클릭하면 그 페이지가 다시 열려요.

- **탭 고정하기**: 탭을 오른쪽 클릭하고 **고정**을 선택하거나, 고정 격자로 드래그하세요. 같은 메뉴의 **고정 해제**를 선택하면 탭 목록으로 돌아가요.
- **순서 바꾸기**: 격자 안에서 드래그해서 고정 탭의 자리를 바꿀 수 있어요.
- **분할 고정하기**: **분할 고정**을 선택하면 두 창으로 이루어진 구성이 하나의 고정 항목으로 유지되고, 열면 양쪽이 함께 다시 열려요. **분할 고정 해제**로 되돌릴 수 있어요.

## 고정 탭 범위 선택하기 {#choose-a-pinned-tab-scope}

**설정 → 스페이스**를 열고 **고정 탭 범위**에서 고정 탭을 얼마나 넓게 공유할지 선택하세요. 기본값은 **프로필**이에요.

| 범위         | 고정 탭이 표시되는 곳                                 |
| ------------ | ----------------------------------------------------- |
| **스페이스** | 스페이스마다 고유한 고정 탭이 있어요.                 |
| **프로필**   | 같은 프로필을 사용하는 스페이스가 고정 탭을 공유해요. |
| **앱**       | 모든 일반 프로필과 스페이스에서 고정 탭을 공유해요.   |

시크릿 스페이스는 어떤 범위를 선택하든 고정 탭을 표시하지도, 허용하지도 않아요.

범위를 바꾸면 기존 고정 탭도 새 구성에 맞게 옮겨져요. 더 좁은 범위로 바꾸면 Phi가 현재 고정 탭을 기존의 각 대상에 복사하고, 그 복사본들은 이후 서로 독립적으로 바꿀 수 있어요. 더 넓은 범위로 바꾸면 Phi가 기존 세트들을 병합해요. 달라지지 않은 복사본은 하나로 합쳐지고, 서로 달라진 버전은 그대로 유지돼요. 어느 쪽이든 변경하기 전에 Phi가 확인 창을 보여 줘요.

북마크는 항상 하나의 스페이스에 속해요. 고정 탭 설정은 북마크에 영향을 주지 않아요. 두 층이 어떻게 맞물리는지는 [스페이스와 프로필](/ko/spaces/)을 참고하세요.

## 원래 페이지로 돌아가기

고정 탭이나 북마크에서 링크를 따라가다 보면 원래 URL에서 멀어질 수 있어요. 돌아가려면 고정 탭을 두 번 클릭하거나, 탭으로 열려 있는 북마크의 파비콘을 클릭하세요.

다른 사이트로 이어지는 링크는 탭을 아예 움직이지 않아요. Phi가 플로팅 [Peek 뷰](/ko/peek/) 패널에서 미리 보여 주기 때문에, 북마크나 고정 탭은 자기가 묶여 있는 페이지를 그대로 유지해요. 이런 링크를 새 탭으로 여는 쪽이 더 좋다면 **설정 → 탐색**에서 **고정된 탭과 북마크에서 Peek 자동 열기**를 끄세요.

현재 페이지를 계속 두고 싶다면 **Command(⌘)** 키를 누른 채로 고정 탭을 두 번 클릭하거나 북마크의 파비콘을 클릭하세요. 현재 페이지는 별도의 탭이 되어 탭 목록으로 옮겨지고, 고정 탭이나 북마크는 원래 URL로 돌아가요.

## 어느 쪽을 써야 할까요?

역할을 간단히 나누면 이래요.

- **고정 탭**은 늘 머무는 페이지예요. 항상 맨 위에서 클릭 한 번 거리에 있고, 스페이스, 프로필, 앱 중 선택한 범위에서 공유돼요.
- **북마크**는 간직하고 싶은 페이지예요. 폴더로 정리되고, 하나의 스페이스에 속하고, 필요할 때 제자리에서 열려요.

Arc나 Dia에서 넘어오는 중이라면 [Phi로 전환하기](/ko/switching-to-phi/)에서 Phi의 살아 있는 사이드바, 북마크, 고정 탭이 어떻게 다른지 비교해 보세요. 다른 브라우저나 파일에서 북마크를 가져오거나 스페이스의 북마크를 HTML로 다시 내보내려면 [가져오기와 내보내기](/ko/import-export/)를 참고하세요.
