# 새 탭과 위젯

Phi는 표준 새 탭을 개인 맞춤 홈 페이지로 바꿔요. 새 탭을 열 때마다 인사말, 검색과 질문을 겸하는 입력란 하나, 그리고 직접 배치하는 위젯 그리드가 나타나요. [테마와 라이트/다크 설정](/ko/themes/)은 자동으로 따라가요.

## 나의 새 탭

- **인사말**, Phi가 나에 대해 아는 것에서 길어 올린, 시간이 지나며 달라지는 개인 맞춤 환영 인사예요. 공유할 수도 있고, 인사말을 두고 어시스턴트와 대화할 수도 있어요.
- **검색과 질문을 겸하는 입력란 하나**, 같은 자리에서 웹을 검색하고, 어시스턴트에게 질문하고, URL로 바로 이동해요. [탭을 첨부](/ko/ai/#chat-with-tabs)하거나 파일을 첨부하고, 대화에 스킬을 불러올 수도 있어요.
- **빠른 접근**, 오른쪽 위 모서리의 메뉴에서 최근 대화, 내 위젯, [스킬](/ko/skills/) 라이브러리로 이동해요.

검색 입력란이 어시스턴트와 연결돼 있어서, 검색이든 질문이든 작업이든 별도의 채팅을 먼저 열지 않고 무언가를 시작하기에는 새 탭이 가장 빠른 곳일 때가 많아요. 어시스턴트가 할 수 있는 일은 [어시스턴트 소개](/ko/ai/)에서 확인하세요.

## 위젯

위젯은 새 탭에 고정하는 작은 카드예요. 시계, 날씨, 자주 방문한 사이트, 집중 타이머 같은 것들이죠. 어떤 위젯을 어디에 둘지는 직접 정해요.

### 내장 위젯

- **한눈에 보기**, 시계(원하는 시간대의 현지 시각과 날짜), 날씨(지정한 위치의 현재 날씨), 오늘의 명언, 오늘의 이미지(최근 메모리 테마에서 가져온 분위기 이미지)예요.
- **도구**, 뽀모도로 집중 타이머, 환율 계산기, 빠른 번역기예요.
- **바로가기**, 자주 방문한 사이트(가장 많이 방문하는 사이트)와 GitHub 스타(저장소의 스타 추이)예요.
- **내 활동**, 최근 읽은 글(최근에 읽은 페이지), 인기 게시물(Hacker News나 Reddit 같은 소스의 화제 글), 그리고 내가 한 일을 요약해 주는 일일 리포트와 주간 리포트예요.

### 위젯 추가와 배치

오른쪽 위 모서리의 **위젯** 메뉴나, 스크롤할 때 나타나는 **맞춤** 버튼으로 위젯 라이브러리를 열어요. 거기에서:

- **위젯을 페이지로 끌어다 놓으면** 고정돼요.
- 고정된 위젯의 메뉴에서 **이동 및 크기 조절**, 데이터 **새로고침**, **편집**, **삭제**를 할 수 있어요.

배치는 기기에 저장되기 때문에, 새 탭을 열 때마다 같은 모습으로 나타나요.

### 나를 아는 위젯

위젯 라이브러리는 Phi가 나에 대해 기억하는 것을 바탕으로 처음 쓸 만한 위젯 몇 개를 추천하고, 일부 위젯은 같은 방식으로 내용을 개인화해요. 예를 들어 내가 실제로 다시 찾는 페이지를 보여주는 식이에요. 대화 중에 바로 어시스턴트에게 **맞춤 위젯을 만들어 달라**고 하거나 기존 위젯을 **다듬어 달라**고 할 수도 있어요.

이 기능은 Phi의 다른 부분과 같은 로컬 우선 메모리 위에 만들어져 있어요. 위젯이 활용하는 데이터는 내 기기에 남고 내 통제 아래 있어요. 자세한 내용은 [개인정보 보호와 내 데이터](/ko/privacy/)에서 확인하세요.
