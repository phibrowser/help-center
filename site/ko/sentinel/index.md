# Phi Sentinel

Phi Sentinel은 Mac에서 Phi의 백그라운드 서비스를 관리해요. 어시스턴트가 하는 일의 상당 부분은 브라우저 창 밖에서 일어나요. 예약된 작업 실행, 메모리 만들기, 연결한 데이터 검색, AI 요청을 가야 할 곳으로 보내기가 그래요. 이 일은 백그라운드에서 실행되는 여러 서비스가 맡고, Phi Sentinel은 그 서비스들이 제대로 돌아가게 지켜요.

Phi Browser와 함께 설치되고, 평소에는 따로 할 일이 없어요. Phi Chat 설정에서는 이 서비스들을 그냥 **백그라운드 서비스**라고 불러요.

## 하는 일 {#what-it-does}

### 백그라운드 서비스 실행 {#running-background-services}

Phi Sentinel 안에는 **Runner**라는 프로세스가 있고, 이 프로세스는 백그라운드 서비스를 관리하는 일만 해요. 맡는 일은 다음과 같아요.

- **시작과 상태 감시.** 각 서비스를 필요할 때 시작하고, 정상인지 주기적으로 확인하고, 문제가 생기면 다시 시작해요.
- **업데이트.** 서비스의 새 버전을 백그라운드에서 다운로드하고 설치해요. 먼저 업데이트마다 서명을 확인하고, 새 버전이 제대로 실행되지 않으면 이전 버전으로 되돌려요.
- **설정 전달.** [프라이빗 AI](/ko/private-ai/)의 작업별 소스처럼 설정에서 고른 내용을 그것이 필요한 서비스에 전달해요.

Runner는 서비스가 계속 돌아가게 할 뿐이에요. 내 콘텐츠는 다루지 않아요. 대화, 페이지, 데이터는 각 서비스가 직접 처리하고, Runner를 거치지 않아요.

Runner가 관리하는 서비스는 다음과 같아요.

- **어시스턴트 서비스**, 대화와 작업을 보관하고 예약된 작업과 백그라운드 작업을 실행해요.
- **메모리 서비스**, 브라우징을 바탕으로 메모리를 만들어요.
- **데이터 인덱싱 서비스**, 연결한 데이터를 인덱싱해서 데이터 검색으로 찾을 수 있게 해요.
- **AI Gateway**, 각 AI 요청을 그 요청에 고른 소스로 보내요. 기본값은 Phi Cloud이고, 프라이빗 AI를 켜면 로컬 모델이나 내 제공자가 될 수도 있어요.
- **AI Guardrail**, 이 Mac에서 텍스트에 민감한 정보가 있는지 확인해요. 아래를 참고하세요.
- **로컬 모델**, 프라이빗 AI를 설정한 뒤에만 설치되고 실행돼요.

### 메모리에 비밀 정보가 들어가지 않게 {#ai-guardrail}

**AI Guardrail**은 Mac에서 실행되는 탐지 서비스예요. 메모리 서비스는 새 내용을 저장하기 전에 AI Guardrail에 확인을 요청해요. 비밀번호, API 키, 개인 키, 복구 문구, 복구 코드 같은 비밀 정보가 발견되면 그 항목 전체가 메모리에서 빠져요.

- 확인은 전부 이 Mac에서 이루어져요. 확인하는 내용은 어디로도 전송되지 않아요.
- 비밀 정보를 걸러 낼 뿐 어떤 내용도 고쳐 쓰지 않아요. 이름이나 전화번호 같은 일반적인 개인 정보는 평소처럼 저장되고, [메모리](/ko/memory/)에서 검토하고 삭제할 수 있어요.

### 데이터 보관 {#keeping-your-data}

서비스는 데이터를 Mac의 로컬 데이터베이스에 보관해요. 대화, 작업과 그 실행 기록, 메모리, 연결한 데이터의 인덱스가 여기에 들어가요.

Phi Chat의 **설정 → 백업 및 업데이트**에서 다음을 할 수 있어요.

- **데이터 내보내기**, 설정과 데이터의 사본을 저장해 다른 Mac으로 옮길 수 있어요. 제공자 API 키는 포함되지 않아요.
- **로컬 스냅샷**, 나중에 되돌아갈 수 있는 사본을 이 Mac에 저장해요. 스냅샷은 이 Mac 밖으로 나가지 않아요.

### 브라우저를 닫아도 작업이 계속 실행돼요 {#keeping-tasks-running}

[예약된 작업](/ko/automation/#scheduled-tasks)은 브라우저 창이 열려 있든 없든 자기 일정대로 실행되어야 해요. Phi Sentinel은 브라우저와 따로 실행되기 때문에, 몇 시간마다 하는 가격 확인이나 지켜보고 있는 페이지는 브라우저 창을 닫은 뒤에도 계속 돌아가요.

## 백그라운드 서비스 상태 확인 {#checking-status}

Phi Chat에서 설정을 여세요.

- **일반**에서는 백그라운드 서비스가 제대로 실행 중인지와 어떤 버전인지 보여 주고, **백그라운드 서비스 다시 시작**도 있어요.
- **서비스**에서는 서비스마다 상태를 보여 줘요. **모두 정상 작동 중이에요**라고 나오면 할 일이 없어요.
- **로그**는 문제가 있어서 신고하고 싶을 때 써요. **진단 로그** 옆의 **저장**을 클릭하면 Phi가 다운로드 폴더에 ZIP 파일을 저장하고, 이 파일을 Phi 지원팀에 보낼 수 있어요.

브라우저의 **설정 → Phi 및 AI → Phi Sentinel**에서는 **Mac에 로그인할 때 Phi Sentinel 실행**과 **Shift Shift Shift로 Phi Chat 불러오기**를 켤지 고를 수 있어요([Phi Chat](/ko/phi-chat/#opening-phi-chat) 참고).
