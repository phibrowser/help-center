# 동기화

동기화는 같은 Phi 계정으로 로그인한 모든 Mac에서 Phi 자체 데이터를 똑같이 유지해요. 한 Mac에서 북마크를 저장하거나 스페이스 이름을 바꾸면 그 변경 사항이 다른 Mac에도 전달돼요. 각 Mac에서 직접 설정하기 전까지는 꺼져 있고, 전달하는 내용을 저희가 읽을 수 없도록 만들어져 있어요. 모든 데이터는 업로드되기 전에 내 Mac에서 암호화되고, 그 키는 내 Mac들만 가지고 있어요.

여기서 설명하는 모든 내용은 **설정 → 동기화**에 있어요.

## 동기화되는 항목 {#what-syncs}

| 항목                          | 세부 내용                                                                                                                                                                                     |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **스페이스**                  | 이름, 아이콘, 색상, 테마, 그리고 각 스페이스가 속한 프로필.                                                                                                                                   |
| **프로필**                    | 프로필 이름, 그리고 각 프로필에 속한 스페이스.                                                                                                                                                |
| **북마크와 폴더**             | 모든 스페이스의 북마크와 그 폴더, 순서.                                                                                                                                                       |
| **고정된 탭**                 | **설정 → 스페이스**에서 선택한 범위 그대로의 고정된 탭.                                                                                                                                       |
| **URL 규칙**                  | 일치하는 사이트를 스페이스, 시크릿 모드 또는 Kiosk로 보내는 규칙.                                                                                                                             |
| **지원되는 설정**             | 레이아웃 모드, 화면 모드, 테마와 선택 영역 색상, 북마크바와 전체 URL 표시 설정, **새 탭 동작**(⌘T로 여는 화면), 시크릿 모드 닫기 경고, 자동 화면 속 화면, 고정된 탭 범위, 기본 스페이스 지정. |
| **브라우징 데이터(프로필별)** | 방문 기록, 기본 검색엔진 같은 브라우저 자체 환경설정, 확장 프로그램과 동기화되는 확장 프로그램 설정.                                                                                          |

::: warning 삭제도 동기화돼요
한 Mac에서 스페이스나 프로필을 삭제하면, 함께 동기화하는 모든 Mac에서 북마크까지 포함해 삭제돼요. 확인 대화상자에도 이 내용이 나오니 확인하기 전에 꼭 읽어 보세요.
:::

일부 항목은 의도적으로 있는 자리에 그대로 남아요.

- **비밀번호, 쿠키, 자동 완성.** 동기화에 절대 포함되지 않아요. Phi에는 자체 비밀번호 관리자가 없고, [에이전트 비밀번호 관리자](/ko/agent-passwords/)로 연결한 보관함은 해당 제공업체의 것이어서 그 제공업체의 조건에 따라 동기화돼요.
- **열려 있는 탭.** 일반적으로 열려 있는 탭은 다른 Mac에서 다시 만들어지지 않아요. 고정된 탭은 다시 만들어져요.
- **Phi Chat과 메모리.** 어시스턴트와 나눈 대화는 대화한 Mac에만 남고, [메모리](/ko/memory/)도 마찬가지예요.
- **시크릿 스페이스**와 에이전트가 작업하는 스페이스. 여기서는 아무것도 동기화되지 않아요. 사이트를 시크릿 모드로 보내는 URL 규칙은 그래도 규칙이므로 다른 규칙처럼 동기화돼요.
- **키보드 단축키.** **설정 → 단축키**에서 지정한 내용은 지정한 Mac에만 남아요.
- **한 Mac에 묶인 설정.** AI 설정과 에이전트 설정도 여기에 포함돼요.

## 시작하기 전에

- **각 Mac에서 로그인한 Phi 계정.** 계정이 없으면 패널에는 **기기 간에 동기화하려면 로그인하세요**만 표시돼요. 계정 없이 둘러보기를 선택했다면 [나중에 로그인하기](/ko/get-started/#signing-in-later)를 참고하세요.
- **공식 Phi 빌드.** 동기화는 Phinomenon의 동기화 서비스를 통해 동작해요. 오픈 소스 코드로 직접 빌드한 Phi는 이 서비스를 사용할 수 없어요.

## 첫 번째 Mac 설정하기 {#set-up-your-first-mac}

1. **설정 → 동기화**를 열고 **이 기기에서 동기화 설정**을 클릭하세요. 창에서 앞으로 진행될 내용을 설명해 줘요. **계속**을 클릭하세요.
2. **복구 코드 저장.** Phi가 복구 코드를 만들어 한 번만 보여 줘요. 다섯 자씩 묶인 27자예요. **복사**를 클릭해 비밀번호 관리자처럼 안전한 곳에 보관한 다음 **저장했어요**를 클릭하세요.
3. **복구 코드 확인.** Phi가 저장한 코드를 입력하라고 요청해요. 하이픈, 공백, 대소문자는 상관없어요. 코드를 저장하지 않았다면 **뒤로**를 클릭하세요. Phi가 같은 코드를 다시 보여 주므로 지금 저장할 수 있어요. 코드가 맞는지 확인되기 전까지 동기화는 꺼져 있어서, 저장하지 않았다는 사실을 나중에야 알게 되는 일은 없어요. 이 단계에서 창을 닫으면 다음에 설정을 열거나 재시작할 때 Phi가 다시 물어보지만, 그때는 **뒤로**가 없어요. 창이 닫히면 코드가 보관되지 않기 때문이에요.
4. **Phi가 알아서 동기화를 설정해요.** 첫 번째 Mac에서는 계정에 아직 연결할 항목이 없어서 채울 연결 페이지가 없어요. Phi가 이 Mac의 프로필과 스페이스를 계정에 추가하고, 그동안 <strong>동기화 설정 중…</strong>을 표시해요. Phi가 계정의 내용을 모두 읽지 못했다면 대신 [다른 Mac 추가하기](#add-another-mac)의 연결 페이지를 보여 줘요.
5. 설정이 끝나면 이 Mac이 업로드하는 동안 패널에 **초기 동기화 진행 중**이 표시되고, 끝나면 **최신 상태**가 표시돼요.

::: warning 복구 코드는 한 번만 표시돼요
코드는 내 Mac에서 만들어지고 저희에게 전송되지 않아요. 그래서 저희가 다시 보여 주거나, 새 코드를 보내 주거나, 재설정해 드릴 수 없어요. 다른 Mac을 추가하려면 코드나 이미 설정된 Mac 중 하나가 필요해요. 둘 다 잃으면 저희를 포함해 누구도 계정에 있는 암호화된 사본을 풀 수 없어요. 코드를 이미 잃어버렸다면 [복구 코드를 잊어버렸나요?](#forgot-your-recovery-code)를 참고하세요.
:::

## 다른 Mac 추가하기 {#add-another-mac}

1. 같은 Phi 계정으로 로그인하고 **설정 → 동기화**를 연 다음, **이 기기에서 동기화 설정**을 클릭하고 **계속**을 클릭하세요.
2. **이 기기를 계정에 추가** 화면에서 이 Mac이 참여할 방법을 선택하세요.
   - **다른 기기에 승인 요청.** Phi가 짧은 코드를 보여 주고 기다려요. 이미 설정된 Mac에서 **설정 → 동기화**를 열면 **기기** 아래에 같은 코드와 요청 만료 시간이 함께 표시돼요. 두 코드가 같은지 확인한 다음 **승인**을 클릭하고, 예상하지 못한 요청이면 **거부**를 클릭하세요. 이 코드는 새 Mac을 식별하는 용도일 뿐 비밀이 아니어서, 전화로 불러 줘도 괜찮아요. 요청이 거부되거나 만료되면 **다른 방법 시도**가 표시돼요.
   - **복구 코드 입력.** 첫 번째 Mac에서 저장한 코드를 입력하세요.
3. **이 Mac의 동기화 방법 선택.** 계정에 이미 데이터가 있고 이 Mac에도 자체 데이터가 있으면, Phi가 <strong>이 Mac을 어떻게 동기화할까요?</strong>라고 묻고 양쪽에 무엇이 있는지 보여 줘요.
   - **이 Mac을 계정과 병합**. **추천** 표시가 붙어 있어요. 다음 단계에서 프로필과 스페이스를 하나씩 연결하고, 양쪽의 북마크, 고정된 탭, URL 규칙이 모두 유지돼요.
   - **계정의 데이터 사용**. 이 Mac의 스페이스, 북마크, 고정된 탭, URL 규칙, 동기화된 설정이 계정의 데이터로 교체되고, 계정에 없는 프로필은 이 Mac에서 삭제돼요. 이 Mac만 변경되며, 되돌릴 수 없어요. 선택하기 전에 [계정의 데이터 사용](#use-your-accounts-data)을 참고하세요.

   기본 프로필과 기본 스페이스 말고는 아무것도 없고 북마크, 고정된 탭, URL 규칙도 없는 Mac에는 이 단계가 나타나지 않아요. 이 Mac의 데이터로 계정의 데이터를 덮어쓰는 옵션은 없어요.

4. **프로필 연결.** Phi가 이 Mac의 프로필을 계정의 프로필과 짝지어 보고, 짝을 찾지 못한 프로필에 대해 물어봐요. 이 Mac의 기본 프로필은 항상 계정의 기본 프로필과 연결돼요. 그 행에는 해당 계정 프로필이 표시되고, 고를 수 있는 메뉴는 없어요. 이 Mac의 나머지 각 프로필에 대해 계정 프로필에 할당하거나 **새로 등록**을 선택하세요. 이 Mac에 대응하는 프로필이 없는 계정 프로필은 **할당되지 않은 계정 프로필** 아래에 표시되고, 여기서 **이 Mac에 만들기**를 누르면 추가돼요. 선택한 내용이 기본 프로필 규칙에 어긋나면 Phi가 <strong>이 Mac의 기본 프로필은 계정의 기본 프로필과만 연결할 수 있어요. 연결 항목을 확인하고 다시 시도해 주세요.</strong>라고 알려 줘요.
5. **스페이스 연결.** 이 Mac의 각 스페이스에 대해 해당하는 계정 스페이스를 고르거나 **새로 추가**를 선택하세요. **모두 새로 추가**를 누르면 아직 정하지 않은 스페이스가 한 번에 정리되고, 이름이 정확히 같은 스페이스는 자동으로 선택돼요. 계정에는 있지만 이 Mac에 없는 스페이스는 **계정에서 추가될 스페이스** 아래에 표시되고, 완료할 때 만들어져요. 이 Mac에 있는 것은 아무것도 삭제되지 않아요. **완료**를 클릭하세요.
6. **변경되는 내용 검토.** 이 화면은 이 Mac의 무언가를 덮어쓰게 될 때만 나타나요. 이 Mac의 스페이스를 계정의 스페이스와 연결했다면, 계정의 이름, 아이콘, 색상, 테마가 이 Mac의 값을 대체하고, 스페이스가 계정에서 속한 프로필로 이동할 수도 있어요. 이 Mac의 탭, 북마크, 고정된 탭, URL 규칙은 변경되지 않아요. 이 Mac의 값을 유지하려면 **뒤로**를 눌러 그 스페이스를 새로 추가하세요. **적용**을 클릭하면 동기화가 시작돼요. 덮어쓸 항목이 없으면 **완료**를 클릭하는 즉시 동기화가 시작돼요.

Phi는 물어볼 것이 있는 페이지만 보여 줘요. 물어볼 것이 없으면, 예를 들어 기본 데이터만 있는 Mac이라면 Phi가 알아서 마무리하면서 <strong>동기화 설정 중…</strong>을 표시하고, 계정의 프로필과 스페이스가 이 Mac에 나타나요.

Phi가 스페이스를 집계하는 동안 계정을 불러오는 데 최대 2분이 걸릴 수 있고, 인터넷 연결이 필요해요. 대신 사용할 캐시된 사본이 없기 때문이에요. **이 Mac을 계정과 병합**을 선택하면 동기화가 시작된 뒤 두 Mac의 북마크, 고정된 탭, URL 규칙이 모두 유지되므로 어느 쪽 데이터도 사라지지 않아요.

### 계정의 데이터 사용 {#use-your-accounts-data}

이 Mac에 있는 Phi 데이터를 남겨 둘 필요가 없을 때 선택하세요. 테스트용으로만 쓴 Mac이 그런 예예요. Phi가 먼저 이 Mac의 Phi 데이터를 삭제한 다음 계정의 데이터를 다운로드해요.

- **이 Mac에서 제거되는 항목:** 기본 스페이스를 제외한 스페이스가 제거되고, 그 스페이스에 열려 있던 탭이 닫혀요. 북마크, 고정된 탭, URL 규칙, 동기화된 설정도 제거되고, 계정에 없는 모든 프로필도 방문 기록, 확장 프로그램, 사이트 데이터와 함께 제거돼요.
- **유지되는 항목:** 이 Mac의 기본 프로필과, 계정의 프로필과 이름이 같은 프로필은 방문 기록, 확장 프로그램, 사이트 데이터가 그대로 유지돼요. 계정과 다른 Mac에는 영향이 없어요.

**계속**을 클릭하면 Phi가 <strong>이 Mac의 데이터를 교체할까요?</strong>라고 묻고 제거되는 항목과 다운로드되는 항목을 보여 줘요. 진행하려면 **이 Mac의 데이터 교체**를 클릭하세요. Phi가 <strong>이 Mac의 데이터 교체 중…</strong>을 표시하고, 끝날 때까지 창이 열려 있어요. 그런 다음 첫 동기화와 함께 계정의 데이터가 도착하고 패널에 **초기 동기화 진행 중**이 표시돼요. 계정의 데이터가 많으면 몇 분 걸릴 수 있어요. 교체가 오류로 멈추면 [이 Mac의 데이터 교체를 완료하지 못한 경우](#replace-did-not-finish)를 참고하세요.

::: warning 교체는 되돌릴 수 없어요
Phi는 삭제하는 데이터의 사본을 보관하지 않아요. 사본이 필요하면 먼저 **나중에 완료**를 선택하고, <strong>도움말 → 사용자 데이터 관리 → 사용자 데이터 내보내기…</strong>로 내보낸 다음 설정으로 돌아오세요. 내보내기는 [가져오기 및 내보내기](/ko/import-export/)와 [동기화와 내보내기](#sync-or-export)를 참고하세요. 로컬 프로필을 유지하려면 대신 **이 Mac을 계정과 병합**을 선택하세요.
:::

### 설정에서 계정을 불러오지 못하는 경우 {#setup-cannot-load-account}

설정은 선택 항목을 보여 주기 전에 계정을 읽어요. 이 과정이 실패하면 창에 그 이유가 표시되고 **다시 시도**가 나타나요.

- **계정의 스페이스를 제시간에 불러오지 못했어요. 연결 상태를 확인하고 다시 시도해 주세요.** 계정의 데이터가 많거나 연결이 느린 경우예요. 연결 상태를 확인하고 다시 시도하세요.
- **지금은 동기화를 사용할 수 없어서 계정의 스페이스를 불러오지 못했어요.** Phi가 지금 동기화 서비스에 연결할 수 없어요. 온라인 상태이고 아직 로그인되어 있는지 확인한 다음 다시 시도하세요.
- **계정의 프로필을 불러오지 못했어요. 연결 상태를 확인하고 다시 시도해 주세요.** 또는 **계정의 스페이스를 불러오지 못했어요. 연결 상태를 확인하고 다시 시도해 주세요.** 연결 상태를 확인하고 다시 시도하세요.
- 계정 프로필에 **지금은 읽을 수 없으며 Phi가 백그라운드에서 계속 다시 시도해요**라고 표시되는 경우: Phi가 계속 다시 시도하는 동안에도 설정의 나머지 단계는 그대로 진행할 수 있어요.
- **이 Mac에서 계정의 기본 프로필을 읽을 수 없어서 지금은 이 Mac의 데이터를 교체할 수 없어요.** 기본 프로필을 읽을 수 있을 때까지 **계정의 데이터 사용**은 실행할 수 없어요. **이 Mac을 계정과 병합**을 선택하거나, **나중에 완료**를 선택하고 다시 시도하세요.

### 나중에 완료 {#finish-later}

동기화 방법 단계와 연결 단계의 페이지에는 **나중에 완료**가 있어요. 이것을 선택하거나 창을 닫으면 이 Mac은 로컬에서 계속 브라우징해요. 아무것도 동기화되지 않고, 패널에는 **페어링되지 않음**이 표시되며, Phi가 설정을 스스로 다시 열지 않아요. 준비가 되면 **설정 → 동기화**로 돌아와 **설정 계속하기**를 클릭하세요. 그 시점에 Phi가 계정을 다시 불러오므로, 끝내지 않은 선택은 유지되지 않아요. 동기화 방법도 마찬가지여서, 다음 설정은 **이 Mac을 계정과 병합**이 선택된 상태로 시작해요.

이미 시작된 교체는 예외예요. Phi가 이 Mac의 데이터를 교체하기 시작했다면, 설정을 떠나도 교체는 취소되지 않아요. 오류가 나거나 Phi가 종료되어 교체가 멈췄고 창을 닫았다면, 다음에 설정을 열 때 **뒤로** 없이 바로 **이 Mac의 데이터를 교체할까요?** 화면이 열리고, **이 Mac의 데이터 교체**를 누르면 멈춘 지점부터 이어서 진행돼요. 이 화면에서도 <strong>동기화에서 이 기기 제거…</strong>를 선택할 수 있어요. 이 경우 교체가 아직 제거하지 못한 항목이 남은 상태로 이 Mac이 동기화에서 빠져요.

## 복구 코드를 잊어버렸나요? {#forgot-your-recovery-code}

저희를 포함해 누구도 복구 코드를 다시 보여 주거나 같은 동기화 데이터에 대한 새 코드를 만들 수 없어요. 아직 할 수 있는 일은 상황에 따라 달라요. **복구 코드 입력** 페이지의 **복구 코드를 잊어버렸나요?** 링크를 누르면 이 섹션이 열려요.

### 아직 첫 번째 Mac을 설정하고 있는 경우

**복구 코드 확인** 화면에 있고 설정 창을 닫지 않았다면 **뒤로**를 클릭하세요. Phi가 같은 코드를 다시 보여 줘요. 코드를 저장하고 **저장했어요**를 클릭한 다음, 코드를 입력해 확인하세요.

Phi 2.14 이하에는 **뒤로** 버튼이 없어요. 창을 닫았거나 Phi를 재시작했다면 코드도 사라진 거예요. Phi는 계속 코드를 요청하지만 보여 줄 수는 없어요. 어느 경우든 필요하면 Phi를 업데이트한 다음, 아래 설명처럼 [동기화 재설정](#reset-sync)으로 처음부터 다시 시작하세요.

### 다른 Mac에 아직 동기화가 설정되어 있는 경우

코드가 없어도 돼요. 새 Mac에서 **다른 기기에 승인 요청**을 선택하고, 설정된 Mac에서 요청을 승인하세요. [다른 Mac 추가하기](#add-another-mac)를 참고하세요. 가지고 있는 Mac들에서는 동기화가 계속 동작해요.

그래도 코드를 다시 보여 주거나 교체할 수는 없어요. 동기화가 설정된 Mac을 최소 한 대는 유지하세요. 한 대라도 설정되어 있으면 코드 없이 Mac을 추가할 수 있어요.

### 이 Mac이 유일한 Mac이거나 처음부터 다시 시작하려는 경우

그 Mac에서 [동기화 재설정](#reset-sync)을 사용하세요. 그 Mac이 동기화에서 제거되고 계정에 저장된 모든 동기화 데이터가 삭제돼요. 로컬 브라우징 데이터는 그 Mac에 그대로 남고, 이 계정에 동기화가 아직 설정되어 있던 다른 Mac에는 이후 [동기화 다시 설정](#set-up-sync-again)이 표시돼요. 그런 다음 [첫 번째 Mac 설정하기](#set-up-your-first-mac)처럼 이 Mac에서 동기화를 처음부터 설정하세요. Phi가 새 복구 코드를 만들어요. **저장했어요**를 클릭하기 전에 꼭 저장하세요.

**동기화 재설정**은 계정에 설정된 마지막 Mac에서만 표시돼요. 다른 Mac이 아직 설정되어 있는 상태에서 처음부터 다시 시작하려면, 먼저 다른 Mac들을 하나씩 동기화에서 제거하세요.

### 가지고 있는 Mac 중 동기화가 설정된 Mac이 없는 경우

코드가 없고 가지고 있는 Mac 중 동기화가 설정된 Mac이 하나도 없다면, 계정에 있는 암호화된 사본은 나도, 저희도 풀 수 없어요. 아직 동기화가 설정되지 않은 Mac은 계정의 동기화를 재설정할 수도 없으므로, 그 Mac에서 처음부터 다시 시작할 방법은 없어요. 설정된 상태에서 잃어버리거나 초기화된 Mac도 여기에 해당해요. 그 Mac은 여전히 설정된 것으로 간주되고, 다른 Mac에서 제거할 수 없어요.

## 동기화 상태 확인하기 {#check-sync-status}

동기화 패널 맨 위에서 현재 상태를 볼 수 있어요.

- **최신 상태**, **동기화 중…**, 또는 첫 동기화가 진행되는 동안 **초기 동기화 진행 중**.
- **오프라인** 상태와 함께, 연결되면 변경 사항이 동기화된다는 안내. Phi는 로컬 데이터로 계속 동작하고, Mac이 다시 온라인이 되면 변경 사항을 보내요.
- **동기화 일시 중지됨.** 이 Mac의 프로필 중 아직 동기화가 설정되지 않은 것이 있어요. 보통 설정을 마친 뒤에 만든 프로필이에요. 패널에 기다리는 프로필과 그 이유가 표시돼요. Phi가 알아서 등록하고 계속 다시 시도하며, **다시 시도**를 누르면 바로 시도해요. [동기화 일시 중지됨](#sync-paused)을 참고하세요.
- **주의 필요.** 무언가 실패했어요. 그 아래에 **일부 콘텐츠에 주의가 필요해요. 세부사항과 연결 상태를 확인해 주세요.** 문구가 표시되고, **최근 문제**에 가장 최근 문제와 발생 시점이 표시돼요. [각 문제의 의미](#needs-attention)를 참고하세요.

상태 아래의 **이 Mac에서 마지막으로 성공한 동기화**에는 이 Mac이 마지막으로 동기화를 마친 시간이 표시돼요. **프로필을 불러올 때까지 기다리는 중**은 Phi가 아직 이 Mac의 프로필 목록을 읽지 못했다는 뜻이에요. Phi가 알아서 계속 시도하고, 5분이 지나면 상태가 **주의 필요**로 바뀌어요.

이 Mac이나 다른 Mac에서 고정된 탭 범위를 바꿨다면 **고정 탭 범위 변경이 아직 적용되지 않았어요**라는 줄이 시도 횟수, 이유와 함께 표시될 수 있어요. 이유는 **브라우저 마이그레이션이 진행 중이에요**, **로컬 브라우저 데이터를 사용할 수 없어요**, **이 Mac에 고정된 탭을 저장하지 못했어요** 중 하나예요. 이 Mac이 아직 고정된 탭을 새 범위로 옮기지 못했다는 뜻이에요. Phi가 알아서 계속 다시 시도하고, 나머지 동기화는 그대로 진행돼요. 이 줄이 사라지지 않으면 Phi를 재시작하고, 그래도 사라지지 않으면 창 오른쪽 위 메뉴의 **피드백**으로 피드백을 보내 주세요.

### 각 문제의 의미 {#needs-attention}

**최근 문제**에는 다음 중 하나가 표시돼요. 다음 동기화가 끝까지 완료되면 사라져요.

| 최근 문제                                 | 의미                                                                                     | 해야 할 일                                                                                                    |
| ----------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **로그인 만료됨**                         | 동기화 서비스가 이 Mac의 로그인을 더 이상 받아들이지 않아요.                             | Phi 계정에 다시 로그인하세요.                                                                                 |
| **연결 없음**                             | 이 Mac이 동기화 서비스에 연결하지 못했어요.                                              | 할 일은 없어요. 온라인 상태가 되어 다음 동기화가 성공하면 사라져요.                                           |
| **서버 오류**                             | 동기화 서비스가 오류를 반환했어요.                                                       | 할 일은 없어요. 다음 동기화가 성공하면 사라져요.                                                              |
| **서버가 변경 사항을 거부함**             | 다른 Mac과 충돌이 반복된 경우처럼, 동기화 서비스가 이 Mac의 변경 사항 일부를 거부했어요. | **지금 동기화**를 클릭하세요. 다시 나타나면 Phi를 재시작하고, 계속되면 피드백을 보내 주세요.                  |
| **이 Mac의 데이터를 읽을 수 없음**        | Phi가 이 Mac에 있는 자체 데이터 일부를 읽지 못했어요.                                    | **지금 동기화**를 클릭하세요. 다시 나타나면 Phi를 재시작하고, 계속되면 피드백을 보내 주세요.                  |
| **이 Mac에 동기화 상태를 저장할 수 없음** | Phi가 무엇이 동기화되었는지에 대한 기록을 저장하지 못했어요.                             | **지금 동기화**를 클릭하세요. 다시 나타나면 Phi를 재시작하고, 계속되면 피드백을 보내 주세요.                  |
| **일부 동기화된 데이터를 읽을 수 없음**   | 계정에 있는 무언가를 이 Mac에서 읽지 못했어요.                                           | **지금 동기화**를 클릭하세요. 다시 나타나면 Phi를 재시작하고, 계속되면 피드백을 보내 주세요.                  |
| **프로필 페어링 대기 중**                 | 이 Mac의 프로필이 계정과 페어링될 때까지 일부 동기화 항목이 기다리고 있어요.             | Phi가 프로필을 설정할 때까지 기다리거나, 패널에 **동기화 일시 중지됨**이 표시되면 **다시 시도**를 클릭하세요. |
| **동기화를 다시 설정해야 함**             | 계정의 동기화 데이터가 재설정되어 이 Mac의 설정이 더 이상 맞지 않아요.                   | **동기화 다시 설정**을 클릭하세요. [동기화 다시 설정하기](#set-up-sync-again)를 참고하세요.                   |

[세부사항](#sync-details)에서 설명하는 보류된 항목이 있어도 문제 이름 없이 상태가 **주의 필요**로 유지될 수 있어요. [고정된 탭이 보류되는 경우](#held-pinned-tabs)를 참고하세요.

### 세부사항 {#sync-details}

**세부사항**에는 프로필마다 브라우징 데이터 상태가 표시되고, 이어서 Phi 데이터 종류마다 한 행씩 **설정**, **스페이스**, **북마크**, **고정된 탭**, **URL 규칙**이 표시돼요. 각 종류의 행은 변경 사항이 있었던 가장 최근 동기화의 내용과 그 동기화가 얼마나 전이었는지를 보여 줘요.

| 개수          | 세는 대상                                                                                                                                                                                                               |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **수신**      | 이 Mac이 계정에서 받은 변경 사항.                                                                                                                                                                                       |
| **전송**      | 이 Mac이 업로드한 변경 사항.                                                                                                                                                                                            |
| **전송 대기** | 이 Mac에서 아직 업로드되지 않은 변경 사항. 이후 동기화에서 보내져요.                                                                                                                                                    |
| **보류**      | 이 Mac이 받았지만 아직 적용할 수 없는 항목. 프로필이나 스페이스가 이 Mac에서 페어링되지 않은 고정된 탭이 그 예이고, Phi는 적용할 수 있을 때까지 이 항목을 보관해요. 다른 고정된 탭 범위에 속한 고정된 탭은 세지 않아요. |

**전송 대기**와 **보류**는 0이 아닐 때만 표시돼요. 최근 변경 사항이 없는 종류에는 **최근 변경 사항 없음**이 표시돼요.

### 지금 동기화 {#sync-now}

**지금 동기화**는 이 Mac에 모든 것을 바로 동기화하도록 요청해요. 이 버튼이 필요한 경우는 드물어요. 다른 Mac에서 무언가 바뀌면 Phi가 알림을 받고 스스로도 확인하는데, 최대 1분에 한 번이에요. **지금 동기화**는 이 대기 시간을 건너뛰어요. 동기화가 기다리거나 실행되는 동안 버튼에 진행 상태가 표시되고, 툴팁에는 **모든 프로필을 사용할 수 있을 때까지 기다리는 중**처럼 무엇을 기다리는지 표시돼요.

직접 시작한 동기화가 완료되지 않으면, 다시 클릭할 때까지 상태 아래 줄에 그 사실이 표시돼요.

- 그 동기화 중에 기록된 문제가 있다면: 위 표에 있는 문제 이름.
- 특정 문제 없이 동기화가 멈췄다면: **동기화가 완료되지 않았어요**. 나중에 다시 시도하세요. 한 Mac에서 계속 이렇게 되면 [고정된 탭이 보류되는 경우](#held-pinned-tabs)를 참고하세요.
- 이 Mac이 동기화를 아예 시작하지 못했다면: **동기화를 시작하지 못했어요. 나중에 다시 시도해 주세요.**

끝까지 완료된 동기화는 줄을 남기지 않고, **이 Mac에서 마지막으로 성공한 동기화**가 새 시간으로 바뀌어요.

## 기기

**기기** 섹션에는 계정에 설정된 모든 Mac이 표시되고 **이 Mac**이 따로 표시돼요. 참여를 기다리는 Mac이 있으면 그 코드, **승인**, **거부**, 요청 만료 시간도 함께 나와요. 승인하려면 이 Mac이 로그인되어 있고 자체 설정을 마친 상태여야 해요.

각 Mac은 자신의 동기화 패널에서 자기 자신만 제거할 수 있어요. 더는 가지고 있지 않은 Mac을 제거하는 방법은 아직 없어요. 잃어버린 Mac은 계정에 남아 있고, 로그인되어 있는 동안 계속 변경 사항을 받아요. 그 Mac에 아직 접근할 수 있다면 로그아웃해서 막을 수 있어요.

## Mac을 동기화에서 제거하기 {#remove-a-mac-from-sync}

**설정 → 동기화**의 **제거** 아래에서 **동기화에서 이 Mac 제거** 행의 <strong>제거…</strong>를 클릭하고 **이 기기 제거**로 확인하세요. 이 Mac에서 설정을 마치지 않았다면, 대신 설정 창 아래쪽에 <strong>동기화에서 이 기기 제거…</strong>가 표시돼요.

- 이 Mac의 동기화가 중단되고, 동기화 서비스가 이 Mac을 해지하며, 이 Mac의 동기화 설정, 키, 프로필과 스페이스 연결 정보가 지워져요.
- 브라우징하던 모든 것은 그대로 남아요. 스페이스, 북마크, 방문 기록, 고정된 탭이 모두 유지되고, 계정에도 계속 로그인되어 있어요.
- 다른 Mac에는 영향이 없고, 서로 계속 동기화해요.
- 이 Mac을 다시 연결하려면 설정을 다시 시작해서 승인이나 복구 코드로 참여하세요.

이 Mac이 계정에서 동기화가 설정된 유일한 Mac이면, 이 행은 대신 **동기화 재설정**으로 표시돼요. 마지막 Mac을 제거하면 계정의 동기화 데이터도 삭제되기 때문이에요. [동기화 재설정](#reset-sync)을 참고하세요.

::: warning 제거해도 계정의 키는 바뀌지 않아요
Mac을 제거하면 그 Mac은 새로운 데이터를 더 받지 않지만, 계정의 암호화 키가 바뀌지는 않고 그 Mac이 이미 동기화한 데이터를 되돌려 받을 수도 없어요. 그 Mac에 있던 것은 그대로 그 Mac에 남아요.
:::

### 동기화 재설정 {#reset-sync}

이 Mac이 계정에서 동기화가 설정된 유일한 Mac이면, **제거** 섹션에 **동기화 재설정**과 <strong>재설정…</strong> 버튼이 표시돼요. 재설정하면 이 Mac이 동기화에서 제거되고 이 계정에 저장된 모든 동기화 데이터가 삭제되므로, 복구 코드를 잃어버렸을 때처럼 처음부터 다시 시작할 수 있어요.

1. **설정 → 동기화**의 **제거** 아래에서 <strong>재설정…</strong>을 클릭하세요.
2. Phi가 <strong>이 계정의 모든 동기화 데이터를 삭제할까요?</strong>라고 물어봐요. **모든 동기화 데이터 삭제**를 클릭해 확인하세요. 이 작업은 되돌릴 수 없어요.

- 모든 기기가 동기화에서 제거되고, 이 계정에 대해 동기화 서버에 저장된 모든 데이터가 삭제돼요.
- 로컬 브라우징 데이터는 이 Mac에 그대로 남아요. 스페이스, 북마크, 방문 기록, 고정된 탭이 유지되고, 계정에도 계속 로그인되어 있어요.
- 이 계정에 동기화가 아직 설정되어 있던 다른 Mac에는 [동기화 다시 설정](#set-up-sync-again)이 표시돼요.
- 동기화를 다시 사용하려면 처음부터 설정하세요. Phi가 새 복구 코드를 만들어요.

설정 창에서 이 Mac을 제거하려는데 마지막 Mac이라면, Phi가 <strong>이 기기는 동기화가 설정된 마지막 기기예요. 이 기기를 제거하고 이 계정에 저장된 모든 동기화 데이터를 삭제하거나, 먼저 다른 기기에서 동기화를 설정할 수 있어요.</strong>라고 알려 줘요. 그런 다음 <strong>이 기기 제거 및 모든 동기화 데이터 삭제…</strong>를 표시하고, 이 버튼도 같은 확인을 요청해요.

그 사이에 다른 Mac이 계정에 참여했다면 아무것도 삭제되지 않아요. Phi가 <strong>그 사이에 다른 기기가 이 계정에 참여해서 아무것도 삭제되지 않았어요. 대신 동기화에서 이 Mac을 제거할 수 있어요.</strong>라고 표시하고, 행이 다시 **동기화에서 이 Mac 제거**로 바뀌어요.

## 동기화 다시 설정하기 {#set-up-sync-again}

패널에 <strong>계정의 동기화 데이터가 변경되었어요. Phi 데이터 동기화가 일시 중지되었어요.</strong>라고 표시되면, 계정의 동기화 데이터가 재설정되어 이 Mac의 설정이 더 이상 맞지 않는 거예요. 직접 조치하기 전까지 Phi 데이터는 동기화되지 않고, 다시 시도하거나 재시작해도 해결되지 않아요. **동기화 다시 설정**을 클릭하고 확인하세요. Phi가 이 Mac의 동기화 설정과 연결 정보를 지우고, 로컬 브라우징 데이터와 계정에 있는 데이터는 그대로 둔 채, 승인이나 복구 코드로 참여하는 단계까지 포함해 설정을 처음부터 다시 안내해요.

계정의 마지막 Mac에서 **동기화 재설정**을 사용한 뒤에도 Mac에 이 메시지가 표시돼요. 그 Mac이 설정될 때 사용한 동기화 데이터가 삭제되었기 때문이에요.

## 문제 해결 {#troubleshooting}

### 두 번째 Mac에 키보드 단축키나 열려 있는 탭이 없는 경우 {#missing-shortcuts-and-open-tabs}

의도된 동작이에요. **설정 → 단축키**의 키보드 단축키는 동기화되지 않고, 일반적으로 열려 있는 탭도 동기화되지 않아요. 동기화되는 것은 고정된 탭뿐이에요. AI 설정과 에이전트 설정도 각 Mac에 남아요. 원하는 Mac마다 따로 설정하세요. [동기화되는 항목](#what-syncs)을 참고하세요.

### 한 Mac에서 동기화가 완료되지 않고 고정된 탭이 보류되는 경우 {#held-pinned-tabs}

한 Mac에는 **동기화가 완료되지 않았어요**가 표시되고 **세부사항**의 **고정된 탭** 행에 **보류**와 숫자가 표시되는데, 다른 Mac에는 **최신 상태**가 표시돼요. **보류**는 이 Mac이 받은 고정된 탭을 둘 곳이 없다는 뜻이에요. 그 탭이 속한 프로필이나 스페이스가 이 Mac에서 페어링되지 않았기 때문이에요.

흔한 원인은 설정할 때 두 Mac의 기본 프로필이 서로 연결되지 않은 거예요. Phi 2.12에서 페어링한 Mac에서 이런 일이 생길 수 있었어요. Phi 2.13부터는 설정할 때 항상 기본 프로필을 계정의 기본 프로필과 연결해요.

지금 해결하려면 고정된 탭이 보류된 Mac에서 [Mac을 동기화에서 제거](#remove-a-mac-from-sync)한 다음, [다른 Mac 추가하기](#add-another-mac)처럼 다시 설정하세요. Phi가 이 Mac의 동기화 방법을 물으면 **이 Mac을 계정과 병합**을 선택하세요. 이 과정 동안 북마크, 방문 기록을 비롯한 모든 것이 Mac에 그대로 남고, 기본 프로필은 계정의 기본 프로필과 연결돼요.

### 동기화 일시 중지됨 또는 프로필 페어링 대기 중 {#sync-paused}

동기화를 설정한 뒤에 만든 프로필은 아직 페어링되지 않은 상태예요. Phi가 알아서 그 프로필을 계정에 등록하고, 등록이 끝나면 그 프로필의 동기화가 시작돼요. 동기화 패널의 **다시 시도**를 누르면 바로 시도해요. 일시 중지가 계속 풀리지 않으면 연결 상태와 로그인 상태를 확인한 다음 **다시 시도**를 다시 클릭하세요.

### 상태에 주의 필요가 표시되는 경우 {#sync-needs-attention}

**최근 문제**에 무엇이 잘못되었는지 표시돼요. [각 문제의 의미](#needs-attention)에 모든 문제와 해야 할 일이 정리되어 있어요.

### 이 Mac의 데이터 교체를 완료하지 못한 경우 {#replace-did-not-finish}

**계정의 데이터 사용**을 선택한 뒤 설정이 멈추고 **이 Mac의 데이터 교체를 완료하지 못했어요.** 메시지가 표시되면 **다시 시도**를 클릭하세요. 다시 시도하면 중단된 지점부터 이어서 진행되고, 완료될 때까지 다른 항목은 변경되지 않아요. 진행되는 동안 Phi를 열어 두세요. 계정의 데이터가 많으면 몇 분 걸릴 수 있어요. 창을 닫으면 [나중에 완료](#finish-later)에서 설명한 것처럼 다음 설정에서 같은 교체가 이어서 진행돼요.

### 연결 후 스페이스의 이름, 아이콘, 색상 또는 테마가 바뀐 경우 {#account-values-replaced}

의도된 동작이에요. 이 Mac의 스페이스를 계정의 스페이스와 연결하면 계정의 이름, 아이콘, 색상, 테마가 적용되고, **적용**을 클릭하기 전에 **변경되는 내용 검토**에서 이 내용을 보여 줘요. 이 Mac의 값을 유지하려면 그 시점에서 **뒤로**를 누르고 그 스페이스에 **새로 추가**를 선택하세요. 그러면 별도의 스페이스로 동기화돼요. 연결이 적용된 뒤에는 이 Mac의 이전 값이 보관되지 않으므로, 되돌리고 싶다면 스페이스를 직접 다시 꾸며야 해요. 이 변경도 다른 Mac에 동기화돼요.

## 로그아웃하기

Phi 계정에서 로그아웃하면 그 Mac의 동기화가 중단되고, 다시 로그인할 때까지 다른 Mac의 변경 사항이 전달되지 않아요. 같은 계정으로 다시 로그인하면 동기화가 멈췄던 곳에서 이어지고 놓친 변경 사항을 따라잡아요. 마무리할 것이 남아 있으면 동기화 패널에서 알려 줘요. 다른 계정으로 바꿔도 두 계정의 데이터가 섞이지 않아요. 계정마다 동기화된 데이터와 연결 정보가 따로 있어요.

## 데이터를 보호하는 방식

- **Mac을 떠나기 전에 암호화돼요.** 키는 내 Mac들이 만들고, 업로드되는 것은 암호화된 사본뿐이에요. 동기화 서비스는 그 사본을 보관했다가 다른 Mac에 전달할 뿐 복호화할 수 없어요.
- **로그인만으로는 읽을 수 없어요.** 새 Mac은 이미 키를 가진 Mac의 승인이나 복구 코드를 통해서만 키를 받아요. 그래서 잃어버린 코드는 되찾을 수 없어요. 설정 화면의 **복구 코드를 잊어버렸나요?** 링크에서 선택할 수 있는 방법을 안내하지만, 어떤 방법으로도 코드를 되찾을 수는 없어요.
- **그래도 저희가 보관하는 데이터예요.** 암호화된 사본은 Phinomenon의 동기화 서비스에 있으므로, 동기화는 Phi가 보내는 것 중 하나예요. 나머지는 [개인정보 보호 및 데이터](/ko/privacy/)에 정리되어 있고, 이 모든 내용에 대한 권위 있는 기준은 [개인정보 처리방침](https://phibrowser.com/privacy/)과 [이용약관](https://phibrowser.com/terms/)이에요.

## 동기화와 내보내기 {#sync-or-export}

동기화는 나란히 계속 사용하는 Mac들을 위한 기능이에요. 새 Mac으로 한 번 옮기거나 직접 보관할 사본을 만들 때는 **도움말** 메뉴의 <strong>사용자 데이터 관리 → 사용자 데이터 내보내기…</strong>가 더 알맞은 도구예요. [가져오기 및 내보내기](/ko/import-export/)를 참고하세요.
