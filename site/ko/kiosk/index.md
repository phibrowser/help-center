# Kiosk

Kiosk는 페이지 하나를 위한 가벼운 윈도우예요. 링크를 탭과 사이드바에서 떨어진 곳에 열어 살펴본 다음, 내 스페이스 중 한 곳에 둘 만한 페이지인지 결정할 수 있어요.

Kiosk는 쓸모 있을지도 모르지만 아직 고정된 자리는 얻지 못한 링크에 알맞아요. Mail에서 온 기사, 메시지에서 온 문서, 지금 하던 일을 끊지 않고 확인하고 싶은 링크 모두 자기만의 윈도우에 머물 수 있어요. 다 봤으면 Kiosk를 닫고, 간직하고 싶으면 페이지를 스페이스로 옮기세요.

Kiosk는 임시 윈도우라서 Phi를 다시 시작해도 돌아오지 않아요.

## Kiosk에서 페이지 열기

흔히 쓰는 세 가지 방법이 있어요.

| 링크가 있는 곳                    | 하는 방법                                                               |
| --------------------------------- | ----------------------------------------------------------------------- |
| Phi의 페이지                      | 링크를 마우스 오른쪽 버튼으로 클릭하고 **Kiosk에서 열기**를 선택하세요. |
| Phi의 페이지, 단축키를 켜 둔 경우 | Command와 Option을 누른 채 링크를 클릭하세요.                           |
| 다른 앱                           | **설정 → 탐색**에서 **외부 링크를 Kiosk에서 열기**를 켜세요.            |

Phi의 페이지에서 연 Kiosk는 그 페이지의 프로필을 사용해요. 다른 앱에서 연 링크는 마지막으로 사용한 프로필을 사용해요.

## URL 규칙으로 일치하는 링크 열기

어떤 사이트의 링크를 항상 Kiosk에서 열고 싶다면 URL 규칙을 사용하세요.

1. **설정 → 탐색**을 여세요.
2. **URL 규칙** 아래에서 <strong>URL 규칙 관리…</strong>를 클릭하세요.
3. 일치시킬 도메인이나 URL에 대한 규칙을 추가하세요.
4. 대상으로 **Kiosk**를 선택하세요.

이제 규칙과 일치하는 링크는 Kiosk 윈도우에서 열려요. 페이지를 나중에 옮기기로 결정하기 전까지는 스페이스 밖에 두고 싶은 사이트에 잘 맞아요.

## 프로필 전환하기

현재 프로필은 주소 표시줄 왼쪽에 표시돼요.

1. 프로필 이름을 클릭하세요.
2. 메뉴에서 다른 프로필을 선택하세요.

Phi가 선택한 프로필로 현재 페이지를 다시 열어요. 프로필마다 쿠키와 로그인 세션이 따로 있어서, 사이트에서 보이는 계정이 달라질 수 있어요. 폼에 입력한 텍스트처럼 페이지에서 아직 제출하지 않은 내용은 페이지가 다시 로드되면서 사라질 수 있어요.

## 페이지를 스페이스에서 열기

**[스페이스]에서 열기** 컨트롤은 Kiosk 툴바 오른쪽에 있어요.

- 컨트롤의 기본 영역을 클릭하면 일반 Phi 윈도우에서 마지막으로 사용한 스페이스로 페이지가 이동해요.
- 화살표를 클릭하고 스페이스를 선택하면 페이지를 다른 곳으로 옮길 수 있어요.
- 기본 단축키에서는 **⌘O**를 누르면 기본 동작이 실행되어 페이지가 현재 스페이스로 이동해요.

페이지는 선택한 스페이스의 일반 탭이 돼요. 다른 스페이스로 옮기면 페이지가 다시 로드될 수 있으니, 작업 중인 내용을 먼저 제출하거나 저장하세요.

## Kiosk가 열리는 시점 선택하기

**설정 → 탐색**을 열고 **Kiosk**를 찾으세요.

- **외부 링크를 Kiosk에서 열기**는 Mail이나 메시지 같은 앱에서 온 링크를 각자의 Kiosk 윈도우로 보내요. 이 링크를 일반 Phi 윈도우에서 열고 싶으면 끄세요.
- **⌘⌥을 누른 채 클릭한 링크를 Kiosk에서 열기**를 켜 두면 Phi에서 Command와 Option을 누른 채 링크를 클릭해 Kiosk를 열 수 있어요. 그 제스처로 Kiosk가 열리는 것을 원하지 않으면 끄세요.

이 스위치들을 꺼도 링크의 오른쪽 클릭 메뉴에서 **Kiosk에서 열기** 항목이 사라지지는 않아요.
