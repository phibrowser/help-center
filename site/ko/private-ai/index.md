# 프라이빗 AI

Phi의 AI 기능은 기본적으로 **Phi Cloud**에서 실행돼요. **프라이빗 AI**를 쓰면 AI 작업 종류마다 누가 처리할지 하나씩 정할 수 있어요. Phi Cloud, 이 Mac에 다운로드한 모델, 또는 Ollama, LM Studio, OpenAI, OpenRouter처럼 직접 연결한 AI 제공자 중에서 고르면 돼요.

프라이빗 AI는 기본적으로 꺼져 있어요. 한 번도 켜지 않으면 모든 AI 기능이 평소처럼 동작하고 Phi Cloud를 사용해요.

## 어시스턴트, Phi Cloud, AI 제공자 {#assistant-phi-cloud-and-providers}

이 셋은 헷갈리기 쉬우니 먼저 구분해 두면 좋아요.

- **어시스턴트**는 내가 이름을 지어 준 그 존재예요. Phi의 에이전트로, 내가 무엇을 원하는지 파악하고 무엇을 할지 정해요. 페이지를 읽을 수도, 브라우저 스킬을 실행할 수도, 브라우저에서 직접 행동할 수도, 작업을 만들 수도 있어요. 어떤 모델을 쓰든 같은 어시스턴트이고, 대화, 메모리, 작업도 모델에 따라 바뀌지 않아요.
- **모델**은 어시스턴트가 생각할 때 빌려 쓰는 '두뇌'예요. 어시스턴트는 단계마다 필요한 내용을 모델에 보내고, 모델이 답해요.
- **AI 소스**는 그 모델이 어디에서 실행되는지를 정해요. 세 종류가 있어요.
  - **Phi Cloud**, Phi에 내장된 AI 서비스예요. 에이전트도 아니고 특정한 모델 하나도 아니에요. Phi가 연결하고 대신 관리해 주는 클라우드 모델 묶음이에요. Phi 로그인을 사용하고, API 키가 필요 없고, 모델을 고르라고 하지도 않아요.
  - **로컬 모델**, 이 Mac에 다운로드해서 이 Mac에서 실행되는 모델이에요.
  - **내 제공자**, 내 주소, 계정, API 키로 직접 연결하는 AI 서비스예요.

그러니까 Phi Cloud는 Ollama나 OpenAI와 같은 자리에 있어요. '어시스턴트의 모델은 어디에서 실행되나?'에 대한 답 중 하나예요. 차이는 Phi Cloud는 내장되어 있어서 바로 동작하고, 나머지는 직접 설정해야 한다는 점이에요.

### 소스 비교 {#comparing-sources}

|                          | Phi Cloud                                                   | 로컬 모델                                            | 내 로컬 제공자(Ollama, LM Studio)             | 내 클라우드 제공자(OpenAI, OpenRouter, Codex 등) |
| ------------------------ | ----------------------------------------------------------- | ---------------------------------------------------- | --------------------------------------------- | ------------------------------------------------ |
| 필요한 것                | Phi 로그인 외에는 없음                                      | 설정 한 번(이때 모델을 다운로드해요)                 | Ollama 또는 LM Studio 설치 및 실행            | 그 서비스의 계정 또는 API 키                     |
| 콘텐츠가 가는 곳         | Phi를 거쳐 Phi가 사용하는 모델 제공자로                     | 아무 데도 가지 않음. 이 Mac에 남아요                 | 내가 설정한 주소. 보통 이 Mac이나 내 네트워크 | 내 Mac에서 그 서비스로 바로                      |
| 어느 계정으로 도착하는지 | Phi의 계정. 모델 제공자에게는 내가 누구인지 전달되지 않아요 | 해당 없음                                            | 해당 없음                                     | 내 계정 또는 키로                                |
| 비용                     | Phi에 포함, [사용량 한도](/ko/ai/#usage-limits) 안에서      | 무료. 이 Mac의 RAM과 처리 능력을 사용해요            | 무료. 실행하는 컴퓨터의 자원을 사용해요       | 그 서비스의 요금                                 |
| Phi 사용량 한도에 포함   | 예                                                          | 아니요                                               | 아니요                                        | 아니요                                           |
| 오프라인에서 동작        | 아니요                                                      | 예                                                   | 이 Mac에서 실행할 때는 예                     | 아니요                                           |
| 품질                     | 일정하고 모든 작업에 적합                                   | 모델 크기에 따라 다르고, 보통 클라우드 모델보다 낮음 | 고른 모델에 따라 다름                         | 고른 모델에 따라 다름                            |

Phi Cloud가 콘텐츠를 어떻게 다루는지는 [개인정보 보호 및 데이터](/ko/privacy/)를 참고하세요. 내 클라우드 제공자를 쓸 때는 그 제공자의 개인정보 처리방침이 적용돼요.

## Phi가 내 제공자를 사용할 때 {#when-phi-uses-your-provider}

제공자를 추가하는 것만으로는 아무것도 바뀌지 않아요. Phi는 다음 두 가지가 모두 충족될 때만 그 제공자를 사용해요.

1. **프라이빗 AI → AI 작업**에서 그 제공자의 모델 하나를 어떤 작업의 소스로 골랐어요.
2. **프라이빗 AI** 스위치가 켜져 있어요.

바꾸지 않은 작업은 계속 Phi Cloud를 사용해요. 프라이빗 AI를 끄면 모든 작업이 즉시 Phi Cloud로 돌아가지만, 내가 고른 설정은 남아 있어서 다시 켜면 설정을 다시 하지 않아도 그대로 복원돼요.

## 작업마다 소스 고르기 {#choosing-a-source-for-each-task}

프라이빗 AI는 전부 아니면 전무가 아니에요. 작업마다 따로 정하고, 페이지 맨 위에 Phi Cloud를 쓰지 않는 작업이 몇 개인지 표시돼요. 예를 들면 **AI 작업 4개 중 2개를 프라이빗 AI로 실행 중**처럼요.

| AI 작업         | 다루는 범위                                | 고를 수 있는 소스                                  |
| --------------- | ------------------------------------------ | -------------------------------------------------- |
| **채팅**        | 사이드바와 Phi Chat의 답변                 | Phi Cloud, 로컬 모델, 내 제공자, Codex             |
| **메모리**      | 브라우징 메모리, 요약 같은 백그라운드 작업 | Phi Cloud, 로컬 모델, 내 제공자, Codex             |
| **웹 작업**     | 브라우저에서 행동하는 어시스턴트, 자동화   | Phi Cloud, 로컬 모델, 내 제공자, Codex             |
| **데이터 검색** | 연결한 데이터 검색                         | Phi Cloud 또는 Phi가 다운로드하는 로컬 검색 모델만 |

이 밖에도 몇 가지 항목이 함께 있어요.

- **비전 대체 모델.** 작업에 고른 모델이 이미지를 읽지 못하면, 이미지는 여기서 정한 모델로 대신 가요. 처음에는 **설정되지 않음**이에요.
- **AI 탭 정리**는 macOS의 Apple Intelligence가 처리하고 바꿀 수 없어요. Apple Intelligence가 없는 Mac에서는 나타나지 않아요.
- **이미지 생성**은 항상 Phi Cloud를 사용해요.

작업을 다른 소스로 바꾸면 Phi가 먼저 그 모델을 테스트해요. 테스트에 실패하면 작업은 이전 소스로 돌아가고, 그 이유를 알려 줘요.

채팅이 Phi Cloud가 아닌 소스를 쓰게 되면 채팅에 **프라이빗 AI를 사용하고 있어요**가 표시돼요. 답변 품질이 온라인 모델과 다를 수 있기 때문이에요.

## 프라이빗 AI 켜기 {#turning-on-private-ai}

프라이빗 AI 설정으로 들어가는 길은 두 가지예요.

- [Phi Chat](/ko/phi-chat/)에서 상단 막대의 설정(톱니바퀴) 버튼을 클릭하고 **프라이빗 AI**를 선택하세요.
- 브라우저에서 **설정 → Phi 및 AI → Phi Sentinel → 프라이빗 AI**로 이동하세요. Phi Chat의 같은 페이지가 열려요.

스위치를 처음 켜면 Phi가 이 Mac에서 로컬 모델을 실행할 수 있는지 확인해요.

- **실행할 수 있으면** 설정 창에 다운로드 크기, 모델이 실행 중에 쓰는 대략적인 RAM 용량, 이 Mac으로 옮겨 올 작업이 나와요. **설정 시작**을 클릭하면 Phi가 로컬 런타임을 설치하고, 모델을 다운로드하고, 실행한 다음 확인해요. 창을 **최소화**하고 설정이 백그라운드에서 계속 진행되게 둘 수 있어요. 설정이 끝날 때까지 모든 AI 기능은 계속 Phi Cloud를 사용해요.
- **실행할 수 없으면** 창에 그 이유가 나와요. 그래도 **내 AI 서비스 사용**을 클릭해서 로컬 모델 없이 내 제공자를 연결할 수 있어요.

### 필요한 사양 {#requirements}

| 항목             | 요구 사항                                             |
| ---------------- | ----------------------------------------------------- |
| 칩               | Apple Silicon. Intel Mac은 로컬 모델을 실행할 수 없음 |
| RAM              | 16GB 이상                                             |
| 디스크 여유 공간 | 10GB 이상, 그리고 다운로드 크기보다 최소 2GB 더       |

내 제공자만 연결한다면, 예를 들어 내 네트워크의 다른 컴퓨터에 있는 Ollama나 OpenAI만 쓴다면 이 사양은 해당되지 않아요.

### 설정이 설치하는 것 {#what-setup-installs}

현재 설정은 모델 두 개를 다운로드하고, 두 모델은 실행 중에 합쳐서 약 7GB의 RAM을 사용해요.

- **Gemma 4 E4B (4-bit)**, **메모리**용이에요.
- **BGE-M3**, **데이터 검색**용이에요.

**채팅**과 **웹 작업**은 Phi Cloud에 남아요. 이 둘에는 긴 컨텍스트와 도구 호출을 안정적으로 처리하는 모델이 필요해서, Phi는 200억 파라미터 이상의 로컬 모델이 있을 때만 이 둘을 자동으로 이 Mac으로 옮겨요. 설정이 다운로드하는 Gemma 모델은 약 40억 파라미터예요. 백그라운드 작업에는 좋지만 대화를 이끌기에는 부족해요. 그래도 테스트를 통과하기만 하면 **AI 작업**에서 채팅을 이 모델로 직접 바꿀 수 있어요. 설정이 끝나면 이제 어떤 작업이 이 Mac에서 실행되는지 정확히 알려 줘요.

설정 후에도 메모리가 관련 항목을 찾는 데 쓰는 인덱스는 여전히 Phi Cloud에서 만들어져요. 그것도 이 Mac에서 처리하고 싶다면 **데이터 검색**에서 로컬 모델을 한 번 직접 고르세요. 그러면 둘 다 이 Mac으로 옮겨 와요.

## Ollama 또는 LM Studio 연결하기 {#connecting-ollama-or-lm-studio}

Ollama와 LM Studio는 내 컴퓨터에서 오픈 모델을 실행하는 무료 앱이에요. 둘 다 Phi에 제공자로 내장되어 있고, 기본 주소는 Ollama가 `http://127.0.0.1:11434`, LM Studio가 `http://127.0.0.1:1234/v1`이에요.

1. Ollama 또는 LM Studio를 설치해서 열고, 모델을 다운로드하세요([권장 모델](#recommended-models) 참고).
   - Ollama: 터미널에서 `ollama pull <model>`을 실행하세요. 예를 들면 `ollama pull gpt-oss:20b`예요.
   - LM Studio: 앱에서 모델을 검색해 다운로드하고, **Developer** 페이지에서 로컬 서버를 시작하세요.
2. Phi Chat에서 **설정 → AI 제공자**를 열고 **Ollama** 또는 **LM Studio**를 선택하세요.
3. **이 제공자 사용**을 켜세요. 서비스가 내 네트워크의 다른 컴퓨터에서 실행 중이라면 **Base URL**을 그 컴퓨터의 주소로 바꾸세요.
4. **불러오기**를 클릭해서 모델 목록을 가져오세요. **모델 액세스**에서 **모든 모델 허용**을 고르거나, **선택한 모델만**을 고르고 원하는 모델에 체크하세요.
5. 모델을 고르고 **테스트**를 클릭한 다음, 연결에 성공했다고 나오면 **변경 사항 저장**을 클릭하세요.
6. **프라이빗 AI**로 돌아가서 **AI 작업**에서 옮기려는 작업(예: **채팅**)에 그 모델을 고르세요.
7. **프라이빗 AI** 스위치를 켜세요.

OpenAI 호환 API를 제공하는 다른 서비스라면 **사용자 지정 제공자 추가**를 사용하고, 이름, Base URL, 그리고 서비스에 필요하면 API 키를 입력하세요.

알아 둘 점:

- Base URL은 `http`와 `https` 둘 다 쓸 수 있고, 로컬 서비스는 보통 키가 필요 없어서 API 키는 선택 사항이에요. `http` 주소로 보낸 키는 암호화되지 않은 채 전송되니, 내 Mac이나 내 네트워크에 있지 않은 곳에는 `https`를 사용하세요.
- Ollama나 LM Studio는 계속 열려 있어야 해요. 컴퓨터가 잠자기 상태가 되거나 앱이 종료되면, 영향을 받는 작업은 [로컬 소스를 사용할 수 없을 때의 설정](#when-a-local-source-is-unavailable)을 따라요.
- 웹 작업과 긴 대화에는 텍스트가 많이 담겨요. 답변이 중간에 끊겨 오거나 어시스턴트가 동작을 끝내지 못하면 컨텍스트 길이를 늘리세요. 예를 들어 32K로요. Ollama는 설정의 **Context length**에서, LM Studio는 모델을 불러올 때 **Context Length**에서 바꿔요. 컨텍스트가 길수록 RAM을 더 많이 써요.
- 내 네트워크의 다른 컴퓨터가 Ollama에 접근하려면, 그 컴퓨터의 Ollama가 네트워크 주소에서 연결을 받도록 해야 해요(`OLLAMA_HOST=0.0.0.0`).

## 권장 모델 {#recommended-models}

오픈 모델은 빠르게 바뀌니 아래 이름은 예시로 봐 주세요. 같은 크기의 더 새로운 모델도 똑같이 잘 동작해요. 가장 중요한 건 두 가지예요. 모델이 충분히 커야 하고, RAM에 들어가야 해요. 모델은 실행 중에 대략 다운로드 크기만큼에 몇 GB를 더한 RAM을 쓰고, macOS와 다른 앱에도 공간이 필요해요.

| Mac의 RAM  | 제안                                                                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 16GB       | 설정을 사용해 메모리와 데이터 검색은 이 Mac에서 실행하고, 채팅과 웹 작업은 Phi Cloud에 두세요. 이 RAM 용량으로는 채팅에 맞는 모델을 담을 수 없어요 |
| 32GB       | 채팅용으로 200억 파라미터급 모델을 실행할 수 있어요. 예를 들면 **gpt-oss-20b**(Ollama: `gpt-oss:20b`)나 **Qwen3 30B**(Ollama: `qwen3:30b`)예요     |
| 64GB       | 더 안정적인 300억 파라미터급 모델을 고를 수 있어요. 예를 들면 **Qwen3 32B**(Ollama: `qwen3:32b`)이고, 더 긴 컨텍스트를 쓸 여유도 있어요            |
| 128GB 이상 | 1000억 파라미터급 모델을 실행할 수 있어요. 예를 들면 **gpt-oss-120b**(Ollama: `gpt-oss:120b`)이고, 클라우드 모델에 더 가까워져요                   |

작업별로 보면:

- **채팅과 웹 작업:** 200억 파라미터 이상이고 도구 호출(함수 호출)을 지원하는 모델을 고르세요. 웹 작업은 도구 호출에 가장 많이 기대고, 작은 모델은 여기서 자주 실패해요.
- **비전 대체 모델:** 이미지를 읽을 수 있는 모델을 고르세요. 예를 들면 Gemma 3 12B(Ollama: `gemma3:12b`)나 Qwen2.5-VL 7B(Ollama: `qwen2.5vl:7b`)예요.
- **메모리:** 설정에서 받은 Gemma 모델로 충분하고, 보통은 바꿀 이유가 없어요.
- **데이터 검색:** Phi가 다운로드하는 로컬 검색 모델 또는 Phi Cloud만 쓸 수 있어요.

아무리 커도 로컬 모델은 보통 Phi Cloud 뒤에 있는 최상위 모델에 미치지 못해요. 콘텐츠를 Mac에 두는 것보다 답변 품질이 더 중요하다면, 채팅과 웹 작업은 Phi Cloud에 두는 것이 합리적인 선택이에요.

## 로컬 소스를 사용할 수 없을 때 {#when-a-local-source-is-unavailable}

로컬 모델, Ollama, LM Studio가 응답하지 않으면 Phi는 **로컬 또는 자체 호스팅 소스를 사용할 수 없을 때** 설정을 따라요.

- **Phi Cloud로 자동 전환(기본값)**. 영향을 받는 작업이 당분간 Phi Cloud를 사용해서 AI 기능은 계속 동작해요. 이는 그동안 그 작업의 콘텐츠가 클라우드로 간다는 뜻이기도 해요.
- **영향받는 AI 기능 일시 중지(클라우드로 데이터를 절대 보내지 않음)**. 로컬 소스가 다시 응답할 때까지 영향을 받는 기능이 일시 중지돼요.

프라이빗 AI를 켠 이유가 콘텐츠를 이 Mac에 두기 위해서라면 두 번째 옵션을 고르세요.

이 설정은 로컬 소스와 자체 호스팅 소스에만 적용돼요. OpenAI, OpenRouter, Codex 같은 클라우드 제공자가 실패하면 Phi는 Phi Cloud로 전환하지 않아요.

문제가 생기면 프라이빗 AI 페이지에 **확인 필요**가 표시되고, **로컬 서비스 다시 시작** 버튼이 함께 나와요.

## Codex 사용하기 {#using-codex}

ChatGPT를 구독하고 있고 이 Mac에서 Codex에 로그인해 두었다면, 그 구독을 AI 제공자로 사용할 수 있어요. **설정 → AI 제공자 → Codex**로 가서 **연결**을 클릭하세요. Phi는 Codex가 이미 보관하고 있는 로그인 정보를 사용하고, 자격 증명을 복사하지 않아요.

- 먼저 Codex를 설치하고 터미널에서 `codex login`을 실행하세요. 키체인에 저장된 Codex 로그인은 Phi가 읽을 수 없어요.
- Codex는 채팅, 메모리, 웹 작업, 비전 대체 모델에 쓸 수 있지만 데이터 검색에는 쓸 수 없어요.
- Codex가 하는 일은 ChatGPT 구독의 한도에 포함돼요. 한도를 다 쓰거나 로그인이 더 이상 동작하지 않아도 Phi는 다른 소스로 전환하지 않아요.

## 끄기와 재설정 {#turning-off-and-resetting}

- **프라이빗 AI 끄기**는 스위치로 해요. 모든 작업이 즉시 Phi Cloud로 돌아가고, 다운로드한 모델과 내가 고른 설정은 남아요.
- **제공자 제거**는 그 제공자 페이지의 **제공자 제거**로 해요. 그 제공자를 쓰던 작업은 Phi Cloud로 돌아가요.
- **재설정**은 **고급 설정**의 **AI 설정 재설정**으로 해요. 모든 작업을 Phi Cloud로 되돌리고, 내 제공자와 그 API 키를 지우고, 로컬 모델을 삭제해요.
