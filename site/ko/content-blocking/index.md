# 콘텐츠 차단

Phi는 Chromium을 기반으로 하며 Brave의 오픈소스 콘텐츠 필터링 엔진을 사용해요. 광고, 추적기, 쿠키 배너를 각각 따로 차단할 수 있어요.

## Phi가 차단할 수 있는 항목

| 설정               | 기능                                                                    |
| ------------------ | ----------------------------------------------------------------------- |
| **광고 차단**      | 규칙과 일치하는 광고와 광고 요청을 차단해요.                            |
| **추적기 차단**    | 규칙과 일치하는 추적 스크립트, 비콘, 분석 요청을 차단해요.              |
| **쿠키 배너 차단** | 규칙과 일치하는 쿠키 안내를 숨겨요. 동의 옵션을 대신 선택하지는 않아요. |

세 스위치는 처음에는 꺼져 있어요. 각 [프로필](/ko/spaces/)에 속하므로 프로필마다 다른 설정과 필터 목록을 사용할 수 있어요.

콘텐츠 차단은 필터 목록의 규칙을 사용해요. 일반 광고나 추적기, 쿠키 안내, 특정 지역의 사이트를 대상으로 하는 목록과 직접 추가한 규칙을 사용할 수 있어요. Phi가 모든 광고나 추적기를 차단하지는 못하고, 규칙이 적용되면 일부 사이트의 동작이 달라질 수 있어요.

## 콘텐츠 차단 켜기

1. **설정 → 프로필**을 열어요.
2. 프로필을 선택하고 **콘텐츠 차단**을 찾아요.
3. 원하는 카테고리를 켜요.
4. Phi가 필터 목록을 선택하라고 하면 사용할 목록을 선택한 뒤 **완료**를 눌러, 아직 Mac에 없는 선택된 목록을 다운로드해요.

카테고리 옆의 규칙 선택 버튼을 열면 언제든 목록을 바꿀 수 있어요. 다운로드 동작을 선택해야 목록 다운로드가 시작돼요. **다운로드된 목록 업데이트**는 Mac에 있는 목록의 최신 버전을 가져와요.

규칙 선택기에서 <strong>필터 추가…</strong>를 선택하면 URL로 목록을 추가하거나 규칙을 직접 붙여넣을 수 있어요. 사용자 지정 목록은 해당 프로필의 세 카테고리 모두에 적용돼요.

다운로드한 필터 목록은 여러 프로필에서 함께 사용할 수 있어요. 목록 선택, 사용자 지정 목록, 사이트 예외는 프로필마다 따로 저장돼요.

## 특정 사이트에서 콘텐츠 허용하기

주소 표시줄 메뉴를 열고 **이 사이트에서 콘텐츠 차단**을 선택하면 현재 프로필에서 보고 있는 사이트의 차단을 끄거나 다시 켤 수 있어요. 이 변경은 해당 프로필의 사이트 예외에만 적용돼요. 다른 사이트의 카테고리는 계속 켜져 있어요.

시크릿 창에서는 이 메뉴 항목을 사용할 수 없어요.

## 사이트가 제대로 작동하지 않을 때

일부 사이트는 필터 목록이 차단하는 리소스를 필요로 해요. 주소 표시줄 메뉴에서 **이 사이트에서 콘텐츠 차단**을 선택해 예외를 설정한 다음 페이지를 새로고침해요. **설정 → 프로필**에서 카테고리를 끄거나 사용할 필터 목록을 바꿀 수도 있어요.

필터 목록은 모든 광고, 추적기, 쿠키 안내를 찾아내지 못해요. 쿠키 배너 차단은 규칙과 일치하는 페이지 요소를 숨겨요. 쿠키에 동의하거나 동의 안내를 닫아 주지는 않아요.
