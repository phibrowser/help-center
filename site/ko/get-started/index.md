# 시작하기

Phi Browser는 macOS에서 실행돼요(Apple Silicon, macOS 14 이상). 아래 두 방법 중 하나로 설치한 다음, 첫 실행 과정을 따라가 보세요.

## Phi 설치하기

### 공식 사이트에서 다운로드

[Phi 다운로드 페이지](https://phibrowser.com/download/)에서 `.dmg` 파일을 다운로드하고, 열어서 Phi를 응용 프로그램 폴더로 드래그하세요.

### Homebrew로 설치

[Homebrew](https://brew.sh/)를 사용한다면 다음 명령으로 Phi를 설치할 수 있어요:

```sh
brew install --cask phibrowser/tap/phi
```

이 명령은 `phibrowser/tap` 저장소를 자동으로 추가(tap)하고 Phi cask를 설치해요. 업데이트는 Phi가 직접 처리하므로 Homebrew를 통해 업그레이드할 필요는 없어요.

## 첫 실행

Phi를 처음 열면 온보딩이 설정을 도와줘요:

- **레이아웃 모드 선택하기**: 성능, 균형, 여유 중 하나를 고르세요. 언제든지 바꿀 수 있으니, 지금 브라우징하는 방식과 가장 가깝게 느껴지는 모드를 고르면 돼요. 각 모드의 의미는 [레이아웃과 탐색](/ko/layouts/)을 참고하세요.
- **어시스턴트 만나기**: 브라우저에 들어가면 새 탭 위쪽의 배너가 어시스턴트를 알아가 보라고 안내해요. 이름을 지어 주면 그에 어울리는 아바타를 스스로 만들어서, 평범한 챗봇 같은 느낌 대신 자기만의 정체성을 가져요. 이 단계는 건너뛰었다가 나중에 돌아와도 돼요.
- **AI는 기본으로 켜져 있어요**: Phi의 AI 기능은 설치 직후부터 켜져 있어요. 순수한 브라우저를 원한다면 나중에 **설정 → Phi AI**에서 끌 수 있어요.

## 다른 브라우저에서 넘어오시나요?

Chrome이나 Safari에 익숙하다면 **여유 모드**로 시작하는 것이 가장 자연스러워요. Chrome, Safari, Arc, Dia 사용자를 위한 더 자세한 이전 안내는 [Phi로 전환하기](/ko/switching-to-phi/)를 참고하세요.
