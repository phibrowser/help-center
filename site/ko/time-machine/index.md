# Time Machine 백업

Time Machine은 업데이트를 위한 Phi의 안전망이에요. 특정 주요 업데이트 전에 Phi가 현재 버전과 데이터의 스냅샷을 자동으로 저장해 두므로, 새 릴리스가 기대와 다르게 동작하면 쓰던 버전으로 되돌아갈 수 있어요. 한 번에 많은 것이 바뀌는 드문 업데이트를 위한 장치예요.

## 무엇이고, 무엇이 아닌가

Phi의 Time Machine은 **버전 롤백** 기능이지, 범용 백업 도구가 아니에요. 혼동하기 쉬운 것이 두 가지 있어요.

- Apple의 Time Machine이 **아니에요**. Mac을 백업하지 않고, 같은 이름의 시스템 기능과는 아무 관련이 없어요.
- 브라우징을 지속적으로, 일정에 따라 백업하는 것도 **아니에요**. Phi는 매일 스냅샷을 만들지 않고, 임의의 시점을 고르게 해 주지도 않아요. 스냅샷은 평소보다 위험이 큰 업데이트 직전에, 가끔, 자동으로 만들어져요.

새 Mac으로 옮기거나 실험해 보기 전에 사본을 남겨 두는 등 직접 관리하는 백업을 원한다면 **사용자 데이터 내보내기**를 대신 사용하세요(아래 [내 데이터 직접 내보내기](#exporting-your-own-data) 참고).

## 스냅샷이 만들어지는 시점

Time Machine 스냅샷은 직접 시작하는 것이 아니에요. Phi가 조건에 해당하는 업데이트로 진입하기 직전에 자동으로 하나 만들고, 그런 업데이트마다 한 번만 만들어요. 대부분의 업데이트에서는 아예 만들어지지 않아요. 스냅샷이 만들어지면 거기에는 이전 버전에 속한 Phi 데이터, 즉 북마크, 스페이스, 고정된 탭, 설정, 메모리, 브라우징 상태가 담기고, 어느 앱 버전과 짝을 이루는지에 대한 기록도 함께 들어가요. 그래서 롤백은 어긋난 조합이 아니라 일관된 상태를 복원해요. 앱 자체는 스냅샷에 저장되지 않고 복원 과정에서 다운로드돼요.

스냅샷은 **내 Mac에 로컬로** 저장돼요. 클라우드에 업로드되지 않고, 계정에 묶이지 않으며, 다른 Mac으로 옮길 수 없어요.

## 이전 버전으로 되돌아가기

1. **도움말** 메뉴를 열고 **Time Machine 백업**을 찾으세요.
2. 사용 가능한 스냅샷은 버전, 빌드, 날짜로 표시돼요. 예를 들면 _Phi 1.6 (590) on 2026.6.11_ 같은 식이에요. 스냅샷이 하나도 없으면 메뉴에 **사용 가능한 백업 없음**이 표시돼요.
3. 원하는 스냅샷을 선택하세요. Phi가 **"Time Machine 백업을 복원할까요?"** 확인 창을 표시하면서 다음 안내를 함께 보여 줘요. _Phi를 종료한 다음 해당 백업을 복원하고, 현재 앱과 선택한 사용자 데이터가 대체돼요._
4. **복원**을 선택하세요. Phi가 이전 버전을 다운로드하고, 현재 앱과 그에 맞는 데이터를 교체한 다음, 복원된 버전으로 재실행돼요.

롤백은 이전 버전을 내려받기 때문에 복원하는 동안 인터넷 연결이 필요해요. 복원은 끝까지 완료되거나 중단되더라도 안전하게 회복되도록 설계되어 있어서, 복원 도중 종료되거나 충돌이 나도 Phi가 망가진 상태로 남지 않아요.

## 내 데이터 직접 내보내기 {#exporting-your-own-data}

Time Machine은 업데이트 롤백을 담당해요. 직접 만들고 원하는 방식으로 보관하는 백업이 필요하면 **도움말** 메뉴의 **사용자 데이터 관리**를 사용하세요.

- **사용자 데이터 내보내기…** 항목은 Phi 데이터를 어디에나 보관할 수 있는 파일 하나로 저장해요.
- **사용자 데이터 가져오기…** 항목은 이전에 내보낸 파일로 현재 Phi 데이터를 교체한 다음 재실행해요.

새 Mac으로 옮기거나 개인 사본을 보관할 때 맞는 도구이고, Time Machine이 의도적으로 다루지 않는 부분이에요.

## Phi의 다른 기능과의 관계

Time Machine 스냅샷에는 [스페이스 및 프로필](/ko/spaces/)과 [메모리](/ko/memory/)를 떠받치는 데이터가 담기므로, 롤백하면 그 데이터가 스냅샷 시점의 상태로 돌아가요. 모든 것은 [개인정보 보호 및 데이터](/ko/privacy/)에서 설명하는 Phi의 로컬 우선 원칙에 따라 내 Mac에 남아요.
