# Phi Browser 빠른 팁

이 페이지는 화면만 봐서는 알기 어려운 Phi의 제스처와 단축키를 모아 놓았어요. 여기 적힌 키보드 단축키는 기본값이에요. **설정 → 단축키**에서 바꿀 수 있어요.

## 단축키 한눈에 보기

| 동작                               | 단축키 또는 제스처                                                        |
| ---------------------------------- | ------------------------------------------------------------------------- |
| Split View 만들기                  | 탭, 고정된 탭, 북마크 또는 지원되는 웹 링크를 Option(⌥) 키를 누른 채 클릭 |
| 링크를 Peek에서 미리 보기          | 웹 링크를 Shift(⇧) 키를 누른 채 클릭                                      |
| 최근 사용한 탭 간 전환             | Control(⌃) + Tab                                                          |
| 역순으로 전환                      | Control(⌃) + Shift(⇧) + Tab                                               |
| 현재 페이지 URL 복사               | Command(⌘) + Shift(⇧) + C                                                 |
| 열려 있는 탭 검색                  | Command(⌘) + Shift(⇧) + A                                                 |
| 이전 또는 다음 스페이스로 이동     | Command(⌘) + Option(⌥) + ← 또는 →                                         |
| 처음 아홉 개 스페이스 중 하나 열기 | Control(⌃) + 1 ~ 9                                                        |

## Split View 만들기

- Option(⌥) 키를 누른 채 다른 탭, 그룹 안의 탭, 고정된 탭, 북마크 또는 지원되는 웹 링크를 클릭하세요. Phi가 현재 페이지 옆에 나란히 배치해요.
- 탭, 고정된 탭 또는 북마크 하나를 현재 페이지의 왼쪽이나 오른쪽으로 드래그하세요. 놓은 쪽에 해당 페이지가 표시돼요.
- 고정되지 않은 기존 Split View의 한쪽 패널 위에 항목을 놓으면 그 패널이 교체돼요.

## 저장된 URL로 되돌아가기

고정된 탭이나 북마크는 처음 저장한 URL에서 다른 페이지로 이동해 있을 수 있어요. 지금 보고 있는 페이지를 잃지 않고 되돌아갈 수 있어요.

- 고정된 탭을 두 번 클릭하면 저장된 URL로 돌아가요.
- 북마크의 파비콘을 클릭하면 저장된 URL로 돌아가요.
- 두 제스처 모두 Command(⌘) 키를 누른 채 사용하면, 저장된 URL을 복원하기 전에 현재 페이지를 별도 탭으로 남겨 둬요.

## 그룹 개요 사용하기

탭 그룹 헤더를 클릭하면 그룹 개요가 열려요. 각 페이지의 스냅샷이 표시되고, Split View는 하나로 합쳐진 카드로 보여요.

그룹 개요에서 페이지로 전환하거나, 페이지를 닫거나, 새 탭을 만들거나, 그룹의 이름과 색상을 바꿀 수 있어요. 그룹 개요가 열린 상태에서 주소 표시줄을 사용하면 새 탭이 그 그룹에 들어가요.

탭 그룹 전체를 북마크 영역으로 드래그하면 북마크 폴더로 바뀌어요. Phi는 탭 순서를 유지한 채 그룹을 해제하지만, 열려 있던 탭은 그대로 열려 있어요.

## 여러 탭과 북마크 함께 다루기

- 일반 탭과 북마크를 Command(⌘) 키를 누른 채 클릭하면 하나씩 선택할 수 있어요.
- Shift(⇧) 키를 누른 채 클릭하면 범위로 선택돼요.
- 선택한 항목으로는 탭 그룹 만들기, 북마크 폴더에 추가, 다른 스페이스로 이동 또는 복제, 닫기 같은 동작을 할 수 있어요.
- 선택된 항목 아무거나 드래그하면 선택 전체가 함께 이동해요. Split View의 양쪽은 함께 붙어 다녀요.
- Escape 키를 누르면 선택이 해제돼요.

## 전환, 검색, 복사

Control(⌃) + Tab은 윈도우에 놓인 탭 순서가 아니라 최근에 사용한 순서를 따라요.

- 한 번 누르면 현재 탭과 직전 탭 사이를 오가요.
- 누르고 있거나 반복해서 누르면 최근 사용한 탭이 최대 다섯 개까지 표시돼요.
- Shift(⇧)를 더하면 목록을 역순으로 이동해요.
- Command(⌘) + Shift(⇧) + A를 누르면 열려 있는 모든 탭을 검색할 수 있어요.
- Command(⌘) + Shift(⇧) + C를 누르면 현재 탭의 URL이 복사돼요.

## 스페이스마다 다르게 꾸미기

**설정 → 스페이스**를 열고 스페이스를 선택하세요.

- Phi에 내장된 아이콘 중에서 고르거나 이모티콘을 사용하세요.
- 테마 색상을 고르고 채도를 조절하세요.

스페이스는 각자 자기 아이콘과 테마를 유지해요. 스페이스를 전환하면 그 스페이스에 지정한 모습이 적용될 뿐, 다른 스페이스는 바뀌지 않아요.

## 스페이스 간 이동

- Command(⌘) + Option(⌥) + ← 또는 →를 누르면 이전 또는 다음 스페이스로 이동해요.
- Control(⌃) + 1부터 9까지를 누르면 처음 아홉 개 스페이스 중 하나가 바로 열려요.

## URL 규칙으로 사이트 보내기

메뉴 막대에서 **스페이스 → URL 규칙…** 명령을 선택하거나, **설정 → 탐색**을 열고 <strong>URL 규칙 관리…</strong>를 클릭하세요. 규칙은 **도메인 접미사**, **도메인**, **도메인 포함**, **URL** 기준으로 일치 여부를 판단해요.

일치한 페이지는 일반 스페이스, 시크릿 모드 또는 Kiosk로 보낼 수 있어요. 페이지를 옮기기 전에 Phi가 물어보길 원하면 **매번 묻기**를 선택하세요. 여러 규칙이 동시에 일치하면 가장 구체적인 규칙이 적용돼요.

::: tip 일반 스페이스 라우팅은 쿠키를 분리하지 않아요
사이트를 일반 스페이스로 보내도 쿠키와 로그인 세션이 분리되지는 않아요. 그 분리가 필요하면 대상 스페이스를 서로 다른 프로필에 지정하세요.
:::

## 화면 속 화면으로 동영상 계속 보기

탭이나 스페이스를 전환할 때 재생 중인 동영상을 Phi가 별도 윈도우로 띄울 수 있어요. **설정 → 일반 → 자동 화면 속 화면**에서 동작을 선택하세요.

| 모드                | 동작                                                                            |
| ------------------- | ------------------------------------------------------------------------------- |
| **끔**              | 화면 속 화면을 자동으로 열지 않아요. 수동 화면 속 화면은 계속 사용할 수 있어요. |
| **일반**            | 탭이나 스페이스를 전환하면 재생 중인 동영상을 별도 윈도우로 띄워요.             |
| **가장자리에 두기** | 동영상을 별도 윈도우로 띄운 다음, 클릭할 때까지 화면 가장자리에 붙여 둬요.      |

화면 속 화면 윈도우를 옮기거나 크기를 조절하면, 다음에 그 사이트가 화면 속 화면을 열 때 Phi가 위치와 크기를 기억해요. 이 정보는 일반 프로필에 사이트별로 저장돼요. 시크릿 스페이스는 저장하지 않아요. 저장해 둔 디스플레이가 더 이상 연결되어 있지 않으면 기본 위치를 사용해요.

열려 있는 화면 속 화면 윈도우를 직접 붙여 두려면, 포인터를 그 위로 옮긴 다음 **화면 가장자리에 고정**이라고 표시된 아래쪽 화살표를 클릭하세요. Phi가 윈도우를 가장 가까운 화면 가장자리에 밀어 넣고 핸들만 보이게 남겨요. 핸들을 클릭하면 윈도우가 다시 돌아와요. 이 컨트롤은 자동 화면 속 화면이 **끔**으로 설정되어 있어도 동작해요.

## 지금 하는 작업에 대해 어시스턴트에게 묻기

- 텍스트를 선택하고 마우스 오른쪽 버튼으로 클릭한 다음 **[어시스턴트 이름]에게 …에 대해 묻기**를 선택하면 선택한 내용이 대화로 들어가요.
- 어시스턴트를 열면 기본적으로 현재 탭이 첨부돼요. 그 탭이 그룹에 속해 있으면 Phi가 그룹 전체를 첨부할 수도 있어요.
- 탭 그룹이나 Split View는 하나의 단위로 첨부할 수 있어요.

현재 탭을 첨부하지 않고 대화를 시작하려면 **설정 → Phi AI → AI 사이드바**에서 **새 대화에 현재 탭을 컨텍스트로 자동 추가**를 끄세요.

Phi Cloud를 사용할 때는 질문에 답하는 데 필요한 콘텐츠가 서드파티 모델 제공업체로 전송되어 처리돼요. 프라이빗 AI에서는 Mac 밖으로 나가지 않아요. 자세한 내용은 [개인정보 보호 및 데이터](/ko/privacy/)를 참고하세요.
