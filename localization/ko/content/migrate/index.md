# Arc 또는 Zen에서 마이그레이션하기

**다른 브라우저에서 마이그레이션…** 명령은 Arc나 Zen에서 쓰던 구성을 Phi에 그대로 다시 만들어요. 원래 브라우저의 프로필마다 Phi 프로필을, 스페이스마다 Phi 스페이스를 하나씩 만든 다음, 각 스페이스에는 북마크를, 각 프로필에는 고정 탭과 브라우징 데이터를 채워 넣어요. 끝나면 예전 사이드바가 Phi에 다시 만들어져 있어요.

마이그레이션은 새로 만들기만 해요. Phi에 이미 있는 프로필이나 스페이스를 바꾸거나, 합치거나, 지우는 일은 절대 없어요.

## 마이그레이션과 가져오기 {#migrate-or-import}

Phi에는 데이터를 옮겨 오는 명령이 두 가지 있고, **Phi** 메뉴(Apple 메뉴 옆의 굵게 표시된 앱 메뉴)에 나란히 있어요.

|                      | **다른 브라우저에서 가져오기...**           | **다른 브라우저에서 마이그레이션…**                         |
| -------------------- | ------------------------------------------- | ----------------------------------------------------------- |
| 하는 일              | 지금 있는 스페이스에 데이터를 추가해요      | 원래 브라우저를 그대로 본뜬 새 프로필과 스페이스를 만들어요 |
| 브라우저             | Chrome, Safari, Arc, Dia 또는 파일          | Arc와 Zen                                                   |
| 데이터가 들어가는 곳 | 현재 스페이스와 그 스페이스의 프로필        | 새로 만들어진 프로필과 스페이스                             |
| 직접 고르는 것       | 가져올 데이터 유형                          | 다시 만들 스페이스                                          |
| 기존 Phi 데이터      | 북마크와 방문 기록이 기존 데이터에 합쳐져요 | 건드리지 않아요                                             |

마음에 드는 Phi 구성이 이미 있고 거기에 북마크나 방문 기록을 더하고 싶다면 **가져오기**를 선택하세요. Arc나 Zen에서 옮겨 오는 중이고 스페이스를 하나하나 다시 만들지 않고 예전 모습 그대로 되찾고 싶다면 **마이그레이션**을 선택하세요. 가져오기는 [가져오기 및 내보내기](/ko/import-export/)에서 다뤄요.

## 시작하기 전에 {#before-you-start}

- **이 Mac에 해당 브라우저가 설치되어 있어야 해요.** 마이그레이션은 Arc나 Zen이 데이터를 보관하는 위치에서 직접 읽어요. 둘 다 설치되어 있지 않으면 **다른 브라우저에서 마이그레이션…** 항목이 흐리게 표시돼요.
- **Phi에 로그인하거나 게스트로 계속하세요.** 마이그레이션된 프로필과 스페이스는 Phi 계정에 속하기 때문에, 마법사는 시작하기 전에 첫 실행 과정을 먼저 마치라고 안내해요.
- **Zen은 먼저 종료하세요.** Phi는 Zen 파일의 복사본을 읽기 때문에, Zen이 아직 디스크에 저장하지 않은 내용은 빠지게 돼요. Zen이 실행 중이면 마법사가 알려 줘요.
- **Arc라면 키체인 요청이 뜰 거예요.** Arc는 쿠키를 암호화하기 때문에, macOS가 Phi에 Arc의 암호화 키를 사용하도록 허용할지 물어봐요. **항상 허용**을 선택하세요. 그렇지 않으면 macOS가 프로필마다 다시 물어봐요. 거부하면 그 프로필의 쿠키는 옮겨지지 않고 나머지만 옮겨지는데, 리포트에는 쿠키가 빠졌다는 표시가 나오지 않아요.
- **가져오기를 동시에 실행하지 마세요.** 마이그레이션이 진행되는 동안에는 **다른 브라우저에서 가져오기...** 항목이 흐리게 표시되고, 반대의 경우도 마찬가지예요.

## 마이그레이션 실행하기 {#running-a-migration}

1. **Phi** 메뉴를 열고 **다른 브라우저에서 마이그레이션…** 항목을 선택하세요. **Phi로 마이그레이션** 창이 열려요.
2. **Arc**나 **Zen**을 고르고 **계속**을 클릭하세요. 이 Mac에 설치된 브라우저만 목록에 나와요.
3. **만들어질 항목 확인** 아래의 미리보기를 살펴보세요. 원래 브라우저의 프로필별로 스페이스가 나열되고, _프로필 2개와 스페이스 5개를 만들 예정이에요._ 같은 요약이 표시돼요. 원하지 않는 스페이스는 체크를 해제하세요. 프로필은 그 안의 스페이스가 하나 이상 체크되어 있을 때만 만들어져요.
4. **마이그레이션 시작**을 클릭하세요. Phi가 프로필과 스페이스를 하나씩 만들면서 진행 상황을 보여 줘요. 몇 분 정도 걸릴 수 있어요. 그동안 계속 브라우징해도 되고, 새 스페이스가 지금 쓰고 있는 스페이스 위에 열리지는 않아요.
5. **마이그레이션 완료** 아래의 리포트를 읽어 보세요. 스페이스 이름 뒤에 **(으)로 이동**이 붙은 버튼을 클릭하면 첫 번째 새 스페이스로 전환되고, **완료**를 클릭하면 창이 닫혀요.

## 옮겨 오는 항목 {#what-comes-across}

구조는 두 브라우저 모두 같아요. 원래 브라우저의 프로필은 각각 Phi 프로필이 되고, 원래 브라우저의 스페이스는 각각 그 프로필에 연결된 Phi 스페이스가 돼요. 이름은 그대로 유지되고, Phi에 맞는 것이 있으면 색상과 아이콘도 유지돼요.

| 원래 브라우저의 항목                                                                 | Phi에서                                                                          |
| ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| Arc 프로필 또는 Zen 컨테이너(컨테이너가 없는 Zen 스페이스는 프로필 하나를 함께 써요) | 새 프로필                                                                        |
| Arc 또는 Zen 스페이스                                                                | 그 프로필 안의 새 스페이스                                                       |
| Arc 사이드바에 고정된 항목 또는 각 Zen 스페이스의 고정 탭(폴더 포함)                 | 그 스페이스의 북마크                                                             |
| Arc의 Favorites 또는 Zen의 에센셜(Essentials)                                        | [고정 탭 범위](/ko/bookmarks/#choose-a-pinned-tab-scope)에 따라 배치되는 고정 탭 |

각 프로필 아래의 브라우징 데이터는 브라우저에 따라 달라요.

| 데이터         | Arc                            | Zen    |
| -------------- | ------------------------------ | ------ |
| 최근 방문 기록 | 예                             | 예     |
| 쿠키           | 예, 키체인 접근을 허용한 경우  | 아니요 |
| 확장 프로그램  | Chrome 웹 스토어 확장 프로그램 | 아니요 |

알아 두면 좋은 제한 사항이 몇 가지 있어요.

- **열려 있는 탭은 옮겨지지 않아요.** 고정된 항목과 Favorites 또는 에센셜만 옮겨져요. 열어 두기만 하고 고정하지 않은 탭은 원래 브라우저에 남아요.
- **방문 기록은 최근 것만 옮겨지고, 전부 옮겨지지는 않아요.** 마이그레이션은 지금까지 방문한 모든 기록이 아니라 가장 최근의 방문 기록 항목만 가져와요.
- **확장 프로그램은 백그라운드에서 설치돼요.** Arc의 경우 리포트에 설치가 시작된 Chrome 웹 스토어 확장 프로그램 수가 표시돼요. 다른 곳에서 받은 확장 프로그램은 옮겨지지 않고, Zen의 Firefox 확장 프로그램은 Phi에서 실행할 수 없어요.
- **비밀번호와 결제 카드는 마이그레이션되지 않아요.**
- **Zen의 비공개 창 스페이스는 건너뛰어요.**
- **고정 탭에는 스페이스가 필요해요.** Phi는 만들 스페이스가 하나 이상 있을 때만 프로필을 만들어요. 어떤 Zen 스페이스도 사용하지 않는 Zen 컨테이너처럼 스페이스가 없는 원래 브라우저의 프로필은 건너뛰고, 그 프로필의 고정 탭 중 몇 개가 남겨졌는지 리포트에 표시돼요.

원래 브라우저는 수정되지 않아요. Arc와 Zen은 갖고 있던 것을 모두 그대로 유지하므로, 마이그레이션한 뒤 비교해 보면서 어느 브라우저든 계속 쓸 수 있어요.

## 리포트 읽기 {#reading-the-report}

리포트에는 모든 프로필과 스페이스가 각각 어떻게 처리되었는지 나와요. 스페이스마다 받은 북마크 수, 추가된 고정 탭 수, 방문 기록과 쿠키와 확장 프로그램이 옮겨졌는지 여부를 보여 줘요. 실패한 것이 있으면 요약에 확인이 필요한 항목 수가 표시되고, 해당 행에 **스페이스를 만들지 못함**이나 **북마크를 저장하지 못함**처럼 무엇이 잘못되었는지 설명이 나와요. 이번 실행에서 처리된 나머지는 모두 유지되므로, 하나가 실패해도 나머지가 취소되지는 않아요.

## 다시 마이그레이션하기 {#migrating-again}

Phi는 어떤 브라우저에서 내 계정으로 마이그레이션했는지 기억해요. 같은 브라우저에서 다시 마이그레이션을 시작하면 먼저 경고를 보여 줘요. 다시 마이그레이션하면 프로필과 스페이스 세트가 하나 더 만들어지고, 첫 번째 세트는 업데이트되지 않아요. 정말 그렇게 하려는 경우에만 **다시 마이그레이션**을 선택하세요. 같은 사본 두 벌이 나란히 생기지 않게 처음부터 다시 하려면, 다시 마이그레이션하기 전에 첫 번째 실행에서 만들어진 것을 삭제하세요. 먼저 스페이스를, 그다음 프로필을 삭제하면 돼요. 스페이스를 삭제해도 그 프로필과 프로필의 쿠키, 방문 기록, 확장 프로그램은 그대로 남아 있어요. [프로필 삭제하기](/ko/spaces/#deleting-a-profile)를 참고하세요.

Arc나 Zen과 계속 동기화되지는 않아요. 마이그레이션은 그 시점에 원래 브라우저에 있던 것을 한 번 복사하는 거예요.
