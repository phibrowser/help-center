# Phi Sentinel

Phi Sentinel은 브라우저와 분리되어 macOS **메뉴 막대**에 사는 작은 컴패니언 앱이에요. 따로 둔 건 의도적이에요. 브라우저는 가볍게 유지되고, 조용한 백그라운드 계층은 창이 하나도 열려 있지 않아도 계속 일해요. 주된 역할은 두 가지예요. 자동화를 계속 돌아가게 하고, **프라이빗 AI**를 호스팅해요.

## 자동화를 계속 돌아가게 해요

Phi가 하는 일 중에는 요청한 순간보다 오래 살아남아야 하는 것들이 있어요. [예약된 작업](/ko/automation/#scheduled-tasks)은 브라우저 창을 닫은 뒤에도 자기 일정대로 계속 실행되어야 하는데, 바로 그걸 위해 Phi Sentinel이 있어요. Sentinel은 이런 작업을 실행하고, AI 작업 기록을 보관하고, 자동화가 백그라운드에서 이어지게 해요. 그래서 몇 시간마다 하는 가격 확인이나 지켜보고 있는 페이지는 브라우저 창이 열려 있든 없든 계속 돌아가요.

## 프라이빗 AI

평소 Phi의 AI 작업은 **Phi Cloud**가 처리해요. **프라이빗 AI**는 그중 일부를 **내 Mac에서 대신** 실행하거나 직접 선택한 모델 제공자를 통해 실행해서, 그 작업이 내 컴퓨터를 떠나지 않게 하는 옵션이에요.

이 기능은 **선택 사항이고 기본값은 꺼짐**이에요. 켜면 몇 가지를 얻게 돼요:

- **프라이버시.** 로컬에서 실행되는 작업은 데이터가 내 Mac에 남고 클라우드 모델로 전송되지 않아요.
- **오프라인.** 그런 작업은 인터넷 연결 없이도 계속 동작해요.
- **요청당 비용 없음.** 내 하드웨어에서 실행하면 사용 요금이 없어요.

### 작업 단위로 동작해요

프라이빗 AI는 전부 아니면 전무가 아니에요. 작업 단위로 적용되고, Phi는 어떤 작업을 넘겨받을 수 있는지 숨기지 않아요. Phi가 설정해 주는 모델 기준으로 **메모리**와 **데이터 검색**은 기본적으로 내 Mac에서 실행되고, **채팅**과 **웹 작업**은 **Phi Cloud**에 남아요. 이 둘은 백그라운드 작업용으로 함께 제공되는 가벼운 모델보다 강력한 모델이 필요해서, 더 큰 모델을 설치해야만 온디바이스로 옮겨 와요. 프라이빗 AI 화면은 이걸 적용 범위로 보여줘요. AI 작업 중 몇 개가 프라이빗하게 실행되고 몇 개가 여전히 Phi Cloud로 가는지를 나타내니, 각 작업이 어디에서 처리되는지 항상 알 수 있어요.

### 내 제공자 연결하기

온디바이스 모델만이 유일한 선택지는 아니에요. **Ollama**, **LM Studio**, 또는 OpenAI 호환 엔드포인트처럼 직접 운영하는 모델 제공자를 작업에 지정할 수도 있어요. 그러면 Phi가 그 작업을 Phi Cloud 대신 그쪽으로 라우팅해요.

### 필요한 사양

프라이빗 AI는 **16GB 이상의 RAM**을 갖춘 **Apple Silicon** Mac에서 가장 잘 동작해요. 기능을 켜면 설정 과정이 하드웨어와 디스크 여유 공간을 확인하고, 필요한 것을 다운로드한 다음 로컬 모델을 켜요.

### 켜는 방법

메뉴 막대에서 Phi Sentinel을 열고, 설정에서 **프라이빗 AI**를 찾아 켜요. 그다음부터는 설정 과정을 안내해 주고, 준비가 끝나면 어떤 작업이 온디바이스로 옮겨 왔는지 보여줘요.

## 통제권은 내 손에

프라이빗 AI는 Phi의 로컬 우선 접근을 한층 더 깊게 만들어요. 메모리뿐 아니라 AI 자체를 내 컴퓨터에서 실행할 수 있게 하니까요. 데이터가 어디에 있는지, Phi가 무엇을 수집하고 무엇을 수집하지 않는지는 [개인정보 보호와 내 데이터](/ko/privacy/)에서 확인하세요.
