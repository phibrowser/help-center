# 가져오기 및 내보내기

Phi는 다른 브라우저에서 북마크와 방문 기록을 가져올 수 있어요. 설치된 브라우저에서 직접 가져오거나, 이미 가지고 있는 파일에서 가져올 수 있어요. 스페이스의 북마크를 표준 HTML 파일로 다시 내보낼 수도 있어요. 이 페이지는 두 방향 모두를 다루고, 파일 형식별로 정확히 무엇을 가져오는지 정리해요.

Phi를 처음 사용하고 이전 과정의 큰 그림부터 보고 싶다면 [Phi로 전환하기](/ko/switching-to-phi/)에서 시작한 다음, 자세한 내용이 필요할 때 이 페이지로 돌아오세요.

## 가져오는 두 가지 방법

진입점은 두 곳이고, 둘 다 같은 **브라우저 데이터** 가져오기 화면을 열어요.

- **처음 실행할 때.** Phi를 설정하는 동안 설정 과정에서 가져오기를 제안해요.
- **나중에 언제든지.** **Phi** 메뉴(Apple 메뉴 옆의 굵게 표시된 앱 메뉴)를 열고 **다른 브라우저에서 가져오기…** 항목을 선택하세요.

가져오기 화면에는 네 가지 소스가 있어요. **Chrome에서**, **Safari에서**, **Arc에서**, **파일에서**예요. Chrome, Safari, Arc는 설치된 브라우저의 데이터를 직접 읽고, 어떤 데이터 유형을 가져올지 고를 수 있게 해 줘요. 아래 섹션에서는 **파일에서**를 더 자세히 다뤄요.

가져온 데이터는 가져오기를 실행한 [스페이스](/ko/spaces/)에 들어가요. 북마크는 그 스페이스의 북마크 트리에, 방문 기록은 내 방문 기록에 합쳐져요. [시크릿 모드](/ko/incognito/)에서는 가져오기를 사용할 수 없으니 먼저 일반 스페이스나 윈도우로 전환하세요.

::: tip Safari에서 가져오기 전에 Safari를 종료하세요
**Safari에서**를 사용한다면 먼저 Safari를 종료하세요. Safari는 최근 활동 일부를 메모리에만 두었다가 종료할 때 비로소 디스크에 전부 기록하기 때문에, 실행 중에 가져오면 최신 북마크와 방문 기록이 빠질 수 있어요. 이미 내보낸 스냅샷을 읽는 **파일에서**에는 해당하지 않아요.
:::

## 파일에서 가져오기

**파일에서**를 선택하고 **파일 선택…** 버튼을 클릭한 다음 파일을 고르세요. Phi는 세 가지 파일을 받아들이고, 무엇을 할지는 파일 자체를 보고 판단해요. 이 옵션에는 데이터 유형 체크박스가 없어서 파일에 든 것을 그대로 가져와요. 진행되는 동안 **파일에서 데이터 가져오는 중…** 메시지가 표시돼요.

### 파일 형식별로 가져오는 항목

| 파일                         | 확장자          | 가져오는 내용               |
| ---------------------------- | --------------- | --------------------------- |
| **북마크 HTML**              | `.html`, `.htm` | 북마크만                    |
| **Safari 방문 기록 JSON**    | `.json`         | 방문 기록만                 |
| **Safari 내보내기 아카이브** | `.zip`          | 북마크**와** 방문 기록 함께 |

**북마크 HTML**은 Chrome, Safari, Firefox, Edge는 물론 Phi 자신까지 모든 주요 브라우저가 내보낼 수 있는 표준 "Netscape 북마크" 형식이에요. 하나를 가져오면 그 북마크들이 현재 스페이스의 **가져온 북마크** 폴더 아래에 추가되어, 한데 모여 있고 나중에 찾거나 지우기도 쉬워요.

**Safari 방문 기록 JSON**과 **Safari 내보내기 아카이브**는 둘 다 Safari의 **파일 → 브라우징 데이터를 파일로 내보내기** 기능에서 나와요. Safari는 `.zip` 아카이브를 만들어요. 이미 압축을 풀었다면 그 안의 `History.json` 파일을 직접 골라도 돼요.

- **Safari 내보내기 아카이브**(`.zip`)가 가장 간단한 선택이에요. 이 파일을 고르면 Phi가 북마크와 방문 기록을 한 번에 모두 가져와요.
- **Safari 방문 기록 JSON** 단독 파일은 방문 기록만 가져와요.

### 가져오는 것과 가져오지 않는 것

- **북마크와 방문 기록만 가져와요.** Safari가 함께 내보낼 수 있는 암호, 결제 카드 등 다른 항목은 이 경로로는 절대 가져오지 않아요. 그런 민감한 데이터를 묻지도 않고 들여오는 것은 옳지 않기 때문에, Safari 아카이브에 들어 있어도 Phi는 해당 파일을 건너뛰어요.
- **문제 있는 파일 하나가 나머지를 막지 않아요.** `.zip` 안에서 Phi는 읽을 수 있는 북마크와 방문 기록 파일을 모두 읽고, 무관한 파일이나 손상된 항목처럼 읽을 수 없는 것은 건너뛰어요.
- **여러 조각으로 나뉜 방문 기록도 통째로 들어와요.** Safari는 방문 기록이 크면 여러 파일(`History.json`, `History-0001.json` 등)로 나눠 내보내기도 하는데, Phi는 그 파일을 전부 가져와요.
- **다시 가져와도 중복이 쌓이지 않아요.** 가져온 방문 기록은 다른 브라우저 가져오기와 같은 방식으로 기존 방문 기록에 병합되므로, 같은 파일을 두 번 가져와도 방문 횟수가 불어나지 않아요.
- **크거나 손상된 파일도 안전하게 처리돼요.** Phi는 파일이나 아카이브 하나에서 읽는 양에 상한을 두기 때문에, 비정상적으로 크거나 잘못된 파일이 브라우저를 멈추게 할 수 없어요. 그런 파일은 건너뛰어요.
- **가져올 것이 없어도 깔끔하게 끝나요.** Phi가 사용할 수 있는 내용이 파일에 하나도 없으면, 가져오기는 멈추는 대신 오류 없이 끝나요.

## 북마크 내보내기

Phi는 **현재 스페이스**의 북마크를 HTML 파일로 내보낼 수 있어요. **북마크** 메뉴를 열어 **북마크 내보내기…** 항목을 선택한 다음 저장할 위치를 고르세요. Phi가 `Phi-Bookmarks-<Space>-<date>.html` 같은 파일 이름을 제안해요.

- 이 파일은 위에서 설명한 표준 **Netscape 북마크** 형식 그대로여서 Chrome, Safari, Firefox, Edge로 깔끔하게 가져올 수 있고, **파일에서**를 통해 Phi로 다시 가져올 수도 있어요.
- 내보내기는 지금 있는 스페이스만 다뤄요. 북마크는 [스페이스별](/ko/bookmarks/)이므로, 다른 스페이스의 북마크를 저장하려면 스페이스를 전환해서 다시 내보내세요.
- 현재 스페이스에 북마크가 없으면 **북마크 내보내기…** 항목이 흐리게 표시되고, 북마크 트리를 아예 갖지 않는 시크릿 스페이스에서는 사용할 수 없어요.
- 두 페이지를 한 항목으로 묶는 [Split View](/ko/layouts/) 북마크는 표준 형식으로 표현할 수 있도록 평범한 항목 두 개로 기록돼요.

### 내보냈다가 다시 가져오기

스페이스의 북마크를 HTML로 내보낸 다음 **파일에서**로 다시 가져오세요. 다른 스페이스든, 다른 프로필이든, 다른 Mac의 Phi든 상관없어요. 프로필 사이나 두 Mac 사이에 북마크 한 묶음을 복사하는 가장 빠른 방법이 보통 이거예요.

## 북마크만이 아니라 전부 내보내기

**북마크 내보내기…** 명령은 북마크만 내보내요. 스페이스, 프로필, 방문 기록을 비롯한 Phi 데이터 전부를 파일 하나로 백업하려면 **도움말** 메뉴의 **사용자 데이터 관리 → 사용자 데이터 내보내기…** 항목을 대신 사용하세요. 새 Mac으로 옮기거나 전체 사본을 따로 보관할 때 쓰는 도구예요. Phi의 자동 롤백 스냅샷과 어떻게 맞물리는지는 [Time Machine 백업](/ko/time-machine/#exporting-your-own-data)을 참고하세요.
