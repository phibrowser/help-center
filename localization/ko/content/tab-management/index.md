# 탭과 북마크 관리

Phi에서는 여러 항목을 선택해서 한 묶음으로 다룰 수 있어요. 선택 영역을 오른쪽 클릭해 일괄 동작을 실행하거나, 드래그해서 일반 탭, Split View, 북마크, 북마크 폴더를 하나씩 옮기지 않고 한꺼번에 재정리할 수 있어요.

## 여러 항목 선택하기

다음 두 가지 보조 키로 선택을 만들 수 있어요.

- **Command-클릭(⌘-클릭)**: 탭이나 북마크를 선택에 추가하거나 선택에서 제외해요. 활성 탭은 자동으로 포함되기 때문에, 다른 탭을 Command-클릭하면 두 탭이 함께 선택돼요.
- **Shift-클릭**: 시작 지점부터 클릭한 항목까지 이어지는 범위를 통째로 선택해요.

사이드바에서 범위 선택에는 보이는 탭, 북마크, 북마크 폴더, 그리고 펼쳐진 그룹이나 폴더의 내용물이 포함될 수 있어요. 접힌 그룹이나 폴더 안에 숨어 있는 항목은 포함되지 않아요. Split View는 보이는 항목 하나로 취급되기 때문에 양쪽 창이 항상 함께 움직여요.

여유 레이아웃에서는 같은 Command-클릭과 Shift-클릭 제스처를 가로 탭 스트립의 탭에도 쓸 수 있어요. 북마크 다중 선택은 균형과 성능 레이아웃의 사이드바에서 사용할 수 있어요.

## 선택 항목으로 작업하기

강조 표시된 항목 아무거나 오른쪽 클릭하면 일괄 메뉴가 열려요. Phi는 선택한 내용에 맞춰 가능한 동작을 조정하기 때문에, 어떤 동작은 탭만 선택했을 때, 북마크만 선택했을 때, 또는 호환되는 조합일 때만 나타나요.

| 동작                            | 하는 일                                                          |
| ------------------------------- | ---------------------------------------------------------------- |
| **탭 복제**                     | 선택한 페이지의 복사본을 현재 스페이스에 열어요.                 |
| **링크 복사**                   | 선택한 페이지의 URL을 목록으로 복사해요.                         |
| **분할로 열기**                 | 호환되는 선택 항목 정확히 두 개를 나란히 배치해요.               |
| **북마크에 추가 / 폴더에 추가** | 선택한 탭을 저장하거나, 선택한 북마크를 지정한 위치로 정리해요.  |
| **탭을 새 그룹에 추가**         | 호환되는 선택 항목으로 탭 그룹을 만들어요.                       |
| **탭을 그룹으로 이동**          | 호환되는 선택 항목을 기존 탭 그룹으로 옮겨요.                    |
| **스페이스로 이동**             | 선택 항목을 다른 스페이스로 옮기고 현재 스페이스에서는 제거해요. |
| **스페이스로 복제**             | 원래 선택 항목은 그대로 두고 다른 스페이스에 복사본을 만들어요.  |
| **탭 닫기 / 다른 탭 닫기**      | 선택한 일반 탭을 닫거나, 선택하지 않은 모든 일반 탭을 닫아요.    |
| **북마크/폴더/항목 삭제**       | 확인을 거친 뒤 선택한 저장 항목을 영구적으로 제거해요.           |

## 여러 항목을 드래그해서 정리하기

선택을 만든 다음, 강조 표시된 항목 아무거나 드래그하면 선택 전체가 함께 움직여요. 드래그 미리보기에는 보이는 항목 몇 개가 이동 중인지 표시돼요. 선택되지 않은 항목을 드래그하기 시작하면 Phi가 일괄 선택을 해제하고 그 항목만 옮겨요.

선택 항목을 어디에 놓는지에 따라 결과가 달라져요.

- **탭 목록 안**: 선택한 탭들의 순서를 함께 바꾸거나, 탭 그룹 안에 놓을 수 있어요.
- **북마크 영역 안**: 선택한 북마크와 폴더의 순서를 바꾸거나, 폴더 위에 놓아 그 안으로 옮길 수 있어요.
- **탭에서 북마크로**: 선택한 탭을 북마크 영역이나 북마크 폴더 위에 놓으면 그곳에 저장돼요.
- **북마크에서 탭으로**: 선택한 북마크 페이지를 탭 목록이나 탭 그룹에 놓으면 탭으로 열리고 정리돼요.
- **혼합 선택**: 대상 위치가 선택한 모든 항목을 지원할 때는 탭과 북마크를 함께 옮길 수 있어요.

드래그하는 동안 Split View는 항상 함께 움직여요. 북마크 폴더가 포함된 선택은 북마크 영역에 남아요. 폴더를 유지할 수 없는 탭 목록이나 탭 그룹 위치에 대해서는, Phi가 선택을 쪼개는 대신 이동 자체를 거부해요.

## 다른 스페이스로 이동하거나 복제하기

선택한 항목이 현재 스페이스를 떠나야 한다면 **스페이스로 이동**을 사용하세요. 같은 탭이나 북마크를 두 스페이스 모두에 두고 싶다면 **스페이스로 복제**를 사용하세요.

두 동작 모두 일반 탭, Split View, 북마크, 북마크 폴더가 호환되게 섞인 선택을 처리할 수 있어요. 선택 항목을 옮길 때 Phi는 Split View의 양쪽 창을 함께 유지하고 북마크 구조도 보존해요. 대상 스페이스는 각 동작의 하위 메뉴에서 선택하세요.

현재 스페이스와 시크릿 스페이스는 대상으로 제공되지 않아요. 시크릿 모드로 브라우징하는 동안에는 스페이스 이동 동작도 사용할 수 없어요.

## 다중 선택 끝내기

**Escape** 키를 누르거나, 항목 하나를 평소처럼 클릭해 그 항목으로 전환하면 다중 선택이 끝나요. 사이드바에서는 빈 공간을 클릭해도 선택이 해제돼요. 대부분의 일괄 동작은 완료되면 선택이 자동으로 해제돼요.

항목이 어디에 속하는지 더 알고 싶다면 [스페이스와 프로필](/ko/spaces/)을 참고하세요. 북마크가 제자리에서 열리는 방식과 고정 탭의 동작은 [북마크와 고정 탭](/ko/bookmarks/)에서 확인할 수 있어요.
