# 記憶

記憶是你的助理認識你的方式。正是 Phi 的這個部分，把一個「你在用的瀏覽器」變成一個「懂你的瀏覽器」，讓助理不必在你每次開口時都從零開始。

它的不同之處在於學習的來源。多數助理只知道你打進對話框的內容；Phi 的記憶則從你瀏覽時實際做的事學習：你閱讀、比較、一再回訪、持續投入的那些事。這是*記得*一段對話與*理解*一個人之間的差別。知道你花了一個下午比較雲端供應商，或是兩週前剛開始一份新工作，正是這種情境讓協助變得貼身，而不是千篇一律。

## 它如何學習

記憶是全自動的，安靜地在背景運作。你不需要教它任何東西，也不用替自己的瀏覽器做無償的資料登打。日子照常過，它會逐漸拼出一幅圖像：什麼對你重要、你一直回頭找什麼，以及哪些任務和主題反覆出現。

它也會從這些活動中萃取出關於你的小而具體的事實：你的興趣、你的工作、你的目標，以及你往來的工具和人。這些稱為**觀察**，合起來構成助理對「你是誰」的現行理解。

近期的行為，比偶一為之的行為更有分量。關聯性會隨時間衰減：現在的習慣勝過幾個月前的一次繞路，因此這幅圖像會跟著你的生活走，而不是停在你的過去。

## Nebula

記憶學到的東西不是黑盒子。**Nebula** 是目前的記憶視覺化檢視，取代了較早的 Memory Galaxy 體驗。它把 Phi 學到的內容化成一幅宛如星空的記憶與星團地圖，讓你探索形塑助理情境的主題、地點、話題和活動模式。你可以親自翻看助理蒐集到了什麼、各個片段之間如何連結，而不是只能選擇相信。

想看的時候，隨時可以打開你的記憶。在新分頁上，搜尋框正下方就有入口。在瀏覽器本體中，位置取決於你的[版面配置模式](/zh-Hant/layouts/)：在**效能**和**平衡**中位於**左下角**，在**舒適**中則移到**右上角**。

## 助理如何使用記憶

當你問助理問題、請它摘要頁面或交辦任務時，它會同時參考對你的記憶和你眼前的內容，不論那是目前的分頁，還是一整組[分割畫面或分頁群組](/zh-Hant/layouts/)。正因如此，它才能用貼合你的方式回答，你不必每次重新解釋自己的處境。記憶也支撐著個人化的[新分頁與小工具](/zh-Hant/new-tab/)，它知道的事會在那裡以有用的形式呈現，而不是藏著不見。想進一步了解如何找到助理、與它交談，請見[認識你的助理](/zh-Hant/ai/)。

## 保持掌控

記憶建立的一切都儲存在你裝置的本機，並且始終由你掌控。具體來說，你可以：

- **檢視、管理和刪除**它記得的任何內容，直接在 Phi 裡完成。
- 當某些頁面你不希望它學習時，**針對個別網站關閉記憶收集**。
- **匯入和匯出**你的記憶，讓它可以帶著走、真正屬於你，而不是被鎖在裡面。

你的記憶永遠不會被用來訓練 AI 模型。想知道你的資料存放在哪裡、Phi 收集什麼和不收集什麼，請見[隱私權與你的資料](/zh-Hant/privacy/)。請注意，[關閉 AI](/zh-Hant/privacy/#turning-ai-off) 並不會清除你的記憶；如果你也想讓記憶消失，請在記憶頁面刪除它，而且這個刪除是永久性的。

## 記憶不只在 Phi：Anamnesis

同一套記憶系統也以獨立產品的形式提供，給（還）沒有使用 Phi Browser 的人。**Anamnesis** 是一款適用於 Chrome 和 Chromium 系瀏覽器的獨立擴充功能，會從你的瀏覽中建立同一種有生命力的本機瀏覽器記憶。

它守著同樣的原則：你的記憶屬於你、跟著你，而且你隨時可以檢視、編輯、刪除或匯出。你使用自己的 API 金鑰，助理直接與你選擇的模型供應商對話；Phi 不會居中經手，也不會把你的記憶存放在伺服器上。由於匯出的記憶是可攜的，你隨時可以把它帶進 Phi Browser 或其他 AI 服務。詳情見 [phibrowser.com/anamnesis](https://phibrowser.com/anamnesis/)。
