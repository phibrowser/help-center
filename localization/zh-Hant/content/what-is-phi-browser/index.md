# 什麼是 Phi Browser？

Phi Browser 是懂你的瀏覽器，也是能把事情辦好的瀏覽器。

它是 macOS 上的智慧瀏覽器，以 Chromium 引擎打造，配上原生的 macOS 介面。核心開放原始碼，資料以本機優先的方式保存，AI 也已內建。Phi 免費使用，AI 的使用費由我們負擔。它會學習你的工作方式、預先想到你的需要，並替你打理例行任務。

這些指南提供整體樣貌，以及 Phi 設計背後的想法。想找快速、具體的解答，請見[常見問題](/zh-Hant/faq/)。

## 為 macOS 而生

Phi 可在配備 Apple 晶片的 Mac（M1 及後續晶片）上執行，需要 macOS 14 或以上版本。它在那裡如魚得水：原生介面、垂直側邊欄，加上三種版面配置模式任你選擇，由你決定多少空間留給網頁、多少留給瀏覽器控制項。

第一次用 Phi？先從[開始使用](/zh-Hant/get-started/)安裝並走完初次設定，再到[版面配置與導覽](/zh-Hant/layouts/)熟悉環境。

## 一個瀏覽器，四個 AI 部件

Phi 的 AI 是內建的，登入後即啟用。它不是一團模糊的「AI」，而是四個各司其職的部分：

- **[記憶](/zh-Hant/memory/)**：從你的瀏覽方式安靜地累積脈絡，讓助理不用你教就懂你。
- **助理**：一位由你親自命名的對話夥伴，你可以問它問題，也可以把工作交給它。
- **AI 代理任務**：真的動手替你做事，從單次動作到自行執行的背景與排程工作。
- **[瀏覽器 Skill](/zh-Hant/skills/)**：助理可以隨時取用的可重複工作流程。

想瞭解記憶、如何與助理交談以及 Skill，請讀[認識你的助理](/zh-Hant/ai/)；想瞭解 AI 代理任務和在手機上使用 Phi，請讀[自動化與 Phi Link](/zh-Hant/automation/)。

## 你的資料還是你的

Phi 是本機優先的。Phi 記得的內容存放在你的 Mac 上，永遠不會被拿去訓練 AI 模型，而且始終在你的掌控之中。你可以檢視、管理，也可以刪除。

這句話還有後半段，在你依賴它之前值得先知道：當助理回答問題時，回答所需的內容會送到你選擇的模型供應商，因為模型只有這樣才能作答。內容會經過我們，過程中不會被儲存。如果你希望資料完全不離開你的 Mac，[Phi Sentinel](/zh-Hant/sentinel/) 可以改在本機執行模型。

詳情請見[隱私權與你的資料](/zh-Hant/privacy/)。
