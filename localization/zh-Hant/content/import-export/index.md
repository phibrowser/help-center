# 匯入與匯出

Phi 可以從其他瀏覽器帶入書籤與瀏覽歷史記錄，來源可以是已安裝的瀏覽器，也可以是你手邊既有的檔案。它也能把某個空間的書籤匯出成標準 HTML 檔案。本頁涵蓋這兩個方向，並逐一說明每種檔案會帶入哪些內容。

如果你剛開始使用 Phi，只想先了解移轉的整體流程，請先閱讀 [改用 Phi](/zh-Hant/switching-to-phi/)，再回到本頁看細節。

## 兩種匯入方式

匯入有兩個入口，都會開啟同一個 **瀏覽器資料** 匯入畫面：

- **首次啟動時。** 新手引導流程會在你設定 Phi 的過程中主動提供匯入。
- **之後隨時。** 開啟 **Phi** 選單（Apple 選單旁那個粗體的 App 選單），選擇 **從其他瀏覽器匯入…**。

匯入畫面提供四種來源：**從 Chrome**、**從 Safari**、**從 Arc** 和 **從檔案**。Chrome、Safari 和 Arc 會直接讀取已安裝瀏覽器的資料，並讓你挑選要帶入哪些資料類型。以下各節會更詳細說明 **從檔案**。

匯入的內容會進入你執行匯入時所在的 [空間](/zh-Hant/spaces/)。書籤會加入該空間的書籤結構，歷史記錄則併入你的瀏覽歷史記錄。[無痕模式](/zh-Hant/incognito/) 中無法匯入；請先切換到一般空間或視窗。

::: tip 從 Safari 匯入前，請先結束 Safari
如果你使用 **從 Safari**，請先結束 Safari。Safari 會把部分最近的活動保留在記憶體中，關閉時才會完整寫入磁碟，因此在它仍在執行時匯入，可能會漏掉你最新的書籤和歷史記錄。這不影響 **從檔案**，因為它讀取的是你已經輸出的快照。
:::

## 從檔案匯入

選擇 **從檔案**，按一下 **選擇檔案…**，然後挑選檔案。Phi 接受三種檔案，並根據檔案本身決定要怎麼處理。這個選項沒有資料類型的勾選框；檔案裡有什麼就匯入什麼。匯入過程中你會看到 **正在從檔案匯入資料…**。

### 每種檔案會匯入的內容

| 檔案                     | 副檔名          | 匯入內容               |
| ------------------------ | --------------- | ---------------------- |
| **書籤 HTML**            | `.html`、`.htm` | 僅書籤                 |
| **Safari 歷史記錄 JSON** | `.json`         | 僅瀏覽歷史記錄         |
| **Safari 輸出封存檔**    | `.zip`          | 書籤 **加上** 歷史記錄 |

**書籤 HTML** 是每個主流瀏覽器都能匯出的標準「Netscape 書籤」格式，包括 Chrome、Safari、Firefox、Edge 和 Phi 本身。匯入後，書籤會加入目前空間的 **已匯入** 資料夾，方便集中存放，之後也容易找到或移除。

**Safari 歷史記錄 JSON** 和 **Safari 輸出封存檔** 都來自 Safari 的 **檔案 → 輸出 → 輸出瀏覽資料…** 功能。Safari 會產生 `.zip` 封存檔；如果你已經解壓縮，也可以直接挑選其中的 `History.json` 檔案。

- **Safari 輸出封存檔**（`.zip`）是最省事的選擇：選好之後，Phi 會一步匯入你的書籤和歷史記錄。
- 單獨的 **Safari 歷史記錄 JSON** 只會匯入歷史記錄。

### 會匯入與不會匯入的內容

- **只有書籤和歷史記錄。** 密碼、付款卡片和其他 Safari 也能輸出的項目，永遠不會透過這個途徑匯入。未經詢問就帶入這類敏感資料並不妥當，所以即使 Safari 封存檔裡包含這些檔案，Phi 也會略過。
- **一個壞檔案不會擋下其他檔案。** 在 `.zip` 內，Phi 會讀取所有它讀得懂的書籤和歷史記錄檔案，並略過讀不懂的，例如無關的檔案或損壞的項目。
- **拆成多個檔案的歷史記錄會完整帶入。** Safari 有時會把大型歷史記錄輸出拆成多個檔案（`History.json`、`History-0001.json` 等），Phi 會全部匯入。
- **重複匯入不會堆出重複項目。** 匯入的歷史記錄會像任何瀏覽器匯入一樣併入你既有的歷史記錄，所以同一個檔案匯入兩次，不會讓你的造訪記錄變成兩倍。
- **過大或損壞的檔案會被安全處理。** Phi 對單一檔案或封存檔的讀取量設有上限，因此異常龐大或格式錯誤的檔案不會讓瀏覽器停住，Phi 會改為略過它。
- **沒有內容可帶入的匯入仍會乾淨結束。** 如果檔案裡沒有 Phi 能使用的內容，匯入會正常結束而不出錯，也不會卡住。

## 匯出你的書籤

Phi 可以把 **目前空間** 的書籤匯出成 HTML 檔案。開啟 **書籤** 選單並選擇 **匯出書籤…**，然後挑選儲存位置。Phi 會建議類似 `Phi-Bookmarks-<Space>-<date>.html` 的檔名。

- 這個檔案就是上文所述的標準 **Netscape 書籤** 格式，因此可以順利匯入 Chrome、Safari、Firefox、Edge，或透過 **從檔案** 匯回 Phi。
- 匯出的範圍是你目前所在的空間。因為書籤 [依空間各自獨立](/zh-Hant/bookmarks/)，切換空間後再匯出一次，即可儲存另一個空間的書籤。
- 目前空間沒有書籤時，**匯出書籤…** 會呈灰色無法點選；在無痕空間中也無法使用（無痕空間從來沒有書籤結構）。
- [分割](/zh-Hant/layouts/) 書籤會把兩個頁面存成一個項目，匯出時會寫成兩個一般項目，讓標準格式能夠表示它。

### 來回移轉

把某個空間的書籤匯出成 HTML，再用 **從檔案** 帶回來，無論是帶進另一個空間、另一個設定檔，還是另一部 Mac 上的 Phi。這通常是在設定檔之間或兩部 Mac 之間複製一組書籤最快的方法。

## 匯出全部資料（不只書籤）

**匯出書籤…** 只會匯出書籤。若要把你所有的 Phi 資料（空間、設定檔、歷史記錄等）備份成單一檔案，請改用 **說明** 選單的 **管理使用者資料 → 匯出使用者資料…**。那才是搬到新 Mac 或保留完整個人副本的工具；關於它與 Phi 自動回溯快照的關係，請參閱 [時光機備份](/zh-Hant/time-machine/#exporting-your-own-data)。
