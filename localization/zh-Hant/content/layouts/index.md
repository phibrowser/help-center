# 版面配置與導覽

Phi 以垂直側邊欄和可選的版面配置模式來組織瀏覽。如果你正從 Chrome 或 Safari 轉換過來，這是最大的改變，也最值得先花時間習慣。

## 為什麼是垂直側邊欄？

現代螢幕大多是寬的，不是高的。水平空間通常綽綽有餘，先用完的往往是垂直空間，閱讀、寫作、查資料或在網頁應用程式裡工作時尤其如此。垂直側邊欄更能善用現代顯示器的形狀，把更多空間留給網頁本身。

## 版面配置模式

Phi 提供三種版面配置模式，讓你決定螢幕空間有多少留給內容、多少留給瀏覽器控制項。你會在新手引導時選擇一種，之後隨時可以更改。

- **效能**，把最多空間留給網頁。分頁和書籤都放在垂直側邊欄，內容區域不顯示網址列。
- **平衡**，保留垂直側邊欄，並在內容上方加上網址列。它是空間效率與熟悉感之間的折衷。
- **舒適**，外觀最接近傳統瀏覽器：分頁在上方、網址列清楚可見，版面與 Chrome 相近。分頁移到水平分頁列，側邊欄便從日常導覽中退居幕後。

### 我該從哪一種開始？

- 從 Chrome 或 Safari 轉換過來：從**舒適**開始。
- 偏好現代的側邊欄瀏覽器：從**平衡**開始。
- 想要最大的網頁空間：使用**效能**。

更完整的搬家建議，請見[改用 Phi](/zh-Hant/switching-to-phi/)。

## 分頁、釘選分頁與書籤

在 Phi 中，分頁、釘選分頁和書籤全都住在側邊欄裡，因為它們其實是同一件事的不同階段：你在意的網頁。**分頁**是現在開著的，**釘選分頁**位於頂端、留給你成天使用的網頁，**書籤**排在下方、收著你想留存的網頁。一個簡單的記法：**釘選分頁是你成天使用的網頁；書籤是你想留存的網頁。**

書籤如何就地開啟成分頁、如何釘選與整理網頁，請見[書籤與釘選分頁](/zh-Hant/bookmarks/)。Arc 和 Dia 的搬家筆記，請見[改用 Phi](/zh-Hant/switching-to-phi/)。

## 分割畫面

分割畫面把兩個網頁並排放在同一個視窗，適合邊讀邊寫、比較兩個頁面，或把說明文件放在網頁應用程式旁邊，不必來回切換。

要建立分割畫面，在分頁、書籤或釘選分頁上按右鍵並選擇**以分割畫面開啟**，或把一個分頁拖曳到目前的頁面上。你也可以按住 **Option（⌥）** 再點釘選分頁、書籤或網頁上的連結，Phi 會在目前分頁旁以分割畫面開啟它。

## 分頁群組

分頁群組把相關的分頁收進一個有名字的群組，當多個頁面同屬一個專案、一趟旅行、一個研究主題或一次購物行程時特別好用。

分割畫面和分頁群組是設計來互相搭配的：你可以在群組內使用分割畫面，也可以把分割的分頁移入或移出群組，讓相關的工作維持條理，而不是散成一顆顆零星的分頁。

簡單的分工方式：**分割畫面用來比較與多工；分頁群組用來整理一項任務、專案或主題。**

## 助理懂你的版面

在分割畫面中對話時，Phi 可以同時運用兩個頁面的脈絡。在分頁群組中對話時，它可以運用整個群組的脈絡，你可以直接跨相關頁面提問，不必先解釋自己的配置。（小提示：用 **ctrl+tab** 依序切換最近的分頁，用 **ctrl+shift+tab** 往回切。）
