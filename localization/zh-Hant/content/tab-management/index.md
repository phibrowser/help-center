# 管理分頁與書籤

Phi 讓你一次選取多個項目、當成一批處理。你可以在選取範圍上按一下滑鼠右鍵執行批次動作，或直接拖曳它來重新整理一般分頁、分割畫面、書籤和書籤資料夾，不必逐一搬動。

## 選取多個項目

用其中一種修飾鍵建立選取範圍：

- **按住 Command（⌘）鍵並按一下**分頁或書籤，可把該項目加入或移出選取範圍。目前使用中的分頁會自動計入，所以按住 Command 鍵再按另一個分頁，等於選取了兩個。
- **按住 Shift 鍵並按一下**另一個項目，可選取它與起點之間的連續範圍。

在側邊欄中，範圍可以包含可見的分頁、書籤、書籤資料夾，以及已展開的群組或資料夾內容。收合的群組或資料夾裡的項目不會被納入。分割畫面被視為一個可見項目，因此它的兩個窗格會保持在一起。

在舒適版面配置中，水平分頁列上的分頁同樣支援按住 Command 鍵按一下和按住 Shift 鍵按一下的手勢。書籤的多重選取則在平衡和效能版面配置的側邊欄中提供。

## 操作選取範圍

在任一個反白的項目上按一下滑鼠右鍵，即可開啟批次選單。Phi 會依你選取的內容調整可用的動作，所以有些動作只在選取分頁、書籤，或相容的混合選取時出現。

| 動作                       | 作用                                                     |
| -------------------------- | -------------------------------------------------------- |
| **複製分頁**               | 在目前的空間開啟所選頁面的副本。                         |
| **拷貝所有連結**           | 把所選頁面的網址複製成清單。                             |
| **以分割畫面開啟**         | 把剛好兩個相容的所選項目並排放置。                       |
| **加入書籤／加入資料夾**   | 儲存所選分頁，或把所選書籤整理到指定位置。               |
| **將分頁加入新群組**       | 用相容的所選項目建立分頁群組。                           |
| **將分頁移至群組**         | 把相容的所選項目移進既有的分頁群組。                     |
| **移至空間**               | 把選取範圍轉移到另一個空間，並從目前的空間移除。         |
| **複製到空間**             | 在另一個空間建立副本，原本的選取範圍留在原地。           |
| **關閉分頁／關閉其他分頁** | 關閉所選的一般分頁，或關閉選取範圍以外的每一個一般分頁。 |
| **刪除書籤／資料夾／項目** | 確認後永久移除所選的已儲存項目。                         |

## 拖曳多個項目來整理

建立選取範圍後，拖曳任一個反白的項目，即可移動整個選取範圍。拖曳預覽會顯示有多少個可見項目正在移動。如果你開始拖曳的是未選取的項目，Phi 會清除這批選取，只移動那一個項目。

放下選取範圍的位置，決定接下來發生的事：

- **在分頁列表內**：一起重新排列所選分頁，或把它們放進某個分頁群組。
- **在書籤區內**：重新排列所選書籤和資料夾，或把它們放到某個資料夾上以移入其中。
- **從分頁到書籤**：把所選分頁放到書籤區或某個書籤資料夾上，即可把它們儲存在那裡。
- **從書籤到分頁**：把所選書籤頁面放到分頁列表或分頁群組中，即可把它們開啟並整理成分頁。
- **混合選取時**：當目的地支援每一個所選項目時，分頁和書籤可以一起移動。

拖曳過程中，分割畫面會保持在一起。包含書籤資料夾的選取範圍會留在書籤區；遇到無法保留資料夾的分頁列表或分頁群組目的地時，Phi 會直接拒絕，而不是把選取範圍拆開。

## 把項目移動或複製到另一個空間

當所選項目應該離開目前的空間時，用**移至空間**。想讓同樣的分頁或書籤同時存在於兩個空間時，用**複製到空間**。

這兩個動作都能處理一般分頁、分割畫面、書籤和書籤資料夾的相容混合。轉移選取範圍時，Phi 會讓分割窗格保持在一起，並保留書籤的組織結構。目的地從動作的子選單中選擇。

目前的空間和無痕空間不會列為目的地。在無痕模式中瀏覽時，也無法使用空間轉移動作。

## 離開多重選取

按下 **Esc** 鍵，或以一般方式按一下某個項目切換過去，即可離開多重選取。在側邊欄中，按一下空白區域也會清除選取。大多數批次動作完成後會自動清除。

想進一步了解項目存放的位置，請見[空間與設定檔](/zh-Hant/spaces/)。書籤如何就地開啟、釘選分頁如何運作，請見[書籤與釘選分頁](/zh-Hant/bookmarks/)。
