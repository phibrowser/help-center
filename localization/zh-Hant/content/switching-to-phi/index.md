# 改用 Phi

如果你正從 Chrome、Safari、Arc 或 Dia 搬到 Phi，這份指南會先說明思考方式上的轉變。各項功能仍有詳細的專頁深入介紹；這一頁給你的是一張搬家地圖。

## 從 Chrome 或 Safari 過來

先從**舒適**模式開始。它保留最熟悉的樣子：分頁在上方、網址列清楚可見，整體版面接近傳統瀏覽器。側邊欄仍然在，但你不必第一天就改用完整的側邊欄工作方式。

等基本操作上手之後，如果你想要現代的側邊欄瀏覽器、又希望網址列保持可見，可以試試**平衡**模式。等你想把最多畫面空間留給網頁、也習慣以側邊欄作為主要導覽介面時，再換到**效能**模式。

認識 Phi 最快的方式，是先把它當成一般瀏覽器來用：照常上網、開分頁、釘選幾個網頁、加幾個書籤，再針對你正在閱讀的頁面問問助理。比起看說明，Phi 在實際使用中更容易理解。

## 從 Arc 過來

如果 Arc 的側邊欄模式適合你，Phi 應該會讓你感到熟悉，不過細節有所不同。

Arc 和 Phi 都把「工作區」這一層和「隔離」這一層分開。在 Phi 中，**空間**是你在側邊欄看到的工作區，**設定檔**則是底層的 Cookie、歷史記錄、登入資料和擴充功能。一個設定檔可以支撐多個空間，所以你可以有多個工作區共用同一份登入狀態。

Phi 的**網址規則**靈感來自 Arc 的 Air Traffic Control：符合規則的網站可以在你指定的空間開啟，或先詢問你要在哪裡開啟。實際做法是 Phi 自己的設計，但目標一致：自動把連結放進正確的情境。

書籤方面最大的差異，是 Phi 保留了含資料夾的完整書籤樹。Arc 捨棄了傳統書籤，改用釘選分頁和 Favorites；Phi 把兩種想法都留了下來。書籤在側邊欄中維持整理好的狀態，點開時就地成為使用中的分頁。釘選分頁位於頂端，留給你成天使用的網頁，而且你可以選擇它屬於單一空間、單一設定檔，還是整個應用程式。

Phi 沒有與 Arc 的 Peek 相對應的功能。從釘選分頁開啟連結時，會直接在分頁內正常前往。

## 從 Dia 過來

Dia 和 Phi 都告別了只有分頁列的舊式瀏覽器型態，但兩者的工作區模式並不相同。

Dia 把 Profile 當作工作區的概念，每個 Profile 各自開在獨立的視窗。Phi 則讓**空間**成為**設定檔**之上的一層。這表示你可以在同一個視窗裡按一下就切換情境，需要分開的 Cookie、登入資料、歷史記錄或擴充功能時，仍然可以使用不同的設定檔。

Dia 保留書籤，但主要透過指令列呈現。Phi 讓書籤在側邊欄中清楚可見、整理有序，與分頁和釘選分頁並列。在 Phi 中，書籤點開時會就地成為使用中的分頁，而不是再生出一個用完即丟的分頁。

Phi 的釘選分頁沿用現代側邊欄瀏覽器帶起的「應用程式置頂」模式。它們是常駐的錨點，留給你成天使用的網頁，並且會跟著設定檔出現在共用該設定檔的各個空間。
