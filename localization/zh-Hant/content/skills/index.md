# 瀏覽器 Skill

瀏覽器 Skill 是你交給助理的一份可重複使用的指示。把一項多步驟任務教給它一次，之後只要一句話就能觸發整個流程，不必每次重新交代步驟。經常要做的事，就變成助理本來就會做的事。

有些 Skill 走實用路線，一次做好一件事：顯示目前頁面的 QR Code、把網頁儲存成 PDF、擷取 YouTube 逐字稿。有些則包住你經常執行的一長串例行流程。無論哪一種，重點都一樣：描述一次，永久重複使用。

::: tip 和 phi-browser skill 不是同一回事
**瀏覽器 Skill** 是本頁的主題：你在 Phi 裡交給助理的指示。**[phi-browser skill](/zh-Hant/phi-browser-skill/)** 則完全是另一回事，它是一個讓外部 AI 代理（例如 Claude Code）從終端機操控 Phi 的套件。同一個字、兩種意思，所以我們把它們分開講：瀏覽器 Skill 住在瀏覽器裡，phi-browser skill 住在你的代理裡。
:::

## 內建 Skill 與你自己的 Skill

Skill 分成兩種：

- **內建 Skill**，由 Phi 提供並維護的一組 Skill，隨時可用。
- **你自己的 Skill**，依照你的工作方式自行建立的 Skill。

內建 Skill 要你主動選用。它們陳列著讓你瀏覽，想用哪個就把哪個加入你的 Skill 庫，而不是一開始就全部開啟。

## Skill 庫

這一切都在「**Skill**」頁面管理。從**新分頁右上角**的選單開啟它，也就是放著你最近對話和小工具的那個選單，然後選擇 **Skill**。

頁面開頭是精選內建 Skill 的展示區，往下則可以瀏覽完整清單。你可以依**全部**、**內建**、**使用者建立**或**已啟用**篩選，也可以用名稱搜尋。這裡最接近一座展示廳，陳列你的助理能做到的事。

對任何一個 Skill，你都可以：

- **加入**：把內建 Skill 加入你的 Skill 庫，之後也可以移除。隨時都能再加回來。
- **啟用或停用**：不必移除就能開關 Skill，由你決定哪些處於作用中。
- **檢視**：查看 Skill 的完整詳細資訊，在使用前確切瞭解它會做什麼。

## 建立你自己的 Skill

你不必受限於內建清單。Phi 內建 **Skill 產生器**，只要描述任務，它就能協助你設計並儲存新的 Skill，所以「建立 Skill」本身就是一個開口即可使用的 Skill。你自己的 Skill 就是用你自己的話寫下的指示，隨著習慣改變，你隨時可以編輯或刪除。

## 在對話中使用 Skill

Skill 透過你的助理執行，不會自行運作。Skill 啟用後，當你的要求符合它的用途，助理就能自己拿來用。你也可以自己把 Skill 帶進對話：想明確指定要用哪一個時，在輸入訊息的過程中從 Skill 清單挑選，包括在[新分頁的提問框](/zh-Hant/new-tab/)裡。

## Skill 能替你行動，請用同樣的謹慎對待它

Skill 能做的不只是擷取和摘要。會填寫表單、發文或在網站上一路操作的 Skill，是以你的身分、從你的瀏覽器、帶著你的登入狀態在做這些事。由此帶出兩件事。

凡是有後果的事仍然算在你頭上：完成的購買、送出的訊息、提交的表單。啟用 Skill 之前先讀清楚它會做什麼，**檢視**詳細資訊就是為此而設。

另外，有些網站並不歡迎自動化。Reddit 是最為人所知的例子：被判定為自動化操作的帳號會遭到限制或封鎖，而這個決定權在對方，不在我們。如果 Skill 需要在這類網站上操作，你就是拿自己的帳號承擔這個風險。詳情請見 [phi-browser skill](/zh-Hant/phi-browser-skill/)。
