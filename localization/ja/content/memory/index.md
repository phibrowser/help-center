# メモリ

メモリは、アシスタントがあなたを知っていくための仕組みです。ただ使うだけのブラウザを、あなたを理解するブラウザへ変えていくPhiの中核であり、時間がたつほど、何かを尋ねるたびにアシスタントがゼロから始める必要がなくなっていきます。

ほかと違うのは、学ぶ場所です。多くのアシスタントは、チャット欄に入力された内容しか知りません。Phiのメモリは、ブラウズ中にあなたが実際にしていること、つまり読んだもの、比較したもの、繰り返し訪れたもの、取り組んでいるものから学びます。会話を*記憶している*ことと、人を*理解している*ことの違いです。午後いっぱいクラウドプロバイダーを比較していたことや、2週間前に新しい仕事を始めたことを知っている。そうしたコンテキストがあってはじめて、支援は誰にでも当てはまる一般論ではなく、自分のためのものに感じられます。

## 学習の仕組み

メモリは自動で、バックグラウンドで静かに働きます。何かを教え込む必要はなく、自分のブラウザのために無償のデータ入力をさせられることもありません。日々ブラウズするうちに、あなたにとって何が大切か、何度も戻ってくる場所はどこか、繰り返し現れるタスクやトピックは何かを、少しずつ描き出していきます。

こうした活動からは、あなたに関する小さく具体的な事実、たとえば興味、仕事、目標、日々関わるツールや人も抽出されます。これらは**観察記録**と呼ばれ、まとまることで、あなたが誰なのかについてのアシスタントの実用的な理解になります。

最近の行動は、一度きりの行動より重く扱われます。関連度は時間とともに減衰し、今の習慣は数か月前の一度きりの寄り道より優先されるため、描かれる像は過去に縛られず、今の生活と足並みをそろえ続けます。

## Nebula

メモリが学んだ内容はブラックボックスではありません。**Nebula**は現在のメモリ可視化ビューで、従来のMemory Galaxyに代わるものです。Phiが学んだ内容を、記憶とクラスターが星空のように広がるマップへ変換するので、アシスタントのコンテキストを形づくるテーマ、場所、トピック、行動パターンを探索できます。アシスタントが何を拾い上げ、それらがどうつながっているのかを、信じるしかないのではなく、自分の目で確かめられます。

メモリは見たいときにいつでも開けます。新しいタブでは、検索ボックスのすぐ下に入り口があります。ブラウザ本体では場所が[レイアウトモード](/ja/layouts/)によって変わり、**パフォーマンス**と**バランス**では**左下**に、**ゆったり**では**右上**にあります。

## アシスタントによる活用

アシスタントに質問する、ページを要約してもらう、タスクを任せる。そうしたとき、アシスタントは、今目の前にあるもの（現在のタブのこともあれば、[分割表示やタブグループ](/ja/layouts/)全体のこともあります）に加えて、あなたについて覚えていることを手がかりにします。だからこそ、毎回自分の状況を説明し直さなくても、あなたに合った答えが返ってきます。メモリはパーソナライズされた[新しいタブとウィジェット](/ja/new-tab/)にも活かされ、知っていることが隠れたままにならず、役立つかたちで表に現れます。アシスタントの呼び出し方や話しかけ方は、[アシスタントの紹介](/ja/ai/)をご覧ください。

## 常に自分の管理下に

メモリが作るものはすべてデバイス上にローカル保存され、あなたの管理下にとどまります。具体的には次のことができます。

- **表示・管理・削除**：覚えている内容は、Phiの中で直接確認し、整理し、削除できます。
- **サイトごとにメモリ収集をオフ**：学んでほしくないページがあるサイトでは、そのサイトからの収集を止められます。
- **インポートとエクスポート**：メモリは持ち出せるので、閉じ込められることなく、本当にあなたのものになります。

あなたのメモリがAIモデルの学習に使われることはありません。データの保存場所と、Phiが収集するもの・しないものについては、[プライバシーとデータ](/ja/privacy/)をご覧ください。なお、[AIをオフにしても](/ja/privacy/#turning-ai-off)メモリは消去されません。メモリも消したい場合はメモリページから削除してください。この削除は元に戻せません。

## Phiの外でも使えるメモリ：Anamnesis

同じメモリの仕組みは、（まだ）Phi Browserを使っていない人のために、単体でも提供されています。**Anamnesis**はChromeおよびChromium系ブラウザ向けのスタンドアロン拡張機能で、ブラウジングから同じように生きた、ローカルなブラウザメモリを育てます。

原則も同じです。メモリはあなたのものとしてあなたの手元にあり、いつでも表示、編集、削除、エクスポートできます。APIキーは自分で用意するため、アシスタントは選んだモデルプロバイダーと直接通信します。Phiが間に入ることも、あなたのメモリをサーバーに保存することもありません。エクスポートしたメモリは持ち運べるので、好きなときにPhi BrowserやほかのAIサービスへ持ち込めます。詳しくは[phibrowser.com/anamnesis](https://phibrowser.com/anamnesis/)をご覧ください。
