# はじめに

Phi BrowserはmacOS（Apple Silicon、macOS 14以降）で動作します。以下のいずれかの方法でインストールし、初回起動を進めてください。

## Phiのインストール

### 公式サイトからダウンロード

[Phiのダウンロードページ](https://phibrowser.com/download/)にアクセスして`.dmg`をダウンロードし、開いて、Phiをアプリケーションフォルダへドラッグします。

### Homebrewでインストール

[Homebrew](https://brew.sh/)を使っている場合は、次のコマンドでPhiをインストールできます。

```sh
brew install --cask phibrowser/tap/phi
```

このコマンドは`phibrowser/tap`を自動的にtapし、Phiのcaskをインストールします。アップデートはPhi自身が処理するため、Homebrew経由でアップグレードする必要はありません。

## 初回起動

初めてPhiを開くと、オンボーディングがセットアップを手伝ってくれます。

- **レイアウトモードを選ぶ**。パフォーマンス、バランス、ゆったりの3つがあります。いつでも変更できるので、今のブラウジングのしかたに最も近そうなものを選んでください。各モードの意味は[レイアウトとナビゲーション](/ja/layouts/)をご覧ください。
- **アシスタントと知り合う**。ブラウザに入ると、新しいタブの上部にあるバナーが、アシスタントのことを知るよう誘います。名前を付けると、それに合わせたアバターを自分で生成し、汎用のチャットボットのような存在ではなく、固有のアイデンティティを持つようになります。ここはスキップして、後から戻ることもできます。
- **AIはデフォルトでオン**。PhiのAI機能は最初から有効になっています。プレーンなブラウザとして使いたい場合は、後から**設定 → Phi AI**でオフにできます。

## ほかのブラウザからの乗り換え

ChromeやSafariに慣れている場合は、いちばん移行しやすい**ゆったりモード**から始めてください。Chrome、Safari、Arc、Diaのユーザーに向けたより詳しい移行マップは、[Phiへの乗り換え](/ja/switching-to-phi/)をご覧ください。
