# phi-browserスキル

**phi-browserスキル**は、ブラウザの外で動くAIコーディングエージェント、すなわち**Claude Code、Codex、Cursor、OpenClaw、Pi、Hermes**とPhiをつなぎます。エージェントにインストールすると、エージェントはPhiを直接操作できるようになります。ページを開く、フォームに入力する、スクリーンショットを撮る、データを抽出する、Webアプリをテストするなど、本物のブラウザを必要とする作業なら何でも任せられます。

::: tip ブラウザスキルとは別物です
これは単数形の「1つのスキル」で、あなたのコーディングエージェント側に属します。逆方向にあたるのが<strong>[ブラウザスキル](/ja/skills/)</strong>で、こちらはブラウザの中でPhi自身のアシスタントに教える指示です。phi-browserスキルは、エージェントがPhiを自分のブラウザとして使えるように、Phiが*あなたのエージェント*に渡すものです。
:::

このスキルの珍しさは、エージェントが*どこで*働くかにあります。あなたのウィンドウを乗っ取ることはなく、機能を削った別のブラウザを走らせることもありません。エージェントは自分専用の**エージェントスペース**、つまりあなたの本物のログイン状態を持つ非表示のブラウザウィンドウの中で働き、あなたはその間もブラウジングを続けられます。リアルタイムで見守り、いつでも操作を引き継ぎ、済んだら操作を戻せます。

## エージェントスペース

Phiは[スペース](/ja/spaces/)を軸に組み立てられています。スペースは独立したワークスペースで、それぞれが固有のログイン情報を持つプロファイルに結び付いています。コーディングエージェントがタスクを始めると、Phiは専用の**エージェントスペース**を割り当てます。非表示で生成される本物のブラウザウィンドウで、スペーススイッチャーには、ステータスバッジの付いた小さなロボット（🤖）マークとして現れます。エージェントが複数いる場合は番号付きのマーク（R1、R2など）になり、見分けが付きます。

マークをクリックすると、エージェントの作業をリアルタイムで見られます。Phiはエージェントの操作をネイティブに描画するため、カーソルは目標へ滑らかに動き、クリックは波紋を描き、入力中のフィールドは点滅して、何をしているのかを正確に追えます。見ている間、ページはあなたのクリックやキー入力を無視するので、うっかりエージェントの邪魔をすることはありません。介入する唯一の入り口は、明示的な**操作を引き継ぐ**ボタンです。

これを補うメニュー項目が2つあります。**表示 → エージェントトランスクリプト**は、エージェントの説明、操作、会話を表示するコンソールを開き、そこからエージェントへコマンドを打ち返すこともできます。**表示 → エージェント自動表示**は、いま操作しているエージェントを自動で追いかけます。

エージェントスペースは、デフォルトできれいに片付きます。一時的なスペースはタスクが静かになってからほどなく自動的に閉じるため、終わったタスクがスイッチャーに積み上がりません。エージェントが恒久的なワークスペースを作るのは、あなたが明示的に頼んだときだけです。

## いつでも操作を引き継げる

エージェントスペースを同時に操作できるのは一方だけで、勝つのは常にあなたです。エージェントスペース上部のオーバーレイには、操作中のエージェントの名前と、そのとき主導権を握っている側のための操作ボタンが表示されます。

- エージェントが操作している間は、**操作を引き継ぐ**で即座に停止できます。あなたが戻すまで、エージェントが試みるそれ以降の操作はすべて拒否されます。
- あなたが操作している間は、**操作を戻す**で主導権がエージェントに返り、エージェントは中断した場所から続けます。**完了**はタスクを終了します。

受け渡しは逆方向にも働きます。ログイン、CAPTCHA、2段階認証コード、影響の大きい選択など、あなたが行うべきステップに当たると、エージェントは操作を戻し、Phiが「**エージェントが操作を待っています**」というプロンプトを、エージェントスペースへ直接移動するボタンとともに表示します。人間のステップを済ませ、**操作を戻す**をクリックすれば、エージェントが再開します。

## ログイン情報の意図的な再利用

エージェントスペースはあなたの既存プロファイルのいずれかに結び付くため、エージェントはあなたがすでにログインしているサイトをそのまま使ってブラウジングします。それこそが狙いです。真っさらなブラウザから始めるのではなく、あなたの現在地から引き継げます。

どこまで許すかはあなたが決めます。「開発者」タブにある**エージェントが使用できるプロファイル**で、エージェントが作業できるプロファイルを制限できます。すべてを不許可にすると、Phiは専用の「Agent」プロファイルを作成し、あなたの主要なログイン情報に触れないままエージェントが作業を続けられるようにします。また、タスクでどこかにログインする必要が出ても、エージェントがパスワードの貼り付けを求めることはありません。すべてのリクエストにあなたの承認が必要な[エージェントのパスワードマネージャー](/ja/agent-passwords/)を通ります。

## エージェントの行動はあなたの責任

ここは2回読む価値があります。何かがひとりでに動いているのを眺めていると、見落としやすいことだからです。

Phiを操作するエージェントは、あなたのブラウザから、あなたのセッションを使って、**あなたとして**行動しています。あなたの指示のもとで行われたことは、当社のサービス上でも他社のサービス上でも、あなた自身の行為です。訪問先サイトの利用規約は、あなたが手作業でクリックした場合とまったく同じように、あなたに適用されます。

<strong>エージェントを望まないサイトがあり、そうしたサイトは対抗措置を取ります。</strong>多くのサイトは、コンテンツこそが自分たちのビジネスであるため、自動アクセスをビジネスへの脅威とみなし、積極的に検出しています。よく知られた例がRedditです。自動化と判定されたアカウントは制限や停止の対象になり、その判断は当社ではなくサイト側のものです。自動化を歓迎しないサイトにエージェントを向ければ、そのサイトのアカウント、履歴、そこに保存していたものを失うおそれがあります。このリスクはあなたが負うものであり、当社が代わりに異議を申し立てたり取り消したりすることはできません。

<strong>影響の大きい操作を許可するのはあなたです。</strong>エージェントは、あなたがログインしているサービスで買い物をし、メッセージを送り、フォームを送信し、設定を変更できます。実行させる前に、何をしようとしているのかを確認してください。Phiが確認を求める場面では、その確認が実際の役割を果たしています。

## セットアップ

すべては**開発者モード**の背後にあり、デフォルトではオフです。手順は3つです。

1. **設定 → 一般**で**開発者モード**をオンにします。これで「開発者」タブが現れます。エージェントのアクセス、権限、パスワードマネージャーはそこにあります。
2. **設定 → 開発者 → phi-browserスキルをインストール**からスキルをインストールします。<strong>スキルを追加…</strong>ボタンには対応エージェントの一覧と**すべてのエージェント**が並び、Phiに同梱されたスキルをそのエージェントのスキルフォルダへリンクして、Phiが更新されるたびに最新の状態を保ちます。Node 22以降が必要です。設定を終えたエージェントは、その後で再起動してください。Piでは`/reload`で十分です。
3. **設定 → 開発者 → エージェント制御**の「**エージェントにPhiの操作を許可（CDP）**」で、エージェントの接続を許可します。再起動は不要で、すぐに適用されます。

あるエージェントが初めて実際に接続すると、Phiは接続元のプロセスをコード署名まで含めて識別したうえで、**今回のみ許可**、**常に許可**、**拒否**のいずれにするかを尋ねます。あなたが承認するまで、ブラウザには何も届きません。承認済みのエージェントは、同じタブの**許可済みのエージェント**に「常に」または「このセッションのみ」と表示されます。削除すると、次の接続時に改めて尋ねられます。

## アクセスが制限される仕組み

この接続は、あなたが承認していないものからは到達できないように設計されています。

- Phiが待ち受けるのは、ネットワークポートではなく、**このMacのプロセスだけが到達できるプライベートソケット**です。ネットワーク上の何者も、このMacの他のユーザーも、接続できません。
- すべての接続は接続元プロセスの身元で検証され、**エージェントごとに個別の同意**が必要です。
- 「**エージェントにPhiの操作を許可（CDP）**」をオフにすると、新しい接続は止まり、接続中のものも即座に切断されます。
- デフォルトでは、エージェントは**自分のエージェントスペース**の中でしか作業できません。あなたの実際のブラウジングデータ、つまりスペース、ブックマーク、固定タブ、URLルール、ウィンドウレイアウトに触れることは別の権限「**エージェントにスペースの操作を許可**」になっており、これもデフォルトでオフです。
- **開発者モード**のオフは全体の停止スイッチです。エージェントアクセスと[エージェントのパスワードマネージャー](/ja/agent-passwords/)がまとめて無効になり、再びオンにしても自動的に再有効化されるものはありません。
