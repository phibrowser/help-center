# ArcまたはZenからの移行

<strong>他のブラウザから移行…</strong>は、ArcやZenの構成をそのままの形でPhiに再現します。移行元のプロファイルごとにPhiのプロファイルを、移行元のスペースごとにPhiのスペースを作成し、各スペースにはそのブックマークを、各プロファイルには固定タブと閲覧データを入れます。完了すると、以前のサイドバーがPhiの中に再現されています。

移行が行うのは作成だけです。Phiにすでにあるプロファイルやスペースを変更したり、統合したり、削除したりすることはありません。

## 移行とインポートの違い {#migrate-or-import}

Phiには、データを取り込むコマンドが2つあり、**Phi**メニュー（Appleメニューの隣にある太字のアプリメニュー）に並んでいます。

|                       | **他のブラウザからインポート…**              | **他のブラウザから移行…**                                |
| --------------------- | -------------------------------------------- | -------------------------------------------------------- |
| 行うこと              | 今いるスペースにデータを追加する             | 移行元と同じ構成の新しいプロファイルとスペースを作成する |
| 対応ブラウザ          | Chrome、Safari、Arc、Dia、またはファイル     | ArcとZen                                                 |
| データの取り込み先    | 現在のスペースと、そのプロファイル           | 移行で作成される新しいプロファイルとスペース             |
| 選べるもの            | 取り込むデータの種類                         | 再現するスペース                                         |
| Phiにある既存のデータ | ブックマークと履歴が、既存のものに追加される | 変更されない                                             |

すでに気に入ったPhiの構成があり、そこにブックマークや履歴を追加したい場合は**インポート**を選びます。ArcやZenから乗り換えるところで、スペースを手作業で作り直さずに元の形のまま戻したい場合は**移行**を選びます。インポートについては[インポートと書き出し](/ja/import-export/)で説明しています。

## 始める前に {#before-you-start}

- <strong>このMacにブラウザがインストールされていること。</strong>移行では、ArcやZenがデータを保存している場所からそのデータを読み取ります。どちらもインストールされていない場合、<strong>他のブラウザから移行…</strong>はグレイ表示になります。
- <strong>Phiにサインインするか、ゲストとして続けること。</strong>移行で作成されるプロファイルとスペースはPhiアカウントに属するため、ウィザードは開始前に初回起動の設定を済ませるよう求めます。
- <strong>先にZenを終了すること。</strong>PhiはZenのファイルのコピーを読み取るため、Zenがまだディスクに保存していない内容は漏れてしまいます。Zenの起動中は、ウィザードがそのことを知らせます。
- <strong>Arcではキーチェーンの確認が表示されること。</strong>ArcはCookieを暗号化しているため、PhiがArcの暗号化キーを使ってよいかをmacOSが確認します。**常に許可**を選んでください。そうしないと、macOSはプロファイルごとに確認を繰り返します。許可しなかった場合、そのプロファイルのCookieは移行されずに残り、それ以外はすべて引き継がれます。レポートには、Cookieが欠けていることは表示されません。
- <strong>インポートと同時に実行しないこと。</strong>移行の実行中は<strong>他のブラウザからインポート…</strong>がグレイ表示になり、インポートの実行中は移行がグレイ表示になります。

## 移行を実行する {#running-a-migration}

1. **Phi**メニューを開き、<strong>他のブラウザから移行…</strong>を選択します。**Phiへ移行**ウインドウが開きます。
2. **Arc**または**Zen**を選び、**続ける**をクリックします。一覧には、このMacにインストールされているブラウザだけが表示されます。
3. **作成される内容を確認**の下にあるプレビューを確認します。移行元のプロファイルごとにそのスペースが表示され、「_2個のプロファイルと5個のスペースを作成します。_」のような概要も表示されます。不要なスペースのチェックを外してください。プロファイルが作成されるのは、そのスペースのうち少なくとも1つにチェックが入っている場合だけです。
4. **移行を開始**をクリックします。Phiはプロファイルとスペースを1つずつ作成し、進行状況を表示します。数分かかることがあります。その間もブラウズを続けられます。新しいスペースが、今使っているスペースの上に開くことはありません。
5. **移行が完了しました**の下にあるレポートを確認します。最初の新しいスペースに切り替えるには、スペース名に続けて**へ移動**と表示されたボタンをクリックします。ウインドウを閉じるには**完了**をクリックします。

## 引き継がれるもの {#what-comes-across}

構成の対応はどちらのブラウザでも同じです。移行元の各プロファイルはPhiのプロファイルになり、移行元の各スペースはそのプロファイルに属するPhiのスペースになります。スペースの名前は保たれ、Phiに対応するものがあれば、カラーとアイコンも保たれます。

| 移行元の項目                                                                                       | Phiでの扱い                                                                        |
| -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Arcのプロファイル、またはZenのコンテナー（コンテナーのないZenのスペースは1つのプロファイルを共有） | 新しいプロファイル                                                                 |
| ArcまたはZenのスペース                                                                             | そのプロファイル内の新しいスペース                                                 |
| Arcのサイドバーに固定した項目、またはZenの各スペースの固定タブ（フォルダを含む）                   | そのスペースのブックマーク                                                         |
| ArcのFavorites、またはZenのEssentials                                                              | 固定タブ（[固定タブの範囲](/ja/bookmarks/#choose-a-pinned-tab-scope)に従って配置） |

各プロファイルに入る閲覧データは、ブラウザによって異なります。

| データ     | Arc                          | Zen  |
| ---------- | ---------------------------- | ---- |
| 最近の履歴 | あり                         | あり |
| Cookie     | あり（キーチェーンの許可後） | なし |
| 拡張機能   | Chromeウェブストアのもの     | なし |

知っておきたい制限がいくつかあります。

- <strong>開いているタブは移行されません。</strong>引き継がれるのは、固定した項目と、FavoritesまたはEssentialsだけです。開いていても固定していなかったタブは、移行元のブラウザに残ります。
- <strong>履歴は最近のもので、すべてではありません。</strong>移行では、これまでのすべての訪問ではなく、最近の履歴の項目だけが引き継がれます。
- <strong>拡張機能はバックグラウンドでインストールされます。</strong>Arcの場合、レポートには、インストールが始まったChromeウェブストアの拡張機能の数が表示されます。それ以外の入手元の拡張機能は移行されず、ZenのFirefox用拡張機能はPhiでは動作しません。
- <strong>パスワードと支払いカードは移行されません。</strong>
- <strong>Zenのプライベートウインドウ用のスペースはスキップされます。</strong>
- <strong>固定タブにはスペースが必要です。</strong>Phiがプロファイルを作成するのは、作成するスペースが少なくとも1つある場合だけです。どのZenのスペースにも使われていないZenのコンテナーなど、スペースのない移行元のプロファイルはスキップされ、その固定タブのうちいくつが残されたかがレポートに表示されます。

移行元のブラウザは変更されません。ArcやZenのデータはすべてそのまま残るため、移行して見比べたうえで、どちらのブラウザも使い続けられます。

## レポートの見かた {#reading-the-report}

レポートには、すべてのプロファイルとスペースについて、それぞれどうなったかが一覧で表示されます。各スペースが受け取ったブックマークの数、追加された固定タブの数、そして履歴、Cookie、拡張機能が引き継がれたかどうかです。失敗したものがある場合は、確認が必要な項目の数が概要に表示され、該当する行に**スペースが作成されませんでした**や**ブックマークを保存できませんでした**のように、何が問題だったかが表示されます。それ以外の結果はすべて保持されるため、1つの失敗で残りが取り消されることはありません。

## もう一度移行する {#migrating-again}

Phiは、どのブラウザからアカウントに移行したかを記録しています。同じブラウザからもう一度移行を始めると、先に警告が表示されます。もう一度移行すると、プロファイルとスペースがもう1セット作成され、最初のセットは更新されません。それが目的の場合にだけ**もう一度移行**を選んでください。最初からやり直したい場合は、2つのコピーが並んでしまわないように、もう一度移行する前に1回目で作成されたスペースを削除してください（[スペースとプロファイル](/ja/spaces/)を参照）。

ArcやZenとの継続的な同期はありません。移行は、その時点で移行元にあったものを1回だけコピーする操作です。
