# Phi Browserの便利なヒント

このページでは、画面からは分かりにくいPhiのジェスチャとショートカットをまとめています。掲載しているキーボードショートカットはデフォルトのもので、**設定 → ショートカット**で変更できます。

## ショートカット一覧

| 操作                              | ショートカットまたはジェスチャ                                                      |
| --------------------------------- | ----------------------------------------------------------------------------------- |
| 分割表示を作成                    | Option (⌥)キーを押しながらタブ、固定タブ、ブックマーク、対応するWebリンクをクリック |
| 最近使ったタブを切り替え          | Control (⌃) + Tab                                                                   |
| 逆順に切り替え                    | Control (⌃) + Shift (⇧) + Tab                                                       |
| 現在のページのURLをコピー         | Command (⌘) + Shift (⇧) + C                                                         |
| 開いているタブを検索              | Command (⌘) + Shift (⇧) + A                                                         |
| 前または次のスペースへ移動        | Command (⌘) + Option (⌥) + ← または →                                               |
| 先頭9個のスペースのいずれかを開く | Control (⌃) + 1〜9                                                                  |

## 分割表示を作成する

- Option (⌥)キーを押しながら、別のタブ、グループ内のタブ、固定タブ、ブックマーク、または対応するWebリンクをクリックします。Phiがそのページを現在のページの隣に配置します。
- タブ、固定タブ、ブックマークを1つ、現在のページの左端または右端へドラッグします。ドロップした側に表示されます。
- 固定されていない既存の分割表示のペインに項目をドロップすると、そのペインが置き換わります。

## 保存したURLに戻る

固定タブやブックマークは、最初に保存したURLから離れてしまうことがあります。今見ているページを失わずに、保存したURLへ戻れます。

- 固定タブをダブルクリックすると、保存したURLに戻ります。
- ブックマークのファビコンをクリックすると、保存したURLに戻ります。
- どちらの操作でも、Command (⌘)キーを押しながら行うと、保存したURLを復元する前に、現在のページを別のタブとして開いたまま残せます。

## グループ概要を使用する

タブグループのヘッダをクリックすると、グループ概要が開きます。各ページのプレビューが表示され、分割表示は1枚にまとめたカードとして表示されます。

グループ概要からは、ページへの切り替え、ページを閉じる操作、新しいタブの作成、グループの名前とカラーの変更ができます。グループ概要を開いたままアドレスバーを使うと、新しいタブはそのグループに加わります。

タブグループ全体をブックマーク領域にドラッグすると、ブックマークフォルダに変わります。Phiはタブの順序を保ったままグループを解除しますが、開いていたタブは開いたままです。

## 複数のタブやブックマークをまとめて操作する

- Command (⌘)キーを押しながらクリックすると、通常のタブやブックマークを1つずつ選択できます。
- Shift (⇧)キーを押しながらクリックすると、範囲で選択できます。
- 状況に応じて、タブグループの作成、ブックマークフォルダへの追加、別のスペースへの移動や複製、まとめて閉じる操作などが行えます。
- 選択した項目のいずれかをドラッグすると、選択全体が移動します。分割表示の2つのペインは一緒に動きます。
- Escキーを押すと選択が解除されます。

## 切り替え、検索、コピー

Control (⌃) + Tabは、ウインドウ内のタブの並び順ではなく、最近使った順に従います。

- 1回押すと、現在のタブと直前のタブを切り替えます。
- 押し続けるか繰り返し押すと、最近使ったタブを最大5つ表示します。
- Shift (⇧)を加えると、リストを逆順にたどります。
- Command (⌘) + Shift (⇧) + Aで、開いているすべてのタブを検索します。
- Command (⌘) + Shift (⇧) + Cで、現在のタブのURLをコピーします。

## 各スペースをカスタマイズする

**設定 → スペース**を開き、スペースを選択します。

- Phi内蔵のセットからアイコンを選ぶか、絵文字を使います。
- テーマカラーを選び、彩度を調整します。

各スペースは独自のアイコンとテーマを保持します。スペースを切り替えると、そのスペースに設定した外観が、ほかのスペースに影響することなく適用されます。

## スペース間を移動する

- Command (⌘) + Option (⌥) + ← または →で、前または次のスペースへ移動します。
- Control (⌃) + 1〜9で、先頭9個のスペースのいずれかを直接開きます。

## URLルールでサイトを振り分ける

メニューバーの**スペース → URLルール…**を開くか、**設定 → スペース**からURLルールを開きます。ルールの一致条件には**ドメインとサブドメイン**、**ドメイン**、**ドメインの部分一致**、**URL**を指定できます。

一致したページは、通常のスペースまたはシークレットスペースへ送れます。移動する前にPhiに確認してほしい場合は**毎回確認する**を選びます。複数のルールが一致した場合は、最も具体的なルールが優先されます。

::: tip スペースの振り分けではCookieは分離されません
URLルールが決めるのは、ページをどこで開くかだけです。Cookieやログイン状態を分けておくには、振り分け先のスペースを別々のプロファイルに割り当ててください。
:::

## ピクチャインピクチャでビデオを表示し続ける

Phiは、タブやスペースを切り替えたときに、再生中のビデオをポップアウトできます。動作は**設定 → 一般 → 自動ピクチャ・イン・ピクチャ**で選択します。

| モード           | 動作                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------ |
| **オフ**         | 自動でピクチャインピクチャを開くことはありません。手動のピクチャインピクチャは引き続き使えます。 |
| **標準**         | タブやスペースを切り替えると、再生中のビデオをポップアウトします。                               |
| **画面端に待機** | 再生中のビデオをポップアウトし、クリックするまでウインドウを画面の端に待機させます。             |

ピクチャインピクチャのウインドウを移動またはサイズ変更すると、そのサイトが次にピクチャインピクチャを開いたときに、Phiが位置とサイズを再現します。これは通常のプロファイルでサイトごとに保存され、シークレットスペースでは保持されません。保存時のディスプレイが接続されていない場合は、デフォルトの位置が使われます。

開いているピクチャインピクチャのウインドウを自分で待機させるには、ポインタをウインドウに重ね、**画面の端にドッキング**というラベルの下向き矢印をクリックします。Phiはウインドウを最も近い画面の端に収め、ハンドルだけを見える状態にします。ハンドルをクリックするとウインドウが戻ります。この操作は、自動ピクチャ・イン・ピクチャが**オフ**のときでも使えます。

## 今の作業についてアシスタントに質問する

- テキストを選択して右クリックし、**…について[アシスタント名]に質問**を選ぶと、選択内容を会話に取り込めます。
- アシスタントを開くと、デフォルトで現在のタブがコンテキストとして添付されます。そのタブがグループ内にある場合は、グループ全体を添付できます。
- タブグループや分割表示は、1つの単位として添付できます。

現在のタブを添付せずに会話を始めるには、**設定 → Phi AI → AIサイドバー**で**新しい会話に現在のタブをコンテキストとして自動的に追加**をオフにします。

Phi Cloudを使う場合、質問に答えるために必要なコンテンツは、処理のためにサードパーティのモデルプロバイダに送信されます。プライベートAIならMacの外には出ません。詳しくは[プライバシーとあなたのデータ](/ja/privacy/)をご覧ください。
