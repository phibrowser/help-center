# Premiers pas

Phi Browser fonctionne sur macOS (Apple Silicon, macOS 14 ou plus récent). Installez-le par l'une des deux méthodes ci-dessous, puis suivez le premier démarrage.

## Installer Phi

### Télécharger depuis le site officiel

Rendez-vous sur la [page de téléchargement de Phi](https://phibrowser.com/download/), téléchargez le fichier `.dmg`, ouvrez-le, puis faites glisser Phi dans votre dossier Applications.

### Installer avec Homebrew

Si vous utilisez [Homebrew](https://brew.sh/), installez Phi avec :

```sh
brew install --cask phibrowser/tap/phi
```

Cette commande ajoute automatiquement le tap `phibrowser/tap` et installe le cask Phi. Les mises à jour sont ensuite gérées par Phi lui-même ; vous n'avez pas besoin de passer par Homebrew pour mettre à niveau.

## Premier démarrage

À la première ouverture de Phi, un parcours de bienvenue vous aide à tout mettre en place :

- **Choisissez un mode de disposition**, Performance, Équilibré ou Confortable. Vous pourrez en changer à tout moment ; choisissez donc celui qui ressemble le plus à votre façon de naviguer aujourd'hui. Consultez [Dispositions et navigation](/fr/layouts/) pour comprendre chaque mode.
- **Faites connaissance avec votre assistant**, une fois dans le navigateur, une bannière en haut du nouvel onglet vous invite à le rencontrer : donnez-lui un nom, et il génère un avatar assorti, pour avoir sa propre identité au lieu de ressembler à un chatbot générique. Vous pouvez aussi passer cette étape et y revenir plus tard.
- **L'IA est activée par défaut**, les fonctions d'IA de Phi sont actives dès l'installation. Vous pourrez les désactiver plus tard dans **Paramètres → Phi AI** si vous préférez un navigateur classique.

## Vous venez d'un autre navigateur ?

Si vous avez l'habitude de Chrome ou de Safari, commencez par le **mode Confortable** pour une transition en douceur. Pour une carte de migration plus complète destinée aux utilisateurs de Chrome, Safari, Arc et Dia, consultez [Passer à Phi](/fr/switching-to-phi/).
