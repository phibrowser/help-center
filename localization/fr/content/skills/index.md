# Browser Skills

Une Browser Skill est une instruction réutilisable que vous confiez à votre assistant. Apprenez-lui une tâche en plusieurs étapes une seule fois, et vous pourrez ensuite déclencher l'ensemble d'une seule demande, au lieu de détailler les étapes à chaque fois. Un travail récurrent devient une chose que l'assistant sait faire.

Certaines Skills sont des gestes pratiques en un coup : afficher un code QR pour la page actuelle, enregistrer une page en PDF, récupérer la transcription d'une vidéo YouTube. D'autres encapsulent une routine plus longue que vous exécutez souvent. Dans les deux cas, l'idée est la même : décrire une fois, réutiliser pour toujours.

::: tip À ne pas confondre avec le skill phi-browser
Les **Browser Skills**, c'est le sujet de cette page : des instructions que vous donnez à l'assistant dans Phi. Le **[skill phi-browser](/fr/phi-browser-skill/)** est tout autre chose : un paquet qui permet à un agent IA extérieur, comme Claude Code, de piloter Phi depuis votre terminal. Un même mot, deux sens, alors nous les distinguons : les Browser Skills vivent dans le navigateur, le skill phi-browser vit dans votre agent.
:::

## Les Skills intégrées et les vôtres

Il en existe deux sortes :

- **Les Skills intégrées**, un ensemble fourni et maintenu par Phi, prêt à l'emploi.
- **Vos propres Skills**, celles que vous créez pour votre façon de travailler.

Les Skills intégrées ne s'activent que si vous le décidez. Elles sont là pour être parcourues : vous ajoutez celles que vous voulez à votre bibliothèque, plutôt que de tout avoir activé d'un coup.

## La bibliothèque de Skills

La page **Skills** est l'endroit où tout cela se gère. Ouvrez-la depuis le menu situé dans le **coin supérieur droit du nouvel onglet**, le même menu que vos conversations récentes et vos widgets, et choisissez **Skills**.

Elle s'ouvre sur une sélection de Skills intégrées mises en avant, et en dessous vous pouvez parcourir l'ensemble. Filtrez par **Toutes**, **Intégrées**, **Créées par vous** ou **Activées**, ou cherchez par nom. C'est ce qui se rapproche le plus d'une galerie de ce que votre assistant sait faire.

Pour chaque Skill, vous pouvez :

- **Ajouter** une Skill intégrée à votre bibliothèque, et la retirer plus tard. Vous pourrez toujours l'ajouter de nouveau.
- **Activer ou désactiver** une Skill sans la retirer, pour contrôler lesquelles sont actives.
- **Afficher** le détail complet d'une Skill pour voir exactement ce qu'elle fait avant de l'utiliser.

## Créer les vôtres

Vous n'êtes pas limité à l'ensemble intégré. Phi inclut un **Créateur de Skills** qui vous aide à concevoir et enregistrer une nouvelle Skill à partir d'une description de la tâche : en créer une est donc en soi une Skill, que vous demandez comme les autres. Vos propres Skills sont des instructions ordinaires, rédigées avec vos mots, et vous pouvez les modifier ou les supprimer à tout moment quand vos routines changent.

## Utiliser les Skills dans la conversation

Les Skills s'exécutent à travers votre assistant, pas toutes seules. Une fois une Skill activée, l'assistant peut s'en saisir de lui-même quand votre demande correspond à ce qu'elle fait. Vous pouvez aussi en amener une vous-même dans une conversation : choisissez-la dans la liste des Skills pendant que vous rédigez un message, y compris depuis le [champ de requête du nouvel onglet](/fr/new-tab/), quand vous voulez être explicite sur celle à utiliser.

## Une Skill peut agir, alors accordez-lui la même réflexion qu'à vos propres actions

Les Skills ne se limitent pas à récupérer et résumer. Une Skill qui remplit des formulaires, publie ou opère sur un site le fait en votre nom, depuis votre navigateur, avec vos sessions. Deux conséquences en découlent.

Tout ce qui porte à conséquence reste à votre charge : un achat, un message envoyé, un formulaire soumis. Lisez ce que fait une Skill avant de l'activer ; c'est précisément à cela que sert le détail **Afficher**.

Et certains sites n'accueillent pas volontiers l'automatisation. Reddit est l'exemple connu : les comptes détectés comme automatisés y sont restreints ou bannis, et cette décision leur appartient, pas à nous. Si une Skill opère sur un site de ce genre, ce risque, vous le prenez avec votre compte. Consultez [le skill phi-browser](/fr/phi-browser-skill/) pour en savoir plus.
