# Astuces rapides pour Phi Browser

Cette page rassemble les gestes et raccourcis de Phi que l'interface ne rend pas évidents. Les raccourcis clavier indiqués ici sont ceux par défaut. Vous pouvez les modifier dans **Paramètres → Raccourcis**.

## Récapitulatif des raccourcis

| Action                                                                                         | Raccourci ou geste                                                                       |
| ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Créer une Split View                                                                           | Clic avec Option (⌥) sur un onglet, un onglet épinglé, un favori ou un lien web éligible |
| Prévisualiser un lien dans la vue Peek                                                         | Clic avec Maj (⇧) sur un lien web                                                        |
| Basculer entre les onglets récemment utilisés                                                  | Contrôle (⌃) + Tab                                                                       |
| Basculer dans l'ordre inverse                                                                  | Contrôle (⌃) + Maj (⇧) + Tab                                                             |
| Copier l'URL de la page actuelle                                                               | Commande (⌘) + Maj (⇧) + C                                                               |
| Rechercher dans les onglets ouverts                                                            | Commande (⌘) + Maj (⇧) + A                                                               |
| Capturer la page entière                                                                       | Commande (⌘) + Maj (⇧) + 1                                                               |
| Capturer une zone sélectionnée                                                                 | Commande (⌘) + Maj (⇧) + 2                                                               |
| Passer à l'Espace précédent ou suivant                                                         | Commande (⌘) + Option (⌥) + ← ou →                                                       |
| Ouvrir l'un des neuf premiers Espaces                                                          | Contrôle (⌃) + 1 à 9                                                                     |
| Ouvrir une nouvelle fenêtre Kiosk depuis n'importe quelle app, avec le raccourci global activé | Commande (⌘) + Option (⌥) + N                                                            |
| Ouvrir une page Kiosk ou un aperçu Peek dans un onglet d'un Espace                             | Commande (⌘) + O                                                                         |
| Ouvrir le menu de sélection d'Espace de Kiosk                                                  | Commande (⌘) + Maj (⇧) + O                                                               |
| Ouvrir ou masquer Phi Chat depuis n'importe quelle app, avec le raccourci activé               | Maj (⇧) trois fois                                                                       |

Activez le raccourci global de Kiosk dans **Paramètres → Navigation → Kiosk**. Pour changer les touches, modifiez **Nouvelle fenêtre Kiosk** dans **Paramètres → Raccourcis → Fichier**.

Le raccourci de Phi Chat est désactivé par défaut. Activez-le avec **Invoquer Phi Chat avec Maj Maj Maj** dans **Paramètres → Phi et IA → Phi Sentinel**. Il n'est pas possible de lui attribuer d'autres touches. Consultez [Phi Chat](/fr/phi-chat/#opening-phi-chat).

Modifiez les deux raccourcis d'ouverture dans un Espace dans **Paramètres → Raccourcis → Kiosk et Peek**. Consultez [Kiosk](/fr/kiosk/) et [Vue Peek](/fr/peek/) pour les détails.

## Créer une Split View

- Maintenez Option (⌥) et cliquez sur un autre onglet, un onglet au sein d'un groupe, un onglet épinglé, un favori ou un lien web éligible. Phi le place à côté de votre page actuelle.
- Faites glisser un onglet seul, un onglet épinglé ou un favori vers le bord gauche ou droit de la page actuelle. Le côté choisi détermine où il apparaît.
- Déposez un élément sur un volet d'une Split View existante non épinglée pour remplacer ce volet.

## Revenir à une URL enregistrée

Un onglet épinglé ou un favori peut s'éloigner de l'URL que vous aviez enregistrée. Vous pouvez y revenir sans perdre la page que vous consultez.

- Double-cliquez sur un onglet épinglé pour le ramener à son URL enregistrée.
- Cliquez sur la favicon d'un favori pour le ramener à son URL enregistrée.
- Maintenez Commande (⌘) pendant l'un ou l'autre geste pour garder la page actuelle ouverte dans un onglet séparé avant de restaurer l'URL enregistrée.

## Utiliser l'Aperçu de groupe

Cliquez sur l'en-tête d'un groupe d'onglets pour ouvrir l'Aperçu de groupe. Il affiche un instantané de chaque page, une Split View apparaissant comme une seule carte combinée.

Depuis l'Aperçu de groupe, vous pouvez passer à une page, fermer une page, créer un nouvel onglet, ou modifier le nom et la couleur du groupe. Si vous utilisez la barre d'adresse pendant que l'Aperçu de groupe est ouvert, le nouvel onglet rejoint ce groupe.

Faites glisser un groupe d'onglets entier vers la zone des favoris pour le transformer en dossier de favoris. Phi conserve l'ordre de ses onglets et dissout le groupe, mais les onglets ouverts restent ouverts.

## Travailler avec plusieurs onglets et favoris

- Cliquez avec Commande (⌘) sur des onglets normaux et des favoris pour les sélectionner un par un.
- Cliquez avec Maj (⇧) pour sélectionner une plage.
- Les actions disponibles peuvent inclure la création d'un groupe d'onglets, l'ajout d'éléments à un dossier de favoris, leur déplacement ou leur clonage vers un autre Espace, et leur fermeture.
- Faites glisser n'importe quel élément sélectionné pour déplacer toute la sélection. Les deux volets d'une Split View restent ensemble.
- Appuyez sur Échap pour annuler la sélection.

## Basculer, rechercher et copier

Contrôle (⌃) + Tab suit l'ordre d'utilisation récente, pas l'ordre des onglets dans la fenêtre.

- Appuyez une fois pour basculer entre l'onglet actuel et le précédent.
- Maintenez le raccourci ou appuyez plusieurs fois pour afficher jusqu'à cinq onglets récemment utilisés.
- Ajoutez Maj (⇧) pour parcourir la liste en sens inverse.
- Appuyez sur Commande (⌘) + Maj (⇧) + A pour rechercher dans tous les onglets ouverts.
- Appuyez sur Commande (⌘) + Maj (⇧) + C pour copier l'URL de l'onglet actuel.

## Personnaliser chaque Espace

Ouvrez **Paramètres → Espaces**, puis sélectionnez un Espace.

- Choisissez une icône dans le jeu intégré de Phi, ou utilisez un emoji.
- Choisissez une couleur de thème et ajustez sa saturation.

Chaque Espace conserve sa propre icône et son propre thème. Changer d'Espace applique l'apparence choisie pour cet Espace sans modifier les autres.

## Passer d'un Espace à l'autre

- Appuyez sur Commande (⌘) + Option (⌥) + ← ou → pour passer à l'Espace précédent ou suivant.
- Appuyez sur Contrôle (⌃) + 1 à 9 pour ouvrir directement l'un des neuf premiers Espaces.

## Diriger les sites avec les Règles d'URL

Ouvrez **Espaces → Règles d'URL…** depuis la barre des menus, ou ouvrez **Paramètres → Navigation** et cliquez sur **Gérer les règles d'URL…**. Une règle peut correspondre par **Suffixe de domaine**, **Domaine**, **Le domaine contient** ou **URL**.

Envoyez une correspondance vers un Espace normal, la Navigation privée ou Kiosk. Choisissez **Toujours demander** si vous voulez que Phi demande avant de déplacer la page. Quand plusieurs règles correspondent, la règle la plus spécifique l'emporte.

::: tip Le routage vers un Espace normal n'isole pas les cookies
Diriger un site vers un Espace normal n'isole ni ses cookies ni sa session connectée. Attribuez les Espaces cibles à des Profils différents quand vous voulez cette séparation.
:::

## Garder la vidéo visible avec Picture-in-Picture

Phi peut détacher la vidéo en cours de lecture quand vous changez d'onglet ou d'Espace. Choisissez le comportement dans **Paramètres → Avancés → Picture-in-Picture automatique**.

| Mode               | Comportement                                                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------------------------------- |
| **Désactivé**      | N'ouvre jamais Picture-in-Picture automatiquement. Le Picture-in-Picture manuel fonctionne toujours.                |
| **Normal**         | Détache la vidéo en cours de lecture quand vous changez d'onglet ou d'Espace.                                       |
| **Ranger au bord** | Détache la vidéo en cours de lecture, puis range la fenêtre au bord de l'écran jusqu'à ce que vous cliquiez dessus. |

Déplacez ou redimensionnez une fenêtre Picture-in-Picture et Phi mémorise sa position et sa taille pour la prochaine fois que ce site ouvre Picture-in-Picture. Ceci est enregistré par site dans un Profil normal. Les Espaces de navigation privée ne le conservent pas. Si l'écran enregistré n'est plus connecté, Phi utilise l'emplacement par défaut.

Pour ranger vous-même une fenêtre Picture-in-Picture ouverte, placez le pointeur dessus et cliquez sur la flèche vers le bas, intitulée **Ranger au bord de l'écran**. Phi cale la fenêtre contre le bord d'écran le plus proche et laisse une poignée visible. Cliquez sur la poignée pour faire revenir la fenêtre. Cette commande fonctionne même quand le Picture-in-Picture automatique est réglé sur **Désactivé**.

## Contrôler les médias en arrière-plan avec le Mini-lecteur

Le Mini-lecteur apparaît en bas de la barre latérale lorsqu'un contenu audio ou vidéo compatible est en cours de lecture dans un onglet en arrière-plan, y compris lorsque vous passez à un autre Espace. Les médias dont le son est coupé ne font pas apparaître automatiquement le Mini-lecteur. Le Mini-lecteur se masque lorsque vous revenez à l'onglet source, lorsque cet onglet est visible en Split View ou lorsque sa vidéo est en mode Image dans l'image.

Utilisez le Mini-lecteur pour lancer ou mettre en pause la lecture et changer de piste. Cliquez sur l'icône du site pour revenir à l'onglet source. Cliquez sur le bouton du haut-parleur pour afficher le curseur de volume ; maintenez Option (⌥) et cliquez sur ce bouton pour couper ou rétablir le son. Si plusieurs onglets en arrière-plan contiennent des médias, balayez le Mini-lecteur vers la gauche ou la droite pour changer de source.

Développez le Mini-lecteur pour voir les détails du média, vous déplacer dans une piste ou ouvrir le mode Image dans l'image. Les détails et commandes disponibles dépendent de ce que le site web prend en charge.

Choisissez un mode dans **Paramètres → Avancés → Mini-lecteur** :

| Mode                   | Comportement                                                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Désactivé**          | Le Mini-lecteur n'apparaît pas automatiquement.                                                                                                    |
| **Auto**               | Le Mini-lecteur s'affiche d'abord sous forme compacte, puis se développe au survol ou lorsqu'il reçoit le focus clavier. C'est le mode par défaut. |
| **Toujours développé** | Affiche le Mini-lecteur développé dès qu'un média compatible est disponible en arrière-plan.                                                       |
| **Toujours compact**   | Garde le Mini-lecteur compact.                                                                                                                     |

## Prendre et modifier des captures d'écran

Choisissez **Fichier → Capturer la page entière** ou appuyez sur Commande (⌘) + Maj (⇧) + 1 pour capturer la page web actuelle, y compris le contenu au-delà de la zone visible.

Choisissez **Fichier → Capturer une zone…** ou appuyez sur Commande (⌘) + Maj (⇧) + 2, puis faites glisser le pointeur pour sélectionner une partie de la page. Pendant ce geste, faites défiler la page avec votre souris ou votre trackpad, ou maintenez le pointeur près d'un bord de la page pour étendre la sélection au-delà de la zone visible. Relâchez pour capturer, ou appuyez sur Échap pour annuler.

Ce sont les raccourcis par défaut. Modifiez-les dans **Paramètres → Raccourcis → Fichier**.

Après la capture, Phi copie l'image originale dans le presse-papiers au format PNG et ouvre l'éditeur d'images.

Utilisez l'éditeur d'images pour recadrer votre capture, dessiner, ajouter du texte et des formes, ou appliquer une pixellisation sur certaines zones.

Cliquez sur **Exporter…** pour enregistrer l'image modifiée au format PNG, JPG ou PDF.

## Interroger l'assistant sur votre travail en cours

- Sélectionnez du texte, faites un clic droit dessus et choisissez **Demander à [votre assistant] à propos de…** pour amener la sélection dans une conversation.
- Ouvrir l'assistant joint l'onglet actuel par défaut. Si cet onglet fait partie d'un groupe, Phi peut joindre le groupe entier.
- Un groupe d'onglets ou une Split View peut être joint comme une seule unité.

Pour démarrer des conversations sans joindre l'onglet actuel, désactivez **Ajouter automatiquement l'onglet actif comme contexte aux nouvelles conversations** dans **Paramètres → Phi et IA → Barre latérale IA**.

Quand vous utilisez Phi Cloud, le contenu nécessaire pour répondre à votre question est envoyé à un fournisseur de modèle tiers pour traitement. Avec l'IA privée, il reste sur votre Mac. Consultez [Confidentialité et vos données](/fr/privacy/) pour les détails.
