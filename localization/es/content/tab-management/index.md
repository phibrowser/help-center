# Administrar pestañas y marcadores

Phi te permite seleccionar varios elementos y tratarlos como un solo lote. Puedes hacer clic derecho en la selección para acciones en lote, o arrastrarla para reorganizar pestañas normales, Vistas divididas, marcadores y carpetas de marcadores sin mover cada elemento por separado.

## Selecciona varios elementos

Usa cualquiera de estos modificadores para construir una selección:

- Haz **clic con Comando (⌘)** en una pestaña o un marcador para añadir ese elemento a la selección o quitarlo de ella. La pestaña activa se incluye automáticamente, de modo que hacer clic con Comando en otra pestaña selecciona ambas.
- Haz **clic con Mayúsculas** en otro elemento para seleccionar el rango continuo entre ese elemento y tu punto de partida.

En la barra lateral, un rango puede incluir pestañas visibles, marcadores, carpetas de marcadores y el contenido expandido de grupos o carpetas. Los elementos ocultos dentro de un grupo o una carpeta contraídos no se incluyen. Una Vista dividida se trata como un único elemento visible, así sus dos paneles permanecen juntos.

En el diseño Cómodo, los mismos gestos de clic con Comando y clic con Mayúsculas funcionan para las pestañas de la franja horizontal de pestañas. La selección múltiple de marcadores está disponible desde la barra lateral en los diseños Equilibrado y Rendimiento.

## Trabaja con la selección

Haz clic derecho en cualquier elemento resaltado para abrir el menú de lote. Phi adapta las acciones disponibles a lo que hayas seleccionado, así que algunas acciones aparecen solo para pestañas, para marcadores o para una mezcla compatible.

| Acción                                          | Qué hace                                                                                            |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| **Duplicar pestañas**                           | Abre copias de las páginas seleccionadas en el Espacio actual.                                      |
| **Copiar enlaces**                              | Copia las URL de las páginas seleccionadas como una lista.                                          |
| **Abrir como vista dividida**                   | Coloca exactamente dos elementos seleccionados compatibles uno junto al otro.                       |
| **Añadir a marcadores / Añadir a carpeta**      | Guarda las pestañas seleccionadas, u organiza los marcadores seleccionados en la ubicación elegida. |
| **Añadir pestañas a nuevo grupo**               | Crea un Grupo de pestañas a partir de los elementos seleccionados compatibles.                      |
| **Mover pestañas a grupo**                      | Mueve los elementos seleccionados compatibles a un Grupo de pestañas existente.                     |
| **Mover a Espacio**                             | Transfiere la selección a otro Espacio y la quita del Espacio actual.                               |
| **Clonar a Espacio**                            | Crea una copia en otro Espacio y deja la selección original donde está.                             |
| **Cerrar pestañas / Cerrar las demás pestañas** | Cierra las pestañas normales seleccionadas, o todas las pestañas normales fuera de la selección.    |
| **Eliminar marcadores/carpetas/elementos**      | Elimina de forma permanente los elementos guardados seleccionados tras una confirmación.            |

## Arrastra varios elementos para organizarlos

Después de hacer una selección, arrastra cualquier elemento resaltado para mover la selección completa. La previsualización del arrastre muestra cuántos elementos visibles se están moviendo. Si empiezas a arrastrar un elemento que no está seleccionado, Phi descarta el lote y mueve solo ese elemento.

Lo que ocurre depende de dónde sueltes la selección:

- **Dentro de la lista de pestañas:** reordena las pestañas seleccionadas juntas, o suéltalas dentro de un Grupo de pestañas.
- **Dentro del área de marcadores:** reordena los marcadores y las carpetas seleccionados, o suéltalos sobre una carpeta para moverlos dentro de ella.
- **De pestañas a marcadores:** suelta las pestañas seleccionadas en el área de marcadores o sobre una carpeta de marcadores para guardarlas ahí.
- **De marcadores a pestañas:** suelta las páginas de marcadores seleccionadas en la lista de pestañas o en un Grupo de pestañas para abrirlas y organizarlas como pestañas.
- **Con una selección mixta:** las pestañas y los marcadores pueden moverse juntos cuando el destino admite todos los elementos seleccionados.

Las Vistas divididas permanecen juntas durante el arrastre. Una selección que contiene una carpeta de marcadores se queda en el área de marcadores; Phi rechaza los destinos de lista de pestañas y de Grupo de pestañas que no puedan conservar la carpeta, en lugar de dividir la selección.

## Mueve o clona elementos a otro Espacio

Usa **Mover a Espacio** cuando los elementos seleccionados deban salir del Espacio actual. Usa **Clonar a Espacio** cuando quieras las mismas pestañas o marcadores en ambos Espacios.

Ambas acciones pueden manejar una mezcla compatible de pestañas normales, Vistas divididas, marcadores y carpetas de marcadores. Phi mantiene juntos los paneles de una Vista dividida y conserva la organización de los marcadores al transferir la selección. Elige el destino en el submenú de la acción.

El Espacio actual y los Espacios de incógnito no se ofrecen como destino. Las acciones de transferencia entre Espacios tampoco están disponibles mientras navegas en Incógnito.

## Salir de la selección múltiple

Presiona **Esc**, o haz clic normal en un elemento para cambiar a él y salir de la selección múltiple. En la barra lateral, hacer clic en un área vacía también borra la selección. Completar la mayoría de las acciones en lote la borra automáticamente.

Para más información sobre dónde viven los elementos, consulta [Espacios y Perfiles](/es/spaces/). Para saber cómo los marcadores se abren en su sitio y cómo se comportan las pestañas fijadas, consulta [Marcadores y pestañas fijadas](/es/bookmarks/).
