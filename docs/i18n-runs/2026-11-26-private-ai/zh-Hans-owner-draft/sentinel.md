# Phi Sentinel

Phi Sentinel 是 Phi 在你的 Mac 上的后台服务管家。助手的很多工作并不在浏览器窗口里完成：执行定时任务、整理记忆、搜索你连接的数据、调度 AI 请求。这些工作由一组在后台运行的服务完成，Phi Sentinel 负责让它们一直正常运行。

它随 Phi Browser 一起安装，平时你不需要操作它。在 Phi Chat 的设置里，这些服务统称为**后台服务**。

## 它做什么 {#what-it-does}

### 运行后台服务 {#running-background-services}

Phi Sentinel 里有一个叫 **Runner** 的进程，专门管理后台服务。它负责：

- **启动和看护**：按需启动每个服务，定期检查它们是否健康，出问题时自动重启。
- **更新**：在后台下载并安装服务的新版本。更新前会校验签名，新版本运行不正常时会回退到之前的版本。
- **传递配置**：把你在设置里做的选择（比如[私有 AI](/zh-Hans/private-ai/) 的任务来源）交给对应的服务。

Runner 只管服务的运行，不经手你的内容：你的对话、网页和数据由各个服务自己处理，不会经过 Runner。

由 Runner 管理的后台服务包括：

- **助手服务**：保存你的对话和任务，执行定时任务和后台任务。
- **记忆服务**：根据你的浏览整理记忆。
- **数据索引服务**：为你连接的数据建立索引，供数据搜索使用。
- **AI 网关**：把每个 AI 请求发往你为它选的来源，默认是 Phi Cloud，打开私有 AI 后也可能是本地模型或你自己的提供商。
- **AI Guardrail**：在这台 Mac 上检测文本里的敏感信息，见下文。
- **本地模型**：只在你设置私有 AI 后才会安装和运行。

### 拦下不该被记住的机密 {#ai-guardrail}

**AI Guardrail** 是一个在本机运行的检测服务。记忆服务在保存新内容之前，会先交给它检查。如果发现密码、API 密钥、私钥、助记词、恢复码这类机密，整条内容都不会进入你的记忆。

- 检测完全在这台 Mac 上进行，被检查的内容不会发到任何地方。
- 它只负责拦下机密，不会改写内容。姓名、电话这类普通个人信息照常保存，你可以在[记忆](/zh-Hans/memory/)中查看和删除。

### 保存你的数据 {#keeping-your-data}

这些服务的数据保存在你的 Mac 上，存放在本机的数据库里，包括你的对话、任务及其运行记录、记忆，以及已连接数据的索引。

你可以在 Phi Chat 的**设置 → 备份与更新**中：

- **导出数据**：把设置和数据的副本保存下来，方便迁移到另一台 Mac。导出内容不包含 AI 提供商的 API 密钥。
- **创建本地快照**：在这台 Mac 上保存一份可以回退的副本。快照不会离开这台 Mac。

### 让任务在浏览器关闭后继续运行 {#keeping-tasks-running}

[定时任务](/zh-Hans/automation/#scheduled-tasks)要按自己的时间表运行，不管浏览器窗口开着没有。因为 Phi Sentinel 和浏览器是分开运行的，关掉浏览器窗口后，每隔几小时的价格检查、你在关注的页面都会照常进行。

## 查看后台服务的状态 {#checking-status}

在 Phi Chat 中打开设置：

- **通用**：后台服务是否运行正常、当前版本，以及**重启后台服务**。
- **服务**：每个服务的状态。显示"一切正常"时，不需要做任何事。
- **日志**：遇到问题需要反馈时，在**诊断日志**一栏点按**保存**，Phi 会把一个 ZIP 文件保存到你的下载文件夹，把它发给 Phi 支持团队即可。

在浏览器的**设置 → Phi 与 AI → Phi Sentinel** 中，可以设置是否**登录 Mac 时启动 Phi Sentinel**，以及是否**用 Shift Shift Shift 召唤 Phi Chat**（见 [Phi Chat](/zh-Hans/phi-chat/)）。
