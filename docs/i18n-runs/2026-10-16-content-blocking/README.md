# i18n run 2026-10-16-content-blocking

Adds the Content Blocking help page in English and syncs it to all eight
registered locales.

## What changed

- Added the English page and its eight localized versions.
- Added the page to the Privacy & Recovery guide group in every locale.
- Added the page to each locale's status file as translation complete and
  content review todo.
- Quoted translated setting labels from
  phibrowser-mac/Resources/Localizable.xcstrings.

## Accuracy and review notes

- The English page describes the native contract in
  phibrowser-mac/docs/content-blocking.md: categories are separate and
  Profile-scoped, downloads are user initiated, downloaded catalog files can
  be shared, and custom lists and site exceptions are Profile-scoped.
- The Brave engine attribution follows the product context supplied for this
  draft. The native integration document describes the framework boundary but
  does not identify the framework's engine internals.
- All eight translations are drafts. Their content review remains open.
